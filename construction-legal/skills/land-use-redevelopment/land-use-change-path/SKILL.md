# 改变用途与供地方式（land-use-change-path）

> **前置**：
> 1. 读取 `construction-legal/skills/_shared/land-law-citations.md` 第一、二、八节；
> 2. 读取所在城市的 `_shared/local-rules-<city>.md`；没有的，按 `search-playbooks.md` 的土地 playbook 现场检索，并按同一结构记录；
> 3. 每处条文经 `shared/research-gate/SKILL.md` 取官方原文。

---

## 目的

回答「这块地能不能变性、怎么变」。重点不在列举政策，而在三件事：

- 说清国家规则与地方通道之间的张力；
- 把地方通道的前提逐项对到客户的证据；
- 给出客户可以执行的签约前提和备选路径。

---

## 详细步骤

### 步骤 1：拆分「变性」并固定现状

「变性」通常包含两层：一是土地用途变更（如教育、工业改住宅）；二是供应方式变更（划拨改出让，即补办出让并缴纳价款）。先固定以下现状事实，每项注明来源：

| 事实 | 来源 | 用途 |
|---|---|---|
| 证载权利人、权利类型（划拨 / 出让）、用途、面积、取得时间 | 土地证、不动产权证 | 适用规则的起点 |
| 划拨决定书或出让合同有无「政府收回」约定 | 供地文件原件 | 决定地方通道是否可用 |
| 是否停止使用、停用时间与原因 | 客户材料 | 停用收回风险 |
| 地上建筑权属登记在谁名下 | 房屋所有权证 | 房地一致、项目库纳入、拆除新建 |
| 控规是否已调整、规划条件是否已核发 | 批准文件、规划条件 | 规划前提 |

### 步骤 2：规划前提

- 改变用途须经自然资源主管部门同意，报原批准用地的人民政府批准；城市规划区内，报批前先经城市规划主管部门同意（《土地管理法》第 56 条）。住宅不在划拨范围内，变更后须有偿使用（第 54 条）。
- 出让前须有依据控规提出的规划条件，并纳入出让合同，否则出让合同无效（《城乡规划法》第 38、39 条）。控规修改须经法定程序（第 48 条）。
- 用途变更为住宅前，须做土壤污染状况调查并经评审（《土壤污染防治法》第 59 条）。
- 地方规划条件管理：规划条件有效期、已供地项目重新申请规划条件须经属地政府批准等，见地方规则。

客户只说「控规已调整」的，基本事实中写「根据贵司介绍」，并注明尚未提供批准文件和规划条件；建议核对用地性质、容积率、限高等指标与客户测算口径是否一致。

### 步骤 3：供地方式三层判断

| 层 | 内容 | 锚点（见引用库） | 写法 |
|---|---|---|---|
| ① 国家一般规则 | 经营性用地（含商品住宅）公开竞价出让；原划拨土地改为商品住宅等的，纳入统一管理、统一供应；非经营性用地改为经营性用地的，应当约定或明确政府可以收回；规避招拍挂的追责 | 《民法典》第 347 条第 2 款；《土地管理法实施条例》第 18 条；39 号令第 4 条；21 号令第 3、9 条；国土资发〔2002〕265 号、〔2003〕356 号；国发〔2008〕3 号（十三）（十四） | 必写，作为反向依据 |
| ② 国家保留通道 | 原划拨使用权人经批准可以协议补办，但划拨决定书、法律、法规、**行政规定**明确应当收回、公开出让的除外；停用的原划拨土地经批准由原使用者自行开发的，按市场价补缴；存量盘活政策鼓励自主、联营、入股、转让 | 114 号文 4.3(2)、6.1(2)；国发〔2008〕3 号（七）；国发〔2004〕28 号（十七）；147 号（七）；205 号二（二）；171 号第 8 项；2025 年中办国办城市更新意见三（二） | 写明除外条款**可能被第①层文件触发**；鼓励性文件均以政府无须收回为前提，且未就商品住宅专门授权 |
| ③ 地方通道 | 城市更新 / 低效用地再开发：适用范围、项目库纳入与报部备案、供地文件未约定收回、政府审核同意、监管协议；同一文件的反向条款 | `local-rules-<city>.md` | 逐项对照「已具备 / 未提供 / 不具备」 |

### 步骤 4：前提条件对照表

| 前提 | 依据 | 客户材料中的证据 | 状态 | 取得途径 |
|---|---|---|---|---|
| 属于地方通道的适用范围（如开发边界内的老旧厂区、城中村等存量低效土地） | 地方意见适用范围条款 | | 已具备 / 未提供 / 不具备 | |
| 已纳入项目库（及报自然资源部备案） | 同上；城市更新条例 | | | |
| 供地文件未约定由政府收回 | 地方意见；114 号文除外条款 | | | 调取划拨决定书原件 |
| 政府审核同意改造申请、方案或实施方案 | 地方意见；城市更新条例 | | | |
| 控规调整已批准、规划条件已核发 | 《城乡规划法》第 38、39 条 | | | |
| 土壤污染状况调查已安排 | 《土壤污染防治法》第 59 条 | | | |
| 不动产权利归属清晰、主体明确 | 171 号第 13 项；城市更新条例拆除新建条款 | | | |

### 步骤 5：结论写法

| 情形 | 客户成稿中的写法 |
|---|---|
| 前提全部具备 | 「具有相应的政策依据」，同时写明残余风险：在国家层面强调公开出让的背景下，出让合同效力可能被质疑，审计或巡视中可能被认定为规避招拍挂。建议保留集体决策记录 |
| 前提未提供 | 附条件结论：「如本地块已……并取得……，则……」；在基本事实中写「截至本法律备忘录出具之日，贵司尚未向我们提供……」。**把有权机关就「以协议方式补办出让、用于商品住宅」出具的书面依据确认列为签约前提** |
| 前提不具备 | 以协议方式补办出让缺乏充分依据。可能后果：出让合同效力争议、土地被收回、被要求按市场价补差、相关人员被追责。转入步骤 6 |

不要使用无出处的理论论证来消解第①层规则，例如「补办出让不属于设立，因而不适用第 347 条」。LWC-2026-0007 的复核因此删去了一处论证。

### 步骤 6：替代路径

- 政府依法收回后招拍挂，并给予原使用权人合理补偿：147 号（七）「有开发意愿，但没有开发能力」的情形。
- 原使用权人形成「净地」后与土地储备机构协商收储：按地方规定，补偿可按新规划用途市场评估价的一定比例计算。应与客户自己估计的补偿（常常只计账面残值和拆除补偿）对比。
- 原使用权人以竞买人身份参加公开出让：须具备开发资质，资金须为合规自有资金。

### 步骤 7：停用收回风险

因迁移等原因停止使用的原划拨土地，政府可依法收回（《土地管理法》第 58 条第 1 款第（三）项）；按暂行条例第 47 条，应当无偿收回，地上物适当补偿。长期「划拨、闲置」本身就有被收回的风险；在地方政府支持原使用权人改造开发的窗口期内依法完成变性，有利于稳定权益。表述要克制，作为背景风险写，不要写成威胁。

### 步骤 8：政府文件与意向性约定

以下材料只说明政府的意向和工作安排，不构成供地方式或价款的法律确认：

- 前置审查申请表中「非招拍挂」的勾选（申请人自报）；
- 政府工作时间表；
- 窗口指导价；
- 战略合作协议。客户常常不是协议当事人；协议中「在……政策范围内」「依法依规」等措辞属于意向性约定，不能替代法定程序。

## 检查清单

- [ ] 现状事实五项已固定并注明来源
- [ ] 规划前提三项（控规与规划条件、城市规划区内报批程序、土壤调查）已写
- [ ] 第①层反向规定已写，未被省略
- [ ] 第②层除外条款与「可能被触发」的风险已写
- [ ] 第③层每个前提都有对照状态；同一地方文件的反向条款已摘录
- [ ] 地方文件有效期与失效状态已核对；客户援引的文件逐条判定
- [ ] 结论按步骤 5 的三种情形之一写，并列出签约前提
- [ ] 替代路径与停用收回风险已写
- [ ] 申请表、时间表、合作协议的效力已说明

## 边界条件

| 情形 | 处理 |
|---|---|
| 已出让土地改变用途 | 不涉及补办出让：按《城市房地产管理法》第 18 条或地方城市更新条例签订变更协议或重新签订合同，补缴价款 |
| 工业用地改住宅 | 先查地方工业类条款与「工改住」联动要求（171 号第 8 项要求建立竞争性准入机制）；工业类地方计收档位不同 |
| 划拨决定书约定收回 | 地方通道不适用，转步骤 6 |
| 所在城市没有地方通道 | 只能依国家保留通道加个案集体决策，结论更保守，签约前提更多 |
| 集体土地、宅基地 | 不适用本技能 |
| 政府平台或开发企业一方委托 | 立场相反：关注取得土地的合规性与可撤销风险，以及合作对价的公允性 |
