# 引用策略与失败回退链

本文件规定中国法律研究的引用规则和来源不可达时的回退策略。

## 引用标记

所有法律研究输出中的引用必须带来源标记：

| 标记 | 含义 |
|------|------|
| `[L1-法院]` | 最高人民法院官网全文 |
| `[L1-法规]` | 国务院/部门规章全文 |
| `[L2-入库]` | 人民法院案例库入库案例 |
| `[L2-指导]` | 指导性案例/公报案例 |
| `[L3-判决]` | 地方法院公开判决 |
| `[L4-监管]` | 监管机构文件 |
| `[L5-律所]` | 律所文章（仅作线索） |
| `[L5-公众号]` | 法律公众号（仅作线索） |
| `[搜索摘要-未抓全文]` | 仅有搜索引擎摘要，未核验全文 |
| `[待律师复核]` | 无可靠权威来源，需人工补检索 |

## 禁止引用

- ❌ 百度百科、知乎、个人博客作为法律依据
- ❌ 未经过 L1/L2 核验的 L5 文章中的法律结论
- ❌ 模型训练记忆中的法条（除非用工具检索验证）

## 原件、摘要与占位规则

来源：LWC-2026-0004 / 0005（摘要工具与子代理底稿导致的核验缺口）。

1. **摘要只定位，原文才核验**：WebFetch 等内置摘要器、搜索引擎摘要、子代理摘录、OCR 文本只用于定位条文与文件；逐字核验必须取原文页面文本（原始 HTTP 抓取 + 去标签，或 `law-database` 的 `get_law_detail` / `get_article_detail`）。
2. **影响结论的事实回原件**：条号、文号、日期、金额、主体全称凡影响结论，由主笔目视原件（PDF 页面 / 原始表格）核对并留记录；OCR 或子代理底稿的结论不得直接进成果。
3. **文号取不到时用条件性占位表**：官方文书文号、公布日期等无法在线取得时，不留空、不臆造，用「应存在的文书 / 推断内容 / 取得途径」三列表占位，并列入证据清单首位。
4. **版本时效先核对**：2025–2026 年大面积换版的领域（信用修复、劳动争议司法解释、公司法配套、外商投资）引用前先核对现行版本与废止情况，再核对条文。
5. **按通行文本引用须声明**：未能下载官方原文、按通行文本引用的条文，在成果中逐条标 `[待律师复核]`，不混入已核实条文。

## 失败回退链

| 失败信号 | 第一回退 | 第二回退 | 最终处理 |
|----------|----------|----------|----------|
| `flk.npc.gov.cn` 拿不到正文 | court.gov.cn 同条文 | WebSearch `法条名 第N条 site:gov.cn` | 标 `[搜索摘要-未抓全文]` |
| `wenshu.court.gov.cn` 维护 | 各省高院/中院/金融法院 site:gov.cn | 律所文章引述（标 L5） | 标 `[待律师复核]` |
| 公众号链接打不开 | 搜狗微信搜标题 | WebSearch 标题精确匹配 | 标 `公众号原文不可达，仅记录标题` |
| 律所文章 timeout | 换同主题其他律所 | WebSearch 摘要（标 L5） | 标 `[待律师复核]` |
| 任何全文都拿不到 | — | — | 标 `本案该论点缺权威源支持，待律师人工补检索` |
| 省税务局公布栏 / 信用中国脚本门控 | 浏览器扩展查询 | 母公司公告、交易所监管函交叉核对 | 条件性占位表（应存在文书 / 推断内容 / 取得途径） |
| 巨潮 / 深交所公告接口被拦截 | 东方财富公告栏目取原始 PDF | 母公司官网投资者关系栏目 | 标 `公告原文不可达，仅记录标题与日期` |
| 税务总局令 / 公告附件取不到 | `fgk.chinatax.gov.cn` 附件直链 | gov.cn 政策文件库 | 标 `[搜索摘要-未抓全文]` |

## 两段式检索协议

由于 `flk.npc.gov.cn`（国家法律法规数据库）是动态 SPA，headless 环境无法直接抓取，**必须**使用两段式：

### 阶段 1：WebSearch 定位

- 法条/司法解释：`"完整法律名" 第N条 site:court.gov.cn OR site:gov.cn`
- 案例：`"案件关键词" "案由" site:court.gov.cn` 或 `"入库编号"`
- 实务理解：`"争议焦点" 实务`（不限 site，但产出当 L5 看待）

### 阶段 2：WebFetch 全文

- **首选**：`court.gov.cn/zixun/xiangqing/{id}.html`（已实测稳定）
- **备选**：`www.gov.cn/gongbao/...`（行政法规）
- **落败**：WebSearch 摘要（必须标注 `[搜索摘要-未抓全文]`）

### 阶段 3：引用格式

```
《XX法》第X条 全文链接：<court.gov.cn URL>
《最高人民法院关于XX的规定》（法释〔YYYY〕NN号）第X条 全文链接：<court.gov.cn URL>
```

## 环境限制

| 限制 | 影响 | 应对 |
|------|------|------|
| flk.npc.gov.cn 动态 SPA | WebFetch 返回空 | 转 court.gov.cn 或 WebSearch site: |
| 裁判文书网维护中 | 无法获取判决 | 转地方法院网站或案例库 |
| 微信公众号需登录态 | 直链不稳 | 搜狗微信 + WebSearch 限定 site: |
| headless 无 X server | chrome-devtools 不可用 | 仅依赖 WebFetch + WebSearch |
| WebFetch 内置摘要器 | 长条文只返回框架 | 原始 HTTP 抓取 + 去标签取原文 |
| 浏览器扩展未连接 | 脚本门控页面（省税务局公布栏、信用中国）不可查 | 条件性占位表 + 证据清单 |
