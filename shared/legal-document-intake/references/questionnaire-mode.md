# 问卷文档模式（一次性问题清单）

供 `legal-document-intake` 在 `ask_mode: questionnaire` 时读取。场景：操作员代律师在本机执行任务，模型把全部问题一次写成一份文档，操作员发给律师填写，再把答复粘贴回会话。

## 1. 什么时候用

- 操作员说「出问卷」「把问题发给律师」「出一个问题清单」；
- 操作员没有指定方式，多数问题需律师或客户回答，操作员在选择题中选了「生成问卷文档」；
- 直接问时操作员对部分题答「不确定」「问律师」：只把这些题做成问卷。

## 2. 文档结构

```text
《<事项简称>》待确认问题清单（致承办律师）
<日期>｜共 N 题：必须确认 a、建议确认 b、可按默认 c；另需材料 d 项

填写说明
- 可直接在每题「答复：」后填写，选项把 ☐ 改为 ☑ 或写字母，保存后发回；
  也可以在微信按编号回复，例如「1A；2：已付；5 按默认」。
- 「可按默认」的题不回复即按默认处理；「必须确认」的题答复前，相关部分暂不定稿。
- 标「客户」的题可直接转给客户。

一、必须确认
1. 【短标题】问题（一句话，不依赖前文）
   背景：材料中的相关事实，注明出处（如「原合同第 5.2 条」）
   影响：答案不同，成果哪里不同
   ☐ A. ……（推荐）
   ☐ B. ……
   ☐ 其他：
   答复：

二、建议确认（不回复则按推荐处理）
（格式同上）

三、可按默认处理
5. 问题 —— 默认：……
   答复：

四、请提供的材料
7. 文件名称 —— 用途（没有可答「无」）

五、我们对材料的理解（如有误请指出）
- 不超过 5 条，每条一句：我方身份、任务与交付物、关键事实、拟采用的底稿和模板。
```

## 3. 写法

- 编号全卷连续，第四、五部分也编号，便于按号回复。
- 每题只问一件事。能做成选择题的做成选择题，推荐项排第一；没有安全默认值的不标推荐。
- 写给律师看：用律师熟悉的说法（「贵司」「客户」「底稿」「落款」），不写 must / should、intake、deferred 等模型术语。
- 「背景」写到律师不翻材料也能回答的程度；涉及数字的，给出各读法的金额或差额。
- 不问材料里已有答案的事，不问「还有其他要求吗」。
- 题量：必须确认加建议确认通常不超过 10 题，可默认不超过 5 题；超过时合并同类，删去能从材料推出的。
- 客户信息只写到回答问题所需的程度。问卷是给律师的内部文件，不发客户、不进 git 仓库。

## 4. 生成与保存

1. 先按第 2 节写 Markdown，再转 Word：有 pandoc 的用 `pandoc 问卷.md -o 问卷.docx`，有律所参考样式 `reference.docx` 时加 `--reference-doc`；也可以用 python-docx、officecli 或宿主的 Word 能力。没有 Word 能力时交付 `.md`。
   - Markdown 里题干、「背景」「影响」、每个选项、「答复：」各占一段，段与段之间空一行；只换一行，pandoc 会把它们并成一段；
   - 题号写成「1．」（全角点），不要写成「1. 」，否则会被识别为自动列表，缩进和编号都可能变；
   - 短标题用【】标出即可，不必加粗。
2. 文件名：`<事项简称>-待确认问题清单（致承办律师）-YYYYMMDD.docx`，保存在事项资料目录（与律师发来的材料同一目录）。
3. 打开或渲染一次，确认 ☐ 显示正常、编号连续、没有 Markdown 残留符号。

## 5. 回复中给操作员的内容

```text
问卷已生成：<完整路径>
共 N 题（必须确认 a、建议确认 b、可按默认 c），另需材料 d 项。其中第 x 题会影响 <什么>。

可转发律师：
「<称呼>，开始起草前有 N 个问题想请您确认，第 x 题影响 <什么>。可以直接在文档里填，也可以微信按编号回复；可按默认的题不回复就按默认处理。」

等待期间：<先做哪些不依赖答案的工作>；<起草等答复 / 因截止紧迫先按推荐答案起草，答复后修订>。
```

随后贴出内容相同的 `[CLARIFY:]` 文本（`../SKILL.md` 第四步），操作员可以不发文件、直接粘贴到微信。

## 6. 答复粘贴回来以后

1. 识别：操作员粘贴的文字带题号，或给出律师回填后的文件路径。文件用 pandoc 或 python-docx 读出文本，☑ 视为选中，「答复：」后的文字为答案。
2. 合并：按题号对应。只给字母的按选项解释；「同意」「按建议」指推荐项；「按默认」只适用于可默认题和写明推荐的建议确认题，不适用于必须确认题。答复里出现新事实或新文件的，并入事项摘要。
3. 输出合并表：

   ```text
   题号｜答复要点｜处理
   1｜A：按原合同单价｜采纳
   2｜签约后付款，付款为生效条件｜采纳
   3｜未答复｜按推荐处理
   6｜律师说文件在客户处｜仍缺，正文用条件句
   ```

4. 仍缺的必须确认题、与材料矛盾的答复：只就这些追问一次，用直接问或一份只含这些题的短问卷。
5. 从暂停处继续，不重新清点材料。答复改变了底稿或任务的，重新输出 `INTAKE_DECISION`。
6. 答复原文不写入日志、案例库或仓库。案例库只记题量、答复率，以及答复是否改变了成果。

## 7. 示例（脱敏）

变更型租赁补充协议，律师给出五点商务条件，其中减租基数与原合同对不上：

```text
《某写字楼租赁补充协议》待确认问题清单（致承办律师）
2026-10-23｜共 5 题：必须确认 1、建议确认 2、可按默认 2；另需材料 1 项

一、必须确认
1. 【减租基数】「在 10 月份的租金标准基础上每月下调 4 元/㎡」中的「10 月份租金标准」指哪一个？
   背景：原合同自 7 月起单价为 X 元/㎡/月；您给出的首月金额折算为 Y 元/㎡/月。
   影响：两种读法下三年减租总额相差约 10 万元，第一条、第三条和附表的金额都不同。
   ☐ A. 原合同单价；首月金额低出的部分视为另一项减免，违约时一并回吐（推荐）
   ☐ B. 按首月金额折算的单价
   ☐ 其他：
   答复：

二、建议确认（不回复则按推荐处理）
2. 【首笔付款】首月租金的付款期限早于协议签署。按哪种顺序？
   ☐ A. 先签署，付款作为协议生效条件（推荐）
   ☐ B. 先付款，后签署
   答复：
3. 【原合同条款】原合同另有出租方提前通知解除、并向承租方支付补偿的条款。本协议的「违约即解除」是否排除该条？
   ☐ A. 排除，避免承租方主张适用原条款（推荐）
   ☐ B. 保留
   答复：

三、可按默认处理
4. 协议编号与签署日期 —— 默认：留空，由客户填写
   答复：
5. 回吐款的滞纳金 —— 默认：按模板或市场常见费率；原合同费率明显偏高的不沿用，以免拖累回吐条款的可执行性
   答复：

四、请提供的材料
6. 原合同项下 2026 年的租金递增通知（如有）—— 用途：确认递增是否已生效

五、我们对材料的理解（如有误请指出）
- 我方为出租方；以律师提供的扫描件为格式模板，出具可直接给客户的补充协议，另附给您的说明。
```
