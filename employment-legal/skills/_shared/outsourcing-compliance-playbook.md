# 外包用工合规调查（发包方视角）作业手册

> employment-legal 共享参考。供 `workforce-compliance-dd` 在「发包方 / 集团对其外包业务的合规调查」任务中使用；交付物通常为「合规调查报告及操作指引」。
> 来源：案例库 LWC-2026-0010。集团总部委托，覆盖十余家下属单位的保安、保洁、餐饮、工程运维与消防控制室外包，分两批材料（首批约 1,300 份，补充约 120 份，含各单位书面答复与凭证）。律师以模型成稿为底稿定稿：章节结构、全部脚注与约 85% 的段落原样保留，删改集中在第五节所列事项。
> 本手册固化流程、写法与核验过的依据，不是质量结论。条号的核验状态以第六节为准。

## 一、适用与边界

- 适用：集团或发包方对其采购的人力密集型服务（保安、保洁、餐饮、工程运维、消控值守、小时工）开展合规调查，判断「名为外包、实为派遣 / 实为劳动关系」的风险，并给出可执行的操作指引；
- 立场：发包方（委托人）合规视角。服务商、外包人员是调查对象，不是委托人；
- 与用人单位自查（三表比对）的区别：本类任务以外包合同、履行证据、凭证和各单位书面答复为主，花名册与社保表只用于核对服务商的参保覆盖；
- 不适用：单份外包合同审查（用合同审查技能）；发包方已被列为被申请人的仲裁、诉讼应对（用劳动争议技能）。

## 二、报告骨架（律师框架，定稿采用）

标题写全交付物：「××及关联公司之外包用工合规调查报告及操作指引」。封面、致函页、前言开头三处一致。

| 部分 | 内容 | 写法 |
|---|---|---|
| 第一部分 前言 | 敬启者、释义、调查范围、声明与假设、签署栏 | 沿用律所模板；调查方法与局限是否逐项写，按第五节「按配置或给选项」 |
| 第二部分 现状评析 | 八章：一、外包合同审核及风险提示；二、服务商及人员资质；三、服务标准细则；四、业务开展及人员管理方式；五、考核及结算；六、社保公积金；七、外包管理制度；八、突发事件风险评估 | 每节「事实陈述 + 法律评析」；法律评析用圆点列表，加粗 |
| 第三部分 操作指引 | 八章：资质审查、合同文本、管理边界、结算管控、社保公积金与商业保险、用工合规（责任边界、风险点与整改、各单位优先整改事项）、履约监控、突发事件应急处置 | 只写指引、清单、条款示范、话术、流程，不写法律评析 |
| 附件 | 审阅材料清单 | 待补充资料、凭证核对明细、统计表是否作附件，按第五节「按配置或给选项」 |

第二部分各章的固定内容：

1. 合同审核：按业务线分表列合同（发包主体、合同编号、相对方、期限与计价要点），未签署文本、示范文本加※；「假外包、真派遣」对照表（对比维度 / 特征 / 本次发现的条款与证据 / 风险判断）；履约担保、侵权责任、人员退回更换、保险、到期交接、管理边界六项分表审查；
2. 资质：分业务线列服务商资质与人员资质及依据；各单位对服务商的尽调记录；资质到期处理机制；
3. 服务标准：成果导向程度表；保安、保洁、餐饮、消控的细化程度；
4. 管理方式：用工规模（自有 / 外包 / 占比）；招聘培训、考勤排班、工时休息、工作标准、考核奖惩、指令下达、工装工牌、越界行为汇总、事故处置、投诉处理；
5. 考核结算：考核送达、结算发起与审核、发票品名、结算单与付款摘要、预付款与失联风险；
6. 社保公积金：合同约定、实缴核对表（服务商 / 凭证 / 与人员规模比对 / 公积金）、服务费与人力成本、超龄人员；
7. 制度：集团、公司、单位三级制度表与漏洞；
8. 突发事件：服务商失联、履职过错、关键安全岗位配置、工伤、集体维权、治安刑事。

## 三、证据与核对方法

1. **三层证据**：合同条款 → 履行证据（考勤排班表、结算单、付款回单摘要、发票、微信记录、约谈记录、现场照片）→ 各单位对问题清单的书面答复。答复中承认的做法写「书面确认」，不写「自认」；
2. **凭证勾稽**（底稿，不进报告附件）：按月逐项核对发票—付款—结算明细—考勤—社保申报—代发工资流水，计算参保覆盖率、服务费与实发工资之比。报告正文只写结论和必要的汇总表；
3. **问题清单**：首批材料审阅后，把需要各单位说明的事项编成问题清单由委托人下发；收回答复后逐题与合同和履行证据比对。答复与证据不一致、影响认定的，在相应事实段中性写明；答复覆盖率等过程统计写进《成稿说明》，是否进正文按第五节；
4. **影像材料**：照片、截图逐幅查看；带生成式 AI 水印或经 AI 处理的图片不作为现场证据，在《成稿说明》中说明；
5. **个人信息**：花名册含身份证号、住址、宗教信仰等字段的，只在底稿中统计；报告用岗位称谓或统计数字，确需列明的人名限于必要的对照表。

## 四、高信号识别要点

| 信号 | 含义 | 处理 |
|---|---|---|
| 发包方人员编制逐人结算表（薪酬标准、迟到 / 未打卡 / 缺勤扣款、实发服务费） | 发包方核算并决定劳动报酬，是《劳务派遣暂行规定》第二十七条最直接的证据 | 改为服务包月度结算单；整改事项列首 |
| 发包方部门逐日签认外包人员到岗离岗时间、加班小时，并据此按小时结算 | 发包方核定个人工时与报酬 | 改为《临时服务需求单》按服务项目结算 |
| 服务费与服务商实发工资基本相等 | 服务费中没有社保、公积金和利润空间；与「报价可覆盖人力成本」的答复矛盾时，构成发包方「明知」的证据 | 采购评审设成本否决项 |
| 本单位员工离职后由服务商安排回原岗位 | 工作年限可能合并计算（《劳动合同法实施条例》第十条），强化「假外包」认定 | 逐人核对离职原因、补偿与间隔 |
| 物业公司、人力资源公司供应餐饮核心岗、消控员 | 纯人员派驻；无派遣许可时为无证经营派遣 | 终止或改由有资质服务商以成果方式承接 |
| 全日制人员另以「临时小时工」身份计酬；小时工连续数周每日 6 小时以上 | 超出非全日制界限（《劳动合同法》第六十八条），加班报酬不足 | 取消该安排 |
| 付款摘要出现「工资」「外包人员费用」「外派」「临时加班」 | 按人头工时付费的书证 | 统一付款摘要与结算单格式 |
| 消防控制室每班 1 人或单人连续 24 小时 | 违反 GB 25506-2010 第 4.2.1 条 a）项；高层建筑另违反应急管理部令第 5 号第二十六条 | 立即恢复每班 2 名持证人员；各单位全面核查 |
| 外包人员超龄比例高 | 自 2026-07-01 起须书面用工协议、工伤保险（人社部等五部门令第 56 号） | 退休证明、用工协议、工伤参保凭证专项核验 |
| 以本单位人员信息模板登记外包人员的宗教信仰、同住人、住址 | 敏感个人信息无处理必要（《个人信息保护法》第二十八条、第二十九条），且属花名册混同 | 停止收集、删除并留痕，改用服务商盖章备案表 |
| 发包方向服务商发函排查外包人员「上访史」等 | 直接干预服务商人事并处理敏感信息 | 由服务商自行落实 |

**不能作为派遣证据的情形**：安全保护服务发票备注「差额征税」或合同写「含差额 5% 增值税」。依财税〔2016〕68号第四条，安全保护服务比照劳务派遣服务政策执行，可以选择差额征税；计税方式本身不说明业务性质。首稿曾据此推定派遣，已更正。

## 五、客户成稿的取舍（律师定稿反馈）

律师定稿的删改按 `shared/references/document-delivery-qa.md` 5.4 分三类处理。律师稿是一位律师在一个事项中的判断，可能受现实因素影响，不是标准答案。与本类报告直接相关的结论：

- **照做**：标题写「合规调查报告及操作指引」；不用材料批次等内部称谓；裁判预测用概率语气；建议而非指令，不自设整改期限，消控室单人值守等正在发生的违法仍建议立即整改；对委托人制度的评价措辞中性，缺口照列；同一事实只写一处；可疑付款只写事实与核查建议，不推测定性；分析段不写外包人员姓名；操作指引中无依据的数字写成示例；
- **按配置或给选项**：风险等级与整改优先级；待补充资料、凭证核对明细、统计表是否作附件；调查方法与局限是否逐项写；答复覆盖率是否写入前言；法律评析是否点名服务商；「法院 / 仲裁委」等用语。未配置的按本例做法起草，在《成稿说明》第四节写明另一种做法；
- **不学**：各单位答复与凭证、记录不一致而影响认定的，在相应事实段中性写明（律师保留了表格中的核对结论，只删了汇总段）；框架要求的内容照写；高风险结论不弱化。

律师原样保留、继续这样写的部分：章节骨架；全部脚注（法条原文逐字引用）；合同汇总表与「假外包、真派遣」对照表；书面确认与履行证据的对照；服务费与工资比对表；第三部分全部八章（条款示范、禁止条款清单、规范话术、管理边界、核验流程、应急场景）。

## 七、操作指引模块清单

第三部分八章的必备内容（律师定稿保留了全部八章，只删去整改表的优先级列、整改期限和个别数字阈值）：

1. 资质审查：服务商准入尽调清单（营业执照、行业许可、失信与被执行、涉诉、欠薪记录、参保人数、受限供应商、履约能力、关联关系、财务）；人员资质与核验规则（服务商盖章的《服务人员资质备案表》，发包方只核验、不面试、不作录用决定）；资质动态复审与清退标准；
2. 合同文本：必备条款清单；履约保证金、保险、侵权追偿、失联应急接管、人员更换、到期交接六项示范条款；服务成果说明书（保安、保洁、餐饮、关键安全岗位配置）；禁止条款清单；关键管理人员、人员转聘、规章制度、沟通、税务、核验、合规承诺条款；
3. 管理边界：允许与禁止行为清单；规范话术表（禁止的表述 / 规范的表述）；工牌工装与人员信息；培训边界；临时增援服务需求单；
4. 结算管控：后付费；服务包月度结算单格式；验收单与考核表填写；发票品名；只对服务商扣款；归档；
5. 社保、公积金、商业保险：进场、每月、每季度核验；不提交凭证的处置；超龄人员专项核验；雇主责任险、公众责任险最低保额与核验要点；
