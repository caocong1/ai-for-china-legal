# 资料清点与三表交叉比对（headcount-reconciliation）

> **前置**：
> 1. 读取 `shared/references/due-diligence-playbook.md` 第 2、3 节，按其 schema 建资料清单与底稿；
> 2. 读取 `employment-legal/skills/_shared/local-rules-beijing.md`（或工作地点对应文件），取当年度社保基数上下限；
> 3. 本子技能只产出**事实口径**，不下法律结论；定性见 `workforce-classification`。
>
> 可被 `workforce-compliance-dd/SKILL.md` 编排入口调用，也可通过 `/employment-legal:headcount-reconciliation` 单独触发。

---

## 目的

单看任何一张表都发现不了的问题，只有交叉比对才会浮现：LWC-2026-0006 中 54 名「代发薪」人员不在花名册、2 人花名册记劳务而考勤记劳动合同、实习人数两表不一致（1 对 3），都来自三表比对。

---

## 详细步骤

### 步骤 1：资料清点与提取路径

| 文件类型 | 提取方式 | 说明 |
|---|---|---|
| xlsx / csv | 本地脚本直接读取 | 保留原列名，另建标准化列 |
| docx / doc | 文本提取 | doc 先转 docx |
| 有文本层 PDF | pdftotext 直取 | — |
| 扫描 PDF / 图片 | OCR，**后台任务** | 结果只用于定位；金额、日期、人名识别不清 → 【待核实】 |

每份文件登记 `file_id`、`sha256`、`extraction`、`chapter`（按指令文件的资料夹对应），`contains_pii` 为 true 的进内部目录。

### 步骤 2：识别三张基础表并固化口径

| 表 | 常见来源 | 关键字段 | 口径决定 |
|---|---|---|---|
| 花名册 / 劳动合同台账 | 人事系统导出、合同登记表 | 工号、姓名、用工类型、合同主体、合同期限、签订日期、工作地点、岗位 | **人员总数与用工类型的基准** |
| 社保公积金缴费表 | 当月社保 / 公积金明细 | 参保单位（自管户 / 代缴机构）、缴费基数、险种、公积金金额 | **参保主体与基数分布的基准** |
| 考勤表 | 月度考勤导出 | 工号、姓名、用工类型（如有）、出勤天数 | **实际用工在岗的基准** |
| 工资表（如有） | 薪酬导出 | 应发、实发、发放主体 | 代发薪识别、社保基数合理性 |

固化口径：

- 统计日：三表尽量取同一月份；不同月份时写明并解释差异；
- 人员键：优先工号；无工号用姓名 + 入职日期；**不以身份证号为键输出**；
- 用工类型标准化：`直签-固定 / 直签-无固定 / 直签-完成任务 / 派遣 / 外包 / 劳务 / 实习 / 返聘 / 代缴 / 代发薪 / 未知`，原始表述保留在旁列；
- 合同主体标准化：被调查公司 / 关联公司 A、B… / 人力资源机构 X、Y… / 未知。

### 步骤 3：差异矩阵

| 比对 | 发现类型 | 候选定性（交给下一步） | 需补资料 |
|---|---|---|---|
| 在社保表、不在花名册 | 代发薪 / 代缴人员不在用人单位名册 | 劳动合同主体不明 → 派遣或委托代缴 | 劳动合同样本、机构服务协议附件 |
| 在花名册、不在社保表 | 未参保、异地参保、劳务 / 实习 | 未参保风险 / 劳务关系定性 | 异地参保凭证、劳务协议 |
| 在考勤表、不在花名册 | 外包 / 派遣人员受用工方考勤 | 「名为外包实为派遣」线索 | 外包合同及补充协议 |
| 花名册类型 ≠ 考勤类型 | 劳务 vs 劳动合同记载冲突 | 事实劳动关系风险 | 两份原件 |
| 实习人数两表不一致 | 实习生口径不同 | 实习协议与学籍 | 实习协议、在校证明 |
| 合同主体 ≠ 参保主体 | 关联公司交叉用工 / 代缴 | 混同用工、变换主体续签 | 签订日期批次、调动文件 |
| 签订日期成批次 | 关联公司集中转签 | 变换主体连续订立固定期限合同 | 原合同、工龄承继约定 |
| 基数 = 下限 / 上限人数、中位数 | 基数偏低或集中下限 | 社保基数合规 | 工资表 |
| 公积金为零 | 未缴或法定例外 | 公积金合规 | 例外证明（残疾、退休返聘等） |

每条差异记录：人数、人员键清单（内部）、来源 `file_id`、候选定性、需补资料。

### 步骤 4：可复算输出

```markdown
## 用工口径表（统计日：YYYY-MM）
| 口径 | 人数 | 来源 |
|---|---|---|
| 花名册劳动合同记录 | 252（直签 248 / 派遣 4） | F-0012 |
| 劳务 / 实习 | 15 / 1 | F-0012 |
| 社保自管户 / 代缴 / 代发薪 / 派遣 | 175 / 26 / 54 / 3 | F-0031 |
| 考勤记录 | 215 | F-0045 |

## 差异清单
| # | 差异 | 人数 | 候选定性 | 需补资料 | 来源 |
```

数字必须能从脚本重新算出；脚本与中间表留在仓库外工作目录，报告只引用结果。

## 边界条件

| 情形 | 处理 |
|---|---|
| 只有花名册、无社保表 | 口径表注明「参保情况未核验」，列入补充资料首项 |
| 三表月份不同 | 分别标注月份，差异中剔除月份间入离职人员后再比较 |
| 花名册含多家关联公司 | 按合同主体分列，不合并计算派遣比例 |
| 资料超 100 份 | 清点与提取交子代理并行，比对口径由主笔固化 |
