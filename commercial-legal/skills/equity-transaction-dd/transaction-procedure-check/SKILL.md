# 交易程序核查（transaction-procedure-check）

> **前置**：
> 1. 读取 `chapter-fact-memos` 的股权、章程、合资合同、重大合同、融资底稿；
> 2. 读取 `commercial-legal/skills/_shared/transaction-procedure-citations.md`（锚点与验证状态）；
> 3. 读取 `shared/references/subject-qualification-traps.md`（国企 / 上市公司 / 外商投资企业）；
> 4. 每一处条文经 `shared/research-gate/SKILL.md` 取官方原文核对现行版本。
>
> 可被 `equity-transaction-dd/SKILL.md` 编排入口调用，也可通过 `/commercial-legal:transaction-procedure-check` 单独触发。

---

## 目的

交易程序章节是投资方最先翻的章节之一，也是最依赖交易结构的章节。本子技能把「谁转给谁、多少比例、是否取得控制权」拆成可核查的程序路线，并在结构未知时诚实地按一般情形写。

---

## 详细步骤

### 步骤 1：主体属性矩阵

| 维度 | 取值 | 决定 |
|---|---|---|
| 转让方属性 | 国有及国有控股 / 外资 / 民营 / 上市公司 | 国资程序；外资程序；信息披露 |
| 目标公司属性 | 中外合资 / 内资 / 国有控股 | 合资合同与章程关系；国资登记 |
| 受让方属性 | 境内 / 境外；是否已持股 | 负面清单；集中申报；优先购买权 |
| 交易结构 | 受让存量 / 增资 / 混合；比例；是否取得控制权 | 几乎所有程序 |

交易结构未知 → 本章开头写「以下按一般情形分析，待交易结构确认后更新」，并在问题清单「需律师决定」列明。

### 步骤 2：程序路线核查

| 路线 | 核查点 | 锚点（见引用文件） | 常见发现 |
|---|---|---|---|
| 国资交易 | 是否属于国有产权转让 / 增资；评估与核准备案；进场交易或非公开协议转让的条件；国资登记状态 | 《企业国有资产交易监督管理办法》 | 国资登记日期晚于设立；非公开转让条件 |
| 外商投资过渡 | 合资合同是否随《外商投资法》修订；过渡期届满后组织形式与章程调整；原合营合同约定的股权转让办法可否继续适用 | 《外商投资法实施条例》第 44、46 条（已核实） | **未修订的合资合同与新章程并存且冲突** |
| 负面清单与信息报告 | 行业是否在负面清单；变更后信息报告义务 | 现行《外商投资准入特别管理措施（负面清单）》；《外商投资信息报告办法》 | 清单版本按年度核对 |
| 经营者集中 | 营业额是否达申报标准；是否取得控制权 | 《国务院关于经营者集中申报标准的规定》第 3 条 | 门槛数值按现行版本 |
| 优先购买权与章程限制 | 有限公司股东优先购买权；章程另有规定；合资合同一致同意条款 | 《公司法》（2023 修订）股权转让条款；章程；合资合同 | 章程与合资合同口径不一致 |
| 认缴出资 | 认缴期限与过渡期；未届期出资转让的责任 | 《公司法》（2023 修订）及过渡期规定 | 2027-06-30 前调整 |
| 上市公司 | 转让方 / 受让方为上市公司时的决策与信息披露 | 上市公司信息披露规则 `[待验证]` | 股东会权限 |
| 控制权变更触发 | 经营权 / 特许合同、核心资产租赁、委贷与担保中的控制权变更、股权变动通知与解除条款 | 合同原文 | 经营权合同届满未续 + 租赁欠付 + 委贷 12 个月内到期 **同时**来自控股股东体系 |
| 行业许可 | 控制权变更是否触发许可重新审批或备案 | 行业规章 `[待验证]` | 许可到期日 |

### 步骤 3：合资合同 vs 章程

逐条对照股权转让、表决、董事委派、利润分配、终止条款：

| 事项 | 合资合同第 X 条 | 章程第 Y 条 | 冲突 | 现行法处理 |
|---|---|---|---|---|

结论用条件句：「若按合资合同约定……；若按章程……」，并引用实施条例第 46 条口径说明过渡安排 `[待律师复核]`。

### 步骤 4：输出

- 「交易程序路线表」：程序 / 是否适用（是 / 否 / 取决于交易结构）/ 核查结论 / 依据与验证状态 / 待补；
- 「控制权变更触发条款表」：合同 / 条款 / 触发条件 / 后果 / 建议；
- 对经营资源依赖控股股东体系的目标公司，在摘要合并提示。

## 检查清单

- [ ] 主体属性矩阵四个维度已填，未知项标明
- [ ] 每条程序结论有现行版本锚点或 `[待验证]`
- [ ] 合资合同与章程逐条对照，条号来源分开
- [ ] 控制权变更触发条款逐合同列出
- [ ] 交易结构未知的章节已注明「按一般情形」
- [ ] 负面清单、申报标准数值按当年版本核对

## 边界条件

| 情形 | 处理 |
|---|---|
| 目标公司为纯内资民营 | 国资 / 外资路线写「不适用」并说明依据 |
| 受让方为境外主体 | 增加负面清单与信息报告；外汇登记 `[待验证]` 列为律师决定 |
| 转让方为上市公司子公司 | 核查母公司披露义务与关联交易程序 |
