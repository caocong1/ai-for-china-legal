# 分章事实底稿（chapter-fact-memos）

> **前置**：
> 1. 读取 `shared/references/due-diligence-playbook.md` 第 3 节 schema；
> 2. 读取 `data-room-inventory` 的清单与章节映射；
> 3. 子代理参与时，先下发统一规则文件（见步骤 4）。
>
> 可被 `equity-transaction-dd/SKILL.md` 编排入口调用，也可通过 `/commercial-legal:chapter-fact-memos` 单独触发。

---

## 目的

底稿是报告唯一的事实来源。LWC-2026-0005 在撰写与自查阶段共纠正 10 处错误（章程「缺句」误判、同编号决议两个版本、委派函实际日期早一年、文号笔误、释义表主体全称错误、合资合同与章程条号混用、分项加总错误等），全部靠回原件与重算发现，结构指标一个都发现不了。

---

## 详细步骤

### 步骤 1：各章事实清单

| 章节 | 必须提取的事实 | 常见陷阱 |
|---|---|---|
| 主体与沿革 | 设立日期、历次名称 / 住所 / 法定代表人 / 经营范围变更、登记机关 | 批准证书与营业执照日期不一致 |
| 股权与出资 | 各股东持股、出资方式与实缴、出资期限、质押 / 冻结 | 认缴未届期；国资登记日期 |
| 章程与治理 | 现行章程条文（表决、转让、优先购买、委派）、历版差异处数、决议清单与版本 | **两版章程差异数要逐条数**；同编号决议多版本；为备案重新出具的委派函日期 ≠ 实际委派日 |
| 资质与许可 | 许可名称、编号（脱敏）、有效期、延续申请截止日 | 截止日早于报告出具日 |
| 资产与租赁 | 权属、租赁期限、租金标准、**实际支付记录**、欠付与滞纳金计算口径 | 支付凭证只覆盖部分期间；滞纳金为合同约定测算 |
| 重大合同 | 相对方、期限、金额、控制权变更 / 转让限制条款、是否届满未续 | 经营权合同届满未续签 |
| 融资与担保 | 本金、利率、到期日、担保、**12 个月内到期金额** | 合同 / 征信 / 月报三方勾稽 |
| 劳动用工 | 人数口径、外包 / 派遣比例、所属单位 | 用 `dispatch-vs-outsourcing-checklist.md` |
| 税务与财务 | 净资产、营收、处罚、补税 | 当年审计数与下年年初数核对 |
| 诉讼仲裁与处罚 | 案件、金额、状态、原告主体（公司 vs 工会） | 调解结案金额；主体识别 |
| 关联交易 | 关联方、交易类型、金额、定价 | 与控股股东体系的经营依赖 |

### 步骤 2：底稿条目规则

按 playbook schema 逐条记录。强制字段：`sources`（file_id + locator）、`evidence_kind`、`confidence`、`verified_by_author`。

- 条号写明出自哪份文件：「合资合同第 X 条」与「章程第 Y 条」分开；
- 释义表中的主体全称以营业执照 / 批准证书为准，一次定稿全文复用；
- 同一事实多个来源不一致 → `conflicts_with` + 进问题清单「待说明」；
- 日期优先取台账 / 原始凭证，其次决议，最后备案材料。

### 步骤 3：数字勾稽

| 数字 | 来源 A | 来源 B | 来源 C |
|---|---|---|---|
| 借款余额 | 借款合同 | 征信报告 | 财务月报 |
| 应收 / 应付 | 明细表 | 月报 | 审计报告 |
| 年度财务数据 | 当年审计报告 | 下年审计报告年初数 | — |
| 欠付租金 | 合同租金标准 × 期间 | 支付凭证 | 对账 / 访谈口径 |

只有一个来源时在报告中写明「仅据 X」；假设性测算（滞纳金、违约金）列假设、公式与敏感性，并注明「按合同条款与访谈口径测算」。表格分项加总必须重算。

### 步骤 4：子代理分工

- 适合子代理：OCR、分章摘录、清单比对、覆盖审计；
- 统一规则文件：禁止联网；禁止修改原始资料；只补缺口；更正须在原处注明；输出按 schema；
- 并发上限由操作员设定；接口限流中断时按章节重派，不重做已落盘章节；
- **子代理底稿一律 `evidence_kind: summary`**，影响结论的事实由主笔回原件后改 `original_viewed`。

### 步骤 5：落盘

每章一个文件（如 `03-章程与治理.md` / `.yaml`），放仓库外内部目录；报告只引用 `fact_id`。上下文压缩后从底稿续写。

## 检查清单

- [ ] 每条事实有 `file_id` + 定位，`evidence_kind` 与 `confidence` 已填
- [ ] 影响结论的事实 `verified_by_author: true`
- [ ] 两版章程 / 多版决议的差异逐条数清
- [ ] 金额有 ≥2 来源或写明单一来源
- [ ] 条号注明出自合资合同还是章程
- [ ] 释义表主体全称与登记文件一致
- [ ] 底稿已按章落盘

---

## 边界条件

| 情形 | 处理 |
|---|---|
| 关键文件只有扫描件且 OCR 不清 | 主笔目视原件页面；仍不清 → 【待核实】+ 补充资料 |
| 访谈口径与文件不一致 | 以文件为准，访谈口径作「待说明」 |
| 补充资料包到达 | 逐份写「对报告的影响」并更新受影响 `fact_id` |
