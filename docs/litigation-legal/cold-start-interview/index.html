01概要

首次使用诉讼仲裁工具前，通过结构化访谈把律所的执业立场写进实践配置文件 litigation-legal/CLAUDE.md，之后所有诉讼流程都从这份文件读取个性化设置。访谈分四步：身份与团队、风险校准、案件管理、文书风格，完整跑一遍约 10-15 分钟；每一步都可以单独运行，只更新对应章节，不动其他已填内容。访谈依据实践配置契约（practice-profile-schema.md）确定字段，写入前逐项展示待写内容并等律师确认，已填字段显示当前值、不静默覆盖。对律师口述的时效期间、条文号和金额阈值做合理性检查，发现金额倒挂或与《民法典》第188条三年一般时效不符时标记 [前提 flagged — 需验证] 并请律师确认。

02适用与边界

适用场景

  • 首次使用诉讼仲裁工具：运行完整访谈
  • 换了新律所或公司：只运行 /litigation-legal:identity-team 更新身份信息
  • 调整风险阈值：只运行 /litigation-legal:risk-calibration
  • 新增外部律师合作或调整和解策略：只运行 /litigation-legal:case-management
  • 调整代理词风格或引用偏好：只运行 /litigation-legal:document-style
  • 配置文件字段过期（超过 6 个月）：重跑完整访谈全面更新
  • 其他诉讼流程检测到配置缺失或含 [PLACEHOLDER] 并发出提示时

不做什么

  • 不录入具体案件（案件录入走 /litigation-legal:matter-intake）
  • 不创建 litigation-legal/CLAUDE.md 以外的任何配置文件
  • 不填充「事项工作区」和「审查过的种子文档」章节，这两节由律师直接编辑
  • 不提供法律意见；合理性检查只是提示，最终写入哪个值由律师决定

03输入与产出

需要律师提供

  • 律师对访谈问题的回答（四步共 10 + 10 + 11 + 8 个问题，均可跳过）必需
  • 现有 litigation-legal/CLAUDE.md可选
    已填字段会显示当前值并询问是否更新
  • litigation-legal/skills/_shared/practice-profile-schema.md 字段契约必需
    流程自动读取，确认写入字段与契约一致
  • litigation-legal/skills/_shared/civil-procedure-citations.md D 节可选
    风险校准步骤用于时效期间合理性检查

产出

  • 更新后的 litigation-legal/CLAUDE.md给律师内部
    按章节写入：我们是谁 / 谁在使用 / 可用集成 / 风险校准 / 利益冲突清除 / 证据保全 / 外部律师合作 / 和解策略 / 文书风格 / 输出；未回答字段保留 [PLACEHOLDER]，存疑值带 [前提 flagged — 需验证] 或 [阈值逻辑存疑 — 请确认] 标注
  • 每步写入前确认清单给律师内部
    「即将写入以下配置（章节名）：字段：值 …… 确认写入？（确认 / 取消 / 修改）」

04开始前

前置条件

  • 每步开始前读取 practice-profile-schema.md 对应节次，确认写入字段与契约一致
  • 读取当前 litigation-legal/CLAUDE.md，识别已填充字段，已有值显示并询问是否保留或更新
  • 文书风格步骤额外读取「谁在使用 → 角色」字段，用于预填工作产物标题
  • 写入目标固定为 litigation-legal/CLAUDE.md，不反复询问输出格式和保存位置

硬性规则

唯一真相来源
所有配置写入 litigation-legal/CLAUDE.md；不创建额外配置文件。
不静默覆盖
已填充字段显示当前值并询问是否更新；不自动覆盖。
写入前确认
每步写入前展示将写入的内容，律师确认后方执行；写入时仅更新本次访谈对应章节，保留其他未提交的配置改动。
版本控制
litigation-legal/CLAUDE.md 纳入 git 版本控制，可随时回滚。
法律事实合理性检查
对律师口述的时效期间、条文号和金额阈值进行合理性检查，由风险校准步骤执行。
配置写入目标确认
固定写入 litigation-legal/CLAUDE.md；仅当律师要求写入其他配置文件或目标不明时，才按 shared/legal-document-intake/SKILL.md 确认。
先检索、后结论
给出任何法律结论、条款建议或风险判断前，优先用检索工具核对现行有效的法律法规、司法解释及指导性案例；无法核实时在结论处标注「未经检索核实，请以现行有效文本为准」；禁止凭记忆断言法条编号、发文文号或生效日期。
配置缺失提示
其他诉讼流程检测到 litigation-legal/CLAUDE.md 缺失或关键字段含 [PLACEHOLDER] 时，提示两个选择：运行本访谈（约 10-15 分钟），或说「临时模式」——使用通用默认值并在每个输出上标记 [临时模式 — 配置你的档案以获得定制输出]。

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置假设，可逐条复制。页面里的英文标记见首页「标记与术语」。

  1. 身份与团队

    /litigation-legal:identity-team可单独运行

    记录律所或公司身份、团队规模、执业角色和角色倾向，为所有诉讼流程提供工作产物标题、升级路由和立场预填的依据

    请律师核对

    • 核对 1.1执业角色只有三档（律师 / 非律师有律师可咨询 / 非律师无律师可咨询），是否足以覆盖贵所的实习律师、律师助理等情形？
    • 核对 1.2「角色倾向」的默认值会被案件录入直接预填（仍会向律师确认），贵所是否接受这种预填方式？
    • 核对 1.3「每月处理案件数量」「最大痛点」等字段目前没有任何流程读取（配置契约标为参考值），是否仍要求律师回答？

    做法

    1. 先读 practice-profile-schema.md 和当前 litigation-legal/CLAUDE.md，已有值逐项显示并询问是否保留或更新。
    2. 第一组六问：机构名称与类型（律师事务所 / 公司法务部 / 政府法务 / 其他）、诉讼团队规模（不含支持人员）、升级联系人（管理合伙人或法务总监的姓名、职位、联系方式）、每月案件量与主要类型（合同纠纷 / 劳动 / 知识产权 / 侵权 / 公司 / 房地产 / 混合）、主要执业法院或仲裁机构（如北京市朝阳区人民法院、北京三中院、CIETAC）、最大痛点（可选）。
    3. 第二组先问执业角色：律师（持执业证书）/ 非律师但有律师可咨询 / 非律师且无律师可咨询；非律师角色追问可联系的律师及其执业机构。
    4. 再问角色倾向：原告 / 被告 / 两者——大多数是原告或被告 / 因案而异；选「两者」时追问哪方更常见，这个默认值将用于案件录入的立场预填。
    5. 第三组快速确认已连接系统：裁判文书网、企业信用信息公示系统、法规数据库（北大法宝 / 威科先行）、案件管理系统、企业微信 / 钉钉，逐项记为已连接 / 未连接 / 不适用。
    6. 回答出现矛盾（如自称律师又说没有执业证书）时暂停写入，指出具体矛盾并请律师确认哪个准确。
    7. 展示「即将写入 ## 我们是谁 / ## 谁在使用」的全部字段值，等律师回复确认 / 取消 / 修改后再写入。
    8. 写入成功后提示下一步运行 /litigation-legal:risk-calibration，或运行完整访谈。

    内置规则

    • 角色与工作产物标题的对应：律师 → 「律师工作产物 — 受律师-当事人特权保护 / 保密」；非律师（有律师可咨询）→ 「研究笔记 — 非法律建议，供律师审查」并须填写律师联系人；非律师（无律师可咨询）→ 同一标题并附高风险提示。
    • 角色倾向是案件录入与代理词起草的立场预设依据；配置为「因案而异」时每个案件直接询问，绝不默默假设立场。
    • 律师拒绝填写某字段：保留 [PLACEHOLDER] 或写入「[用户选择不填写]」，不强制。
    • 律师说「两者」但不指定偏向：写入「两者——因案而异」，案件录入每次直接询问。
    • 非律师角色且无律师联系人：写入「无律师联系人」，并在该字段旁附加高风险提示标注。
    • 律师跳过整个访谈：保留配置文件的 [PLACEHOLDER]，不写入空值。

    产出

    写入 litigation-legal/CLAUDE.md 的「## 我们是谁」「## 谁在使用」「## 可用集成」三个章节；写入前以字段清单形式展示，等待律师确认

  2. 风险校准

    /litigation-legal:risk-calibration可单独运行

    建立律所自己的风险分级尺度——严重程度金额档、可能性百分比段、重大性阈值——供案件录入的风险分级和时效监控的预警联动读取

    请律师核对

    • 核对 2.1可能性分档默认 >70% / 30%–70% / <30%，与贵所评估胜诉可能性的习惯是否一致？
    • 核对 2.2重大性阈值分为「已计提准备金 / 已披露 / 仅监控」三档，这是公司法务视角的分法，律所代理外部客户时是否需要按客户逐一设定？
    • 核对 2.3「准备金阈值必须高于仅监控阈值」被当作逻辑检查，是否符合贵所或客户的财务口径？

    做法

    1. 读取 practice-profile-schema.md 第 2.3 节字段映射、civil-procedure-citations.md D 节（《民法典》第188条）以及当前「## 风险校准」章节的已有值。
    2. 第一组四问：极高 / 高 / 中 / 低各级风险的含义与金额范围；「极高」可从金额阈值、潜在后果（公司停业、刑事责任）、战略影响（核心知识产权纠纷、关键合作关系破裂）三个维度组合描述。
    3. 收齐金额后做倒挂检查：要求极高 > 高 > 中 > 低；发现「高」的上限低于「极高」的下限等倒挂时，向律师指出具体数值并请确认是否正确。
    4. 第二组三问：高 / 中 / 低可能性各对应的百分比段，示例为 >70%、30%–70%、<30%，允许律师自定义。
    5. 第三组三问重大性阈值：已计提准备金阈值（示例 ¥50万以上）、已披露阈值（示例 ¥200万以上）、仅监控阈值（示例 ¥10万以下）。
    6. 律师在回答中提到时效期间（如「准备金阈值适用 1 年内的案件」）时触发时效合理性核查：说明一般诉讼时效为三年（《民法典》第188条，已核实），要求说明特殊时效的具体法律依据，并标 [前提 flagged — 需验证]。
    7. 检查阈值逻辑：准备金阈值应高于仅监控阈值；仅监控阈值高于准备金阈值时标注「[阈值逻辑存疑 — 请确认]」并说明逻辑关系。
    8. 识别风险文化矛盾：严重程度阈值设得进取（极高阈值很高）而重大性阈值很低时，提示两者可能反映不同风险文化，请律师确认组合。
    9. 展示严重程度 / 可能性 / 重大性三块待写内容，确认后写入「## 风险校准」，并提示下一步运行 /litigation-legal:case-management。

    内置规则

    • 可能性定义默认示例：高 >70%、中 30%–70%、低 <30%，可自定义。
    • 金额阈值不得倒挂：极高 > 高 > 中 > 低；准备金阈值 > 仅监控阈值。
    • 律师只用定性描述、不用金额：接受定性描述，写入对应字段。
    • 律师说「用公司标准」但未提供具体值：写入「按公司标准，具体值待填写」，保留 [PLACEHOLDER] 框架。
    • 律师口述条文号与实际规定不符：标注 [前提 flagged — 需验证]，提供两个选项——按口述写入（保留标注）或按建议值修改。
    • 阈值金额明显超出合理范围（如极高阈值设为 ¥1）：提示异常值并要求确认是否为真实设置。
    • 律师选择跳过重大性阈值：保留 [PLACEHOLDER]，不强制。

    法律依据

    • 《民法典》（2020年）第188条 — 一般诉讼时效三年，用于核查律师口述的特殊时效期间（已核实）

    产出

    写入「## 风险校准」的三张表：严重程度定义（极高 / 高 / 中 / 低各级含义与金额区间）、可能性定义（高 / 中 / 低百分比段）、重大性阈值（已计提准备金 / 已披露 / 仅监控）

  3. 案件管理

    /litigation-legal:case-management可单独运行

    记录利益冲突检查方法、证据保全默认策略、外部律师合作与和解策略，供案件录入的冲突预检、证据保全通知、初始理论和时效预警的行动建议读取

    请律师核对

    • 核对 3.1并行录入默认「否」（冲突未清除不得录入案件）是否过于保守，贵所实践中是否允许先录入后清除？
    • 核对 3.2证据保全刷新周期默认 6 个月，贵所是否使用不同周期？
    • 核对 3.3和解倾向只有三档（早期和解优先 / 坚持到底 / 视情况），是否需要按案件类型分别设定？

    做法

    1. 读取 practice-profile-schema.md 第 2.4–2.7 节字段映射与当前对应四个章节的已有值。
    2. 第一组利益冲突：问检查方法（律所管理系统 / 人工对照客户名单 / 依赖当事人声明 / 其他），追问负责人（合伙人 / 专职人员 / 律师本人），再问冲突「待处理」尚未清除时是否允许并行录入案件。
    3. 第二组证据保全：问默认触发方式（自动——每案都发 / 逐案决定——评估后触发）、默认保全范围（如所有相关邮件、合同文件、内部通信、聊天记录）、刷新周期（默认 6 个月）、保全通知模板存放位置（没有可填「待建立」）。
    4. 第三组外部律师：问固定合作律所（可列 2-3 家，没有填「视案件性质确定」）、选择标准（特定领域资质 / 费率 / 地理位置 / 历史合作记录）、预算审批流程（如 ¥X 以下自行决定，超过需法务总监审批）。
    5. 第四组和解：问和解授权阈值及授权角色（示例 ¥50万以下由主办律师决定，超过需法务总监审批）、超过阈值时的审批步骤、总体和解倾向（早期和解优先 / 坚持到底 / 视情况），并追问是否有特别触发和解的情形。
    6. 比对和解倾向与风险校准：风险偏好进取（极高阈值很高）但和解倾向为早期和解优先时，提示两者可能反映不同情况并请律师确认。
    7. 预算阈值明显偏低或偏高时提示异常值，要求确认。
    8. 展示利益冲突清除 / 证据保全 / 外部律师合作 / 和解策略四个章节的待写内容，确认后写入，并提示下一步运行 /litigation-legal:document-style。

    内置规则

    • 并行录入政策默认为「否」：必须在冲突清除完成后才允许录入；选「是」时须在案件行持续标记直到清除完成。
    • 证据保全触发方式两选一：自动（节省时间，但可能过度）/ 逐案决定（谨慎，但需手动触发）。
    • 证据保全默认刷新周期 6 个月，律师可改。
    • 无固定外部律师合作：写入「目前无固定外部律师合作」，选择标准与预算流程填「视案件性质确定」。
    • 利益冲突检查「靠感觉」或无正式程序：记录「人工检查，无正式系统」，并建议考虑建立正式程序 [非强制]。
    • 和解授权无明确阈值：写入「视案件和负责人判断，无固定阈值」。
    • 证据保全策略「视案件而定」：记录「逐案决定」，默认范围字段写「逐案确定，无固定范围」。
    • 跳过某字段：保留 [PLACEHOLDER]，不强制填写。

    产出

    写入「## 利益冲突清除」（清除方法 / 负责人 / 并行录入政策）、「## 证据保全」（触发方式 / 默认范围 / 刷新周期 / 模板位置）、「## 外部律师合作」（合作律所 / 选择标准 / 预算审批）、「## 和解策略」（授权阈值 / 审批流程 / 和解倾向）

  4. 文书风格

    /litigation-legal:document-style可单独运行

    记录代理词与法律意见书风格、输出格式偏好、法条与案例引用偏好，并按执业角色确认工作产物标题

    请律师核对

    • 核对 4.1「案例引用无论偏好一律保留 [待验证]」是不可关闭的纪律，贵所内部阅读版是否也接受？
    • 核对 4.2默认标题沿用「律师-当事人特权」表述，是否要改为贵所惯用的保密声明措辞？
    • 核对 4.3输出格式选项中的「法院文件草稿」没有要求指定具体法院的格式规范，是否需要补充贵所常用法院的要求？

    做法

    1. 读取 practice-profile-schema.md 第 2.8 节映射、当前「## 文书风格」「## 输出」的已有值，以及「## 谁在使用」的角色字段用于预填工作产物标题。
    2. 问代理词风格（可多选或自定义）：简洁有力（适合法官快速审阅）/ 详细论证（逐一分析要件）/ 引用密度高（每项主张均有法条或案例支持）/ 引用密度适中（核心主张引用）。
    3. 问法律意见书风格：正式（完整法律分析含完整引用）/ 半正式（结论导向含关键引用）/ 简洁（执行摘要形式）。
    4. 问客户报告频率（每两周 / 每月 / 里程碑节点 / 按需）和工作产物存放位置（内部文件夹路径或系统名称）。
    5. 问输出格式偏好（可多选并按场景区分）：完整案件备忘录（背景 / 分析 / 结论 / 风险 / 下一步）/ 案件状态摘要（2-3 段要点）/ 法院文件草稿（可直接提交的格式）/ 结构化清单；追问场景差异，如重大案件用完整备忘录、日常更新用状态摘要。
    6. 问法条引用偏好：每项主张都引用（含条文号和来源标签）/ 只引用关键法条 / 否只需结论（只作「根据民法典」等概括引用）。
    7. 问案例引用偏好：积极引用（需经研究闸门核验）/ 谨慎使用（只在有明确指导性案例时引用，不捏造）/ 否只依赖法条；无论选哪种，所有案例引用都保留 [待验证] 标注，未经核验不移除。
    8. 按角色展示默认工作产物标题请律师确认；机构有自定义标题的接受并写入，同时保留律师 / 非律师默认标题作为兜底。
    9. 展示「## 文书风格」「## 输出」待写内容，确认后写入，并提示冷启动访谈全部完成，可运行任意诉讼流程。

    内置规则

    • 律师角色默认标题「律师工作产物 — 受律师-当事人特权保护 / 保密」；非律师角色默认标题「研究笔记 — 非法律建议，供律师审查」。
    • 律师选「否，只需结论」作为法条引用偏好：照写，但提示「代理词和诉讼文书仍建议引用核心法条，以支持法律论证可信度」[非强制]。
    • 律师要求「零待验证标注」：解释不可——为防止臆造条号，所有不确信的条文号须保留标注，这是内容质量控制措施，不是提交法院的最终版本格式。
    • 引用偏好与引用纪律冲突（如要求捏造案例）：明确拒绝并解释法律与职业风险，提供占位符加待验证标注的替代方案。
    • 工作产物存放位置填入无法访问的路径：记录路径并提示确认是否可访问。

    产出

    写入「## 文书风格」（代理词风格 / 法律意见书风格 / 客户报告频率 / 工作产物存放位置 / 法条引用偏好 / 案例引用偏好）与「## 输出」（律师与非律师角色的工作产物标题、默认输出格式与场景差异化）
