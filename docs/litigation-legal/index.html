02概要

面向处理民事诉讼与仲裁案件的律师团队，覆盖冷启动访谈、案件录入、答辩状起草、证据管理、代理词起草和诉讼时效监控六条流程，每条流程下的步骤都可以单独运行。所有输出都先读取律所自己的实践配置文件（角色倾向、风险校准、和解策略、文书风格），再按统一的法律引用规范标注来源标签与「待验证」标记。适配中国大陆法院基层/中院/高院/最高院四级体系以及 CIETAC、北仲、上国仲、深国仲等仲裁机构。

03实践配置

实践配置文件 <a href="https://github.com/caocong1/ai-for-china-legal/blob/master/litigation-legal/CLAUDE.md">litigation-legal/CLAUDE.md</a> 记录贵所的立场与习惯；所有流程开始前先读它。

配置哪些内容

  • 我们是谁
  • 谁在使用
  • 可用集成
  • 风险校准（严重程度定义 / 可能性定义 / 重大性阈值）
  • 利益冲突清除
  • 外部律师合作
  • 证据保全
  • 和解策略
  • 文书风格
  • 输出（输出格式偏好 / 工作产物标题 / 案件录入模板 / 下一步决策树模板）
  • 共享护栏（管辖识别）
  • 事项工作区
  • 审查过的种子文档

会怎样改变输出

  • 「谁在使用 → 角色」决定每份工作产物的标题：律师用「律师工作产物 — 受律师-当事人特权保护 / 保密」，非律师用「研究笔记 — 非法律建议，供律师审查」。
  • 「谁在使用 → 角色倾向」（原告 / 被告 / 两者—默认X / 因案而异）决定案件录入和代理词起草是否预填我方立场；配置为「因案而异」或仍是占位符时每案直接询问，绝不默默假设。
  • 「风险校准 → 重大性阈值」被时效监控台账读取：请求权金额超过已披露阈值时，在预警等级后加注重大性标记并提示同步通知升级联系人。
  • 「和解策略 → 和解倾向 / 授权阈值」预填初始理论与答辩策略中的和解立场和审批路径，并影响时效预警的行动建议。
  • 「文书风格 → 代理词风格 / 法条引用偏好 / 案例引用偏好」控制代理词和答辩状的引用密度与行文；无论偏好如何，案例引用都保留 [待验证] 标注。
  • 配置缺失或含 [PLACEHOLDER] 时，任何流程都会先提示运行冷启动访谈或进入「临时模式」，临时模式的每个输出都带 [临时模式 — 配置你的档案以获得定制输出] 标记。

04领域引用库

这些文件收录本领域各流程共用的法条、口径和规则；法条有误通常改这里。

  • 诉讼仲裁高频引用库 litigation-legal/skills/_shared/civil-procedure-citations.md
    按「法条 / 案例 / 学说」三类组织的引用库。法条类分四组：A 节《民事诉讼法》（2023修正）——起诉与受理、级别管辖、地域与专属管辖、管辖权异议、答辩期与举证期限与反诉时机、普通与简易程序、证据交换、二审再审；B 节《仲裁法》——仲裁协议有效要件、仲裁协议独立性、或裁或审、仲裁庭组成、撤销与不予执行；C 节最高法《关于民事诉讼证据的若干规定》——举证责任分配、三性审查、举证期限与逾期后果、电子数据、鉴定；D 节《民法典》诉讼时效——一般 3 年、起算点、中止、中断、最长 20 年、特殊时效。另有「2026 年更新」表：法释〔2026〕19 号刑民交叉规定、法发〔2026〕10 号涉人工智能纠纷意见（AI 辅助文书须核实并披露）、法释〔2025〕15 号协议管辖批复、《民事案件案由规定》第三次修正、律师法重新编号、法〔2026〕119 号部分指导性案例不再参照等。已核实锚点：《民法典》第188条 3 年时效与起算点、《民事诉讼法》第一百二十八条答辩期 15 日、民诉法解释第九十九条举证期限不少于 15 日、第二百三十二/二百三十三条反诉时机；其余由模型回忆的条号一律标 [待验证]，级别管辖标的额不硬写数字，案例类与学说类目前只是占位结构。
    用于：cold-start-interview、matter-intake、defense-drafting、evidence-management、representation-drafting、limitation-monitoring
  • 诉讼仲裁法律依据引用规范 litigation-legal/skills/_shared/legal-basis-conventions.md
    规定所有法律依据分为法条、案例、学说三类及各自的最小引用格式（如《法律全名》（版本年份）第X条第X款；最高人民法院指导案例第X号 — 裁判要点 — 法院层级 [待验证]）。五个来源标签——[法宝]、[法规网站]、[网络搜索 — 需验证]、[模型知识 — 需验证]、[用户提供]——每条引用必须且只能附一个，禁止剥离。六种必须追加 [待验证] 的情形：模型知识来源、条文距最后更新超 6 个月、用户口述的条款号或时效期间、所有案例引用、法规版本未确认、仲裁法修订状态。成文法优先：不得以案例替代法条，案例须注明「中国采成文法体系，不具判例法约束力」，仲裁裁决不得用作法律依据。管辖判断链：先看仲裁协议，再定级别管辖、地域管辖、专属管辖、专门法院；法院分最高院/高院/中院/基层四级并标注专门法院。末尾为「先检索、后结论」硬性规则。
    用于：matter-intake、defense-drafting、evidence-management、representation-drafting、limitation-monitoring
  • 诉讼版实践配置文件契约 litigation-legal/skills/_shared/practice-profile-schema.md
    规定 litigation-legal/CLAUDE.md 是实践配置的唯一真相来源（不另建 profile.json），并逐字段给出「访谈问题 → 配置章节 → 读取该字段的流程」映射，例如角色倾向 → 案件录入立场预填、重大性阈值 → 时效预警联动、主要执业法院 → 管辖异议与证据目录格式、和解倾向 → 初始理论与答辩策略。所有流程开工前必须读配置并检查 [PLACEHOLDER]；缺失时不得静默猜测，须给出「运行冷启动访谈 / 说「临时模式」」两个选项，临时模式默认值为：风险偏好平衡型、执业角色律师、管辖法律中国大陆、角色倾向因案而异、重大性阈值不自动触发、和解倾向视情况、文书风格规范正式含法条引用、利益冲突清除方法要求律师录入前确认。角色倾向四种配置（原告 / 被告 / 两者—默认X / 因案而异）各自的预填与确认规则，绝不默默假设立场。重跑访谈、直接编辑、git 回滚三种维护方式。第五节法律事实合理性检查四条规则：条文号核查、时效期间核查（以《民法典》第188条三年为基准）、超 6 个月的时效性标记、矛盾回答澄清；存疑字段写入前须展示问题并二选一（按口述写入保留标注 / 按建议值修改）。
    用于：cold-start-interview、matter-intake

05不做什么

  • 不提供法律意见或法律结论
  • 不替代执业律师的判断
  • 不自动提交法院文件
  • 不保证案件结果的预测
