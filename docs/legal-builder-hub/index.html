法律技能中心

替团队查找、审查、安装和发布社区法律技能，未过安全审查的一律不装

01Skill 一览

5 个流程，共 20 个步骤。点名称看详细说明。

skill做什么步骤
技能发现 流程按领域和能力找技能，标清审查状态、来源与许可证4
安装向导 流程先核安全审查与兼容性再安装，全程留日志、可还原4
安全审查 流程技能安装前查代码、权限和数据隐私，给出能否安装的结论4
技能注册表 流程登记技能、管理版本和依赖、发布上架，有问题的可撤下4
冷启动访谈 配置四步访谈，定下技能中心的角色、安全策略与报告风格4

02概要

面向律所、企业法务和技能开发者，管理法律技能（可装进 AI 使用的法律工作流程，来源分官方、组织内部、社区贡献三类）从查找到卸载的全过程：按法律领域和能力类型搜索、筛选、推荐技能；安装前从代码扫描（有无恶意代码和漏洞）、权限范围（要求的权限是否超出功能所需）、数据隐私（收集哪些数据、是否外传）三方面做安全审查，出具审查报告和认证结论（通过、有条件通过、未通过）；通过兼容性检查后安装、配置、更新或卸载；开发者还可以校验技能的说明文件、管理版本号和依赖关系，发布到技能注册表（收录可安装技能的目录）。共五个流程（冷启动访谈、技能发现、安装向导、安全审查、技能注册表），下设 20 个步骤，每一步都能单独使用。核心规则是「未经安全审查的技能不得安装」，审查发现红级（关键）风险即终止安装。所有流程按本领域的实践配置确定使用者角色、安全偏好、绝不接受的权限、升级时通知谁和报告风格；引用《个人信息保护法》《数据安全法》《网络安全法》《著作权法》等依据的，按本领域引用规范逐条注明出处和核实状态。

03实践配置

实践配置记录贵所在本领域的立场与习惯，由冷启动访谈生成，律师也可以直接修改；每个流程开始前都会先读它。

配置哪些内容

  • 我们是谁
  • 谁在使用
  • 可用集成（已接入的系统）
  • 技能偏好（含 技能发现偏好 / 安全审查偏好 / 安装与部署偏好）
  • 风险校准（红、橙、黄、绿四级）
  • 升级矩阵（含 角色权限表 / 自动升级触发条件）
  • 文书风格
  • 输出（含 工作产物标题 / 审查者注释块）
  • 共享护栏（含 安全优先原则 / 数据合规要求 / 来源标签规范 / 知识产权提示）
  • 技能注册表（技能目录的类型、地址、发布审核方式）
  • 事项工作区（可选：把安装、审查关联到具体项目或案件）
  • 审查过的技能（已审技能的版本、日期、结论登记表）

会怎样改变输出

  • 「我们是谁」里的用户角色决定各流程开放哪些操作；「谁在使用」里的角色决定工作产物标题：技术角色（开发者、管理员）用「技能安全审查报告 — 技术审查文档」，法律角色（律师、法务）用「技能合规评估笔记 — 非技术结论，供技术人员审查」。选非技术人员的，安装和安全审查会给出详细的分步指导，涉及安全审查结论时建议交技术人员或安全专家确认；「技术背景」决定安装指导有多细、审查报告有多深。
  • 「技能偏好」中的整体技能管理偏好分三档，校准所有流程的安全口径：保守型只装经过完整安全审查的技能，找技能时默认只看已审查通过的，推荐时排除未审查的；平衡型兼顾审查与效率；进取型可以快速试用社区技能，默认也显示未审查的，但关键场景仍要求审查。
  • 「安全审查偏好」决定审查做多深、能否放行：审查级别分完整审查（代码扫描、权限审查、隐私评估）、标准审查（权限、隐私）、快速检查（只查权限范围）；「是否允许安装未经安全审查的技能」可选否（强制审查）、是（标注风险后允许）、仅开发环境允许；敏感权限零容忍清单和数据隐私要求，分别作为权限审查和隐私评估的标准。
  • 「技能发现偏好」决定搜索结果是否显示未审查的技能、推荐按哪套权重排序；「安装与部署偏好」决定默认装在哪里、是否自动更新（只自动更新修订号即问题修复、所有版本都自动更新、每次手动确认），以及安装前兼容性检查的强度（强制：任何一项不通过都不能装；推荐：先警告，由使用者确认；关闭：跳过检查，成果标 [风险 — 未进行兼容性检查]）。
  • 「风险校准」的四级表决定每项审查发现怎么标（原文用红、橙、黄、绿色圆点）：红级为关键，存在严重安全隐患或违规风险，禁止安装（如含恶意代码或后门、未经授权收集用户数据、要求读取全部文件等过度权限、违反《个人信息保护法》收集个人信息）；橙级为高，修复后方可安装（如权限超出所声明功能的需要、没有隐私政策或数据处理说明、依赖的组件有已知漏洞）；黄级为中等，风险可控但建议改进（如缺少安全文档）；绿级为低，风险可接受。「升级矩阵」的五项自动升级条件——审查发现红级风险，技能要求访问法律文件、客户信息、案件数据等敏感数据，技能能向外部服务器发送数据，依赖的组件有严重漏洞，违反平台安全策略——不论角色，一律暂停，等人工确认。
  • 「共享护栏」规定：未经安全审查的技能不得安装，开发者声明安全也须独立审查，安全审查报告至少保留 2 年；涉及数据处理的技能须同时符合《个人信息保护法》第13条（合法性基础）和第29条（敏感个人信息单独同意）、《数据安全法》第21条（数据分类分级）、《网络安全法》第21条（等级保护），四条均标「已核实」；社区贡献的技能须声明许可证类型（如 MIT、Apache 2.0、GPL），开发者须保证不侵犯第三方知识产权。「技能注册表」一章的类型、地址和发布审核方式（自动审核：通过安全审查即可发布；人工审核：须审核员批准；社区审核：社区投票）决定技能注册表流程怎么运行。

04领域引用库

本领域各流程共用的法条、口径和规则；法条有误通常改这里。

  • 法律依据引用规范
    本领域引用法律与技术依据的统一写法，按六类来源编排。一、法律：《个人信息保护法》（2021年11月1日施行）、《数据安全法》（2021年9月1日施行）、《网络安全法》（2017年6月1日施行）、《著作权法》（2021年6月1日修正施行）、《民法典》（2021年1月1日施行），至少写成「《法律全名》（年份）第X条第X款」，并注明出处和核实状态。二、行政法规：《关键信息基础设施安全保护条例》（2021年9月1日施行）、《网络数据安全管理条例》（施行状态待核实 [待验证]）、《计算机信息网络国际联网安全保护管理办法》（公安部）。三、部门规章与规范性文件：网信办、工信部、公安部、市场监管总局的相关规定，只描述规则、不写条号，标 [模型知识 — 需验证] [待验证]。四、国家标准：GB/T 35273、GB/T 22239 等，编号、发布年份、推荐性还是强制性一律标 [待验证]。五、平台技术规范：技能说明文件、插件信息、安全审查标准、版本号规则、技能市场清单的格式要求。六、案例与学说：一律标 [待验证]。每条依据注明出处，分五类：[平台规范]、[安全标准]、[网络搜索 — 需验证]、[模型知识 — 需验证]（AI 凭记忆写出，依赖前必须对照原始来源核实）、[用户提供]；核实途径：法律条文查国家法律法规数据库，部门规章查制定机关官网，国家标准查全国标准信息公共服务平台。成文法优先：不得以案例或处罚决定代替法条，没有直接成文法规定的，写明「无直接成文法规定，参照以下标准/规范」；安全审查要同时引用技术依据（国际通行的应用安全十大风险清单、GB/T 信息安全标准）和法律依据（《个人信息保护法》《数据安全法》）；引用许可证须注明完整许可证文本的出处。
    用于：技能发现、安装向导、安全审查、技能注册表
  • 实践配置说明
    本领域实践配置的使用规则：配置只有一份，由冷启动访谈生成和更新，使用者也可以直接修改，改后即时生效；不另设其他格式的配置（理由是便于非技术人员阅读和修改，也避免两份配置互相矛盾）；附对照表，分八组（用户画像、技能偏好、安全审查偏好、安装偏好、风险校准、升级矩阵、文书风格、注册表配置），逐项写明访谈问什么、写进哪一章、哪个流程使用。每个流程开展实质工作前先读配置；配置缺失或有未填写的配置项时，不得悄悄按猜测处理，须提示先做冷启动访谈（约 5-8 分钟）或说「临时模式」，临时模式的成果标 [临时模式 — 配置你的法律技能中心档案以获得定制输出]。临时模式默认值九项：平衡型、技能使用者、有编程经验的法律从业者、标准审查（权限 + 隐私）、不允许安装未审查技能、综合排序、兼容性检查强制、每次更新手动确认、本地注册表。
    用于：冷启动访谈、技能发现
  • 技能中心常用依据库
    按四部分编排的常用依据。一、数据安全法律：《个人信息保护法》第13、14条（七类合法性基础、同意规则）、第28、29条（敏感个人信息的范围与单独同意）、第38、39条（向境外提供个人信息的三条路径、跨境单独同意与告知）、第55、56条（须做个人信息保护影响评估的法定情形；评估报告和处理情况记录至少保存三年），《数据安全法》第21条（数据分类分级，分国家核心数据、重要数据、一般数据三级）、第31条（重要数据出境须安全评估），《网络安全法》第21条（网络安全等级保护制度）；均标 [模型知识 — 需验证]，同时注明「已核实，建议复核」，并各附安全审查中的适用说明，例如技能把用户数据发往境外服务器的，须审查跨境合规路径，发现数据外传行为一律标红级（关键）风险。二、知识产权：《著作权法》关于作品著作权归属与合理使用的规定，条号标 [条号待验证]；技能引用的法律条文属于公共领域，但技能的编排、注释、分析模型可能受著作权保护。三、信息安全标准：GB/T 35273（个人信息安全规范）、GB/T 22239（网络安全等级保护基本要求）等，编号与年份 [待验证]；国际通行的应用安全十大风险清单和第三方组件安全分析方法，为公开标准。四、平台技术规范：技能说明文件须写明名称、简介及目的、工作流程、输出；技能命名、调用方式和插件信息有统一格式，版本号分三段（主版本.次版本.修订号）；安全审查分代码扫描、权限范围、数据隐私三个方面。
    用于：技能发现、安装向导、安全审查、技能注册表

05不做什么

  • 不自动安装任何未经使用者确认的技能
  • 不绕过安全审查流程
  • 不保证第三方技能的质量或安全性
  • 不替代使用者对技能是否适用的独立判断
  • 安全审查只针对提交审查时的技能代码，不替代运行中的安全监控；技能更新后须重新审查（实践配置中审查者注释的声明）
