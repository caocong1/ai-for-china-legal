02概要

本插件面向数据合规律师、企业 DPO 与法务，提供五条完整流程：冷启动访谈、个人信息保护影响评估（PIA）、数据出境评估、数据安全法合规检查、网络安全法合规检查，共 20 个可单独触发的步骤。所有流程在开始实质工作前先读取 data-compliance/CLAUDE.md 实践配置文件（数据处理者画像、合规立场、风险矩阵、升级触发、文书风格），再按统一的法律引用规范与引用库出具带来源标签和待验证标注的分析。法律依据以《个人信息保护法》（2021）、《数据安全法》（2021）、《网络安全法》（2017）及《数据出境安全评估办法》（2022）、《个人信息出境标准合同办法》（2023）等为主，凡网信办办法的具体条号与数量门槛一律标 [待验证]，并提示通过国家法律法规数据库核实现行版本。

03实践配置

实践配置文件 <a href="https://github.com/caocong1/ai-for-china-legal/blob/master/data-compliance/CLAUDE.md">data-compliance/CLAUDE.md</a> 记录贵所的立场与习惯；所有流程开始前先读它。

配置哪些内容

  • 我们是谁
  • 谁在使用
  • 可用集成
  • 合规立场（含 敏感数据政策 / 跨境政策 / 数据安全立场）
  • 风险校准
  • 升级矩阵（含 角色权限表 / 自动升级触发条件 / 监管报告触发）
  • 文书风格
  • 输出（含 工作产物标题 / 审查者注释块 / 下一步决策树模板）
  • 共享护栏（含 无静默补充原则 / 时效性触发 / 验证用户陈述的法律事实 / 来源标签规范 / 目的地与特权检查 / 行业监管识别）
  • 事项工作区
  • 审查过的种子文档

会怎样改变输出

  • 「谁在使用 → 角色」为非律师（DPO/法务）时，所有输出改用标题「研究笔记 — 非法律建议，供律师审查」，并在对处理活动作出合规结论、决定出境路径或建议启动监管申报前暂停、建议升级给律师联系人；律师角色则用「律师工作产物 — 受律师-当事人特权保护 / 保密」。
  • 「我们是谁 → 是否为 CIIO / 处理个人信息规模 / 是否有出境场景 / 数据处理者角色」决定出境路径与义务强度：CIIO 须数据本地化（CSL第37条 [待验证]）且出境须安全评估（DSL第31条，已核实），不可走标准合同；处理规模影响出境门槛判断（门槛标 [时效性 flagged]）；受托处理者按委托方指示处理并须签委托处理协议。
  • 「合规立场 → 整体合规偏好」校准所有流程的风险分级口径与建议语气：保守型遇不确定即标待验证、选最严格路径、建议升级；平衡型兼顾合规与业务成本；进取型在合规边界内寻求灵活方案但不越线。敏感数据政策、跨境政策、数据安全立场分别驱动 PIA、出境评估、数据安全与等保定级流程的审查口径。
  • 「风险校准」四级表（关键 / 高 / 中等 / 低）决定输出中每个发现的风险标注，其中「关键」级附处罚参考：最高可处违法所得一倍以上十倍以下罚款，情节严重的最高可处五千万元或上年度营业额5%罚款（PIPL第66条 [待验证具体条款]）；「升级矩阵」决定升级给哪个角色；自动升级触发条件（重要数据出境、处理超过 [PLACEHOLDER — 如：100 万条] 敏感个人信息、监管问询/检查、数据泄露、上市/融资前审查、关基认定）无论风险等级一律升级。
  • 「所属行业」触发「共享护栏 → 行业监管识别」表（金融、医疗健康、汽车、教育、互联网/平台、电信、能源/交通），输出加 [行业监管 flagged — 需核实主管部门规定]；「时效性触发」规定距最后更新超过 6 个月的规章引用、任何网信办办法具体规则、具体处罚金额或量化门槛、GB/T 编号自动标 [时效性 flagged — 需验证最新法规版本]，涉及网信办规章的配置建议每季度复核。
  • 「文书风格」决定合规报告格式（结构化风险清单 + 整改建议 / 律师审查意见书等）、PIA 与出境评估报告的正式版或简明版、监管沟通语气以及工作产物存放位置；「输出」统一附审查者注释块（材料日期、范围、法规来源、各级标记项数量、时效性日期）和五选项下一步决策树（出具合规报告 / 升级处理 / 补充信息 / 申报监管 / 整改优先）。

05不做什么

  • 不提供法律意见或法律结论
  • 不替代执业律师或 DPO 的判断
  • 不保证审查的完整性
  • 不自动向监管部门提交备案或申报文件

本站把 ai-for-china-legal 仓库里的 skill 文件改写成给律师看的说明。所有 skill 的输出都是供律师审查的草稿，不是法律意见。页面由 scripts/build-docs-site.py 从 docs/data/skills/parts/ 生成；生成日期 2026-11-02。
