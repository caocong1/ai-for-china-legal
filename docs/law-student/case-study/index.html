01概要

把一份案例材料拆成法律案例分析的四步来训练：事实识别与争议焦点归纳、法律关系定性与请求权基础分析、多方观点论证与利益衡量、结论提炼与 IRAC/请求权基础答题结构，最后组装成案例分析训练报告，服务法考主观题备考。开始前读学员档案 law-student/CLAUDE.md（未建档时可选临时模式：法学本科在校生、详细逐步分析、总是引用法条），按学历背景调整案例复杂度与事实干扰度，按分析深度、考试侧重调整讲解与答题要求。法律依据按插件引用规范和法考高频法条引用库处理：成文法优先，指导性案例只作「参考」不作「依据」，条文号先描述规则再标 [待验证]，学说以通说和大纲为准。四步都可单独触发，每步配有检查清单、输出模板，以及纠正学员常见错误（遗漏请求权、有R无A、结论与推理矛盾等）的处理规则。

02适用与边界

适用场景

  • 学员拿到一份法考主观题式的案例材料，需要完整走一遍「事实 → 定性 → 论证 → 结论」的分析训练
  • 只练找争议焦点：/law-student:case-fact-identification [案例材料]
  • 已有事实梳理、只练法律定性：/law-student:legal-issue-analysis [事实摘要]
  • 只练多角度论证：/law-student:multi-perspective-argumentation [法律问题]
  • 已有分析结论、只练答题结构：/law-student:conclusion-structured-output [分析内容]
  • 学员交来自己的事实梳理、请求权分析或答案，需要对照指出遗漏、纠正条文引用、改写为 IRAC 结构

不做什么

  • 不出具针对具体案件的法律意见：所有输出仅供法考学习训练，首部或尾部须带教育声明
  • 不代替裁判：案例中的矛盾事实只列出矛盾点并说明需要证据判断
  • 不以案例替代法条：指导性案例仅作参考，标「参考」而非「依据」
  • 不预测具体裁判结果：不同裁判思路与法院层级分析仅为学习训练目的
  • 不直接给答案：学员要求直接给答案时，先引导其自己梳理事实，再对照分析
  • 不编造条文号：条号不确定时写「《XX法》关于[规则描述]的规定」并标 [待验证]

03输入与产出

需要律师提供

  • 案例材料或事实描述必需
    不足100字时提示信息较少、可能需要补充；超过2000字时分段提取关键事实
  • law-student/CLAUDE.md 学员档案可选
    缺失或仍有 [PLACEHOLDER] 时先提示访谈或临时模式；读取身份、学历背景、分析深度偏好、考试侧重
  • 单独触发某一步时的中间成果可选
    第2步宜输入事实摘要与争议焦点，第3步宜输入事实摘要与法律定性，第4步宜输入前三步的完整分析；没有时由该步自行从案例中提取
  • 学员自己的分析或答题稿可选
    用于指出遗漏、纠正引用、诊断 IRAC 常见问题并给出改进建议

产出

  • 案例分析训练报告给学员（带教老师可用于讲评）
    事实梳理 + 争议焦点 + 法律定性 + 多方论证 + 结构化结论，由结论步骤组装；首部或尾部带教育声明，附工作产物标记「法考学习材料 — 仅供学习参考，不构成法律建议」
  • 答题要点提示（可选）给学员
    对照法考主观题评分要点的自检清单
  • 单步训练成果（单独触发时）给学员
    事实识别与争议焦点归纳 / 法律问题定性与请求权基础分析 / 多方观点论证与利益衡量 / 案例分析结论与答题要点，各有固定的 Markdown 模板

04开始前

前置条件

  • 读取 law-student/CLAUDE.md；缺失或仍有 [PLACEHOLDER] 时显示标准提示，由学员二选一：运行 /law-student:cold-start-interview（约5分钟）配置档案，或说「临时模式」
  • 临时模式默认值：身份法学本科在校生（首次备考）、分析深度详细逐步分析、法条引用总是引用、学科侧重无预设（根据案例内容自动识别），输出标 [临时模式]
  • 进入各步骤前统一读取三份共享资源：引用规范 legal-basis-conventions.md、法考高频法条引用库 law-exam-citations.md、学员配置契约 practice-profile-schema.md
  • 顺序固定：事实识别在前（无事实则无分析）→ 法律定性（确定适用何种法律规则）→ 多方论证（培养辩证思维）→ 结论输出（训练答题格式）

硬性规则

教育声明
所有案例研习输出在首部或尾部标注「[教育声明：本案例分析仅供法考学习训练，不构成针对具体案件的法律意见。]」
事实不足时的处理
材料不足以完成完整分析时：1 列出缺失的关键事实；2 标注 [事实不足 — 需要补充：XXX]；3 基于现有事实分析可能方向，并标注假设前提
成文法优先
先检索现行成文法条文；指导性案例仅作参考，标注「参考」而非「依据」；所有具体条文号先描述规则再标 [待验证]
来源标签
按引用规范，每条引用必须且只能附一个来源标签（[教材] [法规网站] [网络搜索 — 需验证] [模型知识 — 需验证] [用户提供] [真题]），不得剥离；引用案例时附注「中国采成文法体系，本案例为参考，不具判例法约束力」
学说中立
涉及学说争议时客观呈现，标注通说/少数说与作者出处，并说明法考中的考查倾向，法考以通说和大纲为准

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置假设，可逐条复制。页面里的英文标记见首页「标记与术语」。

  1. 案件事实识别与争议焦点归纳

    /law-student:case-fact-identification可单独运行

    从案例材料中区分法律事实与干扰信息，梳理主体关系与时间线，归纳2-4个争议焦点，为后续法律定性打基础。

    请律师核对

    • 核对 1.1「法考主观题通常2-4个争议焦点」的数量口径是否符合近年真题？
    • 核对 1.2争议焦点只从事实、法律、因果关系、责任范围四个维度归纳，是否需要加入程序性争议（如管辖、时效）？
    • 核对 1.3难度适配三档没有覆盖档案中的「在职考生（法学背景）」「其他」等身份；100字、2000字两个长度阈值是否合适？

    做法

    1. 读学员档案的身份与学历背景，按难度适配表确定案例复杂度和事实干扰度；读引用规范。
    2. 两遍通读：第一遍了解整体案情、不做标记；第二遍逐段标记人物/主体（用不同标记区分）、时间/日期（画时间线）、行为/事件（标法律意义）、数字/金额（标可能的计算考点）。
    3. 把事实分为四类：法律事实（能引起法律关系产生、变更、消灭，必须纳入分析）、背景事实（帮助理解背景但不直接影响法律关系，选择性使用）、无关事实（如天气、饮食等干扰信息，排除）、争议事实（如「甲称已交付」「乙称未收到」，需要证据分析）。
    4. 填主体识别表（主体 / 自然人·法人·非法人组织 / 原告·被告·第三人 / 与其他主体的关系），并用文字关系图表示，如「甲 ——[买卖合同]——→ 乙」「甲 ——[保证合同]——→ 丙」「乙 ——[抵押合同]——→ 丙」。
    5. 主体三项检查：是否存在多个法律关系（合同关系+侵权关系等）；是否存在第三人（保证人、连带责任人等）；主体资格是否有问题（未成年人、无民事行为能力等）。
    6. 填时间线表（时间 / 事件 / 法律意义 / 相关法条），重点看时效（诉讼时效或除斥期间）、多个法律行为的先后顺序是否影响效力、同时发生的事件是否存在法律冲突。
    7. 从事实争议、法律争议、因果关系争议、责任范围争议四个维度归纳争议焦点，每个焦点按模板写「甲方主张」「乙方主张」。
    8. 控制焦点数量：法考主观题通常2-4个；每个焦点独立且有实质内容；不把同一问题拆成两个焦点（如「合同是否有效」与「合同效力如何」）。
    9. 对照检查清单后按模板输出：主体关系、关键时间线、事实分类（法律事实/争议事实/排除的无关事实）、争议焦点、事实不足之处。

    内置规则

    • 难度适配：非法学背景 → 法律关系简单（单一合同/侵权）、低干扰；法学本科在校生 → 中等复杂度（2-3个法律关系）、中等干扰；多次备考/研究生 → 高复杂度（多主体/多法律关系交叉）、高干扰
    • 材料不足100字 → 提示「案例信息较少，我将基于现有信息识别事实，但可能需要补充以完成完整分析」；超过2000字 → 分段提取关键事实，建议先关注主体关系和核心争议
    • 涉及多个学科交叉 → 标注涉及的学科，建议分步骤处理（先民法后商法等）
    • 学员要求直接给答案 → 引导「案例研习的关键在于过程训练，建议先尝试自己梳理事实，我再对照分析」
    • 案例中存在矛盾事实 → 列出矛盾点，说明需要证据判断，不代替裁判
    • 法律关系定性困难（如合同与侵权竞合）→ 列出两种可能的法律关系，留到第2步深入分析
    • 学员事实梳理有明显遗漏 → 温和指出遗漏点，解释该事实的法律意义
    • 本步主要训练事实识别方法论，涉及法律依据较少；需要引用法条时按引用规范处理

    产出

    「案件事实识别与争议焦点归纳」Markdown：教育声明 + 主体关系表 + 关键时间线表 + 事实分类 + 争议焦点 + 事实不足之处

  2. 法律问题定性与请求权基础分析

    /law-student:legal-issue-analysis可单独运行

    把事实问题转成法律问题：识别法律关系类型，按固定顺序检索请求权基础并拆解构成要件，再检索抗辩，建立「事实 → 法律关系 → 规范 → 结论」的分析链条。

    请律师核对

    • 核对 2.1检索顺序把无因管理归入「类合同请求权」并排在物权请求权之前——是否与贵机构讲授的检索顺序一致？
    • 核对 2.2竞合与聚合表以「违约损害赔偿+解除合同」作为请求权聚合示例，并规定请求权规范竞合时「选择最有利于权利人的规范」——这两处表述是否需要修正或补充说明？
    • 核对 2.3八类法律关系里有行政、刑事关系，但本步只给出民法请求权基础与抗辩权检索一套方法，刑法、行政法案例的定性路径 SKILL.md 未规定。
    • 核对 2.4抗辩三分类（权利未发生/权利消灭/权利阻止）及其示例是否完整？

    做法

    1. 读学员学历背景（决定分析深度）、引用规范与法考高频法条引用库；理想输入是第1步的事实摘要和争议焦点，单独使用时自行从案例中提取。
    2. 对照八类法律关系表识别类型：合同关系 → 民法典合同编；物权关系 → 物权编；侵权关系 → 侵权责任编；婚姻家庭关系 → 婚姻家庭编；继承关系 → 继承编；劳动关系 → 劳动法、劳动合同法；行政法律关系 → 行政法与行政诉讼法；刑事法律关系 → 刑法。
    3. 用「看主体、看行为、看标的」三法判断性质（如用人单位与劳动者 → 劳动关系；签订合同 → 合同关系；侵害权益 → 侵权关系；不动产 → 物权关系可能性大）。
    4. 判断竞合与聚合：请求权竞合（同一事实、目的相同，择一行使，如违约与侵权竞合）；请求权聚合（目的不同，可同时行使，如违约损害赔偿+解除合同）；请求权规范竞合（同一事实可适用多个规范，选择最有利于权利人的规范）。
    5. 以「谁得向谁，依据何种法律规范，主张何种权利？」为路径，按五级顺序检索请求权基础：合同上请求权 → 类合同请求权（缔约过失、无因管理等）→ 物权上请求权（返还原物、排除妨害、消除危险）→ 不当得利请求权 → 侵权损害赔偿请求权（一般侵权+特殊侵权）。
    6. 填请求权基础检索表：请求权人 / 相对人 / 请求内容 / 请求权基础（《XX法》第X条 [待验证]）/ 逐条拆解的构成要件 / 是否成立（是/否/待定）。
    7. 按「如果 A+B+C → 法律效果 R」结构拆解每个请求权基础，逐要件对应事实后判断 R 是否成立；内置示例为一般侵权的四要件：侵权行为（加害行为）、损害结果、因果关系、过错（故意或过失）。
    8. 检索相对人的抗辩并分三类：权利未发生（合同无效、行为能力欠缺）、权利消灭（清偿、抵销、免除、提存）、权利阻止（同时履行抗辩权、先诉抗辩权、时效抗辩），填抗辩权检索表。
    9. 按模板输出：法律关系识别、请求权基础检索表、核心请求权的要件拆解、抗辩权分析、初步结论。

    内置规则

    • 请求权基础分析法被定位为民法案例分析的核心方法（文件称由王泽鉴教授倡导、在法考中广泛应用）
    • 检索顺序固定为合同 → 类合同 → 物权 → 不当得利 → 侵权，目的是避免遗漏
    • 案例涉及多个法律关系 → 逐一识别，分别分析请求权基础；请求权竞合 → 列出竞合的请求权并说明择一行使的规则
    • 不确定适用哪条 → 用「《XX法》关于[规则描述]的规定」替代具体条号，标 [待验证]
    • 学员不熟悉请求权基础分析法 → 先简要介绍方法论再开始分析
    • 学员遗漏关键请求权 → 温和提示「除了你分析的X请求权外，是否还考虑过Y请求权？」；请求权基础引用错误 → 指出错误并解释正确条文的适用范围；要件拆解不完整 → 补充遗漏的要件并解释其重要性
    • 所有法条引用按引用规范标注来源标签和 [待验证]

    法律依据

    • 《民法典》第1165条 — 一般侵权责任，请求权基础要件拆解的典型示例 [模型知识 — 需验证] [待验证]
    • 《民法典》第577条 — 违约责任，合同上请求权基础 [模型知识 — 需验证] [待验证]
    • 《民法典》第985条 — 不当得利请求权基础 [模型知识 — 需验证] [待验证]
    • 《民法典》第235-238条 — 物权请求权，物权上请求权基础 [模型知识 — 需验证] [待验证]

    产出

    「法律问题定性与请求权基础分析」Markdown：教育声明 + 法律关系识别 + 请求权基础检索表 + 要件拆解 + 抗辩权分析 + 初步结论

  3. 多方观点论证与利益衡量

    /law-student:multi-perspective-argumentation可单独运行

    从原被告双方、通说与少数说、利益衡量、不同裁判思路四个角度论证同一法律问题，训练法考主观题所需的辩证思维。

    请律师核对

    • 核对 3.1刑法犯罪构成体系的口径写成「法考中传统以四要件为主，近年趋势待确认 [待验证]」——请按当年大纲与主流教材给出明确的训练口径。
    • 核对 3.2四级法院裁判倾向的概括没有出处，作为法考训练内容是否保留？
    • 核对 3.3学说表的「代表人物」由模型填写，而引用库的学说条目全部是 [待填入] 占位——是否由老师预先填入经核实的教材出处？
    • 核对 3.4双方论据强度只分强/中/弱，判定标准 SKILL.md 未规定。

    做法

    1. 读学员分析深度偏好、引用规范与引用库；理想输入为前两步的事实摘要和法律定性。
    2. 原告/申请人视角按五要素整理：诉讼请求、事实依据、法律依据、证据支撑、论证逻辑（从事实到结论的推理链条）。
    3. 被告/被申请人视角同样五要素：抗辩主张、事实依据、法律依据、证据支撑、论证逻辑。
    4. 逐争议焦点评定双方论据强度（强/中/弱），标出优势方（原告/被告/均衡）。
    5. 有学术争议的问题填学说争议表：学说 / 核心观点 / 代表人物 / 优势 / 劣势 / 法考倾向（通说：大纲采纳或通常考查；少数说：一般不考查）；引用学说须标通说/少数说、作者/出处和法考考查倾向，以通说和大纲为准。
    6. 按四步做利益衡量：识别涉及的各项利益 → 评估权重 → 衡量冲突程度 → 寻找平衡点，填利益衡量表（利益类型 / 具体内容 / 法律保护程度高中低 / 本案权重高中低）。
    7. 用三种裁判思路推演可能结论：文义解释优先（严格按法条文义）、目的解释优先（探究立法目的）、利益衡量优先（权衡各方利益）。
    8. 列出四级法院的裁判倾向（见规则）对本案的可能影响，并注明「以上分析仅为学习训练目的，不代表对具体裁判结果的预测」。
    9. 按模板输出：原告方立场、被告方立场、学说争议表、利益衡量、不同解释路径下的可能结论。

    内置规则

    • 内置学说争议：民法善意取得的构成要件（三要件 vs 四要件）→ 以通说为准 [待验证]；刑法犯罪构成体系（四要件 vs 三阶层）→ 法考中传统以四要件为主，近年趋势待确认 [待验证]；刑法共犯从属性 vs 共犯独立性 → 以通说为准 [待验证]；法理学法律与道德的关系（自然法学 vs 实证法学）→ 按大纲要求处理
    • 内置利益冲突：交易安全 vs 所有权保护（善意取得）；合同自由 vs 公平原则（格式条款规制）；行为自由 vs 权益保护（侵权责任的过错要件）；效率 vs 公平（除斥期间与撤销权）
    • 法院层级倾向：基层法院注重事实认定和简易程序；中级法院注重法律适用统一；高级法院注重辖区裁判统一；最高院注重规则创设和指导（指导案例的参照价值）
    • 学说处理（引用规范）：通说直接引用、标「通说」；少数说标「少数说」并说明法考中通常不以此为准；大纲明确采纳的标「大纲采纳」；多种学说而法考未明确的，列出主要观点并标「法考中依大纲为准 [待验证]」
    • 法律问题无争议（法条明确规定）→ 说明没有争议空间，直接按法条处理；新兴法律问题（如AI相关）→ 说明现行法律框架可能不完善的领域，列出学术讨论
    • 学员只关注一方 → 引导「法考主观题通常要求多角度分析，建议也思考对方立场」；分析偏颇 → 提示另一方可能的论据；学说引用不准 → 纠正并说明通说与少数说的区别；利益衡量流于表面 → 引导深入分析各项利益

    产出

    「多方观点论证与利益衡量」Markdown：教育声明 + 原告方立场 + 被告方立场 + 学说争议表（通说/少数说/法考倾向）+ 利益衡量 + 不同裁判思路

  4. 结论形成与结构化表达

    /law-student:conclusion-structured-output可单独运行

    把前三步的分析转成明确结论，按 IRAC 或请求权基础结构写成符合法考主观题规范的答案，并附自检与改进建议。

    请律师核对

    • 核对 4.1答题格式规范要求「结论前置」，IRAC 模板和请求权基础模板却都把结论放在最后——以哪种写法训练？
    • 核对 4.2扣分风险表和入口所说的「法考主观题评分要点」都没有注明评分口径来源——是否按当年评分细则替换？
    • 核对 4.3主观题题型表列了案例分析题、法律文书题、论述题、简答题四类，请按当年实际题型确认；除民法可用请求权基础模板外，其他学科一律走 IRAC，是否同意？
    • 核对 4.4入口称由本步组装完整训练报告（事实梳理+争议焦点+法律定性+多方论证+结构化结论），本步的输出模板却没有前三步的章节——报告结构请确认。

    做法

    1. 读学员分析深度偏好与考试侧重、引用规范与引用库；理想输入为前三步的完整分析。
    2. 按明确性（不能模棱两可）、有据性（每个结论有法律依据）、完整性（所有争议焦点都有结论）、层次性（主结论与子结论有逻辑关系）四原则提炼结论，填结论提炼表（争议焦点 / 明确结论 / 法律依据 [待验证] / 推理要点）。
    3. 按结论的不确定程度加标注（见规则）。
    4. 逐争议焦点套 IRAC：I 用一句话概括法律问题；R 引用法律依据并拆解构成要件；A 将事实与要件逐一对应；C 明确回答争议焦点（以「综上所述」收尾）。
    5. 民法题可改用请求权基础答题模板：一、甲对乙是否享有XX请求权 →（一）请求权基础（引条文 [待验证]）→（二）构成要件分析 →（三）抗辩权审查 →（四）结论；再按同一结构写乙对甲。
    6. 对照答题格式规范检查扣分风险（分点作答、法条引用、结论前置、术语规范、字数控制），并按题型选择答题结构（见规则）。
    7. 用六项答题自检逐项核对：结论是否明确、法律依据是否引用、分析是否充分、结构是否清晰、术语是否规范、字数是否适当。
    8. 学员提交了自己的作答时，按 IRAC 常见问题诊断（有R无A、有A无R、无C、I不明确），给出具体改进建议。
    9. 按模板输出：结论总览表、逐焦点 IRAC 答题示范、答题要点自检（通过/未通过）、改进建议；完整流程下由本步组装整份案例分析训练报告。

    内置规则

    • 结论不确定性四级：法条明确规定 → 直接给结论、无需标注；存在学说争议 → 以通说为准并注明「依通说」，标 [依通说]；事实不清 → 分情况讨论，标 [事实不清 — 分情况讨论]；法律空白 → 说明现行法无明确规定，标 [法律空白 — 学理分析]
    • 答题格式扣分风险：不分点扣逻辑分；不引用法条扣法律依据分；结论不明确扣结论分（要求结论前置）；口语化表达扣分；超出字数限制或过少扣分
    • 题型结构：案例分析题 → IRAC（每个争议焦点独立成段）；法律文书题 → 按文书格式（起诉状/答辩状等），格式正确是基本分；论述题 → 总论-分论-结论；简答题 → 要点列举+简要说明，覆盖所有得分点
    • IRAC 常见问题：有R无A → 增加事实与要件的对应分析；有A无R → 补充法律依据；无C → 必须给出明确结论；I不明确 → 用问句形式概括争议焦点
    • 难度适配：非法本/基础薄弱 → 基本 IRAC 结构正确，重点练结论明确+法条引用；法学本科在校 → IRAC 完整+分析深入，重点练要件分析的逻辑性；多次备考 → IRAC 精炼+答题速度快，重点练答题效率和得分率
    • 学员结论错误 → 引导找出哪个环节出了问题；有分析无结构 → 帮助重组为 IRAC；只给结论无分析 → 要求补充，并解释「有结论无分析」的扣分风险
    • 法条引用明显错误 → 纠正条文号并解释正确条文的适用场景；结论与推理矛盾 → 指出逻辑不一致处；字数严重超限 → 指导精简表达、保留得分要点

    产出

    「案例分析结论与答题要点」Markdown：教育声明 + 结论总览表 + 逐焦点 IRAC 答题示范 + 答题要点自检 + 改进建议；完整流程下组装为案例分析训练报告

08交付前检查

  • 事实识别：材料已通读两遍；法律事实与无关事实已区分；主体关系图与时间线已完成，关键时间节点标注了法律意义；争议焦点2-4个、每个有双方立场概述；事实不足处已标 [事实不足 — 需要补充]
  • 法律定性：法律关系类型已识别，竞合/聚合已判断；请求权基础已按合同 → 类合同 → 物权 → 不当得利 → 侵权的顺序检索；每个请求权基础的构成要件已拆解并与事实逐一对应；抗辩权（未发生/消灭/阻止）已检索
  • 多方论证：原被告立场均已完整构建（请求或抗辩+事实+法律+证据），双方力量对比已评估；学说争议已标通说/少数说；利益衡量与不同裁判思路已完成
  • 结论输出：所有争议焦点均有结论且有法律依据支撑；IRAC 四要素齐全；术语规范、分点分层次、字数在要求范围内
  • 所有法条引用已附来源标签与 [待验证]；输出首部或尾部有教育声明，并带工作产物标记

09何时暂停或升级

  • 档案缺失或仍有 [PLACEHOLDER] → 先显示标准提示，由学员选择运行冷启动访谈（约5分钟）或说「临时模式」，后者输出标 [临时模式]
  • 案例材料信息不足 → 列出缺失的关键事实，标 [事实不足 — 需要补充：XXX]，只在标注假设前提后分析可能方向
  • 案例事实相互矛盾 → 列出矛盾点，说明需要证据判断，不代替裁判
  • 法律关系定性困难（如合同与侵权竞合）→ 列出两种可能的法律关系，交第2步深入分析
  • 学员要求直接给答案 → 先引导其自己梳理事实，再对照分析
  • 在非学习场景下误用（引用规范第七章）→ 加注「[教育声明：本内容仅供法考学习参考，不构成法律建议。具体法律问题请咨询执业律师。]」
