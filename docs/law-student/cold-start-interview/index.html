01概要

通过四段访谈收集学员的身份背景、备考目标、薄弱环节和学习偏好，填进学员档案，让案例研习、法条记忆、模拟题生成、错题分析四个训练流程据此调整案例难度、讲解深度、出题侧重和输出格式。访谈分四步——身份与学习画像、学习立场与目标、薄弱环节与升级规则、学习风格与资源（含输出偏好），共26个问题（四步分别为6、5、5、10题），多数给出选项，整体约5-10分钟。不想答的题跳过、留空待填；学员口述的分数线、考试日期、大纲变化一律提示以当年司法部公告或官方发布为准，并标「前提需核实」；同一次访谈里前后矛盾的回答，先澄清再写入。四步都可以单独重做、只更新对应章节，学员也可以直接修改档案，改后即时生效。

02适用与边界

适用场景

  • 学员第一次使用法考培训的各流程，学员档案还是未填写的模板
  • 案例研习、法条记忆等流程发现档案缺失或仍有未填写的项，提示「做冷启动访谈（约5分钟），或说『临时模式』」时
  • 备考阶段变化（如从基础学习进入冲刺）：只重做第 2 步「学习立场与目标访谈」
  • 发现新的薄弱学科：只重做第 3 步「薄弱环节与升级规则访谈」
  • 更换教材或刷题工具：只重做第 4 步「学习风格与资源访谈」

不做什么

  • 不做任何法律分析或训练，只收集信息、填进学员档案
  • 不替学员核实分数线、考试日期和大纲变化：只提示以当年司法部公告或官方发布为准，并标「前提需核实」
  • 不填档案的「学习进度追踪」一章（已完成的学习任务、自测成绩记录两张表），四步都没有对应的问题
  • 小改动不必重做访谈：直接修改学员档案即可，改后即时生效

03输入与产出

需要提供

  • 学员档案的现有内容（空白模板或已部分填写）必需
    每步先看本章是否已填写；已填而想部分更新的，先显示现有内容，问是否覆盖
  • 学员对访谈问题的回答必需
    四步分别6、5、5、10题，第 3 步首题要给十个学科逐一打分；可以跳过不答
  • 只更新某一部分的要求可选
    只做对应的那一步，只改该步对应的章节

产出

  • 更新后的学员档案读者：学员；带教老师也可查看
    按访谈结果填写六章：我是谁、学习目标、薄弱环节、升级规则、学习偏好、输出偏好（每章的项目见各步产出）；不另出文件

04开始前

前置条件

  • 每步开始先看学员档案里本步对应的章节是否已填写，再对照学员档案说明，确认每个答案写进哪一章哪一项
  • 写入前按学员档案说明检查：分数线、考试日期以当年司法部公告为准，学员口述的大纲变化以官方发布为准
  • 建议按第 1 至 4 步的顺序做，整体约5-10分钟（四步分别约1-2、2-3、1-2、1-2分钟）；任何一步都可以单独做

硬性规则

档案只有一份
访谈结果直接填进学员档案对应章节，不另建其他配置；每步只改本步对应的章节（第 1 步明确只改「我是谁」一章）
写入前核实前提
学员口述的分数线、考试日期以当年司法部公告为准，口述的大纲变化以官方发布为准，写入时一律提示并标「前提需核实」
矛盾回答先澄清
同一次访谈中信息前后矛盾的（如先说「非法本零基础」、后说「已通过客观题」），写入前先向学员澄清
不填推测值
不想答的题留空待填；只有三处默认：目标分数不确定写通过线并标「[临时 — 建议确认目标分数]」，学习风格不确定写读写型，备考阶段不明确按已完成内容和距考试时间推断
临时模式
不想做访谈的，在任一训练流程说「临时模式」即按默认画像运行：法学本科在校生首次备考、目标通过线（客观题180分/主观题108分，以当年大纲为准 [待验证]）、薄弱学科与教材逐次确认、读写型、主客观题均衡、每日4小时、基础阶段；成果标「[临时模式 — 配置你的档案以获得定制训练]」
重做与直接修改
可以完整重做访谈，也可以只做某一步、只更新对应章节；学员也可以直接修改档案，不必重做访谈；档案的修改留有记录，可以查看历史、退回旧版本

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置判断，可逐条复制。

  1. 身份与学习画像访谈

    可单独使用

    问清称呼、身份、学历背景、备考次数、目标考试时间和最大学习挑战，填进「我是谁」一章，供各流程调整案例难度和讲解深度

    请律师核对

    • 核对 1.1身份六个选项与学员档案说明里的「在校生 / 在职考生 / 跨专业考生」三分法不一致，案例研习的难度适配又只认三档——在职考生（法学背景）、「其他」各落哪一档？
    • 核对 1.2「身份难以归类」举的例子（在职但有法学学位）其实已被「在职考生（法学背景）」选项覆盖，「由 AI 自动适配」怎么适配也没有写明——是否需要补充？
    • 核对 1.3最大学习挑战是开放题，后续流程怎样使用这一项没有规定——是否需要写明？

    做法

    1. 先看档案「我是谁」一章是否已有内容。
    2. 问学员希望怎么被称呼（各流程用来称呼学员）；问身份，六选一：法学本科在校生、非法学本科在校生、在职考生（法学背景）、在职考生（非法学背景）、研究生、其他（案例研习据此调整案例难度，模拟题据此调整题型）。
    3. 问学历背景（如法学本科、非法学本科××专业、法学硕士），并告诉学员这会影响案例分析的深度和基础概念的讲法；问第几次参加法考：首次、第2次、第3次及以上（错题分析据此参考以往的薄弱点）。
    4. 问计划何时参加考试，同时提示「考试时间以当年司法部公告为准」并标「前提需核实」（各流程据此判断进度紧迫程度）。
    5. 开放式地问最大的学习挑战（如时间不足、记忆力差、逻辑分析弱、某学科基础薄弱）。
    6. 把答案逐项填进「我是谁」一章的对应位置，只改这一章，不另出文件。

    内置规则

    • 不想回答的题 → 跳过，该项留空待填
    • 身份难以归类（如在职但有法学学位）→ 选最接近的选项，由 AI 自动适配
    • 已有内容、想部分更新 → 先显示现有内容，问是否覆盖
    • 各项答案的用处（按学员档案说明）：身份 → 案例研习（案例难度）、模拟题（题型）；学历背景 → 案例研习（分析深度）、法条记忆（基础概念讲解深度）；备考次数 → 错题分析（参考以往薄弱点）；目标考试时间 → 所有流程（进度紧迫程度）

    产出

    「我是谁」一章的六项：称呼、身份、学历背景、备考次数、目标考试时间、最大学习挑战

  2. 学习立场与目标访谈

    可单独使用

    问清目标分数、考试侧重、每日学习时间、备考阶段和已学内容，填进「学习目标」一章，决定训练难度、主客观题分配和每日任务量

    请律师核对

    • 核对 2.1「目标分数与每日学习时间不匹配」没有判断标准（多少分对应多少学习时长），全凭 AI 判断——是否给出参考区间？
    • 核对 2.2备考阶段不明确时由 AI 推断，推断规则没有写明，也不要求向学员确认——是否改为必须确认？
    • 核对 2.3通过线默认值（临时模式：客观题180分/主观题108分，[待验证]）请按当年司法部公告核对。
    • 核对 2.4备考阶段四档（基础学习、系统强化、冲刺刷题、主观题专项）是否与贵机构的班型划分一致？

    做法

    1. 先看档案「学习目标」一章是否已有内容。
    2. 问目标分数（如客观题200+／主观题120+，或只求通过），提示「分数线以当年司法部公告为准」并标「前提需核实」；模拟题据此校准难度。
    3. 问考试侧重，三选一：客观题优先、主观题优先、均衡发展，决定案例分析训练（主观题）与模拟题训练（客观题）怎样分配；问每天能学多久（如工作日2小时、周末6小时），用于安排学习计划和任务量。
    4. 问备考阶段，四选一：基础学习、系统强化、冲刺刷题、主观题专项，影响模拟题难度、法条记忆策略和错题分析的侧重；问已经学完哪些内容（如已听完民法基础课、已刷完刑法真题），避免重复已掌握的内容。
    5. 对学员说的备考计划做合理性检查（见内置规则），必要时请学员确认，再填进「学习目标」一章。

    内置规则

    • 说「我计划×天内从零学完所有学科」→ 提示「时间可能较紧，建议确认备考计划是否现实」
    • 说「我只需要考前一个月复习就够了」→ 提示「法考涉及大量知识点，建议确认备考时间是否充分」
    • 目标分数与每日学习时间不匹配 → 提示「目标分数较高但每日学习时间较少，建议调整预期或增加学习时间」
    • 不确定目标分数 → 默认写通过线，标「[临时 — 建议确认目标分数]」
    • 想同时准备客观题和主观题 → 选「均衡发展」，以后按阶段调整
    • 备考阶段不明确 → 按已完成内容和距考试时间推断

    产出

    「学习目标」一章的五项：目标分数、考试侧重、每日可用学习时间、备考阶段、已完成的学习内容

  3. 薄弱环节与升级规则访谈

    可单独使用

    让学员给十个学科逐一自评并写出具体薄弱点，问清主客观题易错题型和反复出错的知识点，并设定何时建议学员找老师辅导

    请律师核对

    • 核对 3.1三条默认升级阈值（连续3次、正确率低于50%、距考试不足30天）是否符合贵机构的辅导介入标准？
    • 核对 3.2「主观题写作反复不得要领」没有量化标准——是否需要给出？
    • 核对 3.3流程总说明和本步的目的都写要采集「历史成绩」，学员档案说明也把「历史考试分数分布」列为错题分析初步诊断的依据，但本步五个问题都不问历史成绩，档案模板也没有对应的位置——是否补问？
    • 核对 3.4自评全部偏低时默认「优先民法、刑法」，是否同意？
    • 核对 3.5「以后用自测数据校正」怎样校正，规则没有写明。

    做法

    1. 先看档案「薄弱环节」一章是否已有内容。
    2. 请学员给十个学科逐一打1-5分并写出具体薄弱点：民法、刑法、行政法与行政诉讼法、民事诉讼法、刑事诉讼法、商法、经济法、国际法（三国法）、理论法学、法律职业道德（如民法：合同解除、物权变动；刑法：犯罪形态、罪名辨析；商法：公司法、破产法；经济法：劳动法、消法；理论法学：法理学、宪法）。评分标准：1几乎未学，2基础薄弱，3有一定基础但不稳定，4较扎实，5有信心。
    3. 问客观题最容易错的题型：单选题、多选题、不定项选择题、案例型选择题；问主观题最容易失分的题型：案例分析、论述题、法律文书，或暂无主观题经验。
    4. 请学员列举反复出错的知识点。
    5. 问学员希望在什么情况下收到找老师辅导的建议：用三条默认规则（见内置规则），或自定义。
    6. 学科自评和具体薄弱点填进「薄弱环节」的各学科自评表，易错题型和反复出错的知识点填进「已做错题的集中类型」，找老师的规则填进单独的「升级规则」一章。

    内置规则

    • 三条默认升级规则：某学科连续3次自测正确率低于50% → 建议寻求专业教师辅导；距考试不足30天但基础阶段未完成 → 建议调整备考策略（档案模板写作「建议调整备考策略或寻求一对一辅导」）；主观题写作反复不得要领 → 建议找老师批改
    • 从未做过题、无法评估错题类型 → 标「暂无错题数据」，以后通过自测积累
    • 所有学科自评都较低 → 建议从基础学科开始，优先民法、刑法
    • 自评与实际可能不符 → 标「自评结果」，以后用自测数据校正
    • 答案的用处（按学员档案说明）：薄弱学科 → 法条记忆（重点学科）、模拟题（出题侧重）；错题集中类型 → 错题分析（初步判断错误模式）

    产出

    「薄弱环节」一章（十学科自评表、主客观题易错题型、反复出错的知识点）和「升级规则」一章

  4. 学习风格与资源访谈

    可单独使用

    问清学习风格、教材、刷题工具等六项学习偏好，以及分析深度、法条引用、题目难度、解析详细度四项输出偏好

    请律师核对

    • 核对 4.1档案允许选「不需要」法条引用、「先看结论再看解析」和「只给答案」，与案例研习「每个结论须有法律依据」「学员要求直接给答案时先引导自己梳理」的训练立场冲突——冲突时以档案为准还是以流程为准？
    • 核对 4.2学习风格四分法据称影响记忆技巧和案例呈现，但各流程都没有列出每种风格对应什么做法；「听觉型」在文字成果里怎么体现，规则没有写明。
    • 核对 4.3「条文引用尽量与教材版本一致」——学员教材的版本与现行法不一致时以哪个为准，规则没有写明。

    做法

    1. 先看档案「学习偏好」「输出偏好」两章是否已有内容。
    2. 问学习风格，四选一：视觉型（图表、思维导图）、听觉型（听课、讨论）、读写型（笔记、阅读）、实践型（做题、案例），影响法条记忆的技巧选择和案例分析的呈现方式；问所用教材（如××机构讲义、××教材、司法部指定教材、无固定教材），并告诉学员条文引用会尽量与教材版本一致。
    3. 问刷题工具（如××题库 APP、纸质真题集、还没开始刷题），影响模拟题的格式；问笔记方式（手写笔记、电子笔记、思维导图、无固定方式），影响各流程的输出格式；问每日学习节奏（如早上听课、下午做题、晚上复习错题），用于安排学习任务。
    4. 问偏好的案例分析方式，三选一：先看结论再看解析、先独立思考再对答案、跟着老师思路走。
    5. 问四项输出偏好：分析深度（详细逐步分析、重点突出关键步骤、只给思路提示）；是否引用法条（总是引用、只在关键节点引用、不需要）；模拟题难度（从易到难渐进、直接按法考真题难度、略高于法考难度）；解析详细度（完整解析含法律依据、简要解析、只给答案）。
    6. 前六项填进「学习偏好」一章，后四项填进「输出偏好」一章。

    内置规则

    • 不确定学习风格 → 默认读写型，注明以后可以调整
    • 用多种教材 → 记下主要教材，提示不同学科可以用不同教材
    • 没有刷题经验 → 标「未开始刷题」，建议从基础题开始
    • 答案的用处（按学员档案说明）：学习风格 → 法条记忆（记忆技巧选择）、案例研习（案例呈现方式）；教材 → 所有流程（条文引用与教材一致）；刷题工具 → 模拟题（题型格式）；笔记方式 → 所有流程（输出格式）
    • 「输出偏好」一章里的工作产物标记固定为「法考学习材料 — 仅供学习参考，不构成法律建议」，访谈不设题目改它

    产出

    「学习偏好」一章六项与「输出偏好」一章四项

06依据的共用规则

这些法条库、口径和流程由多个 skill 共用；里面的法条或口径有误，通常改那里。

  • 学员档案说明
    每个答案写进哪一章、临时模式默认值、写入前核实与矛盾澄清、重做与直接修改

07交付前检查

  • 学员口述的分数线、考试日期、大纲变化，已提示以当年司法部公告或官方发布为准，并标「前提需核实」
  • 同一次访谈中的矛盾回答（如先说「非法本零基础」、后说「已通过客观题」）已在写入前澄清
  • 跳过的题留空待填；目标分数不确定的写了通过线并标「[临时 — 建议确认目标分数]」；学科自评注明为「自评结果」
  • 每步只改本步对应的章节，没有另出文件
  • 流程总说明设定的完成标准：完整访谈后，档案中所有未填写的项都已填上

08何时暂停或升级

  • 同一次访谈出现矛盾信息 → 暂停写入，先向学员澄清
  • 备考计划明显不现实（×天内从零学完所有学科、只在考前一个月复习、目标分数与每日学习时间不匹配）→ 提示学员确认计划或调整预期
  • 档案已有内容 → 显示现有内容并问是否覆盖，不直接改写
  • 后续训练中触发访谈设定的升级规则（如某学科连续3次自测正确率低于50%）→ 建议学员寻求专业教师辅导、调整备考策略或请老师批改主观题

  5. 流程总说明说结果写进「我是谁」「学习目标」「薄弱环节」「学习偏好」四章，实际第 3 步的升级规则写进单独的「升级规则」一章，第 4 步的四项输出偏好写进「输出偏好」一章；学员档案说明的对照表也只列四组——请统一说明。
  6. 学习风格分视觉型、听觉型、读写型、实践型四种，据称会决定记忆技巧选择和案例呈现方式，不确定时默认读写型——是否同意按学习风格分流训练？后续各流程并没有写出每种风格对应的做法。
  7. 学员自评全部偏低时，访谈直接建议「从基础学科开始，优先民法、刑法」——这一默认备考顺序是否同意，是否应结合考试侧重与各科分值？相关批注：核对 3.4
  8. 写入前检查只针对分数线、考试日期、大纲变化三类口述，一律标「前提需核实」而不判断真伪——是否需要增加检查项？
  9. 备考计划合理性只列三种情形（×天内从零学完所有学科、只在考前一个月复习、目标分数与每日学习时间不匹配），「不匹配」也没有判断标准——是否需要给出参考区间？相关批注：核对 2.1
  10. 档案允许学员选择「不需要」法条引用、「先看结论再看解析」和「只给答案」，而案例研习要求每个结论都有法律依据、学员要直接答案时先引导自己梳理——两者冲突时以哪个为准，规则没有写明。相关批注：核对 4.1
  11. 身份六个选项（法学本科在校生、非法学本科在校生、在职考生（法学背景）、在职考生（非法学背景）、研究生、其他）与学员档案说明的「在校生 / 在职考生 / 跨专业考生」三分法不一致，案例研习的难度适配又只认「非法学背景 / 法学本科在校生 / 多次备考或研究生」三档——请确认各身份落入哪一档。相关批注：核对 1.1
  12. 备考阶段不明确时，访谈「根据已完成内容和距考试时间推断」，没有写推断规则，也不要求向学员确认；这与学员档案说明「不得自行使用猜测值」的原则是否一致？相关批注：核对 2.2
