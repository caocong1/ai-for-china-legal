01概要

通过四段结构化访谈收集学员的身份背景、备考目标、薄弱环节和学习偏好，替换 law-student/CLAUDE.md 模板中的 [PLACEHOLDER]，让案例研习、法条记忆、模拟题、错题分析四条训练流程据此调整案例难度、讲解深度、出题侧重和输出格式。访谈按「身份与学习画像 → 学习目标 → 薄弱环节与升级规则 → 学习风格与输出偏好」的顺序进行，共26个问题（各步6、5、5、10问），多数给出选项，整体约5-10分钟。每步先读现有档案判断本章是否已填写，再按配置契约的字段映射表写入对应章节：跳过的问题保留 [PLACEHOLDER]；学员口述的分数线、考试日期、大纲变化一律提示以当年司法部公告或官方发布为准并标 [前提 flagged — 需验证]；同一会话里的矛盾回答写入前先澄清。四步都可单独重跑、只更新一章，学员也可直接编辑档案，编辑后即时生效。

02适用与边界

适用场景

  • 首次使用法考培训插件，law-student/CLAUDE.md 仍是带 [PLACEHOLDER] 的模板
  • 案例研习、法条记忆等流程检测到档案缺失或含占位符，提示「运行 /law-student:cold-start-interview（约5分钟），或说『临时模式』」时
  • 备考阶段变化（如从基础进入冲刺）：单独重跑 /law-student:study-stance-goals
  • 发现新的薄弱学科：单独重跑 /law-student:weakness-escalation
  • 更换教材或刷题工具：单独重跑 /law-student:style-resources

不做什么

  • 不做任何法律分析或训练内容，只收集信息并写入学员档案
  • 不生成独立 YAML 或 JSON 文件：访谈结果填入 law-student/CLAUDE.md（散文模板，学员可读可编辑），这是唯一真相来源
  • 不替学员核实分数线、考试日期和大纲变化，只提示以当年司法部公告或官方发布为准并加 [前提 flagged — 需验证]
  • 不填写档案的「学习进度追踪」章（已完成的学习任务、自测成绩记录两表），四步都没有对应问题
  • 小改动不需要重跑访谈：直接编辑 law-student/CLAUDE.md 即可，编辑后即时生效

03输入与产出

需要律师提供

  • law-student/CLAUDE.md 现有内容（模板或已部分填写）必需
    每步先检查本步章节是否已有非 [PLACEHOLDER] 内容；已有配置想部分更新时，显示当前值并询问是否覆盖
  • 配置契约 law-student/skills/_shared/practice-profile-schema.md必需
    字段映射表决定每个答案写入哪一章哪一项；第四章规定写入前检查与矛盾澄清；第三章 3.3 是临时模式默认值
  • 学员对访谈问题的回答必需
    第1步6问、第2步5问、第3步5问（第1问含十个学科逐一打分）、第4步10问；不想回答的可以跳过
  • 只更新某一部分的要求可选
    直接调用对应步骤的命令，只改该步章节

产出

  • 更新后的 law-student/CLAUDE.md给学员本人；带教老师可直接查看与编辑
    按访谈结果替换占位符的六个章节：我是谁（姓名/昵称、身份、学历背景、备考次数、目标考试时间、最大学习挑战）/ 学习目标（目标分数、考试侧重、每日可用学习时间、备考阶段、已完成的学习内容）/ 薄弱环节（十个学科 1-5 分自评与具体薄弱点、客观题易错类型、主观题易错类型、反复出错的知识点）/ 升级规则（三条默认或自定义的教师辅导建议）/ 学习偏好（学习风格、使用教材、刷题工具、笔记方式、每日学习节奏、偏好的案例分析方式）/ 输出偏好（分析深度、是否需要法条引用、题目难度偏好、解析详细度）；不生成独立文件

04开始前

前置条件

  • 每步开始先读 law-student/CLAUDE.md 本步对应章节，检查是否已有非 [PLACEHOLDER] 内容，再读配置契约的字段映射表
  • 写入前按配置契约第四章校验：分数线、考试日期以当年司法部公告为准，学员口述的大纲变化以官方发布为准
  • 推荐顺序 1 → 2 → 3 → 4，整体约5-10分钟（各步约1-2、2-3、1-2、1-2分钟）；任一步可单独触发

硬性规则

唯一真相来源
访谈结果填充 law-student/CLAUDE.md 对应章节，不生成独立 YAML 文件；每步只写本步章节（第1步明确「仅覆写『我是谁』章节」）
写入前法律事实合理性检查
学员口述的分数线、考试日期以当年司法部公告为准，口述的大纲变化以官方发布为准，写入时一律附 [前提 flagged — 需验证] 提示
矛盾回答澄清
同一访谈会话中出现矛盾信息（如先说「非法本零基础」后说「已通过客观题」），写入前先向学员澄清
不填推测值
学员不想回答的问题跳过并保留 [PLACEHOLDER]；只有三处内置默认：目标分数不确定时写通过线并标 [临时 — 建议确认目标分数]，学习风格不确定时写「读写型」并注明可调整，备考阶段不明确时按已完成内容和距考试时间推断
临时模式
学员不想做访谈时，可在任一训练流程中说「临时模式」，按配置契约默认值运行：身份法学本科在校生（首次备考）、目标通过线（客观题180分/主观题108分，具体以当年大纲为准 [待验证]）、薄弱学科无预设（逐案询问）、学习风格读写型、考试侧重主客观均衡、每日学习4小时、教材无预设（逐案确认）、备考阶段基础阶段，输出上标 [临时模式 — 配置你的档案以获得定制训练]
重跑、直接编辑与版本控制
可完整重跑 /law-student:cold-start-interview，也可单独触发某一步只更新对应章节；学员可直接编辑 law-student/CLAUDE.md，无需重跑；该文件纳入 git 版本控制，可查看历史和回滚

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置假设，可逐条复制。页面里的英文标记见首页「标记与术语」。

  1. 身份与学习画像访谈

    /law-student:identity-enterprise-profile可单独运行

    收集称呼、身份、学历背景、备考次数、目标考试时间和最大学习挑战六项，写入档案「我是谁」章，供各流程按学员背景调整案例难度、分析深度与基础概念讲解深度。

    请律师核对

    • 核对 1.1身份六选项与配置契约字段表里的「在校生/在职考生/跨专业考生」三分法不一致，案例研习的难度适配又只认三档——在职考生（法学背景）、其他各落哪一档？
    • 核对 1.2「身份选择困难」的举例（在职但有法学学位）其实已被「在职考生（法学背景）」选项覆盖，「系统自动适配」的规则没有写明——是否需要补充？
    • 核对 1.3Q6 最大学习挑战是开放题，后续流程怎样使用这一项，SKILL.md 未规定。

    做法

    1. 读取 law-student/CLAUDE.md，检查「我是谁」是否已有非 [PLACEHOLDER] 内容；读取配置契约的字段映射表。
    2. Q1 问希望系统如何称呼，写入姓名/昵称（所有流程用于个性化称呼）。
    3. Q2 身份六选一：法学本科在校生 / 非法学本科在校生 / 在职考生（法学背景）/ 在职考生（非法学背景）/ 研究生 / 其他（案例研习据此适配案例难度，模拟题据此适配题型）。
    4. Q3 学历背景（如法学本科、非法学本科XX专业、法学硕士），并说明它影响案例分析深度和基础概念讲解方式。
    5. Q4 备考次数三选一：首次 / 第2次 / 第3次及以上（错题分析用作历史薄弱点参考）。
    6. Q5 计划何时参加考试，同时提示「考试时间以当年司法部公告为准 [前提 flagged — 需验证]」（所有流程用作进度紧迫度参考）。
    7. Q6 开放式问最大学习挑战（如时间不足、记忆力差、逻辑分析弱、某学科基础薄弱）。
    8. 按写入映射表逐项替换对应占位符，产出更新后的章节内容，不生成独立文件，仅覆写「我是谁」章。

    内置规则

    • 部分问题不想回答 → 跳过并保留 [PLACEHOLDER]
    • 身份选择困难（如在职但有法学学位）→ 选择最接近的选项，由系统自动适配
    • 已有配置但想部分更新 → 显示当前值并询问是否覆盖
    • 字段读取方（配置契约 2.1）：身份 → 案例研习（案例难度适配）、模拟题（题型适配）；学历背景 → 案例研习（分析深度）、法条记忆（基础概念讲解深度）；备考次数 → 错题分析（历史薄弱点参考）；目标考试时间 → 所有流程（进度紧迫度参考）

    产出

    law-student/CLAUDE.md「我是谁」章的六个字段：姓名/昵称、身份、学历背景、备考次数、目标考试时间、最大学习挑战

  2. 学习立场与目标访谈

    /law-student:study-stance-goals可单独运行

    收集目标分数、考试侧重、每日可用学习时间、备考阶段和已完成的学习内容五项，写入「学习目标」章，决定训练难度、主客观题训练分配与每日任务量。

    请律师核对

    • 核对 2.1「目标分数与每日学习时间不匹配」没有判断标准（多少分对应多少学习时长），完全由模型判断——是否给出参考区间？
    • 核对 2.2备考阶段不明确时由系统推断，推断规则未写明，也不要求向学员确认——是否改为必须确认？
    • 核对 2.3通过线默认值（临时模式表：客观题180分/主观题108分，[待验证]）请按当年司法部公告核对；备考阶段四档是否与贵机构的班型划分一致？

    做法

    1. 读取 law-student/CLAUDE.md，检查「学习目标」是否已有非 [PLACEHOLDER] 内容；读取字段映射表。
    2. Q1 目标分数（如客观题200+/主观题120+，或仅求通过），提示「分数线以当年司法部公告为准 [前提 flagged — 需验证]」；模拟题据此校准难度。
    3. Q2 考试侧重三选一：客观题优先 / 主观题优先 / 均衡发展，决定案例分析训练（主观题侧重）与模拟题训练（客观题侧重）的分配。
    4. Q3 每天可投入的学习时间（如工作日2小时/周末6小时），影响学习计划与任务量控制。
    5. Q4 备考阶段四选一：基础学习 / 系统强化 / 冲刺刷题 / 主观题专项，影响模拟题难度、法条记忆策略和错题分析侧重。
    6. Q5 已完成的学习内容（如已听完民法基础课、已刷完刑法真题），用于避免重复已掌握的内容。
    7. 对口述的备考计划做合理性检查（见规则），必要时提示学员确认，再按映射表写入「学习目标」章。

    内置规则

    • 口述「我计划X天内从零学完所有学科」→ 提示「时间可能较紧，建议确认备考计划是否现实」
    • 口述「我只需要考前一个月复习就够了」→ 提示「法考涉及大量知识点，建议确认备考时间是否充分」
    • 目标分数与每日学习时间不匹配 → 提示「目标分数较高但每日学习时间较少，建议调整预期或增加学习时间」
    • 不确定目标分数 → 默认使用通过线，标注 [临时 — 建议确认目标分数]
    • 想同时准备客观题和主观题 → 选「均衡发展」，后续根据阶段调整
    • 备考阶段不明确 → 根据已完成内容和距考试时间推断

    产出

    「学习目标」章的五个字段：目标分数、考试侧重、每日可用学习时间、备考阶段、已完成的学习内容

  3. 薄弱环节与升级访谈

    /law-student:weakness-escalation可单独运行

    采集十个学科的 1-5 分自评与具体薄弱点、主客观题易错类型和反复出错的知识点，并设定何时建议学员寻求教师辅导的升级规则。

    请律师核对

    • 核对 3.1三条默认升级阈值（连续3次、正确率低于50%、距考试不足30天）是否符合贵机构的辅导介入标准？「主观题写作反复不得要领」没有量化标准。
    • 核对 3.2入口与本步目的都写要采集「历史成绩」，配置契约也把「历史考试分数分布」列为错题分析的初始诊断依据，但本步五个问题都不问历史成绩，档案模板也没有对应字段——是否补问？
    • 核对 3.3自评全部偏低时默认「优先民法刑法」是否同意？「后续用自测数据校正」的校正方法 SKILL.md 未规定。

    做法

    1. 读取 law-student/CLAUDE.md，检查「薄弱环节」是否已有非 [PLACEHOLDER] 内容；读取字段映射表。
    2. Q1 十个学科逐一自评：民法、刑法、行政法与行政诉讼法、民事诉讼法、刑事诉讼法、商法、经济法、国际法（三国法）、理论法学、法律职业道德，每科打分并写具体薄弱点（如民法：合同解除/物权变动；刑法：犯罪形态/罪名辨析；商法：公司法/破产法；经济法：劳动法/消法；理论法学：法理学/宪法）。
    3. 自评标准：1=几乎未学，2=基础薄弱，3=有一定基础但不稳定，4=较扎实，5=有信心。
    4. Q2 客观题最易错题型：单选题 / 多选题 / 不定项选择题 / 案例型选择题。
    5. Q3 主观题最易失分题型：案例分析 / 论述题 / 法律文书 / 暂无主观题经验。
    6. Q4 请学员列举反复出错的知识点。
    7. Q5 询问希望系统在什么情况下建议寻求教师辅导：采用三条默认规则或自定义（见规则）。
    8. 按映射写入：Q1 → 「薄弱环节 / 各学科自评」各学科行；Q2–Q4 → 「已做错题的集中类型」；Q5 → 档案中单独的「升级规则」章。

    内置规则

    • 默认升级规则一：某学科连续3次自测正确率低于50% → 建议寻求专业教师辅导
    • 默认升级规则二：距考试不足30天但基础阶段未完成 → 建议调整备考策略（档案模板写作「建议调整备考策略或寻求一对一辅导」）
    • 默认升级规则三：主观题写作反复不得要领 → 建议找老师批改
    • 从未做过题、无法评估错题类型 → 标记「暂无错题数据」，后续通过自测积累
    • 所有学科自评都较低 → 建议从基础学科开始，优先民法刑法
    • 自评与实际可能不符 → 标注「自评结果」，后续用自测数据校正
    • 字段读取方（配置契约 2.3）：薄弱学科 → 法条记忆（重点学科）、模拟题（出题侧重）；错题集中类型 → 错题分析（初始模式识别）

    产出

    「薄弱环节」章（十学科自评表、客观题与主观题易错类型、反复出错的知识点）与「升级规则」章

  4. 学习风格与资源访谈

    /law-student:style-resources可单独运行

    收集学习风格、教材、刷题工具、笔记方式、每日学习节奏、偏好的案例分析方式六项学习偏好，以及分析深度、法条引用、题目难度、解析详细度四项输出偏好。

    请律师核对

08何时暂停或升级
