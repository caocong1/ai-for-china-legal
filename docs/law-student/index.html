法考培训

为法考学员建学习档案，训练案例分析、法条记忆、模拟题与错题复盘

02概要

辅助法律职业资格考试备考，共五个流程、二十个步骤，每一步都能单独使用：冷启动访谈为学员建立学习档案（即本领域的实践配置），案例研习、法条记忆、模拟题生成（题型设计、情景构建、答案解析、难度校准）、错题分析（错误模式、薄弱诊断、补强方案、进步追踪）四个训练流程再按档案调整案例难度、讲解深度、出题侧重和输出格式。还没建档的，先提示做访谈，或按「临时模式」的通用默认值运行，并在成果上注明。引用依据按本领域统一的引用规范分法条、案例、学说三类：成文法优先，指导性案例只作参考，条文号先写规则内容再标 [待验证]，学说以通说和当年大纲为准。所有成果都标「法考学习材料 — 仅供学习参考，不构成法律建议」，定位为学习辅助，答案以当年考试大纲和指定教材为准。

03学员档案

学员档案（即本领域的实践配置）记录学员的背景、考试目标、薄弱环节、学习偏好和进度，由冷启动访谈生成，学员或带教老师可以直接修改；每个流程开始前都会先读它。

配置哪些内容

  • 我是谁
  • 学习目标
  • 薄弱环节（各学科自评 / 已做错题的集中类型）
  • 学习偏好
  • 学习进度追踪（已完成的学习任务 / 自测成绩记录）
  • 输出偏好（案例分析输出 / 模拟题输出 / 工作产物标记）
  • 升级规则（何时建议咨询教师）

会怎样改变输出

  • 「我是谁」里的身份与学历背景决定案例研习的案例复杂度和事实干扰度（非法学背景：单一合同或侵权关系、低干扰；法学本科在校生：2-3个法律关系、中等干扰；多次备考或研究生：多主体、多法律关系交叉、高干扰），案例研习的结论步骤也按三档提出答题要求；法条记忆据此决定基础概念讲多深。
  • 「薄弱环节」的学科自评决定法条记忆先做哪一科的知识图谱、重点法条清单怎样排序，以及模拟题的出题侧重；已做错题的集中类型供错题分析初步判断错误模式。
  • 「学习目标」的考试侧重决定案例研习（主观题）与模拟题（客观题）的训练分配，目标分数用于校准模拟题难度；备考阶段为冲刺刷题时，重点法条清单只出 A 级；间隔复习计划的总时长不超过每日可用学习时间。
  • 「学习偏好」与「输出偏好」决定记忆技巧和案例的呈现方式（学习风格不确定时默认读写型）、条文引用尽量与学员所用教材一致，以及分析深度、是否引用法条、题目难度和解析详细程度；「工作产物标记」固定为「法考学习材料 — 仅供学习参考，不构成法律建议」。
  • 「升级规则」的三条默认——某学科连续3次自测正确率低于50%，建议寻求专业教师辅导；距考试不足30天但基础阶段未完成，建议调整备考策略或寻求一对一辅导；主观题写作反复不得要领，建议找老师批改——决定何时提示学员找老师。
  • 档案缺失或仍有未填写的项时，各流程先提示做冷启动访谈或说「临时模式」；临时模式按默认画像运行（法学本科在校生首次备考、目标通过线、读写型、主客观题均衡、每日4小时、基础阶段），并在成果上标「[临时模式 — 配置你的档案以获得定制训练]」。

04领域引用库

本领域各流程共用的法条、口径和规则；法条有误通常改这里。

  • 法考高频法条引用库
    法考常用依据，分法条、案例、学说三类。法条部分：民法典——民事法律行为（第143条有效要件，第144、146、153、154条无效，第147-151条可撤销）、代理（第161-164条委托代理与法定代理，第171条无权代理，第172条表见代理）、物权变动（第209条不动产登记，第224条动产交付，第311条善意取得）、合同编（第490条合同成立，第496-498条格式条款，第563条法定解除，第577条违约责任）；刑法——第14、15条故意与过失，第20、21条正当防卫与紧急避险，第264条盗窃、第266条诈骗、第234条故意伤害、第133条交通肇事；行政法与行政诉讼法——《行政处罚法》第9条处罚种类、《行政许可法》第14-17条许可设定、《行政诉讼法》第12条受案范围；民事诉讼法——第122条起诉条件、第22-35条管辖、第67条举证责任；商法——《公司法》（2023年修订）第23条法人人格否认、第47-54条股东出资，《合伙企业法》第2-3条普通合伙与有限合伙；理论法学——《宪法》第33-50条基本权利、第57-135条国家机构，法理学不列条文，只列四个基本概念。部分小节附考查要点，如撤销权除斥期间（1年／90日／5年）、表见代理构成要件（权利外观＋合理信赖＋被代理人可归责性）。案例和学说两类目前只有待填的框架（表见代理、善意取得、正当防卫、法人人格否认四类案例；民事法律行为效力三分法、犯罪构成四要件与三阶层之争、法律解释方法三项学说），没有填入任何案号或作者。核实情况：库的开头说已核实的条文会标「已核实」，但目前没有一条这样标注，全部条号都是 AI 凭记忆写出，标 [模型知识 — 需验证] 和 [待验证]。更新规则：法规修订后更新版本年份，案例经检索核实后才填入，学说须有完整出处并注明通说或少数说，大纲调整后更新考查要点；核实渠道为国家法律法规数据库、最高人民法院官网和指定教材。
    用于：案例研习、法条记忆、模拟题生成、错题分析
  • 法律依据引用规范
    本领域统一的引用规则。依据分三类：法条（法律、行政法规、部门规章、司法解释、地方性法规；成文法是分析基础，每个结论先援引现行成文法，不得以案例替代法条，没有直接规定的写明「无直接成文法规定，参照以下案例/学说」），至少写成「《全名》（版本）第×条第×款」，民法典注「2020年通过」，刑法注「1997年修订」并注明修正案编号；案例（指导性案例只作参考、不具判例法约束力，案号和指导案例编号默认标 [待验证]）；学说（注明作者与出处、是否通说、法考考查倾向）。每条引用附且只附一个来源标签——[教材] [法规网站] [网络搜索 — 需验证] [模型知识 — 需验证] [用户提供] [真题]，不得删去；AI 凭记忆写出的、距最后更新超过6个月的、所有案例、版本未确认的，一律加 [待验证]，核实渠道为国家法律法规数据库、最高人民法院官网、中国裁判文书网、北大法宝，已接入元典开放平台的也可以用。条文号一律先写规则内容再标 [待验证]，绝不编造；学说争议分通说、少数说、大纲采纳、法考未明确（标「法考中依大纲为准 [待验证]」）四种情形处理；另列十个学科的主要法律渊源、真题的引用写法（「某年法考客观题／主观题第×题 [真题]」），以及五条教育护栏（学习辅助、不构成法律建议、教材为准、条文号审慎、学说中立）和用在学习以外场合时须加的声明。
    用于：案例研习、法条记忆、模拟题生成、错题分析
  • 学员档案说明
    学员档案（即本领域的实践配置）的使用规则：档案只有一份，由冷启动访谈生成和更新，学员可以直接修改、改后即时生效，修改留有记录，可以查看历史、退回旧版本；附访谈各项答案写进哪一章、由哪些流程使用的对照（如学历背景决定案例研习的分析深度和法条记忆的基础概念讲解深度，目标分数用于校准模拟题难度，学习风格决定记忆技巧和案例呈现方式，所用教材决定各流程的条文引用尽量与之一致）。各流程动手前先读档案，关键信息未填写的不得自行猜测，要提示学员「做冷启动访谈（约5分钟），或说『临时模式』」；临时模式默认八项：法学本科在校生首次备考、目标为通过线（客观题180分/主观题108分，以当年大纲为准 [待验证]）、薄弱学科不预设（逐次询问）、读写型、主客观题均衡、每日4小时、教材不预设（逐次确认）、基础阶段。写入前，学员口述的分数线、考试日期、大纲变化一律提示以司法部公告或官方发布为准，并标「前提需核实」；同一次访谈里前后矛盾的回答，先澄清再写入。
    用于：冷启动访谈、案例研习、法条记忆、模拟题生成、错题分析

05不做什么

  • 不构成法律建议、不替代法律执业：案例分析与法条解读只供法考学习参考，不构成针对具体案件的法律意见；被用在学习以外的场合时，须加注「[教育声明：本内容仅供法考学习参考，不构成法律建议。具体法律问题请咨询执业律师。]」
  • 不替代教材和大纲：法考答案以当年考试大纲和指定教材为准，本领域的流程只辅助理解；条文号须对照教材或国家法律法规数据库核实
  • 不凭记忆断言条文号和案号：条号不确定时写「《××法》关于（规则内容）的规定」；所有案例引用默认标 [待验证]，未经检索核实不得去掉
  • 不以案例替代法条：中国采成文法体系，指导性案例只用来说明法条怎样适用，不具判例法约束力
  • 学说争议不选边：客观呈现，标明通说或少数说，并注明法考的考查倾向
