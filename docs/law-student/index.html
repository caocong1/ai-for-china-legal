02概要

辅助法律职业资格考试备考的五条训练流程：冷启动访谈先建立学员档案，案例研习、法条记忆、模拟题生成（题型设计/情景构建/答案解析/难度校准）、错题分析（错误模式/薄弱诊断/补强方案/进步追踪）四条流程再按档案调整难度、讲解深度与输出格式，共二十个可单独触发的步骤。各流程先读 law-student/CLAUDE.md（未建档时提示先做访谈，或按临时模式默认值运行并在输出上标注），再按插件统一的引用规范把依据分为法条、案例、学说三类：成文法优先，指导性案例只作参考，条文号先描述规则再标 [待验证]，学说以通说和当年大纲为准。所有输出带「法考学习材料 — 仅供学习参考，不构成法律建议」标记，定位为学习辅助，答案以当年考试大纲和指定教材为准。

03实践配置

实践配置文件 <a href="https://github.com/caocong1/ai-for-china-legal/blob/master/law-student/CLAUDE.md">law-student/CLAUDE.md</a> 记录贵所的立场与习惯；所有流程开始前先读它。

配置哪些内容

  • 我是谁
  • 学习目标
  • 薄弱环节（各学科自评 / 已做错题的集中类型）
  • 学习偏好
  • 学习进度追踪（已完成的学习任务 / 自测成绩记录）
  • 输出偏好（案例分析输出 / 模拟题输出 / 工作产物标记）
  • 升级规则（何时建议咨询教师）

会怎样改变输出

  • 「我是谁」的身份与学历背景决定案例研习的案例复杂度与事实干扰度（非法学背景：单一合同或侵权、低干扰；法学本科在校生：2-3个法律关系、中等干扰；多次备考/研究生：多主体多法律关系交叉、高干扰），结论步骤按同样分层提出答题要求；法条记忆据此调整基础概念讲解深度。
  • 「薄弱环节」的学科自评决定法条记忆先做哪科的知识图谱、重点法条清单如何排序，以及模拟题的出题侧重；错题集中类型供错题分析做初始模式识别。
  • 「学习目标」的考试侧重决定案例研习（主观题）与模拟题（客观题）的训练分配，目标分数用于模拟题难度校准；备考阶段为冲刺刷题时重点法条清单只出 A 级，间隔复习计划的总时长不超过每日可用学习时间。
  • 「学习偏好」与「输出偏好」决定记忆技巧选择与案例呈现方式（学习风格不确定时默认读写型）、条文引用尽量对齐学员所用教材、分析深度、是否引用法条、题目难度和解析详细度；工作产物标记固定为「法考学习材料 — 仅供学习参考，不构成法律建议」。
  • 「升级规则」三条默认（某学科连续3次自测正确率低于50% → 建议寻求专业教师辅导；距考试不足30天但基础阶段未完成 → 建议调整备考策略或寻求一对一辅导；主观题写作反复不得要领 → 建议找老师批改）决定何时提示学员找老师。
  • 档案缺失或含 [PLACEHOLDER] 时，各流程先提示运行冷启动访谈或说「临时模式」；临时模式按默认画像运行（法学本科在校生首次备考、通过线、读写型、主客观均衡、每日4小时、基础阶段），并在输出上标 [临时模式 — 配置你的档案以获得定制训练]。

04领域引用库

这些文件收录本领域各流程共用的法条、口径和规则；法条有误通常改这里。

  • 法考高频法条引用库 law-student/skills/_shared/law-exam-citations.md
    按「法条 / 案例 / 学说」三类组织的法考引用库。法条类分六节：A 民法典（A.1 民事法律行为第143条有效要件、第144/146/153/154条无效、第147-151条可撤销；A.2 代理第161-164条、第171条无权代理、第172条表见代理；A.3 物权变动第209条不动产登记、第224条动产交付、第311条善意取得；A.4 合同编第490条合同成立、第496-498条格式条款、第563条法定解除、第577条违约责任），B 刑法（B.1 第14、15条故意与过失，第20、21条正当防卫与紧急避险；B.2 盗窃第264条、诈骗第266条、故意伤害第234条、交通肇事第133条），C 行政法与行政诉讼法（行政处罚法第9条处罚种类、行政许可法第14-17条许可设定、行政诉讼法第12条受案范围），D 民事诉讼法（第122条起诉条件、第22-35条管辖、第67条举证责任），E 商法（公司法（2023年修订）第23条法人人格否认、第47-54条股东出资，合伙企业法第2-3条），F 理论法学（宪法第33-50条基本权利、第57-135条国家机构；法理学无具体条文，只列四个基本概念）。每行给出简要内容、来源标签 [模型知识 — 需验证] 与验证状态，部分小节附考查要点（如撤销权除斥期间1年/90日/5年、表见代理构成要件「权利外观+合理信赖+被代理人可归责性」）。案例类与学说类目前只有占位结构（表见代理、善意取得、正当防卫、法人人格否认四类案例；民事法律行为效力三分法、犯罪构成四要件 vs 三阶层、法律解释方法三项学说），没有填入任何案号或作者。文件头说已核实的锚点会标「已核实」，但目前没有任何一行这样标注，全部条号都是 [待验证]。末附使用方式、更新规则（法规修订更新版本年份、核验后的案例填入占位、学说须有完整出处并注明通说/少数说、大纲调整后更新考查要点）和核验渠道（flk.npc.gov.cn、court.gov.cn、指定教材）。
    用于：case-study、law-memorization、practice-questions、wrong-answer-analysis
  • 法考培训法律依据引用规范 law-student/skills/_shared/legal-basis-conventions.md
    八章引用纪律。一、来源三分类：法条（法律、行政法规、部门规章、司法解释、地方性法规；成文法是分析基础，最小格式「《全名》（版本）第X条第X款」，民法典标「2020年通过」，刑法标「1997年修订」并注修正案编号）、案例（指导性案例仅作参考、不具判例法约束力，案号与指导案例编号默认 [待验证]）、学说（标作者/出处、是否通说、法考考查倾向）。二、六种来源标签（[教材] [法规网站] [网络搜索 — 需验证] [模型知识 — 需验证] [用户提供] [真题]），每条引用必须且只能附一个，不得剥离。三、四种必须追加 [待验证] 的情形（模型知识来源、距最后更新超过6个月、所有案例、版本未确认）与核验资源（国家法律法规数据库、最高法官网、中国裁判文书网、北大法宝、已配置连接器时的元典开放平台）。四、成文法优先：每个结论先援引现行成文法，不得以案例替代法条，无直接法条时须写明「无直接成文法规定，参照以下案例/学说」。五、法考特殊规范：条文号一律「先描述规则再标 [待验证]」、绝不编造；学说争议四种处理（通说、少数说、大纲采纳、法考未明确时标「法考中依大纲为准 [待验证]」）；十个学科的主要法律渊源表。六、最小格式汇总（含真题写法「[年份]年法考[客观题/主观题]第X题 [真题]」）。七、五条教育护栏（学习辅助、不构成法律建议、教材为准、条文号审慎、学说中立）与非学习场景误用时的声明。八、列出引用本规范的流程。

05不做什么

  • 不构成法律建议、不替代法律执业：案例分析与法条解读仅供法考学习参考，不构成针对具体案件的法律意见；在非学习场景下误用时须加注「[教育声明：本内容仅供法考学习参考，不构成法律建议。具体法律问题请咨询执业律师。]」
  • 不替代教材和大纲：法考答案以当年考试大纲和指定教材为准，本插件辅助理解但不替代教材；条文号须对照教材或国家法律法规数据库核实
  • 不凭记忆断言条文号与案号：条号不确定时写「《XX法》关于[规则描述]的规定」；所有案例引用默认标 [待验证]，未经检索核验不得移除
  • 不以案例替代法条：中国采成文法体系，指导性案例只用于说明法条适用方式，不具判例法约束力
  • 学说争议不选边：客观呈现，标注通说/少数说，并注明法考中的考查倾向
  • 不另建 JSON 或 YAML 配置文件：学员档案只存于 law-student/CLAUDE.md
