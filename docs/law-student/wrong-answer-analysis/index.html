01概要

面向法考学习者，对提交的错题做系统分析：按七类错误类型逐题归因，区分偶然错误和系统性错误；把薄弱点定位到学科、章节、知识点三级，按红/橙/黄/绿级排序（红级=严重、橙级=较重、黄级=中等、绿级=轻微，原文用四色圆点标示）；再生成按优先级排列的补强计划表，并用自测正确率追踪补强效果、出阶段评估报告。流程先读学习者配置文件 law-student/CLAUDE.md（薄弱学科、错题集中类型、学科自评、历史成绩、每日学习时间、学习风格、自测成绩），缺失时提示先做冷启动访谈或按「临时模式」运行。随后依次走错误模式识别 → 知识薄弱点诊断 → 针对性补强方案 → 进步追踪四步，每一步都可以单独触发。薄弱程度用出错频率30%、考点级别30%、错误类型20%、时间紧迫度20% 的加权矩阵评分，补强任务以自测正确率≥80% 为完成标准。

02适用与边界

适用场景

  • 学习者积累了一批错题（真题、模拟题或自测题），要找出反复出错的规律和根本原因。
  • 需要把薄弱点诊断结果转成按优先级排序的补强任务和每日时间安排。
  • 补强一段时间后，用自测成绩检验效果，决定维持、加强还是升级补强策略。
  • 只需要其中一环时单独触发：只做错误类型分类、只做薄弱点诊断、只排补强计划、只出阶段评估报告。

不做什么

  • 不替代系统学习和教师指导，分析仅供学习改进参考。
  • 不批评学习者，不在缺少错题证据时臆断错因。
  • 粗心等偶然错误只单列，不纳入重点分析。
  • 产出不构成法律建议。

03输入与产出

需要律师提供

  • 错题内容必需
    三种方式：文字描述题干和选项；无法直接识别图片时，用文字描述截图中的错题；一次批量导入多道错题
  • 每道错题的配套信息可选
    题目来源（真题/模拟题/自测题）、学科、知识点、题型、我的答案、正确答案、自述错因、难度级别 L1-L5；来源不明的标「来源不明」并降低权重，未提供自述错因的仅按答案偏差推断并标 [推断]
  • 学习者配置文件 law-student/CLAUDE.md可选
    读取薄弱学科、错题集中类型、学科自评、历史成绩、每日学习时间、学习风格、学习进度追踪记录和自测成绩；缺失或含 [PLACEHOLDER] 时先提示，可选「临时模式」
  • 前一步的产出可选
    单独触发后续步骤时作为输入：薄弱点诊断用错误模式分析结果，补强方案用薄弱点诊断报告
  • 补强记录或自测成绩可选
    进步追踪用；无自测数据时建议先完成一轮自测后再评估

产出

  • 错误模式分析报告给学习者
    一、错题概览（分析错题总数、涉及学科数、时间范围）；二、主要发现（最大薄弱学科及其错题占比、主要错误类型和集中知识点；主要错误模式、涉及学科和建议方向）；三、系统性错误清单（错误模式 / 出现次数 / 涉及知识点 / 严重程度）；四、偶然错误清单；附按学科、错误类型、知识点三个维度的统计表
  • 知识薄弱点诊断报告给学习者
    一、薄弱点总览（红/橙/黄/绿级各几个）；二、优先级排序表（优先级 / 知识点 / 学科 / 严重程度 / 建议补强时间）；三、关联分析（前置知识和关联薄弱点）；四、与学习者自评对照（一致 / 不一致，如「自评偏高」）；补强建议概要
  • 针对性补强方案（补强计划表）给学习者
    一、补强总览（知识点 / 薄弱程度 / 补强策略 / 预计用时 / 计划完成）；二、每个知识点的四步补强任务；三、每日/每周时间安排；四、效果检验（自测标准和完成标志）
  • 阶段评估报告（进步追踪报告）给学习者
    一、补强进度总览；二、补强效果（补强前后正确率与评级）；三、学科层面变化（阶段初与当前正确率）；四、策略调整建议；五、下一阶段计划；六、与考试时间对照（距考试天数、剩余未补强知识点数、是否来得及）

04开始前

前置条件

  • 开始前读取学习者配置文件 law-student/CLAUDE.md；缺失或仍含 [PLACEHOLDER] 时提示「错题分析需要参考你的薄弱学科和历史成绩来准确诊断错误原因」，由用户选择运行 /law-student:cold-start-interview（约5分钟），或说「临时模式」使用通用默认值并在输出上标记 [临时模式]。
  • 临时模式默认值见 practice-profile-schema.md 第 3.3 节，例如每日学习时间 4 小时、备考阶段为基础阶段、薄弱学科无预设（逐案询问）。
  • 每一步读取 law-student/skills/_shared/legal-basis-conventions.md（法考培训引用规范）；薄弱点诊断和补强方案两步另读 law-exam-citations.md（法考高频法条引用库）。
  • 四步按「发现是什么错 → 找出为什么错 → 解决怎么补 → 检验效果」的顺序执行，后一步的理想输入是前一步的产出。

硬性规则

教育声明
所有错题分析输出须标注「[教育声明：本错题分析仅供学习改进参考，不替代系统学习和教师指导。]」；各步输出模板另有简写版声明。
分析客观
错题分析须客观，不批评学习者。
基于证据归因
错误归因须基于证据（错题内容），不臆断；学习者未提供自述错因时仅按答案偏差推断，标注 [推断]。
诊断具体到知识点
薄弱点诊断须具体到知识点层级，不泛泛而谈。
法条标注
所有法条引用标注 [待验证]（薄弱点诊断检查清单）。
工作产物标记
完整流程输出加「法考学习材料 — 仅供学习参考，不构成法律建议」；每一步的产出也都声明不构成法律建议。
成文法定位
中国采成文法体系，各步所有引用仅作参考，不具判例法约束力。

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置假设，可逐条复制。页面里的英文标记见首页「标记与术语」。

  1. 错误模式识别

    /law-student:error-pattern-recognition可单独运行

    对错题系统分类，识别反复出现的错误模式，区分偶然错误（如粗心）与系统性错误（如知识漏洞），为薄弱点诊断提供数据基础。

    请律师核对

    • 核对 1.1七类错误类型是否覆盖贵机构常见错因；判断表中出现的「记忆模糊」不在七类之列，是否并入「记忆遗忘」。
    • 核对 1.2「同一知识点出错≥2次」即可视为系统性错误的门槛，以及「错题少于5道」的提示门槛，是否合适。
    • 核对 1.3来源不明的错题「降低权重」，但未规定降多少；标 [推断] 的错因是否需要老师复核后再进入诊断。

    做法

    1. 读取 law-student/CLAUDE.md 的薄弱学科记录和错题集中类型。
    2. 逐题填写错题信息表八项：题目来源（真题/模拟题/自测题，用于判断题目质量）、学科、知识点、题型（单选/多选/不定项/案例）、我的答案、正确答案、自述错因（与实际原因对照）、难度级别（L1-L5）。
    3. 把每道错题归入七类错误类型之一：知识盲区、知识混淆、理解偏差、记忆遗忘、审题错误、推理失误、粗心失误。
    4. 按答案偏差判断错因：答案完全偏离正确方向 → 知识盲区或理解偏差；答案接近但不完全正确 → 知识混淆或记忆模糊；同一知识点反复出错 → 理解偏差或记忆遗忘；不同知识点犯同类错误 → 审题错误或推理失误；仅偶尔出错 → 粗心失误。
    5. 做三维统计：按学科（错题数、占总错题比、主要错误类型、优先级高/中/低）；按错误类型（出现次数、占比、涉及学科、是否系统性，未定的标「待观察」）；按知识点（出错次数、所属学科、错误类型、是否高频考点）。
    6. 识别系统性错误：同一知识点出错≥2次，很可能是理解偏差或记忆遗忘；同一错误类型在不同知识点重复出现，可能是审题或推理的方法论问题；同一学科错题占比明显偏高，说明该学科存在系统性薄弱环节。
    7. 把偶然错误单列，不纳入重点分析。
    8. 出报告：错题概览、主要发现（最大薄弱学科、主要错误模式及建议方向）、系统性错误清单（严重程度分红级=高、黄级=中、绿级=低三档）、偶然错误清单（逐题注明是否需要关注）。

    内置规则

    • 七类错误类型与解决方向：知识盲区（对相关知识点完全不了解，如不知道法条存在）→ 系统学习该知识点；知识混淆（如混淆无效与可撤销）→ 对比记忆；理解偏差（如误解构成要件）→ 重新理解法条；记忆遗忘（记得学过但想不起内容）→ 间隔复习；审题错误（如漏看「不正确」的限定词）→ 审题训练；推理失误（推理链条断裂）→ 分析逻辑训练；粗心失误（如看错选项字母）→ 检查习惯。
    • 答案偏差与错误类型的五条对应关系是归因的判断依据。
    • 系统性错误三条识别标准：同一知识点出错≥2次；同一错误类型在不同知识点重复出现；同一学科错题占比明显偏高。
    • 错题少于5道时提示「错题数量较少，分析结论可能不够准确，建议积累更多错题后再分析」。
    • 来源不明的错题标记「来源不明」，仍纳入分析但降低权重。
    • 学习者未提供自述错因时，仅基于答案偏差推断错误类型，标注 [推断]。

    产出

    「错误模式分析报告」：错题概览、主要发现、系统性错误清单、偶然错误清单，附按学科、错误类型、知识点三个维度的统计表。

  2. 知识薄弱点诊断

    /law-student:knowledge-gap-diagnosis可单独运行

    在错误模式结果基础上，把薄弱点定位到学科、章节、知识点三级，评估严重程度并排出补强优先级。

    请律师核对

    • 核对 2.1评分矩阵只给了各因素的定性档（如出错≥3次=严重），SKILL.md 未规定定性档如何换算成分数，「≥80分」等分数段无法直接算出；错误类型只给了知识盲区、理解偏差、记忆遗忘三类的档次，其余四类如何计分未规定。
    • 核对 2.2前置知识检查把「犯罪形态」的检查方法写为「测试四要件」，是否与所用教材的犯罪构成体系一致；是否补充行政法、诉讼法、商法的前置关系。
    • 核对 2.3时间紧迫度以「距考试<60天且未掌握」为严重，与进步追踪步骤「距考试不足30天」的口径不同，是否统一。

    做法

    1. 读取 law-student/CLAUDE.md 的各学科自评分和历史成绩，以及引用规范和高频法条引用库；理想输入是上一步的错误模式分析结果。
    2. 三维定位：学科维度看哪个学科错题最多（薄弱学科排序）；章节维度看学科内哪个章节/编出错最多（薄弱章节排序）；知识点维度看具体哪个知识点反复出错（薄弱知识点清单）。
    3. 填写薄弱点定位表：学科、薄弱章节、薄弱知识点、出错次数、错误类型、考点级别、薄弱严重程度。原文示例：民法·合同编·合同法定解除，出错3次，理解偏差，A级，严重；刑法·总则·犯罪形态，2次，知识混淆，A级，较重；商法·公司法·股东出资，1次，记忆遗忘，B级，中等。
    4. 按四因素加权评分：出错频率30%（出错≥3次=严重，2次=较重，1次=中等）；考点级别30%（A级=严重，B级=较重，C级=中等）；错误类型20%（知识盲区=严重，理解偏差=较重，记忆遗忘=中等）；时间紧迫度20%（距考试<60天且未掌握=严重）。
    5. 按综合评分分四级：红级（严重，≥80分，高频考点且反复出错，立即补强）；橙级（较重，60-79分，重要考点且多次出错，优先补强）；黄级（中等，40-59分，有一定基础但不稳定，正常补强）；绿级（轻微，<40分，偶尔出错、基础尚可，复习巩固）。
    6. 做前置知识检查：合同解除 ← 合同效力（测试合同有效要件）；善意取得 ← 物权变动（测试登记/交付生效）；犯罪形态 ← 犯罪构成（测试四要件）；管辖 ← 法律关系定性（测试法律关系识别）。
    7. 画关联薄弱点网络，区分「可能关联（待检查）」和「关联（需确认是否掌握）」，例如民法·合同解除（红级）可能关联合同效力，并关联违约责任。
    8. 与学习者自评对照，标「一致」或「不一致」（如「自评偏高」）；差异大时讨论差异原因，以错题数据为主要依据。
    9. 出诊断报告：薄弱点总览（各级个数）、优先级排序表（含建议补强时间）、关联分析、与自评对照、补强建议概要（详细方案留给下一步）。

    内置规则

    • 加权矩阵：出错频率30%、考点级别30%、错误类型20%、时间紧迫度20%。
    • 四级分数段：≥80分为红级（立即补强）；60-79分为橙级（优先补强）；40-59分为黄级（正常补强）；<40分为绿级（复习巩固）。
    • 前置知识检查四组：合同解除—合同效力；善意取得—物权变动；犯罪形态—犯罪构成；管辖—法律关系定性。
    • 错题数据不足以定位时，建议补充特定学科的自测题来定位。
    • 薄弱点过多（>10个）时建议分批补强，每批聚焦3-5个。
    • 诊断结果与自评差异大时，讨论差异原因，以错题数据为主要依据。
    • 所有法条引用标注 [待验证]。

    产出

    「知识薄弱点诊断报告」：按优先级排序的薄弱知识点表、前置知识和关联薄弱点说明、补强建议概要；完整版另含四级总览和与学习者自评的对照表。

  3. 针对性补强方案

    /law-student:targeted-remediation可单独运行

    把诊断结果变成个性化、可执行的补强方案：每个薄弱点的补强任务、推荐方法、时间安排和检验标准。

    请律师核对

    • 核对 3.1每知识点用时估计（知识盲区2-3小时、知识混淆和理解偏差1-2小时、记忆遗忘0.5-1小时）是否符合学员实际。
    • 核对 3.2补强强度占比是按每个知识点还是按该级别合计计算，SKILL.md 未说明；多个红级知识点同时存在时如何封顶也未规定。
    • 核对 3.3推理失误的补强方法是「案例研习+IRAC训练」，是否与贵机构的主观题答题结构一致；「距考试时间极短」没有量化。

    做法

    1. 读取 law-student/CLAUDE.md 的每日学习时间和学习风格，以及引用规范和高频法条引用库；理想输入是上一步的薄弱点诊断报告。
    2. 按错误类型选补强策略和用时：知识盲区—系统学习（教材学习+知识图谱+记忆技巧，每知识点2-3小时）；知识混淆—对比辨析（对比记忆表+辨析练习，每知识点1-2小时）；理解偏差—重新理解（教材重读+案例分析+老师讲解，每知识点1-2小时）；记忆遗忘—强化复习（间隔复习+自测+记忆卡片，每知识点0.5-1小时）；审题错误—审题训练（审题清单+专项练习，持续训练）；推理失误—逻辑训练（案例研习+IRAC训练，持续训练）。
    3. 按薄弱程度定补强强度：红级（严重）强度高、集中突破，每日学习时间的30-40%用于补强；橙级（较重）中高，20-30%；黄级（中等）中，10-20%；绿级（轻微）低、复习巩固，5-10%。
    4. 为每个知识点写四步补强任务：知识回顾（阅读教材相关章节、整理知识要点）→ 理解深化（涉及混淆的完成对比记忆表，分析1-2个典型案例）→ 巩固练习（完成针对性练习题，整理错题到错题本）→ 自测检验（检验标准为自测正确率≥80%，达标方可标记完成）。
    5. 排补强任务顺序表（知识点、补强策略、预计用时、计划完成日期），前置知识薄弱点优先安排。
    6. 生成每日补强安排：按时间段排补强、日常学习（常规）、自测练习（检验）三类任务，列出今日补强重点和明日预览。
    7. 按知识点推荐资源：教材（名称+章节）、记忆技巧（如对比记忆法）、练习题（推荐练习范围）、案例（分析某类型案例）。
    8. 边界处理：补强量超出可用时间时按优先级裁剪，保留红级和橙级任务；某知识点补强后仍出错时升级补强策略（如从记忆复习升级为重新学习）；距考试时间极短时仅聚焦 A 级高频考点的补强。

    内置规则

    • 错误类型—补强策略对应表共六类（知识盲区、知识混淆、理解偏差、记忆遗忘、审题错误、推理失误）；粗心失误没有对应策略。
    • 补强强度按每日学习时间占比：红级30-40%、橙级20-30%、黄级10-20%、绿级5-10%。
    • 完成标准：自测正确率≥80%。
    • 检查清单：每个薄弱知识点已有对应补强任务；补强策略与错误类型匹配；补强时间与每日可用时间匹配；每个任务有明确检验标准；补强计划时间安排已生成；前置知识薄弱点已优先安排。
    • 裁剪与升级规则：超出可用时间时保留红级和橙级；补强后仍出错则升级策略；距考试时间极短时只做 A 级高频考点。

    产出

08何时暂停或升级

  • 学习者配置文件缺失或含 [PLACEHOLDER]：先提示，由用户选择运行冷启动访谈或进入「临时模式」。
  • 错题少于5道：提示分析结论可能不够准确，建议积累更多错题后再分析。
  • 错题数据不足以定位薄弱点：建议补充特定学科的自测题；薄弱点超过10个：建议分批补强，每批聚焦3-5个。
  • 补强量超出可用时间：按优先级裁剪，保留红级和橙级任务。
  • 补强后仍出错或评估为无效：升级补强策略，最高一级为教师辅导，也可直接建议寻求教师辅导。
  • 距考试不足30天但补强未完成：聚焦红级薄弱点、放弃绿级；距考试时间极短：仅聚焦 A 级高频考点。
