01概要

系统分析学员提交的一批法考错题：逐题归入七类错因，分开偶然失误与系统性错误；把薄弱点定位到学科、章节、知识点，按红、橙、黄、绿四级排出补强优先级；再排补强计划，用自测正确率检验效果，出阶段评估报告。分四步，每步都可单独使用：错误模式识别、知识薄弱点诊断、针对性补强方案、进步追踪。动手前先读学员档案（即本领域的实践配置），未建档的先提示做冷启动访谈，或按临时模式运行。薄弱程度按出错频率30%、考点级别30%、错误类型20%、时间紧迫度20%加权评分，补强任务以自测正确率达到80%为完成标准。

02适用与边界

适用场景

  • 学员攒了一批错题（真题、模拟题或自测题），要找出反复出错的规律和根本原因。
  • 要把薄弱点诊断结果变成按优先级排列的补强任务和每日时间安排。
  • 补强一段时间后，用自测成绩检验效果，决定维持、加强还是升级补强办法。
  • 只需要其中一环时单独使用：只给错题分类（第 1 步）、只诊断薄弱点（第 2 步）、只排补强计划（第 3 步）、只出阶段评估报告（第 4 步）。

不做什么

  • 不替代系统学习和教师指导，分析只供改进学习参考。
  • 不批评学员；没有错题作依据时不臆断错因。
  • 粗心等偶然失误只单列，不作重点分析。
  • 成果不构成法律建议。

03输入与产出

需要提供

  • 错题内容必需
    直接输入题干和选项，图片读不了时用文字描述截图里的题，也可一次批量提交
  • 每道错题的配套信息可选
    来源、学科、知识点、题型、作答、正确答案、自述错因、难度；没给错因的标 [推断]
  • 学员档案可选
    读薄弱学科、错题类型、自评与成绩、时间与风格、进度；未建档先提示访谈或临时模式
  • 前一步的成果可选
    单独做后面的步骤时提供：第 2 步用错误模式分析结果，第 3 步用诊断报告
  • 补强记录或自测成绩可选
    第 4 步用；没有自测数据的，先做一轮自测再评估

产出

  • 错误模式分析报告读者：学员
    错题概览（题数、涉及学科、时间范围）、主要发现（最大薄弱学科、主要错误模式及建议方向）、系统性错误清单、偶然错误清单，附按学科、错因、知识点的统计表
  • 知识薄弱点诊断报告读者：学员
    四级薄弱点各几个、优先级排序表（含建议补强时间）、前置知识与关联薄弱点分析、与学员自评对照（如「自评偏高」）、补强建议概要
  • 针对性补强方案（补强计划表）读者：学员
    补强总览（知识点、薄弱程度、补强办法、预计用时、计划完成日期）、每个知识点的四步补强任务、每日或每周时间安排、自测检验标准和完成标志
  • 阶段评估报告（进步追踪报告）读者：学员
    补强进度、补强前后正确率与效果评级、学科层面变化、策略调整建议、下阶段计划、与考试时间对照（距考试天数、剩余未补强知识点数、是否来得及）

04开始前

前置条件

  • 开始前先读学员档案；没有档案或仍有未填写的项时，提示「错题分析需要参考你的薄弱学科和历史成绩来准确诊断错误原因」，由学员选择做冷启动访谈（约5分钟），或说「临时模式」按通用默认值运行，成果标「[临时模式]」。
  • 临时模式的默认值见学员档案说明，例如每日学习4小时、备考阶段为基础阶段、薄弱学科不预设（逐次询问）。
  • 各步都按法律依据引用规范引用依据；第 2、3 步另读法考高频法条引用库。
  • 四步按「先看是什么错 → 再找为什么错 → 再定怎么补 → 最后检验效果」的顺序做，后一步最好以前一步的成果为输入。

硬性规则

教育声明
所有错题分析成果标注「[教育声明：本错题分析仅供学习改进参考，不替代系统学习和教师指导。]」；第 2 至 4 步另有简短版声明，第 1 步的报告模板没有。
分析客观
错题分析须客观，不批评学员。
基于证据归因
错因须以错题内容为依据，不臆断；学员没给自述错因的，只按答案偏差推断，标 [推断]。
诊断到知识点
薄弱点诊断须具体到知识点，不泛泛而谈。
法条标注
所有法条引用标 [待验证]（规则写在第 2 步的检查清单里）。
工作产物标记
完整流程的成果标「法考学习材料 — 仅供学习参考，不构成法律建议」；每一步的成果也都声明不构成法律建议。
成文法定位
中国采成文法体系，各步所有引用只作参考，不具判例法约束力。

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置判断，可逐条复制。

  1. 错误模式识别

    可单独使用

    给错题系统分类，找出反复出现的错误模式，分开偶然失误（如粗心）和系统性错误（如知识漏洞），为诊断打基础。

    请律师核对

    • 核对 1.1七类错因是否覆盖贵机构常见的错因？判断表里出现的「记忆模糊」不在七类之中，是否并入「记忆遗忘」？
    • 核对 1.2「同一知识点出错2次及以上」即算系统性错误、「错题少于5道」才提示结论可能不准，这两个门槛是否合适？
    • 核对 1.3来源不明的错题「降低权重」，没有规定降多少；标 [推断] 的错因是否要经老师复核后再进入诊断？

    做法

    1. 读学员档案里的薄弱学科记录和错题集中类型。
    2. 逐题登记八项信息：题目来源（真题、模拟题、自测题，用来判断题目质量）、学科、知识点、题型（单选、多选、不定项、案例）、学员答案、正确答案、自述错因（用来与实际原因对照）、难度级别（一至五级）。
    3. 把每道错题归入七类错因之一（见内置规则），按答案偏差判断：完全偏离正确方向 → 知识盲区或理解偏差；接近但不完全正确 → 知识混淆或记忆模糊；同一知识点反复出错 → 理解偏差或记忆遗忘；不同知识点犯同类错误 → 审题错误或推理失误；只是偶尔出错 → 粗心失误。
    4. 按三个维度统计：按学科（错题数、占全部错题的比例、主要错因、优先级高中低）；按错因（出现次数、占比、涉及学科、是否系统性，定不下的标「待观察」）；按知识点（出错次数、所属学科、错因、是否高频考点）。
    5. 按三条标准识别系统性错误（见内置规则）；偶然错误单列，不作重点分析。
    6. 写出报告：错题概览、主要发现（最大薄弱学科、主要错误模式及建议方向）、系统性错误清单（严重程度分高、中、低三档，用红、黄、绿标示）、偶然错误清单（逐题注明是否需要关注）。

    内置规则

    • 七类错因及对策：知识盲区（对相关知识点完全不了解，如不知道有这条法条）→ 系统学习该知识点；知识混淆（如混淆无效与可撤销）→ 对比记忆；理解偏差（如误解构成要件）→ 重新理解法条；记忆遗忘（记得学过但想不起内容）→ 间隔复习；审题错误（如漏看「不正确」这类限定词）→ 审题训练；推理失误（推理链条断裂）→ 分析逻辑训练；粗心失误（如看错选项字母）→ 养成检查习惯。
    • 系统性错误三条标准：同一知识点出错2次及以上（多半是理解偏差或记忆遗忘）；同一错因在不同知识点重复出现（可能是审题或推理的方法问题）；某一学科错题占比明显偏高（该学科有系统性薄弱环节）。
    • 错题少于5道时提示「错题数量较少，分析结论可能不够准确，建议积累更多错题后再分析」。
    • 来源不明的错题标「来源不明」，仍纳入分析但降低权重；学员没给自述错因的，只按答案偏差推断错因，标 [推断]。

    产出

    「错误模式分析报告」：错题概览、主要发现、系统性错误清单、偶然错误清单，附按学科、错因、知识点三个维度的统计表。

  2. 知识薄弱点诊断

    可单独使用

    在错误模式的基础上，把薄弱点定位到学科、章节、知识点，评估严重程度，排出补强优先级。

    请律师核对

    • 核对 2.1评分只给了各因素的定性档（如出错3次及以上为严重），没有规定怎样换算成分数，「80分及以上」等分数段无法直接算出；错误类型只给了知识盲区、理解偏差、记忆遗忘三类的档次，其余四类怎样计分没有规定。
    • 核对 2.2前置知识检查把「犯罪形态」的检查方法写成「测试四要件」，是否与所用教材的犯罪构成体系一致？是否补充行政法、诉讼法、商法的前置关系？
    • 核对 2.3时间紧迫度以「距考试不足60天且未掌握」为严重，与第 4 步「距考试不足30天」的口径不同，是否统一？

    做法

    1. 读学员档案的各学科自评分和历史成绩，以及法考高频法条引用库；最好以第 1 步的错误模式分析结果为输入。
    2. 分三个层次定位：哪个学科错题最多（薄弱学科排序）、学科内哪一章或哪一编出错最多（薄弱章节排序）、具体哪个知识点反复出错（薄弱知识点清单）。
    3. 填薄弱点定位表：学科、章节、知识点、出错次数、错因、考点级别、严重程度。规则里的示例：民法·合同编·合同法定解除，出错3次，理解偏差，A 级，严重；刑法·总则·犯罪形态，2次，知识混淆，A 级，较重；商法·公司法·股东出资，1次，记忆遗忘，B 级，中等。
    4. 按四项因素加权评分，分为红、橙、黄、绿四级（见内置规则）。
    5. 查前置知识（四组对应见内置规则），画出关联薄弱点，区分「可能关联（待检查）」与「关联（需确认是否掌握）」，例如合同解除（红级）可能关联合同效力，并关联违约责任。
    6. 与学员自评对照，标「一致」或「不一致」（如「自评偏高」），差距大的讨论原因、以错题数据为主；写出诊断报告：各级薄弱点个数、优先级排序表（含建议补强时间）、关联分析、与自评对照、补强建议概要（详细方案在第 3 步）。

    内置规则

    • 加权评分：出错频率占30%（出错3次及以上为严重、2次较重、1次中等）；考点级别占30%（A 级严重、B 级较重、C 级中等）；错误类型占20%（知识盲区严重、理解偏差较重、记忆遗忘中等）；时间紧迫度占20%（距考试不足60天且未掌握为严重）。
    • 四级划分：80分及以上为红级（严重：高频考点且反复出错，立即补强）；60-79分为橙级（较重：重要考点且多次出错，优先补强）；40-59分为黄级（中等：有一定基础但不稳定，正常补强）；不足40分为绿级（轻微：偶尔出错、基础尚可，复习巩固）。
    • 前置知识四组：合同解除 ← 合同效力（测试合同有效要件）；善意取得 ← 物权变动（测试登记或交付生效）；犯罪形态 ← 犯罪构成（测试四要件）；管辖 ← 法律关系定性（测试法律关系识别）。
    • 错题数据不足以定位的，建议补做特定学科的自测题；薄弱点超过10个的，建议分批补强，每批聚焦3-5个。
    • 诊断与自评差距大时，讨论差距原因，以错题数据为主要依据；所有法条引用标 [待验证]。

    产出

    「知识薄弱点诊断报告」：按优先级排序的薄弱知识点表、前置知识与关联薄弱点、补强建议概要；完整版另含四级总览和自评对照。

  3. 针对性补强方案

    可单独使用

    把诊断结果变成个性化、可执行的补强方案：每个薄弱点的补强任务、方法、时间安排和检验标准。

    请律师核对

    • 核对 3.1每个知识点的用时估计（知识盲区2-3小时、知识混淆和理解偏差1-2小时、记忆遗忘0.5-1小时）是否符合学员实际？
    • 核对 3.2补强强度的时间占比是按每个知识点算，还是按该级别合计算，没有说明；多个红级知识点同时存在时怎样封顶，也没有规定。
    • 核对 3.3推理失误的补强办法是「案例研习+IRAC训练」，是否与贵机构的主观题答题结构一致？「距考试时间极短」没有量化。

    做法

    1. 读学员档案的每日学习时间和学习风格，以及法考高频法条引用库；最好以第 2 步的诊断报告为输入。
    2. 按错因选补强办法和用时，按薄弱程度定补强强度（对应表见内置规则）。
    3. 每个知识点排四步补强任务：知识回顾（读教材相关章节、整理要点）→ 理解深化（涉及混淆的做对比记忆表，分析1-2个典型案例）→ 巩固练习（做针对性练习题，错题整理进错题本）→ 自测检验（自测正确率达到80%才算完成）。
    4. 排补强顺序表（知识点、补强办法、预计用时、计划完成日期），前置知识薄弱点排在前面；再排每日安排：分时间段安排补强、日常学习、自测三类任务，列出今日补强重点和明日预告。
    5. 按知识点推荐资源：教材（名称和章节）、记忆技巧（如对比记忆法）、练习题（推荐范围）、案例（分析某类案例）。
    6. 特殊情形：补强量超出可用时间的，按优先级裁剪，保留红级和橙级任务；某知识点补强后仍出错的，升级补强办法（如从记忆复习升级为重新学习）；距考试时间极短的，只补 A 级高频考点。

    内置规则

    • 错因与补强办法（六类）：知识盲区—系统学习（教材学习+知识图谱+记忆技巧，每个知识点2-3小时）；知识混淆—对比辨析（对比记忆表+辨析练习，每个知识点1-2小时）；理解偏差—重新理解（重读教材+案例分析+老师讲解，每个知识点1-2小时）；记忆遗忘—强化复习（间隔复习+自测+记忆卡片，每个知识点0.5-1小时）；审题错误—审题训练（审题清单+专项练习，持续训练）；推理失误—逻辑训练（案例研习+IRAC训练，持续训练）。粗心失误没有对应办法。
    • 补强强度按每日学习时间的占比：红级（严重）高强度、集中突破，30-40%；橙级（较重）中高，20-30%；黄级（中等）中等，10-20%；绿级（轻微）低强度、复习巩固，5-10%。
    • 完成标准：自测正确率达到80%及以上。
    • 检查清单：每个薄弱知识点都有补强任务；办法与错因匹配；用时与每日可用时间匹配；每项任务有明确检验标准；时间安排已排出；前置知识薄弱点已优先安排。

    产出

    「针对性补强方案」：补强总览表、每个知识点的四步补强任务、每日或每周时间安排、效果检验（自测标准和完成标志）。

  4. 进步追踪与自测

    可单独使用

    追踪补强方案的执行和效果，用定期自测检验成果，出阶段评估报告，并据此调整后续补强办法。

    请律师核对

    • 核对 4.1「提升20%」没有说明是百分点还是相对增幅；规则示例 30%→60%（+30%）被评为「部分有效」，与「提升20%及以上即有效」的标准矛盾。
    • 核对 4.2升级路径把「案例分析」排在「系统学习」之上、「教师辅导」为最高级，是否符合贵机构的带教做法？本步和第 3 步举例都写「升级为重新学习」，路径里并没有这一级。
    • 核对 4.3距考试不足30天就「放弃绿级」是否合适？学员档案「升级规则」里「某学科连续3次自测正确率低于50%，建议寻求专业教师辅导该学科」没有被本步引用。

    做法

    1. 读学员档案的学习进度追踪记录和自测成绩。
    2. 更新补强任务完成表：计划完成日期、实际完成日期、完成状态（已完成、进行中、未开始）、自测正确率及变化（如从40%升到85%）。
    3. 算进度指标：补强任务总数，已完成（补完且自测达标）、进行中、未开始各几项，完成率（已完成占总数的比例），自测达标率（自测正确率达到80%的比例）。
    4. 按四个维度评估效果（标准见内置规则），填效果评估表：补强前正确率、补强后正确率、变化幅度、效果评级。规则里的示例：40%→85%（+45%）有效；30%→60%（+30%）部分有效；50%→55%（+5%）无效。
    5. 按评级调整：有效的维持当前办法，可以进入下一个知识点；部分有效的加大练习量、延长补强时间；无效的沿升级路径往上升（如从记忆升级为重新学习），或建议找老师辅导。
    6. 写出阶段评估报告：补强进度总览、补强效果、学科层面变化（阶段初与当前正确率）、调整建议、下阶段计划、与考试时间对照（距考试天数、剩余未补强知识点数、是否来得及或要调整办法）。

    内置规则

    • 效果三级：自测正确率提升20%及以上为有效、10-20%为部分有效、不足10%为无效；再次出错率低于10%为有效、10-30%为部分有效、高于30%为无效；另看答题速度（明显提升、略有提升、无明显变化）和自信度（高、中、低）。
    • 自测达标线：自测正确率80%。
    • 升级路径由低到高五级：记忆复习 → 对比辨析 → 系统学习 → 案例分析 → 教师辅导。
    • 没有自测数据的不做评估，建议先完成一轮自测；全部知识点补强有效的，肯定进步，建议进入下一阶段学习。
    • 距考试不足30天而补强没做完：建议集中补红级（严重）薄弱点，放弃绿级（轻微）。

    产出

    「进步追踪报告」：补强进度表、补强前后效果对比、调整建议、下阶段计划；阶段评估报告另含学科层面变化和与考试时间的对照。

07交付前检查

  • 错误模式：每道错题都已登记并归入一类错因，按学科、错因、知识点三个维度统计完毕；系统性错误已识别，偶然错误已排除在重点分析之外。
  • 薄弱点：已按学科、章节、知识点定位，按红、橙、黄、绿四级评估；前置知识检查和关联薄弱点已完成，优先级已排序，已与学员自评对照。
  • 补强方案：每个薄弱知识点都有补强任务，办法与错因匹配，用时与每日可用时间匹配，每项任务有明确的检验标准，前置知识薄弱点优先安排。
  • 进步追踪：任务完成情况和自测正确率变化已更新，效果按有效、部分有效、无效三级评估，已给出调整建议并与考试时间对照。
  • 所有法条引用标 [待验证]，成果带教育声明和工作产物标记。

08何时暂停或升级

  • 没有学员档案或仍有未填写的项：先提示，由学员选择做冷启动访谈或进入临时模式。
  • 错题少于5道：提示分析结论可能不够准确，建议积累更多错题后再分析。
  • 错题数据不足以定位薄弱点：建议补做特定学科的自测题；薄弱点超过10个：建议分批补强，每批聚焦3-5个。
  • 补强量超出可用时间：按优先级裁剪，保留红级和橙级任务。
  • 补强后仍出错或评为无效：升级补强办法，最高一级是教师辅导，也可以直接建议找老师辅导。
  • 距考试不足30天而补强没做完：集中补红级、放弃绿级；距考试时间极短：只补 A 级高频考点。
