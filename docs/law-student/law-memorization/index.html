01概要

帮学员系统记忆法考核心法条、提升客观题的法条应用能力，分四步：先搭法考学科全景与单学科编/章/节知识图谱；再按近5年考查频率把法条分为 A/B/C/D 四级，对 A 级标注构成要件、易混淆点和考查陷阱；然后按知识点特征选用对比、联想、口诀、案例串联、图表、数字编码等技巧生成记忆卡片；最后按 1/3/7/14/30 天的间隔制定每日与每周复习计划，每轮出5-10道自测题并追踪记忆强度。开始前读学员档案 law-student/CLAUDE.md：薄弱学科决定先做哪科、清单如何排序，学习风格决定技巧选择，备考阶段与每日可用时间决定清单范围（冲刺阶段只出 A 级）和复习时长。法条锚点取自插件的法考高频法条引用库，所有条文号标 [待验证]，口诀与联想须提醒学员回归法条原文。产出知识图谱、重点法条清单、记忆卡片和复习计划四类学习材料。

02适用与边界

适用场景

  • 学员开始系统学习某一学科，需要先建立体系框架：/law-student:legal-system-mapping [学科名称]
  • 时间有限，需要确定先背哪些法条：/law-student:key-provision-identification [学科名称]
  • 某些易混淆的知识点总记不住，需要对比表、口诀或记忆卡片：/law-student:memory-technique-application [法条或知识点]
  • 需要按遗忘曲线安排每日/每周复习并自测：/law-student:spaced-repetition-review [学科名称或法条范围]
  • 进入冲刺阶段或距考试时间不足，需要聚焦 A 级高频考点

不做什么

  • 不构成法律建议：法条内容以教材和国家法律法规数据库为准；记忆效果因人而异，建议结合教材系统学习
  • 不保证考频：频率分级为参考性质，不保证当年一定考查或不考查 [待验证]
  • 不以口诀代替法条：法考答题时须引用完整法条内容，不能只写口诀
  • 不一次铺开所有学科：学员要求一次生成所有学科的图谱或完整清单时，建议逐学科生成，避免信息过载
  • 不编造条文号：所有具体条文号须标 [待验证]，建议学员对照教材核实

03输入与产出

需要律师提供

  • 学科名称或知识点必需
    图谱与重点清单按学科、一次一科；记忆技巧按具体法条或知识点；间隔复习按学科或复习的法条范围
  • law-student/CLAUDE.md 学员档案可选
    缺失或含 [PLACEHOLDER] 时提示访谈或临时模式；图谱读薄弱学科，重点识别读薄弱学科与备考阶段，记忆技巧读学习风格，间隔复习读备考阶段与每日可用学习时间
  • 上一轮自测结果与记忆追踪记录可选
    间隔复习据此评定记忆强度（强/中/弱/极弱）并调整下次复习间隔

产出

  • 知识图谱给学员
    教育声明 + 学科概览（核心法律及版本、体系结构X编X章X条、法考分值）+ 编/章/节树状图谱（核心法条 [待验证]、关联法条、考点关键词、高频标记）+ 核心关联 + 基于学员档案的学习建议
  • 重点法条清单给学员
    教育声明 + A级表（条文、考点、构成要件、易混淆点）+ B级同格式 + C级简化格式 + 本学科常见陷阱提醒
  • 记忆卡片给学员
    每个知识点一张：法条依据 [待验证] / 核心内容 / 记忆技巧 / 易混淆点 / 自测问题；卡片末附三项自测（能否不看法条复述核心内容、能否区分易混淆的知识点、能否在案例中正确适用）
  • 复习计划给学员
    今日复习内容表（知识点、复习轮次、记忆强度、预计用时）+ 5-10道自测题 + 自测后查看的答案与解析 + 明日预告；另有每日计划的时间分配、周计划表与记忆追踪表

04开始前

前置条件

  • 读取 law-student/CLAUDE.md；缺失或仍有 [PLACEHOLDER] 时显示标准提示：运行 /law-student:cold-start-interview（约5分钟），或说「临时模式」使用通用默认值并在输出上标 [临时模式]（入口未单列默认值，配置契约 3.3 有临时模式默认值表）
  • 统一读取三份共享资源：引用规范、法考高频法条引用库、学员配置契约
  • 推荐顺序：体系图谱（建立框架）→ 重点识别（确定优先级）→ 记忆技巧（高效编码）→ 间隔复习（长期巩固），四步均可单独触发

硬性规则

教育声明
所有记忆训练输出标注「[教育声明：本内容仅供法考学习参考，法条内容请以教材和国家法律法规数据库为准。]」，并带工作产物标记「法考学习材料 — 仅供学习参考，不构成法律建议」
条文号待验证
所有具体条文号须标 [待验证]，建议学员对照教材核实；条号不确定时写「《XX法》关于[规则描述]的规定」
口诀与联想的简化风险
记忆口诀和联想方法可能过度简化法律规则，须提醒学员回归法条原文；不得因记忆训练而产生对法条的错误理解

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置假设，可逐条复制。页面里的英文标记见首页「标记与术语」。

  1. 法律体系与部门法知识图谱

    /law-student:legal-system-mapping可单独运行

    搭建法考学科全景和单学科的编/章/节知识图谱，标注法条之间的关联与跨学科关联，让学员在体系框架中记忆法条（孤立记忆效果远不如体系记忆）。

    请律师核对

    • 核对 1.1分值表与备考优先级是模型回忆、全部 [待验证]——请按当年大纲与真题替换。
    • 核对 1.2「客观题卷一公法、卷二私法」与主观题三类题型的结构是否与当年考试一致？
    • 核对 1.3民法总则编各部分的条文范围（第1-12条、第13-56条、第57-101条、第133-160条、第161-175条、第188-199条）请核对；跨学科关联「请求权类型决定管辖法院」「劳动合同特殊规定优先」等概括是否准确？

    做法

    1. 读学员档案中的薄弱学科（优先生成薄弱学科的图谱），读引用规范与引用库。
    2. 给出法考学科全景：客观题（卷一：公法 + 卷二：私法）十个学科——民法（民法典7编1260条）、刑法（总则+分则）、行政法与行政诉讼法、民事诉讼法、刑事诉讼法、商法、经济法、国际法、理论法学、法律职业道德；主观题——案例分析题（民法/刑法/诉讼法/商法）、法律文书题、论述题。
    3. 给出各学科客观题大约分值、主观题涉及频度与备考优先级参考表（见规则），并注「以上分值为参考，实际以当年大纲和真题为准 [待验证]」。
    4. 按「学科 → 编/章 → 节 → 核心法条（《XX法》第X-X条 [待验证]）/ 关联法条 / 考点关键词」模板构建单学科图谱。
    5. 民法示例按七编展开，总则编标注条文范围：基本规定第1-12条、自然人第13-56条、法人第57-101条、民事法律行为第133-160条、代理第161-175条、诉讼时效第188-199条（均 [待验证]），物权编所有权下列善意取得第311条 [待验证]。
    6. 用高频标记标出重点节点（原文用星号标注）；民法示例标在民事法律行为、代理、诉讼时效、物权编、担保物权、合同编、合同终止（解除）、违约责任、侵权责任编。
    7. 标注五类法条关联：总分（民法典总则编与各分编）、前后（合同成立 → 合同效力 → 合同履行 → 违约责任）、交叉（合同违约与侵权竞合）、例外（物权变动登记生效原则 + 法律另有规定例外）、对比（无效 vs 可撤销 vs 效力待定）。
    8. 说明跨学科关联：民法 ↔ 商法（商事合同适用民法典合同编）、民法 ↔ 民事诉讼法（请求权类型决定管辖法院）、刑法 ↔ 刑事诉讼法（犯罪类型影响追诉程序）、行政法 ↔ 行政诉讼法（行政行为类型决定可诉性）、民法 ↔ 劳动法（劳动合同特殊规定优先）。
    9. 按模板输出：学科概览（核心法律与版本、体系结构、法考分值）、知识图谱、核心关联、基于学员档案的学习建议。

    内置规则

    • 分值参考表（全部 [待验证]）：民法约40-50分、主观题高频、优先级高；刑法约35-45分、高频、高；民事诉讼法约15-20分、高频、中高；刑事诉讼法约15-20分、中频、中高；行政法与行政诉讼法约15-20分、中频、中高；商法约15-20分、中频、中；经济法约10-15分、低频、中；国际法约8-12分、低频、中低；理论法学约15-20分、论述题、中；法律职业道德约5-8分、低频、低
    • 学员要求一次生成所有学科图谱 → 建议逐学科生成，避免信息过载
    • 学科法律近期有修订 → 标注「该法近期修订，请注意新旧条文差异」
    • 学员对某个子领域特别薄弱 → 在该子领域展开更详细的图谱
    • 检查清单：已确认需要重点构建的学科；图谱按编/章/节结构生成；核心法条含 [待验证]；高频考点已标记；五类关联已标注；跨学科关联已说明

    法律依据

    • 《民法典》第133-160条 — 民事法律行为（含第143条有效要件），民法图谱的高频节点 [待验证]
    • 《民法典》第161-175条 — 代理，民法图谱的高频节点 [待验证]
    • 《民法典》第188-199条 — 诉讼时效，民法图谱的高频节点 [待验证]
    • 《民法典》第311条 — 善意取得，物权编所有权节点 [待验证]

    产出

    「[学科] 知识图谱」Markdown：教育声明 + 学科概览 + 树状知识图谱 + 核心关联 + 学习建议

  2. 重点法条识别与高频考点

    /law-student:key-provision-identification可单独运行

    按考查频率把法条分为 A/B/C/D 四级，对 A 级法条标注构成要件、易混淆点和考查陷阱，让学员在有限时间里先记最可能考的法条。

    请律师核对

    • 核对 2.1C级「近5年考查1-2次」与D级「近5年未考查或仅考过一次」在「考过一次」上重叠，A级「几乎每年」与B级「3次以上」界限也不清——请确认分级口径。
    • 核对 2.2第563条考点写「五种法定解除情形」，引用库只列（一）至（四）四项，口诀也只覆盖四项——请统一并核对。
    • 核对 2.3善意取得写「构成要件四要素」，与多方论证步骤「三要件 vs 四要件，以通说为准」不一致——训练采用哪种口径？
    • 核对 2.4示例清单是模型回忆的框架（全部 [模型知识 — 需验证]），是否由老师用本机构的考频统计或当年大纲替换？

    做法

    1. 读学员档案的薄弱学科与备考阶段，读引用规范和引用库。
    2. 按四级标准分级（见规则），判定依据按优先级递减：当年考试大纲明确列出的考点 → 近5年真题考查情况 → 主流辅导教材的重点标注 → 司法解释新增内容（新增法条考查概率较高）。
    3. 生成学科高频法条表：级别 / 条文（「《XX法》关于…… [第X条，待验证]」）/ 考点 / 考查形式（客观题、主观题）/ 来源标签 / 验证状态；民法、刑法各有示例框架（见法律依据）。
    4. 对每条 A 级法条做五项深度标注：法条原文要点（明确记忆目标）、构成要件（主观题答题框架）、易混淆点（对比记忆）、常见考查陷阱（应试技巧）、须一并记忆的关联法条（体系记忆）。
    5. 汇总本学科常见考查陷阱（见规则）。
    6. 按学员薄弱学科优先排列清单；学员处于冲刺阶段时只生成 A 级清单，聚焦最高频考点。
    7. 按模板输出：A级表（条文、考点、构成要件、易混淆点）、B级同格式、C级简化格式、常见陷阱提醒。

    内置规则

    • A级（高频必考，原文标三颗星）：近5年几乎每年考查，主观题也可能涉及 → 必须熟练记忆
    • B级（中频常考，两颗星）：近5年考查3次以上，客观题常出现 → 需要准确记忆
    • C级（低频选考，一颗星）：近5年考查1-2次，偶尔出现 → 理解即可，不必强记
    • D级（极少考查，无标记）：近5年未考查或仅考过一次 → 了解存在即可
    • 频率分级为参考性质，不保证当年一定考查或不考查 [待验证]
    • 常见陷阱：民法「善意」的认定标准（不同制度中含义不同）；民法诉讼时效与除斥期间（混淆两者的起算和法律效果）；刑法此罪与彼罪的界限（如盗窃vs侵占、抢劫vs敲诈勒索）；刑法犯罪形态（预备/未遂/中止/既遂的区分标准）；行政法可诉与不可诉的界限（受案范围的排除事项）；商法股东有限责任的例外（法人人格否认的适用条件）
    • 大纲调整导致考点变化 → 标注「注意：当年大纲可能有调整，请以最新大纲为准 [待验证]」；学员要求所有学科的完整清单 → 建议逐学科生成

    法律依据

    • 《民法典》第143条 — 民事法律行为效力，A级，考点「有效要件三要素」[模型知识 — 需验证] [待验证]
    • 《民法典》第311条 — 善意取得，A级，考点「构成要件四要素」[模型知识 — 需验证] [待验证]
    • 《民法典》第563条 — 合同法定解除，A级，考点「五种法定解除情形」[模型知识 — 需验证] [待验证]
    • 《民法典》第577条 — 违约责任，A级，考点「违约责任承担方式」[模型知识 — 需验证] [待验证]
    • 《民法典》第172条 — 表见代理，B级，考点「构成要件」[模型知识 — 需验证] [待验证]
    • 《民法典》第496-498条 — 格式条款，B级，考点「提示义务+无效+解释规则」[模型知识 — 需验证] [待验证]
    • 《民法典》第686-687条 — 保证方式，C级，考点「一般保证vs连带保证」[模型知识 — 需验证] [待验证]
    • 《刑法》第20条 — 正当防卫，A级，考点「防卫限度+特殊防卫」[模型知识 — 需验证] [待验证]
    • 《刑法》第25-29条 — 共同犯罪，A级，考点「主犯从犯胁从犯教唆犯」[模型知识 — 需验证] [待验证]
    • 《刑法》关于盗窃罪、诈骗罪的规定（清单未给条号）— A级，考点「构成要件+此罪彼罪」[模型知识 — 需验证] [待验证]
    • 《刑法》关于犯罪中止与未遂的规定（清单未给条号）— B级，考点「区分标准」[模型知识 — 需验证] [待验证]

    产出

    「[学科] 重点法条清单」Markdown：教育声明 + A级表 + B级表 + C级简化表 + 常见陷阱提醒

  3. 记忆技巧应用

    /law-student:memory-technique-application可单独运行

    根据知识点特征和学员偏好选用记忆技巧，把法条编码成对比表、联想、口诀、案例串联或图表，并为每个知识点生成带自测问题的记忆卡片。

    请律师核对

    • 核对 3.1口诀原则写「不超过10个字为佳」，示例「不可抗力预期违，催告迟延目的灭」为14字，且只覆盖四种解除情形。
    • 核对 3.2正当防卫口诀「正在不法为防卫」只覆盖三项，没有涉及重点清单里的 A 级考点「防卫限度」——是否补全？
    • 核对 3.3对比表的简化短语（自始无效/撤销后无效/追认后有效；可变期间vs不变期间；占有转移方式不同）是否准确、会否误导学员？
    • 核对 3.4流程图「判决 → 上诉（15日内）」没有标 [待验证]，也未注出处——请确认该期限及适用范围。

    做法

    1. 读学员学习风格偏好（视觉/听觉/读写/实践）与引用规范；开始前提醒：记忆口诀和联想方法可能过度简化法律规则，须回归法条原文。
    2. 按六类技巧的适用场景选择方法（见规则）。
    3. 对比记忆：按「定义 / 适用条件 / 法律效果 / 记忆关键词」四行填写概念A与概念B的对比表并写出关键区别，可直接使用内置的七组对比（见规则）。
    4. 联想记忆：用谐音联想、场景联想、故事串联给抽象内容编码；联想只是辅助工具，须个人化，不得产生对法条的错误理解。
    5. 口诀记忆：按准确性（准确反映法条核心内容）、简洁性（不超过10个字为佳）、完整性（不遗漏关键要素）三原则编写，每个口诀附含义和「须回归第X条原文 [待验证]」的注意事项。
    6. 案例串联：用一个综合案例串起多个关联法条，如「甲与乙签订买卖合同（合同成立/效力）→ 甲交付的货物质量不合格（违约/质量瑕疵）→ 乙发现货物为丙所有（善意取得/物权）→ 丙要求返还（物权请求权/侵权）」；案例须符合法律逻辑、事实合理，每个法条在案例中有明确对应。
    7. 图表记忆：程序性知识用流程图（示例：起诉 → 受理 → 举证 → 开庭 → 判决 → 上诉（15日内）→ 二审 → 执行），体系性知识用思维导图（沿用知识图谱格式），并列知识点用对比表。
    8. 为每个知识点生成记忆卡片：法条依据 [待验证] / 核心内容 / 记忆技巧 / 易混淆点 / 自测问题；卡片末附三项自测：能否不看法条复述核心内容、能否区分易混淆的知识点、能否在案例中正确适用。

    内置规则

    • 六类技巧：对比记忆（易混淆的法条/概念；区分度高，但须先理解两者）；联想记忆（抽象概念、构成要件；生动但可能偏离原意）；口诀记忆（多项列举，如权利类型、期限；有过度简化风险）；案例串联（关联性强的多个法条；案例本身须准确）；图表记忆（体系结构、程序流程；制作成本较高）；数字编码（含期限/比例/数额的法条；适用范围有限）
    • 内置对比组：无效 vs 可撤销 vs 效力待定（自始无效/撤销后无效/追认后有效）；一般保证 vs 连带保证（先诉抗辩权有无）；盗窃 vs 侵占 vs 抢劫（占有转移方式不同）；犯罪中止 vs 犯罪未遂（是否出于意志以外原因）；行政拘留 vs 刑事拘留 vs 司法拘留（性质和决定机关不同）；诉讼时效 vs 除斥期间（可变期间vs不变期间）；上诉 vs 申诉 vs 申请再审（程序和效果不同）
    • 内置口诀：民事法律行为有效要件「能力真实不违反」（行为能力+意思表示真实+不违反强制性规定，须回归第143条原文 [待验证]）；合同法定解除情形「不可抗力预期违，催告迟延目的灭」（不可抗力+预期违约+迟延经催告+目的不能实现，须回归第563条原文 [待验证]）；正当防卫要件「正在不法为防卫」（正在进行+不法侵害+防卫行为，须回归第20条原文 [待验证]）
    • 口诀仅为记忆辅助，法考答题时须引用完整法条内容，不能仅写口诀
    • 学员偏好某种记忆方法 → 优先使用该方法；知识点不适合口诀化 → 改用对比记忆或案例串联；口诀可能导致误解 → 明确标注「口诀简化，须回归原文」

  4. 间隔复习与自测

    /law-student:spaced-repetition-review可单独运行

    按遗忘曲线制定每日与每周复习计划，每轮生成5-10道自测题，根据自测表现追踪记忆强度并动态调整复习间隔。

    请律师核对

    • 核对 4.11/3/7/14/30 天间隔对应的预期保持率（约80%/85%/90%/93%/95%）没有出处，是否保留具体百分比？
    • 核对 4.2记忆强度有两套口径（按正确与流畅度、按3秒/10秒作答时间），以哪套为准？延长或缩短间隔的幅度 SKILL.md 未规定。
    • 核对 4.3「距考试时间不足」没有天数阈值；记忆追踪表存放在哪里（是否写回档案「学习进度追踪」）SKILL.md 未规定。

    做法

    1. 读学员档案的备考阶段和每日可用学习时间，读引用规范。
    2. 按五次复习间隔排期（见规则）。
    3. 生成每日计划：今日复习内容（序号、知识点、所属学科、复习轮次、上次自测结果、预计用时）、今日新学内容（按 A/B/C 级优先级）、时间分配（复习/新学/自测，总计不超过每日可用学习时间）。
    4. 生成周计划：周一至周五各安排复习内容、新学内容和自测范围，周六做周综合自测，周日弹性复习、查漏补缺。
    5. 按四种题型出自测题：填空式（记忆法条核心内容）、判断式（检验易混淆知识点）、选择式（模拟法考客观题）、简述式（检验理解深度，如「简述善意取得的构成要件」）。
    6. 出题规则：每轮5-10道；覆盖当前复习轮次的所有知识点；优先出 A 级高频考点；记忆强度弱的知识点出更多变体题；法条引用标 [待验证]；答案折叠，自测后再对照。
    7. 按自测表现评定记忆强度并调整下次间隔（见规则），更新记忆追踪表（知识点 / 学习日期 / 复习1–4 / 当前强度 / 下次复习）。
    8. 按模板输出：今日复习内容、自测题、答案（自测后查看）、明日预告。

    内置规则

    • 间隔与预期记忆保持率：第1次复习1天后（约80%）；第2次3天后（约85%）；第3次7天后（约90%）；第4次14天后（约93%）；第5次30天后（约95%）——注「以上数值为参考，实际记忆效果因个人差异而异」
    • 按结果调整：完全正确且流畅 → 强 → 延长间隔；基本正确但不够流畅 → 中 → 维持当前间隔；有明显遗忘 → 弱 → 缩短间隔；几乎全部遗忘 → 极弱 → 重新学习
    • 按作答时间评定：3秒内准确回答 → 强（延长间隔）；10秒内回答但有犹豫 → 中（维持）；需要思考较长时间 → 弱（缩短）；无法回答或回答错误 → 极弱（重新学习该知识点）
    • 某天无法完成复习计划 → 记录未完成内容，合并到次日复习
    • 某知识点连续3次自测「极弱」→ 建议回到记忆技巧步骤重新编码记忆
    • 距考试时间不足 → 压缩复习间隔，聚焦 A 级高频考点

    产出

    「间隔复习计划 — [学科/日期]」Markdown：教育声明 + 今日复习内容表 + 5-10道自测题 + 自测后查看的答案与解析 + 明日预告；另可输出周计划表与记忆追踪表
