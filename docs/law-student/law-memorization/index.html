01概要

帮学员系统记忆法考核心法条、提高客观题的法条运用能力，分四步：搭建学科全景和单学科编、章、节知识图谱；按近5年考查频率把法条分为 A、B、C、D 四级，对 A 级标注构成要件、易混淆点和考查陷阱；按知识点特点选用对比、联想、口诀、案例串联、图表、数字编码等技巧，做成记忆卡片；按1、3、7、14、30天的间隔排复习，每轮出5-10道自测题并追踪记忆强度。学员档案里的薄弱学科决定先做哪一科、清单怎样排序，学习风格决定技巧选择，备考阶段和每日学习时间决定清单范围（冲刺阶段只出 A 级）和复习时长。法条取自法考高频法条引用库，条文号一律标 [待验证]，口诀和联想都提醒学员回到法条原文。产出知识图谱、重点法条清单、记忆卡片和复习计划四类学习材料。

02适用与边界

适用场景

  • 学员开始系统学一门学科，需要先搭体系框架：做第 1 步，给学科名称
  • 时间有限，要先确定背哪些法条：做第 2 步，给学科名称
  • 易混淆的知识点总记不住，需要对比表、口诀或记忆卡片：做第 3 步，给法条或知识点
  • 要按遗忘曲线安排每日、每周复习并自测：做第 4 步，给学科或复习的法条范围
  • 进入冲刺阶段或离考试时间不多，需要聚焦 A 级高频考点

不做什么

  • 不构成法律建议：法条内容以教材和国家法律法规数据库为准；记忆效果因人而异，建议结合教材系统学习
  • 不保证考频：频率分级只作参考，不保证当年一定考或不考 [待验证]
  • 不以口诀代替法条：法考答题须引用完整法条内容，不能只写口诀
  • 不一次铺开所有学科：学员要求一次生成所有学科的图谱或完整清单时，建议逐科生成，避免信息过载
  • 不编造条文号：所有具体条文号都标 [待验证]，建议学员对照教材核实

03输入与产出

需要提供

  • 学科名称或知识点必需
    图谱和重点清单一次一科；记忆技巧针对具体法条或知识点；复习按学科或法条范围
  • 学员档案可选
    读薄弱学科、备考阶段、学习风格、每日学习时间；未建档时先提示访谈或临时模式
  • 上一轮自测结果与记忆追踪记录可选
    第 4 步据此评定记忆强度（强、中、弱、极弱），调整下次复习间隔

产出

  • 知识图谱读者：学员
    教育声明、学科概览（核心法律及版本、体系结构几编几章几条、法考分值）、编章节树状图谱（核心法条 [待验证]、关联法条、考点关键词、高频标记）、核心关联、学习建议
  • 重点法条清单读者：学员
    教育声明、A 级表（条文、考点、构成要件、易混淆点）、B 级同格式、C 级简化格式、本学科常见陷阱提醒
  • 记忆卡片读者：学员
    每个知识点一张：法条依据 [待验证]、核心内容、记忆技巧、易混淆点、自测问题；末附三项自测（能否不看法条复述、能否区分易混点、能否在案例中正确适用）
  • 复习计划读者：学员
    今日复习表（知识点、复习轮次、记忆强度、预计用时）、5-10道自测题、自测后再看的答案与解析、明日预告；另有时间分配、周计划和记忆追踪表

04开始前

前置条件

  • 先读学员档案；档案缺失或仍有未填写的项时，显示标准提示：做冷启动访谈（约5分钟），或说「临时模式」用通用默认值，成果标「[临时模式]」（本流程没有单列默认值，按学员档案说明的临时模式默认值）
  • 统一读三份共用规则：法律依据引用规范、法考高频法条引用库、学员档案说明
  • 推荐顺序：体系图谱（建立框架）→ 重点识别（确定优先级）→ 记忆技巧（高效记忆）→ 间隔复习（长期巩固），四步都可以单独使用

硬性规则

教育声明
所有成果注明「[教育声明：本内容仅供法考学习参考，法条内容请以教材和国家法律法规数据库为准。]」，并带工作产物标记「法考学习材料 — 仅供学习参考，不构成法律建议」
条文号待验证
所有具体条文号都标 [待验证]，建议学员对照教材核实；条号不确定时写「《××法》关于（规则内容）的规定」
口诀不得失真
口诀和联想可能过度简化法律规则，须提醒学员回到法条原文；不得因记忆训练造成对法条的误解

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置判断，可逐条复制。

  1. 法律体系与部门法知识图谱

    可单独使用

    搭建学科全景和单学科编、章、节知识图谱，标出法条之间、学科之间的关联，让学员在体系中记法条（孤立记忆效果远不如体系记忆）

    请律师核对

    • 核对 1.1分值表与备考优先级是 AI 凭记忆写的、全部 [待验证]——请按当年大纲与真题替换。
    • 核对 1.2「客观题卷一公法、卷二私法」与主观题三类题型的结构，是否与当年考试一致？
    • 核对 1.3民法总则编各部分的条文范围（第1-12条、第13-56条、第57-101条、第133-160条、第161-175条、第188-199条）是否准确？
    • 核对 1.4跨学科关联「请求权类型决定管辖法院」「劳动合同特殊规定优先」等概括是否准确？

    做法

    1. 读学员档案里的薄弱学科，先做薄弱学科的图谱。
    2. 给出法考学科全景：客观题（卷一公法、卷二私法）十个学科——民法（民法典7编1260条）、刑法（总则、分则）、行政法与行政诉讼法、民事诉讼法、刑事诉讼法、商法、经济法、国际法、理论法学、法律职业道德；主观题——案例分析题（民法、刑法、诉讼法、商法）、法律文书题、论述题；并给各学科客观题大约分值、主观题涉及频度和备考优先级的参考表（见内置规则），注明「以上分值为参考，实际以当年大纲和真题为准 [待验证]」。
    3. 按「学科 → 编或章 → 节 → 核心法条（《××法》第×-×条 [待验证]）、关联法条、考点关键词」搭单学科图谱。民法示例按七编展开，总则编注明条文范围：基本规定第1-12条、自然人第13-56条、法人第57-101条、民事法律行为第133-160条、代理第161-175条、诉讼时效第188-199条（均 [待验证]），物权编所有权下列善意取得第311条 [待验证]。
    4. 标出高频节点；民法示例标在民事法律行为、代理、诉讼时效、物权编、担保物权、合同编、合同终止（解除）、违约责任、侵权责任编。
    5. 标出五类法条关联：总分（民法典总则编与各分编）、前后（合同成立 → 合同效力 → 合同履行 → 违约责任）、交叉（合同违约与侵权竞合）、例外（物权变动登记生效原则加「法律另有规定」的例外）、对比（无效、可撤销、效力待定）；再说明跨学科关联：民法与商法（商事合同适用民法典合同编）、民法与民事诉讼法（请求权类型决定管辖法院）、刑法与刑事诉讼法（犯罪类型影响追诉程序）、行政法与行政诉讼法（行政行为类型决定可诉性）、民法与劳动法（劳动合同特殊规定优先）。
    6. 写出学科概览（核心法律与版本、体系结构、法考分值）、知识图谱、核心关联和按学员档案给出的学习建议。

    内置规则

    • 分值参考表（全部 [待验证]）：民法约40-50分、主观题高频、优先级高；刑法约35-45分、高频、高；民事诉讼法约15-20分、高频、中高；刑事诉讼法约15-20分、中频、中高；行政法与行政诉讼法约15-20分、中频、中高；商法约15-20分、中频、中；经济法约10-15分、低频、中；国际法约8-12分、低频、中低；理论法学约15-20分、论述题、中；法律职业道德约5-8分、低频、低
    • 学员要求一次生成所有学科的图谱 → 建议逐科生成，避免信息过载
    • 学科法律近期有修订 → 注明「该法近期修订，请注意新旧条文差异」
    • 学员对某个子领域特别薄弱 → 在该子领域展开更细的图谱
    • 检查清单：已确认重点学科；图谱按编、章、节生成；核心法条含 [待验证]；高频考点已标记；五类关联已标注；跨学科关联已说明

    法律依据

    • 《民法典》第133-160条 — 民事法律行为（含第143条有效要件），民法图谱的高频节点 [待验证]
    • 《民法典》第161-175条 — 代理，民法图谱的高频节点 [待验证]
    • 《民法典》第188-199条 — 诉讼时效，民法图谱的高频节点 [待验证]
    • 《民法典》第311条 — 善意取得，物权编所有权下的节点 [待验证]

    产出

    「（学科）知识图谱」：教育声明、学科概览、树状知识图谱、核心关联、学习建议

  2. 重点法条识别与高频考点

    可单独使用

    把法条按考查频率分为 A、B、C、D 四级，A 级标注构成要件、易混淆点和考查陷阱，让学员在有限时间里先记最可能考的法条

    请律师核对

    • 核对 2.1C 级「近5年考查1-2次」与 D 级「近5年未考查或仅考过一次」在「考过一次」上重叠，A 级「几乎每年」与 B 级「3次以上」界限也不清——请确认分级口径。
    • 核对 2.2第563条的考点写「五种法定解除情形」，引用库只列（一）至（四）四项，口诀也只覆盖四项——请统一并核对。
    • 核对 2.3善意取得写「构成要件四要素」，与案例研习「多方观点论证与利益衡量」这一步的「三要件还是四要件，以通说为准」不一致——训练采用哪种口径？
    • 核对 2.4示例清单是 AI 凭记忆列的框架（全部 [模型知识 — 需验证]），是否由老师用本机构的考频统计或当年大纲替换？

    做法

    1. 读学员档案里的薄弱学科和备考阶段。
    2. 按四级标准分级（见内置规则），依据按优先级递减：当年考试大纲明确列出的考点 → 近5年真题考查情况 → 主流辅导教材的重点标注 → 司法解释新增内容（新增法条考查概率较高）。
    3. 列学科高频法条表：级别、条文（「《××法》关于……的规定 [第×条，待验证]」）、考点、考查形式（客观题、主观题）、来源标签、核实状态；民法、刑法各有示例（见法律依据）。
    4. 对每条 A 级法条做五项标注：条文要点（明确记什么）、构成要件（主观题答题框架）、易混淆点（对比记忆）、常见考查陷阱（应试技巧）、须一并记的关联法条（体系记忆）；并汇总本学科常见陷阱（见内置规则）。
    5. 按学员薄弱学科优先排列；学员处于冲刺阶段时只出 A 级清单，聚焦最高频考点。
    6. 写出 A 级表（条文、考点、构成要件、易混淆点）、B 级同格式、C 级简化格式和常见陷阱提醒。

    内置规则

    • 四级标准（以近5年为窗口）：A 级（高频必考，标三颗星）几乎每年考查、主观题也可能涉及 → 必须熟练记忆；B 级（中频常考，两颗星）考查3次以上、客观题常出现 → 需要准确记忆；C 级（低频选考，一颗星）考查1-2次、偶尔出现 → 理解即可，不必强记；D 级（极少考查，不标星）未考查或仅考过一次 → 了解存在即可
    • 频率分级只作参考，不保证当年一定考或不考 [待验证]
    • 常见陷阱：民法「善意」的认定标准（不同制度中含义不同）；诉讼时效与除斥期间（混淆两者的起算和法律效果）；刑法此罪与彼罪的界限（如盗窃与侵占、抢劫与敲诈勒索）；犯罪形态（预备、未遂、中止、既遂的区分标准）；行政法可诉与不可诉的界限（受案范围的排除事项）；商法股东有限责任的例外（法人人格否认的适用条件）
    • 大纲调整导致考点变化 → 注明「注意：当年大纲可能有调整，请以最新大纲为准 [待验证]」；学员要求所有学科的完整清单 → 建议逐科生成

    法律依据

    • 《民法典》第143条 — 民事法律行为效力，A 级，考点「有效要件三要素」[模型知识 — 需验证] [待验证]
    • 《民法典》第311条 — 善意取得，A 级，考点「构成要件四要素」[模型知识 — 需验证] [待验证]
    • 《民法典》第563条 — 合同法定解除，A 级，考点「五种法定解除情形」[模型知识 — 需验证] [待验证]
    • 《民法典》第577条 — 违约责任，A 级，考点「违约责任承担方式」[模型知识 — 需验证] [待验证]
    • 《民法典》第172条 — 表见代理，B 级，考点「构成要件」[模型知识 — 需验证] [待验证]
    • 《民法典》第496-498条 — 格式条款，B 级，考点「提示义务+无效+解释规则」[模型知识 — 需验证] [待验证]
    • 《民法典》第686-687条 — 保证方式，C 级，考点「一般保证与连带保证」[模型知识 — 需验证] [待验证]
    • 《刑法》第20条 — 正当防卫，A 级，考点「防卫限度+特殊防卫」[模型知识 — 需验证] [待验证]
    • 《刑法》第25-29条 — 共同犯罪，A 级，考点「主犯从犯胁从犯教唆犯」[模型知识 — 需验证] [待验证]
    • 《刑法》关于盗窃罪、诈骗罪的规定（清单未给条号）— A 级，考点「构成要件+此罪彼罪」[模型知识 — 需验证] [待验证]
    • 《刑法》关于犯罪中止与未遂的规定（清单未给条号）— B 级，考点「区分标准」[模型知识 — 需验证] [待验证]

    产出

    「（学科）重点法条清单」：教育声明、A 级表、B 级表、C 级简化表、常见陷阱提醒

  3. 记忆技巧应用

    可单独使用

    按知识点特点和学员偏好选用记忆技巧，把法条编成对比表、联想、口诀、案例串联或图表，并为每个知识点生成带自测问题的记忆卡片

    请律师核对

    • 核对 3.1口诀原则写「不超过10个字为佳」，示例「不可抗力预期违，催告迟延目的灭」为14字，且只覆盖四种解除情形——口诀或原则是否要改？
    • 核对 3.2正当防卫口诀「正在不法为防卫」只覆盖三项，没有涉及重点清单里的 A 级考点「防卫限度」——是否补全？
    • 核对 3.3对比表的简化短语（自始无效／撤销后无效／追认后有效；可变期间与不变期间；占有转移方式不同）是否准确，会不会误导学员？
    • 核对 3.4流程图「判决 → 上诉（15日内）」没有标 [待验证]，也没有注明出处——请确认该期限及适用范围。

    做法

    1. 读学员的学习风格偏好（视觉、听觉、读写、实践）；开始前提醒：口诀和联想可能过度简化法律规则，须回到法条原文。
    2. 按六类技巧的适用场景选方法（见内置规则）；对比记忆按「定义、适用条件、法律效果、记忆关键词」四行列出两个概念的对比并写明关键区别，可直接用内置的七组对比。
    3. 联想记忆用谐音、场景、故事给抽象内容编码，只作辅助、因人而异，不得造成对法条的误解；口诀按准确（反映法条核心内容）、简洁（不超过10个字为佳）、完整（不漏关键要素）三项原则编写，每个口诀附含义和「须回归第×条原文 [待验证]」的提醒。
    4. 案例串联用一个综合案例串起多个关联法条，如「甲与乙签订买卖合同（合同成立与效力）→ 甲交付的货物质量不合格（违约、质量瑕疵）→ 乙发现货物为丙所有（善意取得、物权）→ 丙要求返还（物权请求权、侵权）」；案例须符合法律逻辑、事实合理，每个法条在案例中都有明确对应。
    5. 图表记忆：程序性知识用流程图（示例：起诉 → 受理 → 举证 → 开庭 → 判决 → 上诉（15日内）→ 二审 → 执行），体系性知识用思维导图（沿用知识图谱的格式），并列知识点用对比表。
    6. 为每个知识点生成记忆卡片：法条依据 [待验证]、核心内容、记忆技巧、易混淆点、自测问题；卡片末附三项自测：能否不看法条复述核心内容、能否区分易混淆的知识点、能否在案例中正确适用。

    内置规则

    • 六类技巧：对比记忆（易混淆的法条或概念；区分度高，但须先理解两者）；联想记忆（抽象概念、构成要件；生动但可能偏离原意）；口诀记忆（多项列举，如权利类型、期限；有过度简化风险）；案例串联（关联性强的多个法条；案例本身须准确）；图表记忆（体系结构、程序流程；制作成本较高）；数字编码（含期限、比例、数额的法条；适用范围有限）
    • 内置七组对比：无效、可撤销与效力待定（自始无效／撤销后无效／追认后有效）；一般保证与连带保证（有无先诉抗辩权）；盗窃、侵占与抢劫（占有转移方式不同）；犯罪中止与犯罪未遂（是否出于意志以外的原因）；行政拘留、刑事拘留与司法拘留（性质和决定机关不同）；诉讼时效与除斥期间（可变期间与不变期间）；上诉、申诉与申请再审（程序和效果不同）
    • 内置口诀：民事法律行为有效要件「能力真实不违反」（行为能力+意思表示真实+不违反强制性规定，须回归第143条原文 [待验证]）；合同法定解除情形「不可抗力预期违，催告迟延目的灭」（不可抗力+预期违约+迟延经催告+目的不能实现，须回归第563条原文 [待验证]）；正当防卫要件「正在不法为防卫」（正在进行+不法侵害+防卫行为，须回归第20条原文 [待验证]）
    • 口诀只是记忆辅助，法考答题须引用完整法条内容，不能只写口诀
    • 学员偏好某种方法 → 优先用它；知识点不适合编口诀 → 改用对比记忆或案例串联；口诀可能导致误解 → 明确标注「口诀简化，须回归原文」

    法律依据

    • 《民法典》第143条 — 口诀「能力真实不违反」须回归的原文 [待验证]
    • 《民法典》第563条 — 口诀「不可抗力预期违，催告迟延目的灭」须回归的原文 [待验证]
    • 《刑法》第20条 — 口诀「正在不法为防卫」须回归的原文 [待验证]

    产出

    「（知识点）记忆卡片」：教育声明、法条依据、核心内容、记忆技巧、三项自测

  4. 间隔复习与自测

    可单独使用

    按遗忘曲线排每日和每周复习计划，每轮出5-10道自测题，按自测表现追踪记忆强度、动态调整复习间隔

    请律师核对

    • 核对 4.11、3、7、14、30天间隔对应的预期保持率（约80%、85%、90%、93%、95%）没有出处，是否保留具体百分比？
    • 核对 4.2记忆强度有两套口径（按正确与流畅程度、按3秒／10秒作答时间），以哪套为准？
    • 核对 4.3延长或缩短间隔的幅度没有规定——是否给出具体天数？
    • 核对 4.4「距考试时间不足」没有天数阈值——是否与档案升级规则的「距考试不足30天」一致？
    • 核对 4.5记忆追踪表存在哪里（是否写回档案「学习进度追踪」一章）没有规定。

    做法

    1. 读学员档案里的备考阶段和每日可用学习时间。
    2. 按五次复习间隔排期（见内置规则）；每日计划列今日复习（序号、知识点、学科、复习轮次、上次自测结果、预计用时）、今日新学（按 A、B、C 级优先）和时间分配（复习、新学、自测，合计不超过每日可用学习时间）。
    3. 周计划：周一至周五各排复习内容、新学内容和自测范围，周六做一周综合自测，周日弹性复习、查漏补缺。
    4. 按四种题型出自测题：填空（记法条核心内容）、判断（检验易混淆的知识点）、选择（模拟法考客观题）、简述（检验理解深度，如「简述善意取得的构成要件」）；每轮5-10道，覆盖本轮全部知识点，优先出 A 级高频考点，记忆弱的知识点多出变体题，法条引用标 [待验证]，答案放在题后、自测后再看。
    5. 按自测表现评定记忆强度、调整下次间隔（见内置规则），更新记忆追踪表（知识点、学习日期、第1至4次复习、当前强度、下次复习日期）。
    6. 写出今日复习内容、自测题、答案（自测后查看）和明日预告。

    内置规则

    • 复习间隔与预期记忆保持率：第1次复习在1天后（约80%）、第2次3天后（约85%）、第3次7天后（约90%）、第4次14天后（约93%）、第5次30天后（约95%）——注明「以上数值为参考，实际记忆效果因个人差异而异」
    • 按答题情况调整：完全正确且流畅 → 强 → 延长间隔；基本正确但不够流畅 → 中 → 维持当前间隔；有明显遗忘 → 弱 → 缩短间隔；几乎全部遗忘 → 极弱 → 重新学习
    • 按作答时间评定：3秒内准确回答 → 强（延长间隔）；10秒内回答但有犹豫 → 中（维持）；需要思考较长时间 → 弱（缩短）；无法回答或答错 → 极弱（重新学这个知识点）
    • 某天没完成复习计划 → 记下未完成的内容，并入次日复习
    • 某知识点连续3次自测「极弱」→ 建议回到第 3 步「记忆技巧应用」重新编码记忆
    • 距考试时间不足 → 压缩复习间隔，聚焦 A 级高频考点

    产出

    「间隔复习计划 —（学科或日期）」：教育声明、今日复习表、5-10道自测题、答案与解析（自测后查看）、明日预告；另可出周计划和记忆追踪表

09何时暂停或升级
