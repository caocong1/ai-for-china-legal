02概要

本插件面向 AI 合规律师、企业合规官与法务，提供五条完整流程：冷启动访谈、深度合成备案、算法备案、生成式 AI 合规、AI 应用场景分类，共 20 个可单独触发的步骤。所有流程在实质工作前先读取 ai-governance/CLAUDE.md 实践配置文件（企业画像与 AI 服务类型、服务立场、合规严格度、监管关系、风险分级与升级矩阵、文书风格），再按插件统一的法律依据引用规范和 AI 治理法律引用库出具带来源标签与 [待验证] 标注的分析。法律依据以《互联网信息服务深度合成管理规定》（2022）、《互联网信息服务算法推荐管理规定》（2022）、《生成式人工智能服务管理暂行办法》（2023）和网络安全法、数据安全法、个人信息保护法为主，专项规章一律只描述规则、不写条号，统一标 [待验证 — AI 治理法规快速演进，须核实现行版本]。涉及行刑衔接、被责令下架关停或用户重大权益损害时一律强制升级执业律师，该护栏不能通过配置关闭。

03实践配置

实践配置文件 <a href="https://github.com/caocong1/ai-for-china-legal/blob/master/ai-governance/CLAUDE.md">ai-governance/CLAUDE.md</a> 记录贵所的立场与习惯；所有流程开始前先读它。

配置哪些内容

  • 我们是谁（含 执业角色 / 主要服务事项 / 企业画像）
  • 谁在使用
  • 可用集成
  • 合规与监管立场（含 合规严格度 / 监管关系）
  • AI 合规风险校准
  • 升级矩阵（含 角色权限表 / 强制升级触发条件 / 备案时限触发升级表）
  • 文书风格
  • 输出（含 工作产物标题 / 审查者注释块 / 下一步决策树模板）
  • 共享护栏（含 无静默补充原则 / AI 治理合规立场护栏 / 行刑衔接升级护栏 / 律师审查护栏 / 时效性触发 / 来源标签规范）
  • 事项工作区
  • 审查过的种子文档

会怎样改变输出

  • 「执业角色」「谁在使用 → 角色」为非律师（企业合规官、法务、当事人本人）时，输出标题改为「研究笔记 — 合规研究与初步分析，非法律建议，供律师审查」，并在备案材料定稿与提交、安全评估报告定稿、向监管机关报送任何材料、合规制度定稿、重大整改方案确定前暂停并升级执业律师；律师角色用「律师工作产物 — 受律师-当事人特权保护 / 保密」。
  • 「整体服务立场」（深度合成备案 / 算法备案 / 生成式 AI 合规 / AI 使用案例分类与合规评估 / 混合多类型）决定工作侧重；「合规严格度」决定风险标记强度与措辞：保守型一切疑点从严标红并升级，平衡型重大风险标红、一般风险关注整改路径，务实型仅拦截明显高风险；在 AI 应用场景分类流程中，保守型会把每个场景的风险等级再提一级。
  • 「监管关系」为被动应对（已收到整改通知、处罚决定、约谈）时，时限护栏自动加强：须识别通知送达日期、强标整改与备案期限，所有备案与整改时限标红，一般风险即可触发升级，所有输出加时效性与紧迫性提示。
  • 「AI 合规风险校准」四级表（红级=关键、橙级=高、黄级=中等、绿级=低）决定每个发现的标注；涉及刑事追诉风险、被责令下架关停或用户重大权益损害时，无论其他因素一律标 [强制升级 — 行刑衔接] 或 [强制升级 — 重大违规]；「升级矩阵 → 角色权限表」决定谁可独立处理、何时升级，强制升级条件凌驾于服务立场与严格度之上。
  • 「备案时限触发升级表」要求识别服务上线日期倒推备案准备时间（算法备案、深度合成备案均须在上线前完成，具体时限 [待验证]），整改通知送达后立即标记期限；「时效性触发」对 AI 治理专项规章引用标 [时效性 flagged — AI 治理法规快速演进，须核实现行版本]、备案流程细节标 [时效性 flagged — 备案实践持续更新]、地方性 AI 法规标 [地方 flagged]。
  • 「输出」统一附审查者注释块（材料日期、分析范围、法规快速演进提示、行刑衔接提示与 criminal-compliance 插件衔接、引用来源、服务立场、监管关系、各级标记项数量）和七选项下一步决策树（深度合成备案 / 算法备案 / 生成式 AI 合规 / AI 使用案例分类 / 强制升级律师 / 更新合规配置 / 观望记录并记入合规义务台账）。

05不做什么

  • 不提供法律意见或法律结论
  • 不替代执业律师的判断
  • 不保证审查的完整性
  • 不自动向网信办或任何监管机构提交备案或申报文件
  • 绝不提供规避 AI 监管、虚假备案、伪造安全评估材料、绕过算法备案义务或内容安全审查、隐匿训练数据侵权事实的方法，识别即拒绝并标 [合规边界 — 拒绝]
  • 不替代刑事辩护工作：AI 服务违规可能触发刑事追诉、被监管机关责令下架关停或涉及用户重大权益损害时，一律强制升级执业律师，并提示衔接 criminal-compliance 插件
