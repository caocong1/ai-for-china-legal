01概要

通过四段结构化访谈，把执业角色与当事人画像、代理立场与审查严格度、敏感度校准与升级矩阵、文书风格与地方性规定写入 family-legal/CLAUDE.md 的九个章节，使离婚协议、继承权分析、遗嘱起草、财产分割四条流程能按配置个性化运行。访谈按「身份与当事人画像 → 审查与代理立场 → 敏感度与升级 → 文书风格与地方规定」顺序进行，每步先读现有配置判断是已有配置、含占位符还是首次配置，再按实践配置契约的字段映射表逐题提问（28 个主问题加若干条件追问），写入时只更新本步对应章节、跳过的字段保留 [PLACEHOLDER] 不填推测值。对用户口述的旧法条号自动纠正为民法典新条号，司法解释条号一律标 [待验证]，抚养费比例、彩礼返还、房产增值分割等地方差异数字标 [地方 flagged] 且不写为确定结论。第三步固化家暴、涉刑、未成年人利益三项不可被代理立场覆盖的护栏，完整访谈中不可跳过；当事人一旦描述家暴或出现情绪危机信号，立即暂停访谈并输出安全提示。四步均可单独触发只更新某一章节，律师也可直接编辑配置文件，变更可用 git 查看与回滚。

02适用与边界

适用场景

  • 首次使用婚姻家事插件，family-legal/CLAUDE.md 仍是带 [PLACEHOLDER] 的模板
  • 其他流程检测到配置缺失或四个关键字段（执业角色、整体代理立场、角色、家暴识别等级）含占位符，提示「运行冷启动访谈，或告知代理立场以临时模式继续」时
  • 承接新事项、代理立场变化（如从主张方换到被主张方，或同时处理离婚与继承需分别配置）时只重跑第 2 步
  • 新事项出现家暴、未成年子女、涉刑情形，或需调整重大财产隐匿转移的升级阈值时只重跑第 3 步
  • 更换执业地区、需要记录当地彩礼/房产/抚养费裁判口径，或调整文书风格时只重跑第 4 步

不做什么

  • 不进行任何实质法律分析：不审查协议、不判断遗嘱效力、不计算继承份额，只收集并写入配置；法律事实合理性检查仅限条号纠正与待验证标注
  • 不生成独立 practice-profile.yaml 或任何 YAML/JSON 文件；family-legal/CLAUDE.md 是唯一真相来源，旧版访谈文本中「生成 YAML 格式配置文件」的表述已被纠正
  • 不替律师核实司法解释条号、人身安全保护令申请期限、诉讼时效、抚养费比例与彩礼返还标准，只加 [待验证] / [地方 flagged] 标注
  • 不填充「事项工作区」「审查过的种子文档」两章（总流程列出的九个填充章节不含这两章），由律师直接编辑
  • 不记录未成年子女姓名或高度个人信息，只记录年龄范围与事项类型
  • 小改动（更换律师联系人、改工作产物存放路径、改单个字段）不需要重跑访谈，直接编辑配置文件即可

03输入与产出

需要律师提供

  • family-legal/CLAUDE.md 现有内容（模板或已部分填写）必需
    每步先读取：关键字段已填写且非占位符 → 提示「已有配置，是否要更新？」；含 [PLACEHOLDER] → 只更新含占位符的字段；文件不存在 → 完整访谈
  • family-legal/skills/_shared/practice-profile-schema.md 字段映射表必需
    决定每个答案写入哪个章节、哪个字段；第 1 步另用其第七章法律事实合理性检查，第 2 步用第四章代理立场选择规则，第 3 步用第五章敏感情形与强制升级契约
  • 律师/法务/当事人对访谈问题的回答必需
    第 1 步 9 问、第 2 步 4 问（含 1a 继承人详情、2A/2B/2C 按立场展开的关切清单、4a 具体倾向等条件追问）、第 3 步 6 问（含子女年龄与关切追问）、第 4 步 9 问；多数问题给选项，均可跳过
  • 参数：律所/当事人描述，或只更新哪一部分（身份画像 / 代理立场 / 敏感度升级 / 文书风格地方规定）可选
    留空运行完整四步；单独更新直接调用对应步骤的命令，只改该步章节
  • 主要执业地区或城市（第 4 步问题 8）可选
    用于地方性规定标注；不确定或跨地区填「全国通用」或「跨地区」，此时所有地方性规定一律标 [地方 flagged — 需核实当地具体口径]

产出

  • 更新后的 family-legal/CLAUDE.md给律师内部
    按访谈结果替换占位符后的九个章节：我们是谁（名称、实体类型、执业角色、主要事项类型、典型财产构成、主要痛点、团队规模、负责人）/ 谁在使用（角色、律师联系人）/ 可用集成（七类机构与文档存储的确认状态）/ 审查与代理立场（整体代理立场及继承人详情或多事项立场、审查严格度、主张方/被主张方保守重点、诉讼倾向、离婚方式倾向、继承纠纷倾向）/ 敏感度校准（家暴识别等级、涉未成年子女事项、情绪危机等级、涉刑风险、重大财产隐匿阈值）/ 风险校准 / 升级矩阵（七项强制升级触发条件各自保留默认或自定义）/ 文书风格（五类文书风格与存放位置）/ 共享护栏 > 地方性规定提示（主要处理地区、彩礼/房产/抚养费/家事审判口径及参考来源）
  • 每步完成提示块给律师内部
    markdown 引用块：本步已填充到哪些章节；第 2、3 步附「护栏确认」三行（家暴/虐待 → 强制升级、优先人身安全；未成年人重大利益 → 最有利于未成年子女原则；涉刑 → 强制升级刑事律师）；下一步三选项（运行下一步命令 / 继续 /family-legal:cold-start-interview 完整访谈 / 直接调用业务流程——第 1 步后未配置立场时以临时模式、立场默认中立运行）；第 4 步末尾宣布「冷启动访谈已完成」，列出可随时更新的途径与四条可用业务流程命令
  • 家暴敏感情形即时提示块（第 3 步问题 1 选 A 或 B 时，不等访谈完成）给律师内部 / 当事人
    五项处理优先级：1 请先确认当前人身安全，有危险立即拨打 110 或联系妇联庇护热线；2 家暴是诉讼离婚的法定准予条件（民法典第1079条，建议复核）；3 家暴构成离婚损害赔偿的法定情形（第1091条，建议复核）；4 可向法院申请人身安全保护令（反家庭暴力法，具体程序须核实）；5 建议立即联系执业律师；末注「本访谈可在确认安全后继续」

04开始前

前置条件

  • 每步开始先读取 family-legal/CLAUDE.md 对应章节：关键字段已填写且非占位符 → 提示「已有配置，是否要更新？」；含 [PLACEHOLDER] → 直接进入问卷，只更新含占位符的字段；文件不存在或首次配置 → 完整访谈
  • 写入目标固定为 family-legal/CLAUDE.md，不反复询问输出格式与保存位置；只有用户要求写入其他配置文件或目标不明时，才按 shared/legal-document-intake/SKILL.md 确认
  • 第 2 步提问代理立场前，先输出「代理立场说明」边界声明：未成年人利益最大化、家庭暴力护栏、涉刑强制升级三项不可被任何立场覆盖
  • 第 3 步提问前先说明情绪护栏：用「我需要了解一些敏感情形以配置安全护栏」提问，而非「你是否受过家暴」
  • 第 4 步问题 7 在第 1 步问题 9 已采集可用集成资源的基础上只做再确认，不重复采集
  • 推荐顺序 1→2→3→4，任一步可单独触发；family-legal/CLAUDE.md 纳入 git 版本控制，git log family-legal/CLAUDE.md 查看历史，git checkout HEAD~1 family-legal/CLAUDE.md 回滚

硬性规则

唯一真相来源
访谈结果写入 family-legal/CLAUDE.md 对应章节（散文模板），不生成 practice-profile.yaml 或任何独立 YAML/JSON；写入时仅更新本次访谈对应章节，保留其他未提交的配置改动
第 3 步不可跳过
敏感度与升级是婚姻家事插件最重要的特有配置，完整访谈中不可省略；家暴、涉刑、未成年人三项强制升级条件是安全护栏，不建议自定义降低，确需自定义须在 CLAUDE.md 中明确注明原因
护栏凌驾于立场
识别到家庭暴力、虐待、遗弃或涉刑情形时，敏感度护栏优先于一切其他配置：家暴 → 优先人身安全 → 提示人身安全保护令路径 → 强制升级律师 → 暂停访谈；涉刑 → 暂停常规分析 → 强制升级刑事律师；两项不可被代理立场配置覆盖
未成年人利益最大化
涉未成年子女事项以「最有利于未成年子女」为首要原则（民法典第1084条，建议复核），不因代理立场改变，是所有流程的固定护栏
当事人情绪护栏
访谈措辞中立、克制、非煽动，不替当事人作情绪化判断，不激化与对方的对立情绪；识别到自我伤害语言、极度绝望等危机信号时立即暂停访谈，提示心理援助热线
不填推测值
用户跳过或不确定的字段保留原有 [PLACEHOLDER] 或填「未确认」，不强行填入推测值；用户只提供部分信息时填已知部分、未知部分保持占位符
先检索、后结论
给出任何法律结论、条款建议或风险判断前，优先用检索工具核对现行有效的法律法规、司法解释与指导性案例（注意修订、修正与废止）；无检索工具或无法核实时在结论处标「未经检索核实，请以现行有效文本为准」；禁止凭记忆断言法条编号、发文文号或生效日期
法律事实合理性检查
用户口述旧法条号（如「原婚姻法第17条」）→ 提示「该条号属旧法，已废止；对应民法典新条号为第1062条（建议复核）」后纠正写入；口述司法解释条号 → 标 [待验证 — 司法解释条号易变，须核实现行版本]，不写为确定结论；口述抚养费比例、彩礼数额、房产分割比例 → 标 [地方 flagged] 与 [前提 flagged — 需验证]
立场唯一
代理立场一旦写入，对应流程须按该立场分析，不得在单次分析中同时呈现主张方与被主张方双重结论；家暴/未成年人/涉刑强制升级护栏不写入为可被立场覆盖的配置

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置假设，可逐条复制。页面里的英文标记见首页「标记与术语」。

  1. 身份与当事人画像访谈

    /family-legal:identity-party-profile可单独运行

    采集执业角色、当事人画像与可用集成资源，写入「我们是谁」「谁在使用」「可用集成」三章，为所有流程提供输出定性（律师工作产物还是研究笔记）、升级路由、事项类型识别与财产分析侧重的基础。

    请律师核对

    • 核对 1.1问卷执业角色只有 A–E 五类，而配置模板「主要执业角色」字段列了六项，多出「非律师且无律师可咨询」——是否要补入问卷？
    • 核对 1.2角色 C 在签协议、遗嘱定稿前暂停升级，角色 D 的升级提示「更强烈」但文件未具体定义——贵所是否需要明确 D 类在哪些步骤前必须升级（配置模板写的是「全部实质性法律行动前须升级找律师」）？
    • 核对 1.3典型财产构成八项清单是否覆盖贵所常见资产？车辆、保险、虚拟货币、农村宅基地与承包地权益均未列入。
    • 核对 1.4可用集成资源表只有七项，没有配置模板中的中国裁判文书网与企业微信/钉钉——是否由律师直接编辑补充？

    做法

    1. 读取 family-legal/CLAUDE.md：关键字段已填写 → 提示「已有配置，是否要更新？」；含占位符 → 只更新含占位符的字段；文件不存在 → 完整访谈。
    2. 第一部分问题 1–2：组织/律所/当事人名称（跳过则保留 [PLACEHOLDER]）；实体类型五选一（律所婚姻家事部 / 企业法务部 / 个人当事人 / 家事调解机构 / 其他）。
    3. 第二部分问题 3 执业角色五选一（A 婚姻家事律师 / B 企业或个人法务，有律师可咨询 / C 当事人本人，有律师可咨询 / D 当事人本人，无律师可咨询 / E 非律师但有律师联系人，如助理、调解员），并说明每项对输出标题与升级的影响（见规则）。
    4. 第三部分问题 4 主要事项类型多选（离婚·协议离婚 / 离婚·诉讼离婚 / 财产分割专项 / 子女抚养与探望 / 继承权分析 / 遗嘱起草 / 遗产纠纷 / 混合多类型），每项对应会被调用的流程（如协议离婚 → 离婚协议 + 财产分割 + 子女抚养与探望；混合多类型 → 全部流程）。
    5. 问题 5 典型财产构成多选八项（婚房·共同还贷/一方婚前购房 / 存款与理财 / 股票基金投资账户 / 有限公司股权或合伙份额 / 知识产权及其收益 / 养老金与社会保险权益 / 跨境资产·境外房产账户 / 其他重要财产），用于财产分割流程聚焦。
    6. 问题 6 主要痛点多选（财产隐匿转移 / 子女抚养争夺 / 遗嘱效力存疑 / 共同债务认定 / 家庭暴力 / 继承顺序争议 / 遗嘱形式要件 / 其他）；问题 7 团队规模选填（如婚姻家事律师 2 人 + 法务助理 1 人，或「个人」）。
    7. 第四部分问题 8：直接使用者角色（律师 / 法务 / 当事人本人 / 助理）与律师联系人姓名、联系方式（选填）。
    8. 第五部分问题 9 七项资源逐项确认状态：当地基层法院与家事审判庭（已确认：___区人民法院 / 未确认）、民政局婚姻登记机关、公证机构（已委托 / 未委托 / 可根据需要）、不动产登记机构、司法鉴定机构、妇联与反家暴庇护机构（已知联系方式 / 不适用 / 未确认）、文档存储路径或系统。
    9. 对访谈中口述的条号、期限、数额做法律事实合理性检查：旧法条号纠正为民法典新条号；司法解释条号标 [待验证 — 司法解释条号易变，须核实现行版本]；抚养费比例提示「因地区差异较大 [地方 flagged]，请核实当地裁判口径」。
    10. 按写入映射表写入三章（问题 1–2 → 我们是谁名称与实体类型；问题 3 → 执业角色；问题 4–7 → 事项类型、财产构成、痛点、团队规模、负责人；问题 8 → 谁在使用；问题 9 → 可用集成）；完成后输出提示块：下一步运行 /family-legal:review-representation-stance，或继续完整访谈，或直接调用任意流程（以临时模式运行，立场默认中立）。

    内置规则

    • 执业角色 A 婚姻家事律师：输出标题「律师工作产物——受律师-当事人特权保护」，风险提示以专业法律分析为主
    • 角色 B 法务（有律师可咨询）与 E 非律师但有律师联系人：输出标题「研究笔记——供律师审查」，重大步骤前提示升级
    • 角色 C 当事人本人（有律师可咨询）：同 B，且签协议、遗嘱定稿等婚姻家事重大步骤须暂停升级
    • 角色 D 当事人本人（无律师可咨询）：同 C，升级提示更强烈，家暴/涉刑情形强制升级
    • 用户完全跳过问卷 → 以「临时模式」继续，所有字段保持占位符，提示随时可更新
    • 部分回答不确定 → 填「未确认」并保留占位符，不推测；用户只想更新部分字段 → 只更新明确回答的字段，其他不变
    • 访谈重复进行 → 提示「已有现有配置，以下是当前设置，是否需要更新？」

  2. 审查与代理立场访谈

    /family-legal:review-representation-stance可单独运行

    配置婚姻家事工作的核心变量——代理立场（离婚一方主张方或被主张方、某继承人、遗嘱人、中立），以及协议审查严格度与诉讼倾向，写入「审查与代理立场」章，使后续流程按同一立场调整分析侧重与风险判断，避免立场缺失导致分析偏差。

    请律师核对

    • 核对 2.1问卷把「主张方」等同于「原告侧」、「被主张方」等同于「被告侧」——实践中原告未必是主张分割更多财产的一方，这一对应是否需要拆开？
    • 核对 2.2被主张方默认关切清单把「冷静期内撤回权利」列入、主张方清单把「对方伪造共同债务」列入——两张默认侧重清单是否符合贵所办案经验，有无遗漏（如抚养费标准、探望权安排、经济帮助）？
    • 核对 2.3保守型被推荐给「主张方/无过错方/当事人本人使用」——是否同意当事人本人默认采用保守型？
    • 核对 2.4「胁迫/威胁签字」被归为潜在家暴/涉刑信号，提示语只说「可能涉及协议效力问题（须核实）」——是否足够，是否应直接指向可撤销路径？

    做法

    1. 读取 CLAUDE.md「审查与代理立场」：整体代理立场含 [PLACEHOLDER] → 完整访谈；已填写 → 提示「当前代理立场为 [X]，是否更新？」。
    2. 先输出「代理立场说明」边界声明：代理立场决定分析侧重，但未成年人利益最大化、家庭暴力护栏、涉刑强制升级不可被任何立场覆盖。
    3. 问题 1 整体代理立场五选一（A 离婚一方侧·主张方/原告侧 / B 离婚一方侧·被主张方/被告侧 / C 某继承人侧 / D 遗嘱人侧 / E 中立审查），同时处理离婚与继承等多个事项时可分别配置；选 C 追问 1a：代理哪位继承人（姓名、与被继承人关系、第一还是第二顺序继承人、是否有遗嘱指定）。
    4. 选 A 问 2A 主张方关切多选（共同财产足额分割，特别是隐匿/转移财产 / 房产婚后还贷增值补偿 / 股权或公司份额分割 / 家务劳动补偿，第1088条，建议复核 / 离婚损害赔偿，家暴/重婚，第1091条，建议复核 / 子女主要抚养权 / 对方伪造共同债务 / 其他），写入「主张方保守重点」。
    5. 选 B 问 2B 被主张方关切多选（婚前财产范围明确与举证 / 房产个人来源举证，婚前购买或父母出资 / 非共同债务排除 / 子女意愿与抚养能力举证 / 限制对方损害赔偿主张 / 冷静期内撤回权利 / 折价方式与评估时点 / 其他），写入「被主张方保守重点」。
    6. 选 C 问 2C 继承关切多选（法定继承份额确认 / 遗嘱效力核查，维护或质疑 / 遗嘱形式要件是否满足 / 其他继承人是否存在丧失继承权情形 / 代位继承或转继承 / 先析产夫妻共同财产后继承 / 遗产债务清偿 / 其他），在「整体代理立场」中注明。
    7. 问题 3 协议审查严格度三选一（A 保守型 / B 平衡型 / C 进取型，定义与适用场景见规则）。
    8. 问题 4 诉讼倾向三选一（A 协议优先：推动调解协商、避免诉讼，通常成本更低 / B 诉讼优先：对方不合作、协议不公平或需保全时 / C 视情况：按财产、子女、对方态度综合判断）；问题 4a 选填：离婚方式倾向（协议离婚·民政冷静期30日 / 诉讼离婚）、继承纠纷倾向（协商和解 / 析产诉讼 / 公证处理）。
    9. 法律事实合理性检查：旧法条号纠正（「原婚姻法第17条」→ 民法典第1062条，建议复核）；司法解释条号标 [待验证 — 司法解释条号易变，须核实现行版本]；用户描述「胁迫/威胁签字」→ 识别为潜在家暴/涉刑信号，提示「如存在强迫签字情形，可能涉及协议效力问题（须核实），且若有人身威胁须优先安全」；用户明确描述家暴 → 立即提示强制升级护栏、优先人身安全。
    10. 写入「审查与代理立场」章（问题 1 → 整体代理立场含继承人详情；2A/2B/2C → 主张方/被主张方保守重点；3 → 审查严格度；4 → 诉讼倾向、离婚方式倾向、继承纠纷倾向）；完成提示块附「护栏确认」三行与下一步（运行 /family-legal:sensitivity-escalation / 继续完整访谈 / 直接调用流程按已配置立场运行）。

    内置规则

    • 立场 A 主张方的分析侧重：扩大共同财产范围、追查隐匿财产、争取抚养权、家务补偿、损害赔偿主张
    • 立场 B 被主张方的分析侧重：个人财产剥离举证、合理折价、非共同债务排除、限制损害赔偿扩大、冷静期撤回权利
    • 立场 C 某继承人：代理继承人的份额主张、遗嘱效力核查（维护或挑战）、代位继承与转继承识别；立场 D 遗嘱人：遗嘱形式要件齐备、意思表示真实、必留份安排、受益人身份明确；立场 E 中立：双向识别显失公平条款与争议点，不偏向任何一方
    • 严格度 A 保守型：任何对当事人不利的条款均标红，优先保护当事人权益；适用主张方、无过错方、当事人本人使用
    • 严格度 B 平衡型：重大风险标红、一般风险标橙，优先促成协议；适用双方协商推进、节省诉讼成本
    • 严格度 C 进取型：仅拦截明显不利条款，一般条款尽量放行；适用协议意向明确、双方谈判已成熟
    • 用户不确定代理立场 → 以「临时模式-中立」写入，并说明「中立模式下分析将均衡呈现双方主张」
    • 用户是调解员或中立第三方 → 立场设为中立审查，说明调解员不代理任何一方
    • 同时代理离婚与继承等多个立场 → 分别记录各事项立场（可在 CLAUDE.md 增加事项字段）；立场中途改变 → 重跑本步更新
    • 代理立场已确定时不得多方向分析；立场边界护栏（家暴/未成年人/涉刑强制升级）不写入为可覆盖配置

    法律依据

    • 《民法典》第1088条 — 家务劳动补偿请求权，主张方关切选项（建议复核）
    • 《民法典》第1091条 — 离婚损害赔偿（家暴/重婚），主张方关切选项与家暴护栏（建议复核）
    • 《民法典》第1079条 — 家暴为诉讼离婚法定准予条件，家暴护栏（建议复核）
    • 《民法典》第1084条 — 最有利于未成年子女原则，未成年人护栏（建议复核）

  3. 敏感度与升级访谈

    /family-legal:sensitivity-escalation可单独运行

    固化婚姻家事最重要的敏感护栏：家暴识别等级、未成年人利益保护、当事人情绪危机、涉刑情形、重大财产隐匿升级阈值与七项强制升级触发条件，写入「敏感度校准」「风险校准」「升级矩阵」三章，使后续所有流程自动识别敏感情形并升级，且这些护栏不被代理立场覆盖。

    请律师核对

    • 核对 3.1重大财产隐匿升级阈值的三档参考 50万 / 100万 / 300万元是否符合贵所客户资产水平？配置模板示例为 50万。
    • 核对 3.2家暴即时提示块只写「拨打 110 或联系妇联庇护热线」，未给出具体热线号码；保护令申请期限与反家庭暴力法条号均标 [待验证]——是否由律师预先写入经核实的号码、条号与程序？
    • 核对 3.3子女年龄分段 不满2岁 / 2-8岁 / 8岁以上 自标 [建议核实民法典第1084条适用规则]——请律师确认分段与现行条文一致。
    • 核对 3.4本步声称写入「风险校准」章，但六个问题中没有一题询问风险四级表定义，实际沿用配置模板预设的关键/高/中等/低口径——是否需要加一题让律师确认或调整？
    • 核对 3.5「协议离婚生效前」「遗嘱定稿前」两项强制升级只对非律师角色生效，律师角色不暂停——是否同意？

    做法

    1. 开场用中立措辞说明目的（「我需要了解一些敏感情形以配置安全护栏」），全程记录当事人描述、不作道德评判；回答中出现强烈情绪化或危机信号 → 立即暂停，优先提示心理支持。
    2. 问题 1 家庭暴力识别等级四选一（A 高风险：已明确描述家暴/虐待/遗弃且有证据或记录 / B 中风险：有疑似迹象，如恐惧、受伤迹象、控制行为 / C 低风险：无任何相关描述或迹象 / D 待评估：不确定需进一步了解）；选 A 或 B 不等访谈结束立即输出家暴护栏提示块（确认人身安全、110 或妇联庇护热线、第1079条、第1091条、人身安全保护令、立即联系执业律师）。
    3. 问题 2 当前事项是否涉及未成年子女（A 是 / B 否 / C 不确定：默认开启保护，发现涉子女内容即激活）；选 A 选填追问子女年龄段（不满2岁 / 2-8岁 / 8岁以上，标 [建议核实民法典第1084条适用规则]）与主要关切（主要抚养权争议 / 探望权安排 / 子女财产安排 / 其他）。
    4. 问题 3 当事人情绪状态四选一（A 高：强烈情绪化表达或危机信号，须立即暂停分析 / B 中：明显情绪波动但无危机信号 / C 低：相对平稳能理性沟通 / D 待观察）；所有等级下输出一律中立、克制、非煽动，不激化对立。
    5. 问题 4 涉刑风险三选一（A 是：重婚 / 虐待家庭成员罪 / 遗弃家庭成员罪 / 拒不执行判决裁定罪，所有流程强制升级刑事律师 / B 待评估：开启识别，发现信号即强制升级 / C 否：正常运行）。
    6. 问题 5 重大财产隐匿转移强制升级金额阈值：推荐参考 50万元（较保守）、100万元（一般）、300万元（高净值财产情况）；不确定可填「不设阈值，由律师判断」。
    7. 问题 6 逐项确认七项强制升级触发条件保留默认（推荐）还是自定义（见规则）；家暴/涉刑/未成年人三项不建议自定义降低，确需自定义须在 CLAUDE.md 明确注明原因。
    8. 法律事实合理性检查：用户描述家暴后提及条号 → 核对是否为第1079条/第1091条（建议复核），旧法条号自动纠正；提到人身安全保护令申请期限 → 标 [待验证]，须核实反家庭暴力法现行规定；口述诉讼时效 → 标 [待验证]。
    9. 写入三章（问题 1 → 家暴识别等级；2 → 涉未成年子女事项及年龄与关切；3 → 情绪危机等级；4 → 涉刑风险；5 → 敏感度等级表中的重大财产隐匿转移阈值；6 → 升级矩阵强制升级触发条件各项状态）；完成提示块列出护栏固化确认三行与下一步（运行 /family-legal:style-local-rules / 继续完整访谈 / 直接调用流程按已配置敏感度运行）。

    内置规则

    • 家暴等级 A 高风险 → 所有流程强制开启家暴护栏，优先提示人身安全保护令路径；B 中风险 → 开启疑似家暴护栏，评估安全状况；C 低风险 → 正常运行但保留识别机制；D 待评估 → 默认开启识别，发现信号即触发
    • 涉未成年子女 A → 所有涉子女事项强制以「最有利于未成年子女」为首要原则（第1084条，建议复核）；C 不确定 → 默认开启保护
    • 七项强制升级默认配置：家暴/虐待/遗弃（确认或高度疑似）→ 强制升级、优先人身安全 + 保护令；涉刑（重婚/虐待罪/遗弃罪/拒执罪）→ 强制升级刑事律师；未成年人重大利益（主要抚养权/子女生活保障）→ 强制升级、以最有利于未成年子女为首要原则；重大财产隐匿转移超过阈值 → 强制升级、提示申请财产保全；协议离婚生效前（非律师角色）→ 须律师审核；遗嘱定稿前（非律师角色）→ 须律师审核遗嘱形式要件；当事人情绪危机信号 → 暂停分析、提示心理援助
    • 用户回避家暴问题 → 中立提示「配置家暴识别是为了确保系统在相关情形下自动提供保护，如暂时不确定可设为待评估」；用户主动描述家暴 → 立即输出护栏提示、优先人身安全、暂停访谈
    • 用户希望降低家暴护栏等级 → 告知风险，须在 CLAUDE.md 中明确注明，不建议降低
    • 涉及未成年子女信息 → 不记录具体子女姓名或高度个人信息，只记录年龄范围和事项类型

  4. 文书风格与地方规定访谈

    • 核对 4.4本步头部声称填充「## 输出」章（工作产物标题与审查者注释块格式），但九个问题与写入映射表均未涉及该章——实际未配置，律师须直接编辑模板预设的标题与注释块。

    做法

    1. 读取 CLAUDE.md「文书风格」：关键字段含占位符 → 完整访谈；已部分填写 → 提示「当前文书风格为 [X]，是否更新？」；本步属配置性访谈、情绪风险较低，仍保持婚姻家事敏感措辞基准。
    2. 问题 1 离婚协议风格多选（中立克制·未成年人利益优先、避免激化对立 / 各项条款逐一明确·财产、子女、债务各条单独列示 / 措辞清晰不留歧义·明确数字和时间节点 / 详细说明·含背景与执行步骤 / 简洁精炼·重点条款 / 自定义）。
    3. 问题 2 继承分析意见书风格（分析框架明确：遗产范围→析产→继承顺序→遗嘱效力→分配方案 / 含继承人资格核查清单 / 注明需进一步核实的条号、待验证标记透明呈现 / 表格化继承人与份额对照 / 详细文字分析 / 自定义）。
    4. 问题 3 遗嘱文本风格（严谨正式：签名/日期/见证人格式逐项注明 / 遗嘱人意思表示清晰、受益人身份明确无歧义 / 必留份安排单独说明以避免遗嘱无效风险 / 自定义）。
    5. 问题 4 财产分割方案风格（按财产类型逐项列示：房产/存款/车辆/股权 / 标注各方归属、折价金额与过户时间节点 / 含估值依据和补偿计算说明 / 方案多选：提供 A/B 方案供协议谈判 / 自定义）。
    6. 问题 5 律师函/起诉材料风格（正式书面、措辞坚定 / 家暴情形须突出证据：照片、医疗记录、保护令 / 含完整诉讼请求、事实与理由结构 / 自定义）；问题 6 工作产物存放位置选填（内部系统路径 / 共享文件夹 / 其他）。
    7. 问题 7 再确认四类外部机构状态：法院家事审判庭（离婚诉讼、财产保全、人身安全保护令申请）、民政局婚姻登记机关（协议离婚登记与冷静期管理，第1077条）、公证机构（遗嘱公证、财产分割协议公证、继承权公证）、司法鉴定机构（股权/房产评估、亲子鉴定、遗嘱人精神状态鉴定），更新或确认「可用集成」。
    8. 问题 8 主要处理地区或城市（不确定或跨地区填「全国通用」）；问题 9 四类地方性规定是否已有了解及参考来源：彩礼返还认定标准（省高院指导意见/当地口径 [待验证]）、房产分割口径·婚前房产婚后还贷增值（省高院意见，描述规则 [待验证]）、抚养费标准·月均收入比例（当地裁判惯例 [待验证] [地方 flagged]）、家事审判特色（调解机制/未成年人调查制度）。
    9. 法律事实合理性检查：口述抚养费比例 → 提示「抚养费比例地区差异大，你提到的 [X]% 是否已核实当地裁判口径？」并标 [地方 flagged] [前提 flagged — 需验证]；口述彩礼返还数额或比例 → 提示是否已经当地法律专业人士确认，同样标注；口述房产分割具体比例 → 标 [地方 flagged] [待验证]；口述司法解释条号 → 标 [待验证 — 司法解释条号易变，须核实现行版本]。
    10. 写入三处（问题 1–6 → 文书风格；7 → 可用集成；8–9 → 共享护栏 > 地方性规定提示）；输出「冷启动访谈已完成」提示块：全部章节已填充（部分字段可能仍为占位符）、可随时单独更新或直接编辑或完整重跑、现在可用的四条业务流程命令（/family-legal:property-division、/family-legal:divorce-agreement、/family-legal:inheritance、/family-legal:will-drafting）。

    内置规则

    • 地方性规定的具体数字（彩礼比例 / 抚养费比例 / 房产增值分割比例）不写入为确定结论，保留 [待验证] 和 [地方 flagged]
    • 地区填「全国通用」或处理跨地区案件 → 所有地方性规定一律标 [地方 flagged — 需核实当地具体口径]
    • 用户跳过文书风格问卷 → 填入默认风格「中立克制、条款逐一明确」，提示可随时更新
    • 文书风格偏好由当事人自由选择，不强制推荐特定风格
    • 地方性规定信息过于具体（含确定数字）→ 提示不宜写入为确定结论，须标 [待验证]

09何时暂停或升级

  • 当事人出现自我伤害语言、极度绝望等情绪危机信号 → 立即暂停访谈，提示心理援助热线，根据情况升级
  • 第 3 步问题 1 选 A 高风险或 B 中风险，或当事人在任一步主动描述家暴/虐待/遗弃 → 不等访谈完成立即输出家暴护栏提示（先确认人身安全，有危险拨打 110 或联系妇联庇护热线；第1079条、第1091条；人身安全保护令；立即联系执业律师），暂停访谈，确认安全后再继续
  • 识别到重婚、虐待家庭成员、遗弃家庭成员、拒不执行判决裁定等涉刑情形 → 暂停常规分析，强制升级刑事律师
  • 用户描述「胁迫/威胁签字」→ 作为潜在家暴/涉刑信号处理，提示协议效力问题须核实，有人身威胁时优先安全
  • 用户希望降低家暴护栏等级或自定义家暴/涉刑/未成年人三项强制升级 → 告知风险，须在 CLAUDE.md 明确注明原因，不建议降低
  • 目标章节已有非占位符配置 → 暂停询问「已有配置，是否要更新？」；用户要求写入其他配置文件或目标不明 → 按 shared/legal-document-intake/SKILL.md 确认
  • 执业角色为当事人本人或非律师 → 告知后续流程在协议离婚生效前、遗嘱定稿前等重大步骤暂停并升级律师；无律师可咨询的当事人升级提示更强烈，家暴/涉刑情形强制升级

10请律师重点核对

下面是这个流程内置的法律假设、立场、阈值和清单，每一条都可以同意、反对或补充。条目下的「相关批注」按文字重合自动匹配到步骤旁的核对条目，可能不全。

  1. 执业角色问卷只有 A–E 五类，配置模板的「主要执业角色」字段却有六项（多出「非律师且无律师可咨询」），且角色 D「升级提示更强烈」未具体定义——请确认是否补入第六类，并明确 D 类在哪些步骤前必须升级。相关批注：核对 1.1
  2. 代理立场把「主张方」等同于「原告侧」、「被主张方」等同于「被告侧」，并预设两张默认侧重清单（主张方：扩大共同财产范围、追查隐匿财产、争取抚养权、家务补偿、损害赔偿；被主张方：个人财产剥离举证、合理折价、非共同债务排除、限制损害赔偿扩大、冷静期撤回权利）——原告与「要求更多分割的一方」是否应拆开？两张清单是否符合贵所实践、有无遗漏？相关批注：核对 2.1
  3. 协议审查严格度三档定义（保守型：任何不利条款即标红；平衡型：重大风险标红、一般风险标橙；进取型：仅拦截明显不利条款）与推荐对应（保守型推荐给主张方/无过错方/当事人本人）——是否同意当事人本人默认走保守型？相关批注：核对 2.3
  4. 重大财产隐匿转移强制升级阈值的推荐参考为 50万元（较保守）、100万元（一般）、300万元（高净值财产情况），配置模板示例 50万——贵所客户资产水平下应以哪一档为默认？是否同意「不设阈值，由律师判断」作为可选项？相关批注：核对 3.1
  5. 七项强制升级默认（家暴/涉刑/未成年人重大利益/重大财产隐匿/协议离婚生效前·非律师/遗嘱定稿前·非律师/情绪危机），其中「协议离婚生效前」「遗嘱定稿前」只对非律师角色生效——律师角色是否也需要在这两个节点设强制复核？家暴/涉刑/未成年人三项「不建议自定义降低」的立场是否同意？相关批注：核对 3.5
  6. 家暴护栏即时提示写「拨打 110 或联系妇联庇护热线」，没有具体热线号码；人身安全保护令申请期限与程序一律标 [待验证]，反家庭暴力法条号也未给出——是否由律师预先写入经核实的号码、条号与程序？相关批注：核对 3.2
  7. 未成年子女年龄分段 不满2岁 / 2-8岁 / 8岁以上（自标 [建议核实民法典第1084条适用规则]），且不记录子女姓名只记录年龄范围——请核实分段与现行第1084条一致，并确认隐私处理口径是否符合贵所要求。相关批注：核对 3.3
  8. 旧法条号纠正在访谈文本中只给了一个映射示例（「原婚姻法第17条」→ 第1062条，建议复核），完整对照表在引用规范第五章——是否要让访谈直接按对照表自动纠正，而不是仅凭示例？
  9. 彩礼返还比例、抚养费比例、婚前房产婚后还贷增值分割比例被定为「任何口述数字一律标 [待验证] 与 [地方 flagged]、不写为确定结论」——若贵所已有经核实的本省高院口径，是否希望允许按「已核实 + 来源 + 日期」写入作为默认？相关批注：核对 4.2
  10. 情绪危机信号（自我伤害语言、极度绝望）触发「暂停法律分析」且不区分使用者是律师还是当事人——律师代当事人操作时是否也应暂停？「中立、克制、非煽动」的措辞要求与第 4 步允许律师函「措辞坚定、家暴情形突出证据」之间的边界如何把握？
  11. 用户不确定立场时写入「临时模式-中立」并均衡呈现双方主张；调解员/中立第三方一律设为中立审查——是否同意中立作为缺省立场？
  12. 跳过文书风格时默认「中立克制、条款逐一明确」；第 3 步与第 4 步分别声称填充「风险校准」「输出」两章，但都没有对应问题，实际沿用模板预设的风险四级表、工作产物标题、审查者注释块与十选项决策树——请确认模板预设是否可直接采用，或需增加访谈问题。
