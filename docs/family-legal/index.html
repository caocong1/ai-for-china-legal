02概要

面向婚姻家事律师、法务与当事人，覆盖离婚协议起草（财产分割条款、子女抚养与探望、债务处理、协议生效与登记）、继承权分析（法定继承顺序、遗嘱继承效力、遗产范围与债务、代位与转继承）、遗嘱起草（形式选择、遗嘱能力与意思表示、内容与必留份、见证与生效）和财产分割方案（共同财产认定、房产股权等特殊财产、分割原则与照顾、隐藏转移财产救济），加上初始化实践配置的冷启动访谈，共五条流程、二十个可单独触发的步骤。所有流程先读 family-legal/CLAUDE.md 取执业角色、代理立场、敏感度校准、文书风格与地方性规定，再按统一引用规范引用民法典婚姻家庭编（第1040-1118条）与继承编（第1119-1163条），司法解释条号一律标 [待验证]、以描述规则呈现，旧法（原婚姻法、原继承法）条号自动纠正。家暴/虐待/遗弃、涉刑、未成年人重大利益、当事人情绪危机、非律师角色在协议离婚生效前或遗嘱定稿前这五类情形触发强制升级或暂停，且凌驾于任何代理立场。

03实践配置

实践配置文件 <a href="https://github.com/caocong1/ai-for-china-legal/blob/master/family-legal/CLAUDE.md">family-legal/CLAUDE.md</a> 记录贵所的立场与习惯；所有流程开始前先读它。

配置哪些内容

  • 我们是谁（组织/律所/当事人名称、实体类型、执业角色、主要事项类型、典型财产构成、主要痛点、团队规模、负责人）
  • 谁在使用（角色、律师联系人、非律师角色提示与婚姻家事特别提示）
  • 可用集成（基层法院与家事审判庭、民政婚姻登记机关、公证机构、不动产登记机构、司法鉴定机构、妇联与反家暴庇护机构、中国裁判文书网、文档存储、企业微信/钉钉）
  • 审查与代理立场（整体代理立场五种及各立场说明；协议审查严格度与主张方/被主张方保守重点；诉讼倾向、离婚方式倾向、继承纠纷倾向）
  • 敏感度校准（家庭暴力识别与处理、未成年人利益、当事人情绪危机、涉刑情形识别、敏感度等级与处理策略表）
  • 风险校准（关键 / 高 / 中等 / 低四级与婚姻家事典型触发情形）
  • 升级矩阵（角色权限表、强制升级触发条件、诉讼/保护令/公证触发表）
  • 文书风格（离婚协议、继承分析意见书、遗嘱文本、财产分割方案、律师函/起诉状、工作产物存放位置）
  • 输出（工作产物标题律师版与非律师版、审查者注释块、十选项下一步决策树）
  • 共享护栏（无静默补充、当事人情绪护栏、未成年人利益最大化、家暴识别与人身安全、律师审查护栏、时效性触发、验证用户陈述的法律事实、来源标签规范、目的地/特权检查、地方性规定提示）
  • 事项工作区
  • 审查过的种子文档

会怎样改变输出

  • 「谁在使用 → 角色」与「我们是谁 → 执业角色」决定标题与升级节点：律师角色输出「律师工作产物 — 受律师-当事人特权保护 / 保密」；当事人本人或法务输出「研究笔记 — 非法律建议，供律师审查」，并在签署离婚协议并申请登记、遗嘱定稿、财产分割定案、发律师函或起诉、签署重大财产协议前暂停升级；无律师的当事人在全部实质性法律行动前须升级找律师；法务助理在协议效力判断、遗嘱效力意见、涉家暴涉刑、财产分割主张超 [PLACEHOLDER] 万时升级。
  • 「审查与代理立场 → 整体代理立场」是所有流程的核心变量：主张方侧重足额分割共同财产、追查隐匿财产、争取抚养权与有利探望、减少债务负担；被主张方侧重个人财产剥离、合理折价、避免承担非共同债务、子女意愿与抚养能力举证；某继承人侧重份额、丧失继承权情形排除、遗嘱效力挑战或维护；遗嘱人侧重形式要件、遗嘱能力与意思表示、必留份、受益人身份；中立审查平衡双方、识别显失公平条款。「协议审查严格度」决定标注口径：保守型任何不利于当事人的条款即标红，平衡型重大风险标红、一般风险标橙并优先对话，进取型仅拦截明显不利条款；「诉讼倾向」决定协议路径还是诉讼路径优先。
  • 「敏感度校准」与「升级矩阵」凌驾于代理立场：家暴/虐待/遗弃（确认或高度疑似）→ 优先人身安全、提示人身安全保护令路径、强制升级律师；涉刑（重婚/虐待罪/遗弃罪/拒执罪）→ 暂停常规分析、强制升级刑事律师；未成年人重大利益（主要抚养权、子女生活保障）→ 以最有利于未成年子女为首要原则（民法典第1084条，建议复核）并强制升级，8周岁以上子女意愿须尊重，抢夺藏匿子女标关键风险；单方隐匿财产超过配置阈值（模板示例 50万）→ 提示财产保全并强制升级；情绪危机信号 → 暂停法律分析、提示心理支持；一般情绪化表达 → 中立克制措辞。
  • 「风险校准」四级决定每个发现的标注：关键（家暴/涉刑/重大财产隐匿转移/未成年人人身安全受威胁/离婚冷静期撤回机会临近丧失/继承纠纷诉讼时效临近）、高（协议离婚条款重大不公平/遗嘱形式要件存疑/抚养费标准明显不合理/共同债务认定争议/财产隐匿疑似/继承人资格争议）、中等（条款约定不明/探望权执行难/见证人资格边缘/必留份计算不确定/彩礼返还争议/抚养费变更风险）、低（协议明确公平/遗嘱要件齐备/继承顺序清晰/财产清单完整）；涉人身安全或刑事情形无论等级一律 [强制升级]。
  • 「可用集成」决定路径与资源提示：法院家事审判庭（离婚先行调解、人身安全保护令申请）、民政婚姻登记机关（协议离婚登记、30日冷静期撤回与期满发证，期满30日内须双方共同申请发证否则视为撤回）、公证机构（遗嘱/财产分割协议/继承权公证）、不动产登记（析产/继承过户）、司法鉴定（亲子鉴定/精神状态/财产评估）、妇联庇护资源；集成未连接时核心功能仍可工作，案件材料与协议文本须手动提供。
  • 「文书风格」「输出」「共享护栏」决定成果形态与标注：按配置的五类文书风格起草；每份成果附审查者注释块（材料日期、分析范围、司法解释条号提示、敏感性提示、法律依据来源、涉及文件、各级标记项数量、代理立场）与十选项下一步决策树；司法解释条号引用标 [时效性 flagged — 需验证现行司法解释版本]，彩礼返还、抚养费比例、婚前房产婚后还贷增值分割口径标 [地方 flagged — 需核实地方性规定与地方裁判口径]；用户口述旧法条号（原婚姻法第17条、原继承法第10条）自动纠正为民法典新条号并说明；面向对方当事人、法院、民政登记机关、媒体等会使特权失效的目的地须提供特权版与脱敏版两套。

05不做什么

  • 不替代执业律师：当事人本人或法务角色的输出一律是「研究笔记 — 非法律建议，供律师审查」，在签署离婚协议并申请登记、遗嘱定稿、财产分割定案（房产过户、股权转让等不可逆行为）、发律师函或起诉、签署重大财产协议前必须暂停并升级给执业律师
  • 不做刑事分析：识别到重婚、虐待家庭成员、遗弃家庭成员、拒不执行判决裁定等涉刑情形时暂停常规婚姻家事分析，强制升级给刑事律师
  • 不提供心理支持或危机干预本身：识别到自我伤害语言、极度绝望等危机信号时暂停法律分析，只提示寻求专业心理支持（如心理援助热线）
  • 不以案例为约束性依据：最高院指导性案例与各地典型案例仅作参考、不具判例法约束力，案号一律标 [待验证]
  • 不另存独立 YAML 或 JSON 配置文件，family-legal/CLAUDE.md 是唯一真相来源；不在无法检索核实时凭记忆断言法条编号、发文文号或生效日期
  • 不替用户填补信息空白：查询结果不足时只报告已找到的内容并说明还需哪些补充信息（无静默补充原则）
