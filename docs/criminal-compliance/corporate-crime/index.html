01概要

从事前预防角度帮企业识别单位犯罪风险：判断某一行为是否可能构成单位犯罪、双罚制下哪些高管和经办人会被追责，按行业梳理七大类高发罪名的构成要件，设计内控与防范机制，并在出现涉案苗头时给出合规应对框架、视情况转入合规不起诉流程。流程按「单位犯罪构成识别 → 常见单位犯罪类型 → 内控与防范机制 → 涉案应对」四步进行，前三步属事前预防，第四步遇真实涉案须由执业刑事辩护律师主导；四步均可单独触发。开始前读取 criminal-compliance/CLAUDE.md 的执业角色、服务立场、是否已涉案与企业画像，配置不全时可走临时模式（默认律师角色、事前预防立场、保守型）。法律依据只把刑法第30/31/67/68/72条、刑事诉讼法第15/177条作为「建议复核」的锚点，具体罪名条号一律标 [条号待验证]、定罪量刑数额只描述规则，引用口径参照插件共享的引用规范与条文库。全程设有不可被立场覆盖的涉刑强制升级、合规边界（拒绝任何规避侦查或逃避责任的需求）和对外提交材料内外两版等护栏。

02适用与边界

适用场景

  • 企业想知道某一业务做法是否可能构成单位犯罪，以及双罚制下哪些高管、经办人可能被追责
  • 按行业梳理高发单位犯罪罪名（走私、金融、税收、商业贿赂、扰乱市场秩序、环境、安全生产七大类），用于风险评估、内控设计或辩护研究
  • 设计或完善反商业贿赂、发票管理、招投标等专项内控，禁止性行为清单，不相容职务分离与举报机制，或做定期内控自查
  • 出现涉案苗头（被监管关注、相关人员被调查）时，了解配合调查的可为与不可为、自首立功与认罪认罚路径，并在律师主导下判断是否转入合规不起诉
  • 辩护研究立场下分析三要素是否完整满足、是否属于借单位之名的个人犯罪（须律师主导）

不做什么

  • 不替企业作有罪无罪的最终结论，也不作「某行为一定构成/不构成某罪」的绝对判断，只做构成要件比对
  • 不提供规避侦查、伪造毁灭证据、串供或统一口径、转移资产逃避追缴、把单位犯罪伪造成个人行为以减轻单位责任等任何帮助逃避法律追究的方法；识别到即拒绝并标 [合规边界 — 拒绝]
  • 不用于已涉案情形的直接应对：已立案、被采取强制措施、收到侦查传唤等情形由执业刑事辩护律师主导，涉案后应改用合规不起诉流程（/criminal-compliance:non-prosecution）
  • 不臆造具体罪名条号、法定刑档与定罪量刑数额
  • 不做刑事合规体系的全面建设（风险识别体系、制度体系、组织架构、有效性评估），那是刑事合规体系建设流程（/criminal-compliance:compliance-system-building）的范围

03输入与产出

需要律师提供

  • 企业行业、规模与业务模式描述必需
    启动参数「[企业行业/业务模式描述]」；配置文件「我们是谁」中的企业画像含占位符时会追问
  • 关注的犯罪风险类型可选
    启动参数，可选；留空时按行业风险地图推荐重点类别
  • 当前涉案状态（纯预防 / 有苗头线索 / 已立案或被采取强制措施）必需
    读取配置「是否已涉案」或直接询问；决定是否触发强制升级
  • 具体行为描述：决策层级、收益归属、是否以单位名义实施可选
    单位犯罪构成识别一步的参数，用于三要素分析与责任人员识别
  • 现有内控制度与薄弱环节可选
    内控与防范机制一步的参数，用于判断各类制度现状（已有 / 缺失 / 不完善）
  • 涉案情况：案件状态、涉嫌罪名类型、是否已有律师可选
    涉案应对一步的参数，用于紧迫性分级与从宽情节评估
  • criminal-compliance/CLAUDE.md 实践配置可选
    读取执业角色、服务立场、合规严格度、是否已涉案、企业画像；缺失或含占位符时可说「临时模式」按默认值继续

产出

  • 单位犯罪构成识别分析报告给律师内部
    抬头（分析对象、服务立场、是否已涉案、分析日期）+ 研究性提示；一、主体资格确认；二、三要素分析（满足 / 不满足 / 存疑）与初步认定；三、双罚制责任人员识别；四、罪名单位主体可构成性（只写罪名描述，条号 [条号待验证]）；五、综合认定意见（研究性，非最终结论）
  • 常见单位犯罪类型分析报告给律师内部；可整理后给客户
    抬头（企业名称/行业、服务立场、重点关注类别、分析日期）+ 条号纪律提示；本企业重点风险罪名速查表（罪名描述 / 条号 / 单位可构成 / 保护法益 / 合规红线要点）；各类别详细构成要件分析；内控要点提示
  • 单位犯罪防范内控建议报告给客户（企业合规部门），律师审核后使用
    抬头 +「须经执业律师审核后实施重大内控调整」提示；一、制度建设优先级；二、禁止性行为清单（红线）；三、重点环节风险控制；四、岗位制衡与举报机制；五、内控有效性自查（符合 / 待改进 / 缺失）
  • 涉案合规应对指引给客户（企业），律师主导下使用
    抬头（企业名称、案件状态、涉嫌罪名类型（不写裸条号）、当前律师、编制日期）+ 必读声明（含 [强制升级 — 涉刑情形]）；一、紧迫性评估；二、配合调查合规边界（可为 / 不可为）；三、从宽情节评估（自首、立功、认罪认罚、合规整改）；四、合规不起诉路径初步判断
  • 对外提交版本给监管机关 / 执法机关
    向监管机关、执法机关提交的内控审查报告或合规说明材料：内部工作草稿与对外脱敏版两套，提交前须律师审核

04开始前

前置条件

  • 读取 criminal-compliance/CLAUDE.md，检查三处是否含 [PLACEHOLDER]：「我们是谁 > 执业角色」「合规与服务立场 > 整体服务立场」（须含「单位犯罪预防」或「事前合规」）、「合规与服务立场 > 是否已涉案」
  • 配置缺失或含占位符时显示配置提示：运行 /criminal-compliance:cold-start-interview 完成配置，或说「临时模式」按默认值继续
  • 临时模式默认值：执业角色为律师（最高权限）；服务立场为事前预防（单位犯罪预防立场）；合规严格度为保守型（所有疑点从严处理）；是否已涉案按用户陈述逐案判断，识别任何涉案迹象即强制升级。所有输出标 [临时模式 — 请运行冷启动访谈完成配置]，并警示：企业已被传唤、被立案或被采取强制措施的，立即联系执业刑事辩护律师，不要单独依据本工具作任何决策
  • 确认企业画像（行业 / 规模 / 业务模式 / 历史涉案情况 / 重点刑事风险领域）；含占位符时询问「请告知企业行业与主要业务模式，以便聚焦常见犯罪类型分析。」
  • 确认服务立场：事前预防立场（聚焦犯罪风险识别、内控制度建设与预防机制设计）；合规不起诉辅助立场（聚焦涉案应对与从宽路径，配合合规不起诉流程使用）；合规研究立场（单位犯罪法律研究与构成分析，不针对具体案件）
  • 在任何实质性分析前完成涉案情形检查：读取「是否已涉案」，或询问用户当前状态

硬性规则

涉案情形识别与强制升级（不可覆盖）
识别任一情形即触发并标记：企业或相关人员已被立案（公安或检察机关）→ [强制升级 — 已立案]；被采取强制措施（拘留/逮捕/取保候审/监视居住）→ [强制升级 — 强制措施]；已收到侦查传唤/询问通知 → [强制升级 — 侦查传唤]；有明确迹象可能构成具体罪名（非预防性询问）→ [强制升级 — 具体罪名风险]；重大涉案（多名高管/金额巨大/跨地区协查）→ [强制升级 — 重大涉案]。触发后输出 [强制升级 — 涉刑情形]：本流程定位于事前预防，不适用于已涉案情形的直接应对，请立即联系执业刑事辩护律师由其主导；建议改用合规不起诉流程并在律师指导下使用；律师指导下仍可调用单位犯罪构成识别（律师参考）与涉案应对框架（律师主导下使用）作研究背景
立场不能覆盖护栏
服务立场只决定各步骤的侧重：事前预防立场聚焦合规制度建设，涉案后应使用合规不起诉流程；强制升级与合规边界护栏不可被任何立场覆盖
不作最终定性
仅用于合规风险预防与刑事辩护研究，不替企业作有罪无罪的最终结论（那是司法机关与辩护律师的职责）；所有输出立足于「帮助企业在日常经营中识别和降低单位犯罪风险」
不提供规避侦查或逃避责任的方法
本流程及各步骤绝不提供：规避侦查的方法；伪造毁灭证据的建议；串供或统一口径的方案；转移资产逃避追缴的操作；将单位犯罪伪造成个人行为以减轻单位责任的操作；任何帮助逃避法律追究的方法。识别到一律拒绝，标 [合规边界 — 拒绝]，并提示「合规的唯一正道是依法整改、如实供述、认罪认罚争取从宽」
目的地/特权检查
向监管机关、执法机关提交的内控审查报告或合规说明材料，律师-当事人特权可能失效；生成此类材料前提供内部工作草稿版和对外提交脱敏版两套选项，并提示须律师审核后提交
地方涉案企业合规试点提示
各地涉案企业合规试点的适用口径、第三方监督评估机制、合规考察期标准存在地区差异；涉案应对中的相关内容均为规则描述，标 [地方 flagged — 需核实地方涉案企业合规试点口径与地方检察机关/公安机关实践]
条号与数额纪律
刑法第30/31/67/68/72条、刑事诉讼法第15/177条以「已核实锚点（中度把握），建议复核」引用；具体罪名条号一律 [条号待验证]、以构成要件描述呈现；定罪量刑数额只写「依相关司法解释，数额达一定标准」并标 [待验证]，绝不臆造条号与法定刑档

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置假设，可逐条复制。页面里的英文标记见首页「标记与术语」。

  1. 单位犯罪构成识别

    /criminal-compliance:unit-crime-constitution可单独运行

    判断企业特定行为是否可能构成单位犯罪（刑法第30条）、双罚制如何适用（第31条）、哪些人可能被认定为直接负责的主管人员和其他直接责任人员，并区分单位犯罪与借单位之名的个人犯罪；预防立场用于找出可能触发单位犯罪认定的行为特征以调整内控，辩护研究立场用于寻找不构成单位犯罪的抗辩要点。

    请律师核对

    • 核对 1.1主体资格表只列五类主体，合伙企业、个人独资企业、分支机构、一人公司的认定全部留作 [待验证]——是否由律师写入贵所采用的认定口径？
    • 核对 1.2原文一方面说「三要素须综合判断，不必全部单独满足即可认定单位犯罪」，另一方面在辩护立场下说「若能证明三要素中任一不满足，可能主张不构成单位犯罪」——两句是否需要统一表述？
    • 核对 1.3直接负责的主管人员典型人员列到「部门负责人（视决策链条）」，并称任何批准、签字、指示涉案业务的高管均可能被认定——这一责任范围是否符合贵所判断？
    • 核对 1.4部分违法所得归单位、部分归个人的情形如何认定，原文只写参见司法解释 [待验证]——是否需要律师补充现行认定规则？

    做法

    1. 读取配置的服务立场与是否已涉案：单位犯罪预防立场输出「哪些行为特征可能触发单位犯罪认定」供内控调整；辩护研究立场侧重不构成单位犯罪的抗辩要点（非以单位名义、未为单位利益、违法所得未归单位、单位人格否认），须律师主导；事前刑事风险评估立场输出风险等级。配置缺失时默认单位犯罪预防立场，标 [临时模式]
    2. 已立案或被采取强制措施的，立即标 [强制升级 — 涉刑情形]，构成要件分析只作辩护律师参考背景
    3. 步骤一 确认主体资格：对照公司、企业、事业单位、机关、团体五类主体表判断；合伙企业和个人独资企业是否被认定为单位、分支机构（子公司/分公司）、一人公司三类情形提示须参见相关司法解释 [待验证]
    4. 步骤二 三要素对照：逐项判断「以单位名义实施」（是否经决策机构决定、主要负责人授意或批准）、「为单位利益」（增加营收、扩大市场份额、规避成本等）、「违法所得归单位」（是否进入单位账户或用于单位经营），每项标满足 / 不满足 / 存疑，给出初步认定：可能构成单位犯罪 / 可能为借单位之名个人犯罪 / 需进一步核实
    5. 三要素综合判断，不要求全部单独满足（司法实践判断较复杂，须律师专项分析）；部分违法所得归单位、部分归个人的情形参见相关司法解释 [待验证]；辩护立场下若能证明任一要素不满足，可主张不构成单位犯罪
    6. 步骤三 识别双罚制责任人员：区分直接负责的主管人员（在单位犯罪中起决策、批准、授意、指挥作用）与其他直接责任人员（直接实施犯罪行为、起关键作用），列出可能涉及的人员及其决策或实施证据；并核对该罪名是否属于「分则另有规定」的单罚制情形 [条号待验证]
    7. 步骤四 核对刑法分则是否明确规定单位可构成该罪：明确规定（如单位行贿罪、虚开增值税专用发票罪，条号待验证）/ 未规定（如故意杀人罪等人身类犯罪，单位不能作为主体）/ 分则仅规定处罚自然人（单罚制，[待验证]）
    8. 步骤五 区分真实单位犯罪、借单位之名的个人犯罪、人格混同（一人公司股东与公司财产高度混同）三种情形；辩护研究立场下须以内部决策文件、资金流向记录等书面证据论证，由律师主导
    9. 特殊情形逐一标注风险并转律师专项分析：单位人格否认、一人公司财产混同程度、分公司是否具有独立法人资格、单位犯罪中的自然人与外部人员共同犯罪、涉嫌行为可能触发多个罪名（逐一分析各罪名的单位主体资格并标竞合风险）、并购重组后主体对历史涉案行为的责任继承
    10. 用户要求给出「是否构成犯罪」的最终结论时拒绝，改以构成要件比对描述，标 [合规说明 — 最终定性须律师判断]；用户提供条号要求确认时标 [待验证 — 请核实现行刑法条文]；「如何证明不知情以逃避追诉」这类投机性请求，区分合规辩护分析（由律师主导）与规避侦查，明显是逃避责任的标 [合规边界 — 拒绝]
    11. 按输出模板出具《单位犯罪构成识别分析报告》，第31条处注明建议复核与 [模型知识 — 需验证]

    内置规则

  4. 涉案应对

    /criminal-compliance:incident-response可单独运行

    企业被认定涉嫌犯罪（苗头 / 立案 / 强制措施）后，在合规边界内提供应对框架：配合调查的可为与不可为、自首与立功路径（刑法第67/68条）、认罪认罚从宽（刑事诉讼法第15条）、单位与责任人员的责任切割，并在符合条件时转入合规不起诉流程；全程以强制升级执业刑事辩护律师为硬性前提。

    请律师核对

    • 核对 4.1紧迫性分级把「已被立案」写为「律师到位前不采取任何应对行动」、把「已收到传唤」写为「当日联系律师」——时限与措辞是否符合贵所应急实践？
    • 核对 4.2可为/不可为表把「主张律师会见权、不被强迫自证其罪」列为可为，把「无律师在场接受询问并作出重大供述」列为不可为（建议律师确认后）——这些权利表述是否准确、措辞是否需要律师调整？
    • 核对 4.3自首要件写「被采取强制措施前主动投案」，又写投案时机「立案后仍可争取」，准自首、单位自首、重大立功均留作司法解释 [待验证]——是否需要律师补齐口径？
    • 核对 4.4转入合规不起诉的四项条件中「刑罚区间适宜」只写 [待验证]，未给区间——是否需要补充？

    做法

    1. 首先显著呈现声明：本工具不提供任何规避侦查、伪造或毁灭证据、逃避法律责任的方法；刑事合规的唯一正道是依法整改、如实供述、配合调查、认罪认罚争取从宽；所有实质性步骤须在执业刑事辩护律师指导下进行，企业涉嫌犯罪后务必立即聘请
    2. 硬性前提：本步骤的使用场景本身即涉案，无论处于苗头、立案还是强制措施阶段，一律输出 [强制升级 — 涉刑情形]，并按紧迫性分级表给出立即行动
    3. 读取服务立场：涉案企业合规不起诉立场侧重通过合规整改争取酌定不起诉（转入合规不起诉流程）；单位犯罪辩护研究立场侧重责任切割与量刑从宽（须律师主导）。配置缺失时按最保守处理，所有步骤须律师主导，标 [临时模式]
    4. 步骤一 给出配合调查合规边界清单，按供述、证据、资产、内部沟通、配合调查、律师权利六类逐项对照可为、不可为及后果，并再次声明不提供规避侦查等六类内容
    5. 步骤二 在律师指导下分析自首（自动投案 + 如实供述；准自首、单位自首参见司法解释 [待验证]）与立功（一般立功、重大立功）的要件与从宽幅度；投案时机须律师评估（立案后仍可争取）；上下游犯罪中揭发供应商或客户的违法行为可能构成立功，须律师评估，不当立功可能引发新问题
    6. 步骤三 说明认罪认罚从宽：自首、立功是刑法总则规定的从宽情节，认罪认罚是刑事诉讼程序中的从宽机制，二者可叠加适用，叠加策略须律师评估；列出四类从宽措施（标 [待验证 — 规范性文件快速演进]）与具结书签署须知
    7. 步骤四 在律师指导下按四个维度做责任切割：区分单位行为与个人行为（个人私下行为、超越授权行为）、直接负责的主管人员认定边界（不知情高管可收集会议记录、邮件记录中未参与决策的证据）、其他直接责任人员认定边界（分析各人具体角色与主观认识）、主动揭发与配合（相关人员揭发单位犯罪可能构成立功，单位揭发个人犯罪也可争取从宽）
    8. 责任切割的目标是准确区分各方的真实责任，不设计「让某人替他人受过」的方案；任何不实指控或推卸都不是合规应对，可能加重责任，须建立在真实事实基础上并由律师主导
    9. 步骤五 按四项要点判断是否转入合规不起诉：涉嫌经济类/职务类犯罪（非暴力犯罪）、认罪认罚三要件满足、愿意并有能力合规整改、刑罚区间适宜（描述规则 [待验证]）；符合时依次进入适用条件评估 → 合规计划制定 → 第三方监督评估配合 → 不起诉申请与听证
    10. 按边界情形处理：不同调查阶段（初查/立案/强制措施）分阶段说明要点且均须升级律师；单位与责任人员利益冲突时律师须同时评估并说明可能需要分别聘请律师；多名责任人员建议各自聘请律师避免利益冲突；行政处罚已先行时说明其对刑事追诉的影响（如逃税罪的特别规定 [待验证]）；涉外案件标注跨境复杂性与国际司法协助风险
    11. 识别到规避侦查、伪造毁灭证据、串供（统一口径）、转移资产需求一律拒绝，标 [合规边界 — 拒绝] 并提示加重罪责风险；非律师角色要求作出辩护策略最终判断时拒绝，标 [强制升级 — 辩护须律师主导]
    12. 按输出模板出具《涉案合规应对指引》

    内置规则

    • 紧迫性分级：已被立案（公安/检察机关）→ 紧急，立即聘律师，律师到位前不采取任何应对行动；被采取强制措施（拘留/逮捕/取保/监视居住）→ 紧急，立即聘律师，律师须尽快会见被羁押人员；已收到侦查传唤/询问通知 → 高，当日联系律师，由律师指导传唤应对；有苗头线索（监管关注/相关人员被调查）→ 高，尽快聘律师评估风险，避免在无律师指导下采取任何行动
    • 供述：可为——如实供述自己知晓的犯罪事实，对不知道的事实说明不知道；不可为——虚假供述、选择性供述（隐瞒关键事实）、对他人的事实作虚假陈述；后果为加重罪责、影响认罪认罚的真实性认定
    • 证据与资产：可为——依法保存与业务相关的合法文件、配合合法取证，如实申报资产、配合依法查封扣押；不可为——删除电子记录、销毁合同、篡改财务数据、转移账目、隐匿证据（构成独立的妨碍司法罪名 [条号待验证]），转移隐匿财产或离境转移资产（加重罪责、被认定为掩盖犯罪）
    • 内部沟通、配合调查与律师权利：可为——如实向律师汇报案情（受律师-客户特权保护）、在律师陪同下配合合法询问、主张律师会见权和不被强迫自证其罪；不可为——与涉案人员统一口径（串供，可能构成独立罪名）、销毁内部沟通记录、对抗调查或逃避传唤（加重情节）、在无律师在场情况下接受询问并作出重大供述（建议律师确认后，可能损害辩护权益）
    • 自首（第67条）：犯罪后、被采取强制措施前主动向公安/检察机关/法院投案（含犯罪地、居住地机关），并如实供述主要犯罪事实；不得仅供述次要事实而隐瞒关键事实，如实供述不等于替他人承担责任，不得以投案名义逃脱另案羁押；可以从轻或减轻处罚，犯罪较轻的可以免除处罚；单位自首可能同时覆盖相关责任人员，须律师评估
    • 立功（第68条）：一般立功——揭发他人犯罪经查证属实、提供重要线索得以侦破其他案件，可以从轻或减轻；重大立功——协助抓获重大犯罪嫌疑人、揭发重大犯罪线索经查证属实（「重大」参见司法解释 [待验证]），可以减轻或免除；须真实有效、不得捏造
    • 认罪认罚从宽措施四类：从轻量刑建议（认罪认罚满足三要件）；缓刑建议（须满足刑法第72条要件，认罪认罚 + 合规整改有助于满足缓刑四要件）；酌定相对不起诉（第177条，认罪认罚 + 合规整改有效 + 检察机关裁量）；适用速裁/简易程序 [待验证]
    • 具结书须知：须有辩护律师或值班律师在场见证；充分了解内容与后果后自愿签署；对量刑建议有重大分歧时由律师评估是否接受或申请调整

    法律依据

    • 《刑法》第68条 — 立功：揭发他人犯罪查证属实/提供侦破重要线索，可以从轻或减轻；重大立功可以减轻或免除 [模型知识 — 需验证]，已核实锚点（中度把握），建议复核
