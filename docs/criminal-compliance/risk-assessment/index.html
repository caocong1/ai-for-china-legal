01概要

帮助企业及其律师、合规官、法务系统识别刑事风险敞口、评定风险等级，输出带控制建议、责任部门和整改时限的刑事风险清单与刑事风险评估报告，既用于事前合规预防，也用于涉案应对中的合规整改。流程先读取 criminal-compliance/CLAUDE.md 的企业画像、服务立场（事前预防 / 涉案应对）、是否已涉案、合规严格度、刑事风险校准和升级矩阵；加载任何步骤前先检查是否已涉案，已立案或被采取强制措施即停止并强制升级执业刑事辩护律师。四步依次为：按行业对照表识别高发罪名并做构成要件速查；按采购、销售、财务、高管/实控人、法务/合规五类岗位识别行为风险点与单位犯罪责任人员范围；用「可能性 × 影响」4×4 矩阵评出关键 / 高 / 中 / 低四级，并判断风险是否已现实化；整合成 13 列风险清单、分级控制建议，并按目的地出内部完整版或对外脱敏版。具体罪名一律以构成要件描述、标 [条号待验证]，定罪量刑数额只描述规则并标 [待验证]，不作「一定构成 / 不构成某罪」的结论。

02适用与边界

适用场景

  • 需要评估「某具体行为或业务环节是否有刑事风险」，或对企业做一次刑事风险扫描
  • 事前预防立场：全面风险扫描，输出完整风险地图，控制建议侧重事前制度建设
  • 涉案应对立场（尚未立案或采取强制措施）：聚焦已涉嫌问题，输出整改建议，衔接合规不起诉流程
  • 实践配置「是否已涉案」为「有苗头线索」：继续评估，各步输出标注苗头预警
  • 只需其中一环时单独启动：某行业的罪名识别、某岗位的行为风险、对已知风险点评级，或仅输出风险报告
  • 刑事合规体系建设前后，需要用单次评估结论充实或更新合规风险地图

不做什么

  • 企业或相关人员已被立案或被采取强制措施：立即停止，标 [强制升级 — 涉刑情形]，联系执业刑事辩护律师；本流程输出只作辩护律师参考背景
  • 不替企业作有罪无罪的最终结论，不作「XX 行为一定构成/不构成 XX 罪」的绝对结论
  • 不提供规避侦查、对抗调查、销毁或转移证据、串供或统一口径、转移资产逃避刑事追缴等任何帮助逃避法律追究的方法
  • 不臆造具体罪名条号与法定刑档，不写裸数额
  • 境外法律风险超出本插件范围：涉外业务只说明中国刑法的属地管辖与属人管辖
  • 建立完整的合规制度、组织与培训体系：转刑事合规体系建设流程（/criminal-compliance:compliance-system-building）

03输入与产出

需要律师提供

  • criminal-compliance/CLAUDE.md 实践配置必需
    「我们是谁」（行业、业务模式、重点刑事风险领域）；「合规与服务立场」（整体服务立场、是否已涉案、合规严格度）；「刑事风险校准」四级定义；「升级矩阵」；报告步骤另读「文书风格」「输出」工作产物标题与「共享护栏」目的地/特权检查
  • 企业画像：主要行业、核心业务模式、是否涉外、历史涉案/行政处罚情况必需
    缺失时提示补充，不得猜测行业后静默进行；行业信息不足时暂停并标 [信息不足 — 请补充行业与业务模式]
  • 需分析的岗位/部门范围可选
    用户指定或取自配置的痛点；未指定时询问「请指定要分析的岗位范围，或选择全部岗位」
  • 已知风险事件或行为线索可选
    用户陈述；涉案应对立场下用于与构成要件比对，无则不询问
  • 已识别的风险点清单或前序步骤成果可选
    单独启动评级或报告步骤时必须提供，否则标 [信息不足 — 须先完成行业与岗位风险识别]
  • 报告目的地必需
    出具报告前确认：企业内部合规使用 / 向检察机关提交 / 向第三方监督评估组织提交，决定报告版本与脱敏范围

产出

  • 行业刑事风险识别报告给律师内部
    行业高发刑事风险点概览（风险点 / 罪名 / 典型触发情形 / 主体 / 初级评级）/ 重点罪名构成要件速查 / 行业监管特色（行刑衔接）/ 单位犯罪风险提示 / 标红项目 / 下一步
  • 岗位刑事风险点分析报告给律师内部
    岗位行为风险点汇总表（岗位 / 高风险行为 / 罪名 / 风险等级 / 控制要点）/ 各岗位详细分析 / 单位犯罪责任人员范围分析 / 重点风险项目 / 下一步
  • 刑事风险等级评估报告给律师内部
    风险等级汇总表（风险点 / 罪名 / 可能性 / 影响程度 / 风险等级 / 是否已现实化 / 处置优先级）/ 各风险点详细评估 / 关键风险汇总 / 风险排序与整改优先级 / 下一步
  • 刑事风险评估报告（内部完整版）给律师内部 / 客户
    按执业角色选标题（律师角色「律师工作产物 — 受律师-当事人特权保护 / 保密」；非律师角色「研究笔记 — 合规研究与初步分析，非法律建议，供律师审查」）/ 执行摘要 / 刑事风险清单 / 重点风险项详述与控制建议 / 待升级事项清单 / 控制建议汇总与合规体系衔接 / 涉案企业合规衔接（仅涉案应对立场）/ 报告限制声明
  • 对外提交版本给检察机关 / 第三方监督评估组织（须律师审核定稿）
    向检察机关提交的脱敏版（仅含整改措施与成果，不含内部法律意见）；向第三方监督评估组织提交的整改评估版（聚焦整改措施的可验证性与实施进度）

04开始前

前置条件

  • 读取 criminal-compliance/CLAUDE.md 六项配置：企业画像（驱动行业罪名识别范围）、整体服务立场（决定各步侧重与输出内容）、是否已涉案、合规严格度（风险标红阈值）、刑事风险校准（四级定义，驱动风险评级步骤）、升级矩阵（贯穿全流程）
  • 加载任何步骤前先检查「是否已涉案」：已立案或被采取强制措施立即停止；有苗头线索继续评估但标注苗头预警；纯预防正常进行全流程
  • 配置文件不存在或关键字段含 [PLACEHOLDER] 时，提示运行 /criminal-compliance:cold-start-interview；或由用户告知服务立场与是否已涉案后以临时模式继续：事前合规预防立场 / 律师角色 / 合规严格度保守 / 是否已涉案按用户陈述逐案判断且识别涉案即强制升级 / 行业按用户陈述判断，输出标 [临时模式 — 请运行冷启动访谈完成配置]
  • 确认已从「我们是谁」读取企业画像，并明确告知用户当前服务立场；立场缺失时以事前预防为默认

硬性规则

企业画像确认
开始任何步骤前确认已读取企业画像（行业、业务模式、重点风险领域）；缺失时提示用户补充，不得猜测行业后静默进行
服务立场是核心变量
事前合规预防立场做全面风险扫描、输出完整风险地图、控制建议侧重事前制度建设；涉案应对立场聚焦已涉嫌问题、输出整改建议、衔接合规不起诉流程；立场缺失时进入临时模式并以事前预防为默认
合规严格度
保守型偏高评级 / 平衡型按实际证据评级 / 务实型有明确证据方提高等级
涉案强制升级（最高优先级）
加载任何步骤前检查是否已涉案；已立案或被采取强制措施立即停止，标 [强制升级 — 涉刑情形]，提示请立即联系执业刑事辩护律师，本插件仅提供合规研究背景材料，不替代辩护律师的专业判断与辩护工作；本护栏凌驾于服务立场与合规严格度之上，不可被任何立场配置覆盖
不作定罪结论
所有输出立足事前预防与依法整改，不替企业作有罪无罪的最终结论（司法机关与辩护律师的职责），不作「一定构成/不构成」的绝对结论；具体罪名以构成要件描述呈现并标 [条号待验证]
不提供规避方法
规避侦查、对抗调查、销毁或转移证据、串供或统一口径、转移资产逃避刑事追缴、任何帮助逃避法律追究的方法，一律拒绝并标 [合规边界 — 拒绝]，提示合规的唯一正道是依法整改、如实供述、认罪认罚争取从宽；已涉案须在执业刑事辩护律师指导下处理
目的地与特权检查
面向检察机关、公安机关或第三方监督评估组织提交的材料须律师指导脱敏，不得包含自证其罪的内容；具体处理见第四步
地方试点提示
涉及具体地区时标 [地方 flagged — 需核实地方涉案企业合规试点口径与地方检察机关实践]；各地试点覆盖范围、第三方监督评估机制运行细节、合规认定标准可能有差异

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置假设，可逐条复制。页面里的英文标记见首页「标记与术语」。

  1. 行业高发罪名识别

    /criminal-compliance:industry-crime-identification可单独运行

    按企业所属行业识别高发刑事风险点与对应罪名类别，给出行业刑事风险地图与构成要件速查表，帮助快速定位风险敞口。

    请律师核对

    • 核对 1.1行业表只有 7 个具体行业加「混合/跨行业」，实践配置模板举例的「食品」行业没有对应行，是否需要补充？补充哪些罪名？
    • 核对 1.2安全生产高危行业的主体只标「自然人（直接责任人）」，其他行业均为「单位 + 自然人」，这一区分是否认同？
    • 核对 1.3金融/投资行业写「操纵证券期货市场罪」，合规风险识别步骤写「操纵证券市场罪」，引用库 C节写「操纵证券、期货市场罪」，罪名表述需要统一。
    • 核对 1.4涉案应对立场下做构成要件比对时只加标 [强制升级 — 涉案应对]、不停止分析，这一处理是否恰当？

    做法

    1. 读取 CLAUDE.md「我们是谁」的行业、业务模式、重点刑事风险领域，以及服务立场、是否已涉案、合规严格度；识别到已被立案、被采取强制措施、可能构成具体罪名（明确迹象）、重大涉案的，立即标 [强制升级 — 涉刑情形] 并不继续分析，只提供初步合规背景。
    2. 确认行业与业务模式四项：主要行业（如制造、金融、医药、建设）、核心业务模式（如自营生产 + 出口、经纪 + 理财产品销售）、是否涉外、历史涉案/行政处罚情况；配置未写的逐项询问用户（如「请描述企业主要业务」），不猜测。
    3. 对照 8 行业高发罪名表提取罪名类别：制造/贸易、金融/投资、医药/器械、房地产/建设、环保敏感行业、安全生产高危行业、互联网/科技、混合/跨行业（结合各行业风险点综合识别），每行写明典型触发情形与主体（单位 + 自然人 / 自然人）。
    4. 对每个识别出的罪名按 8 个维度做构成要件速查：罪名（[条号待验证]）、保护法益、客观行为、主体（单位犯罪双罚制适用 / 自然人 / 均可）、主观要件（故意 / 过失 + 是否有特殊目的）、定罪量刑数额标准（依相关司法解释，[待验证]）、行业触发特征、是否适用双罚制；具体罪名参照 _shared/criminal-law-citations.md C节。
    5. 按服务立场调整侧重：事前预防立场列出本行业所有高发罪名类别，重点写哪些业务环节存在触发风险、如何在制度与流程层面预防，为风险评级和风险清单提供输入；涉案应对立场聚焦已涉嫌或关注的罪名，比对企业实际行为与构成要件（哪些已满足、哪些存疑），标 [强制升级 — 涉案应对]，注明比对仅为初步分析、最终认定须执业刑事辩护律师判断。
    6. 说明本行业常见的单位犯罪形态：单位犯罪认定（刑法第30条，建议复核：以单位名义、为单位利益实施，违法所得归单位）与双罚制（刑法第31条，建议复核）对单位、直接负责的主管人员、其他直接责任人员的影响。
    7. 单独识别涉外行业风险点（走私 / 跨境），并说明本行业主要监管机构（税务、市场监管、证监、药监、环境、应急、网信）与刑事追诉衔接的典型路径，移送标准只描述规则并标 [待验证]。
    8. 输出行业刑事风险识别报告：每个风险点给出「高 / 中 / 低」初级评级并注明待风险评级步骤精评，已有明确风险迹象的列为须优先处置的标红项目。

    内置规则

    • 行业表要点：制造/贸易 → 虚开增值税专用发票罪、逃税罪、假冒注册商标罪、走私普通货物物品罪、重大责任事故罪；金融/投资 → 非法吸收公众存款罪、集资诈骗罪、操纵证券期货市场罪、内幕交易罪；医药/器械 → 对非国家工作人员行贿罪、单位行贿罪、生产销售伪劣产品相关罪名；房地产/建设 → 串通投标罪、单位行贿罪、对非国家工作人员行贿罪、重大责任事故罪；条号一律 [条号待验证]
    • 环保敏感行业（化工 / 能源 / 制造）→ 污染环境罪；安全生产高危行业（矿山 / 建筑 / 危化品）→ 重大责任事故罪、重大劳动安全事故罪，主体标为「自然人（直接责任人）」；互联网/科技 → 非法经营罪（无资质从事特许经营业务）、侵犯公民个人信息罪
    • 行业表只是识别指引，不构成对企业是否构成犯罪的判断，具体认定须结合企业实际情况与执业律师专业意见
    • 定罪量刑数额一律「描述规则 + [待验证]」，不写裸数额；绝不臆造罪名条号与法定刑档；用户要求或口述具体条号时拒绝臆造，标 [前提 flagged — 具体罪名条号待验证]
    • 以单位名义但实为个人获益、单位犯罪与自然人犯罪区分不清时，说明单位意志与个人决定、违法所得归属的认定逻辑，标 [待验证 — 须律师核实单位犯罪认定]
    • 一行多罪时逐一列出可能的罪名类别并说明竞合逻辑，标 [待验证 — 罪数认定须律师核实]
    • 新型业务模式（互联网新业务、数字资产等）标 [待验证 — 新型业务模式刑事定性尚存争议，须律师专项研究]
    • 涉外业务只说明中国刑法的属地管辖与属人管辖，境外法律风险超出本插件范围；行业信息不足时暂停询问，标 [信息不足 — 请补充行业与业务模式]

    法律依据

    • 《刑法》第30条 — 单位犯罪定义：公司、企业、事业单位、机关、团体实施危害社会的行为，法律规定为单位犯罪的应当负刑事责任 [模型知识 — 需验证]，已核实锚点（中度把握），建议复核
    • 《刑法》第31条 — 单位犯罪双罚制：对单位处罚金，对直接负责的主管人员和其他直接责任人员处刑 [模型知识 — 需验证]，已核实锚点（中度把握），建议复核

  2. 岗位与行为风险点

    /criminal-compliance:position-conduct-risk可单独运行

    按岗位与职责识别各岗位人员的职务相关行为风险点与对应罪名类别，梳理单位犯罪双罚制下的责任人员范围，精准定位岗位刑事合规风险。

    请律师核对

    • 核对 2.1岗位只覆盖采购、销售、财务、高管/实控人、法务/合规五类，安全生产、环保、对外融资负责人未覆盖（合规风险识别步骤与插件说明均列有安全生产岗），是否需要补充？
    • 核对 2.2各岗位红线行为（如「收受任何形式的供应商财物利益」「无书面审批凭证付款」）是否过严或过宽？
    • 核对 2.3对照表把挪用资金罪写为「已归还不一定免责」，把「直接负责的主管人员」扩展到分管业务的中层主管，这些口径是否认同？
    • 核对 2.4法务/合规岗位「提供虚假合规意见」的对应罪名只写「视具体情形」，是否需要更具体的罪名指引？

    做法

    1. 读取 CLAUDE.md 行业、业务模式、重点刑事风险领域以判断本企业的高风险岗位，并读取服务立场、是否已涉案、合规严格度（影响红线行为标注密度）；已被立案、被采取强制措施或可能构成具体罪名的，立即标 [强制升级 — 涉刑情形]，只提供合规背景参考。
    2. 确认岗位范围（采购、销售、财务、高管、法务/合规，或全部岗位）、企业行业、是否有已知风险事件；未指定岗位时询问用户，无已知事件则不追问。
    3. 采购岗位对照 5 个行为风险点：收受供应商回扣/礼金、向供应商索取好处换取订单（非国家工作人员受贿罪，主动索取亦构成）、串通特定供应商排斥竞争（串通投标罪，招投标环节）、虚构采购套取资金（职务侵占罪）、挪用资金至供应商账户（挪用资金罪）。
    4. 销售岗位对照 5 个行为风险点：向客户行贿以获取合同（对非国家工作人员行贿罪）、无真实交易虚开销售发票（虚开增值税专用发票罪）、以欺骗手段签订合同（合同诈骗罪）、向政府采购人员行贿（单位行贿罪，以单位名义行贿则构成单位犯罪）、销售仿冒品牌产品（假冒注册商标罪）。
    5. 财务岗位对照 5 个行为风险点：私自挪用账款（挪用资金罪）、将公司财物占为己有（职务侵占罪）、明知虚开仍配合记账核销（可能构成虚开增值税专用发票罪共犯）、协助虚假申报（逃税罪）、资金往来用于非法目的（须结合资金用途与知情程度判断 [待验证]）。
    6. 高管/实控人岗位对照 5 个行为风险点：决策实施单位行贿（单位与决策高管均受追诉）、虚报业绩操纵股价（操纵证券期货市场罪，上市公司场景）、利用内幕信息决策交易（内幕交易罪）、关联交易损害公司利益（背信损害上市公司利益等职务类罪名）、决策批准虚开发票（直接负责的主管人员，双罚制适用）。
    7. 法务/合规岗位对照 3 类风险：明知违规仍参与（共同犯罪）、帮助违规操作合法化（帮助类罪名）、提供虚假合规意见（视具体情形，须结合主观故意与危害后果判断 [待验证]），并特别提示「明知」边界与合规人员自身的合规义务。
    8. 按刑法第31条（建议复核）分析单位犯罪责任人员范围：「直接负责的主管人员」指对犯罪行为有决策、批准、授意、指挥、参与作用的领导人员（法定代表人、董事长、总经理、分管副总、部门负责人，视具体案件）；「其他直接责任人员」指直接实施、起关键实施作用的工作人员（具体操作人员、经办人员）。
    9. 用对照表区分易混淆的职务类罪名：职务侵占罪（公司企业非国家工作人员，非法占有目的）、挪用资金罪（公司企业非国家工作人员，暂时使用，已归还不一定免责）、贪污罪/挪用公款罪（国家工作人员）；按服务立场调整侧重：事前预防侧重红线与预防，涉案应对侧重责任切割。

    内置规则

    • 采购红线（保守型严格度标红）：收受任何形式的供应商财物利益；为特定供应商泄露竞争对手信息；私自修改采购合同关键条款
    • 销售红线：以单位名义向政府采购人员或国有企业采购人员给付任何形式财物；销售无品牌授权产品
    • 财务红线：无书面审批凭证付款；无真实业务凭证核销；违反授权审批程序操作大额资金
    • 高管红线：批准向政府官员或其亲属给付任何财物；利用任何内幕信息交易本公司证券；决策损害上市公司股东利益的关联交易
    • 责任人员认定要点：须结合具体案件事实，不能仅凭职务名称认定；「直接负责的主管人员」不限于最高层领导，分管业务的中层主管亦可能被认定；「其他直接责任人员」须对犯罪行为有直接参与，不包括一般知情人员；具体认定以司法机关与辩护律师的专业判断为准
    • 法务/合规人员知悉公司某项业务存在刑事风险仍参与推动，可能构成共同犯罪；合规人员知悉违规时建议书面记录异议并升级汇报，不得压制风险报告
    • 单位意志与个人行为区分不清标 [待验证 — 须律师核实单位犯罪认定]；明知与共谋边界模糊、跨岗位多人参与标 [待验证 — 共同犯罪认定须律师核实]；国家工作人员与非国家工作人员区分标 [待验证 — 身份认定须核实]
    • 涉案责任人员已被刑事追诉的，暂停本步并标 [强制升级 — 责任人员已涉案]；岗位信息不足时暂停并标 [信息不足 — 请补充岗位与职责描述]；用户要求具体条号时标 [前提 flagged — 具体罪名条号待验证]

  3. 风险等级与可能性评估

    /criminal-compliance:risk-level-likelihood可单独运行

    对前两步或用户提供的刑事风险点做「可能性 × 影响程度」结构化评估，输出关键 / 高 / 中 / 低四级风险等级与是否已现实化分层，为风险清单提供评级基础。

    请律师核对

    • 核对 3.1矩阵中「低可能性 × 极高影响」「极高可能性 × 低影响」都只评为「中」，这一配置是否符合贵所的风险偏好？
    • 核对 3.2等级定义把「关键」限定为「可能构成具体罪名或已立案/强制措施」，但矩阵对尚未现实化的风险（如可能性高 × 影响极高）也会得出「关键」并触发强制升级，是否接受？
    • 核对 3.3「已有线索」层建议「评估主动披露/自首选项」，这一建议的提出时机与措辞是否恰当？
    • 核对 3.4多罪并存时按「最重可能罪名」定级，是否认同？

    做法

    1. 读取 CLAUDE.md「刑事风险校准」的四级定义与本企业适用的触发情形阈值，以及服务立场、是否已涉案、合规严格度；「是否已涉案」为已立案或被采取强制措施、或识别到明确可能构成具体罪名的迹象，立即标 [强制升级 — 涉刑情形]，评估只作辩护律师参考背景。
    2. 确认待评估风险点：取自行业罪名识别与岗位风险识别的输出，或用户直接描述的具体行为或业务环节（做构成要件比对的合理性检查，标 [待验证]）；清单为空或不完整时要求用户提供或先跑前两步。
    3. 评估可能性四级（极高 Very High / 高 High / 中 Medium / 低 Low），综合五个因素：行为触发程度（是否已满足或接近满足客观构成要件，条号待验证）、内控有效性、行业监管强度（是否处于重点监管阶段，行政违法升格刑事的路径是否通畅）、历史行政处罚记录、相关岗位人员合规意识。
    4. 评估影响程度四级（极高 Catastrophic / 高 Severe / 中 Moderate / 低 Minor），综合五个因素：可能罪名法定刑档（描述规则，条号与刑期档位标 [待验证]）、单位罚金对企业财务的冲击、直接负责的主管人员与其他直接责任人员被判处有期徒刑的可能性、企业声誉与行业资质（如金融牌照、药品许可证）、客户流失、合同解除、融资困难等次级影响。
    5. 套用 4×4 矩阵得出风险等级，并按等级定义给出处置原则：关键 → 强制升级刑事辩护律师、立即停止相关行为、紧急整改；高 → 律师主导评估、列入优先整改清单、设立专项控制措施；中 → 纳入合规改进计划、定期复查、补充内控；低 → 维持现有控制、定期审查确认有效性。
    6. 对每个风险点另判「是否已现实化」四层：未现实化（纯风险）→ 预防控制、合规制度建设；苗头（内审异常、举报线索、异常业务往来）→ 立即核查、启动内部调查、评估是否升级律师；已有线索（行政检查已关注、关联方已被立案、有举报或媒体曝光）→ 立即升级律师、评估主动披露/自首选项、停止违规行为；已立案/强制措施 → 立即强制升级刑事辩护律师。
    7. 按服务立场调整侧重：事前预防侧重发生可能性与预防控制，为合规体系建设提供优先级；涉案应对侧重是否已现实化与可能构成具体罪名的程度，须配合律师主导。
    8. 输出风险等级汇总表、各风险点详细评估（评级理由）、关键风险汇总、风险排序与整改优先级（关键「立即」、高「1个月内」、中「季度内」），高风险项建议启动专项合规整改并转刑事合规体系建设流程。

    内置规则

    • 矩阵（每行是一个可能性等级，四列依次对应影响 极高 / 高 / 中 / 低）：可能性极高 → 关键 / 关键 / 高 / 中；可能性高 → 关键 / 高 / 高 / 中；可能性中 → 高 / 高 / 中 / 低；可能性低 → 中 / 中 / 低 / 低
    • 等级定义：关键 = 可能构成具体罪名或已立案/强制措施，须立即处置；高 = 重大刑事风险敞口、高发罪名典型行为模式、尚未现实化；中 = 风险存在但未到紧迫程度、合规制度存在缺口；低 = 风险可接受、内控基本有效
    • 合规严格度：保守型同等证据下偏高评级、遇不确定情形偏高评级；平衡型按实际证据评级；务实型有明确证据方提高等级
    • 识别到关键级风险即触发 [强制升级]；评级为关键的必须标注涉刑强制升级建议，不得评级后仅给出「加强内控」等轻描述
    • 风险敞口难以量化（无法判断构成要件满足程度）时偏高评级（保守原则），标 [评级不确定 — 须律师专项研究]
    • 同一行为可能触发多个罪名时，按最重可能罪名（构成要件最严格匹配的）定级，并说明其他竞合可能性
    • 可能性与影响评级矛盾（可能性低但影响极高，或反之）时按矩阵规则处置，说明矛盾原因与不确定性，标 [评级说明 — 矩阵结果受限于已知信息]
    • 行刑衔接只说明行政处罚是否已被触发以及升格刑事的条件（描述规则，[待验证]）；用户要求判断是否构成某罪时只做构成要件比对，注明「构成要件描述仅供参考，刑事定性须执业律师判断」，标 [合规说明 — 最终定性须律师判断]

    「刑事风险等级评估报告」markdown：评估对象来源、服务立场、是否已涉案、合规严格度、评估日期；风险等级汇总表（风险点 / 罪名 / 可能性 / 影响程度 / 风险等级 / 是否已现实化 / 处置优先级）；各风险点详细评估与评级理由；关键风险汇总；风险排序与整改优先级（建议行动与时限）；下一步。

  4. 风险清单与控制建议输出

    /criminal-compliance:risk-list-control-output可单独运行

    整合行业、岗位与评级成果，输出结构化刑事风险清单与分级控制建议，生成按目的地区分版本的刑事风险评估报告。

    请律师核对

    • 核对 4.1关键风险的主责预设为「CEO/法定代表人直接负责」，若风险点本身源于法定代表人决策，是否应改由董事会或外部律师牵头？
    • 核对 4.2关键风险控制建议中的「证据保全」限定为在律师指导下保全「合规努力证据（审批记录、培训记录等）」，这一表述是否足以避免被理解为选择性留存？
    • 核对 4.3报告模板中的风险清单汇总表只有 10 列（缺控制建议、责任部门、验收标准），与本步要求的 13 列不一致，三列只出现在逐项详述中，是否接受？
    • 核对 4.4向检察机关的脱敏版「仅包含整改措施与成果，不包含内部法律意见」，这一脱敏边界是否符合贵所实践？

    做法

    1. 读取 CLAUDE.md 服务立场、是否已涉案、「文书风格」报告风格偏好、「输出」工作产物标题（律师 / 非律师）、「共享护栏」目的地/特权检查；已立案或被采取强制措施的标 [强制升级 — 涉刑情形]，报告降级为辩护律师参考背景材料。
    2. 汇集前三步成果：行业高发罪名与触发情形、岗位行为风险点与责任人员范围、风险等级与是否已现实化分层；缺失的要求用户补充或先启动对应步骤，以不完整输入继续时标 [信息不足 — 报告基于不完整输入]。
    3. 构建 13 列刑事风险清单：风险点编号（R-001、R-002…）、风险点描述、对应罪名（罪名类别 + 构成要件要素，[条号待验证]）、涉及岗位、涉及业务环节（采购 / 销售 / 财务 / 审批 / 外部合作等）、可能性等级、影响程度等级、综合风险等级、是否已现实化、控制建议、责任部门、整改时限（立即 / 30天内 / 90天内 / 持续改进）、验收标准。
    4. 按等级制定控制建议：关键 → 立即停止可能构成罪名的行为、立即联系执业刑事辩护律师评估法律性质、在律师指导下保全相关合规努力证据（审批记录、培训记录等）、触发内部强制上报程序以避免后续共同犯罪风险；高 → 制定或修订专项合规制度、关键节点增设审批或合规审查、禁止性清单书面告知相关岗位、规定合同/发票/审批单/往来函件的留痕存档、针对性培训并记录考核结果；中 → 完善制度漏洞、增加复核或抽查、建立风险指标监测；低 → 维持现有措施、纳入年度合规审查。
    5. 按等级分配整改时限与主责、监督部门（见规则）。
    6. 按目的地区分报告版本：企业内部合规使用出完整版（含律师工作产物特权标注，不得对外披露）；向检察机关提交出脱敏版（仅含整改措施与成果，不含内部法律意见，提示律师-当事人特权可能失效、须律师指导脱敏、不包含自证其罪的内容）；向第三方监督评估组织提交出整改评估版（聚焦整改措施的可验证性与实施进度，须律师指导明确提交范围）。
    7. 撰写报告：按执业角色选标题；执行摘要写明识别风险点总数及关键 / 高 / 中 / 低各多少个、须立即处置项、条号与数额待验证提示；附刑事风险清单、重点风险项逐项详述（R-001 等）、待升级事项清单（已涉案应对方案 → 执业刑事辩护律师；向检察机关提交材料 → 执业刑事律师；合规整改计划定稿 → 执业律师）、控制建议按主题汇总并指向刑事合规体系建设流程、涉案企业合规衔接（仅涉案应对立场，转 /criminal-compliance:non-prosecution 并由执业律师主导）、报告限制声明。
    8. 交付前做合规边界检查：逐条检查控制建议是否含规避侦查成分，有则删除并标 [合规边界 — 拒绝]；面向检察机关或第三方监督评估的版本须律师审核定稿。

    内置规则

    • 整改时限与责任：关键 → 立即（发现当日），CEO/法定代表人直接负责，法律部/合规部（律师主导）监督；高 → 30天内完成初步整改、90天内完成全面整改，分管副总/业务负责人主责，合规部监督并须律师参与审核；中 → 90天内纳入合规改进计划并启动，相关部门负责人主责，合规部监督；低 → 下一周期合规审查时复核，相关岗位负责人主责
    • 风险点超过30个时分层呈现：汇总表先行，重点呈现关键和高风险项，中低风险项放附录
    • 风险清单须定期更新（建议季度或年度），重大业务变化时触发重新评估
    • 事前预防立场输出完整风险地图，清单覆盖全部识别到的风险点，控制建议侧重事前防范制度建设；涉案应对立场聚焦已涉嫌问题与整改建议，控制建议衔接合规不起诉申请，须与律师主导的合规计划协调
    • 非律师角色在报告定稿前要求对外提交的，暂停并标 [律师审查护栏 — 须律师审核]，注明非律师角色须律师审核后方可对外提交；涉案应对报告拟作对外自证材料的，标 [特权检查 — 须律师确认披露范围]
    • 已涉案时报告仅作律师参考，不得直接提交检察机关；面向检察机关的版本强制律师审核并明确提示特权失效
    • 控制建议落地难（内部阻力大）时建议升级管理层背书，并纳入刑事合规体系建设的组织支持设计
    • 罪名条号一律 [条号待验证]，定罪量刑数额依司法解释描述规则并标 [待验证]，涉案企业合规规范性文件标 [待验证]；报告声明本报告不构成法律意见，不替代执业律师的专业判断

09何时暂停或升级

  • 「是否已涉案」为「已立案或被采取强制措施」，或识别到可能构成具体罪名的明确迹象、重大涉案：立即停止，标 [强制升级 — 涉刑情形]，提示立即联系执业刑事辩护律师，输出只作辩护律师参考背景
  • 「是否已涉案」为「有苗头线索」：继续评估，各步输出标注苗头预警，并在风险评级步骤触发高优先级评级
  • 评级为关键：必须标注涉刑强制升级建议，立即停止相关行为并升级律师
  • 风险点「已有线索」（行政检查已关注、关联方已被立案、有举报或媒体曝光）：立即升级律师，评估主动披露 / 自首选项
  • 涉案责任人员已被刑事追诉：暂停岗位风险分析，标 [强制升级 — 责任人员已涉案]
  • 识别到规避侦查、销毁文件、串供、转移资产需求：拒绝并标 [合规边界 — 拒绝]
  • 非律师角色在报告定稿前要求对外提交：暂停，标 [律师审查护栏 — 须律师审核]；面向检察机关、第三方监督评估组织的版本一律律师审核定稿
  • 单位犯罪认定、罪数、共同犯罪、身份认定、新型业务定性、评级不确定：标相应 [待验证 — 须律师核实……] 或 [评级不确定 — 须律师专项研究]，提示律师专项研究
  • 行业信息或岗位信息不足：暂停询问，不猜测

10请律师重点核对

下面是这个流程内置的法律假设、立场、阈值和清单，每一条都可以同意、反对或补充。条目下的「相关批注」按文字重合自动匹配到步骤旁的核对条目，可能不全。

  1. 流程只区分「事前预防」与「涉案应对」两种立场，而实践配置文件列出 6 种整体服务立场（事前刑事风险评估、事前合规体系建设、涉案企业合规不起诉、单位犯罪预防、单位犯罪辩护研究、混合多类型），报告模板又写「若服务立场为『涉案企业合规不起诉』」。SKILL.md 未规定其余立场如何对应到这两种侧重。
  2. 风险矩阵中「低可能性 × 极高影响」只评为「中」，「极高可能性 × 低影响」也只评为「中」；保守型严格度另有「遇不确定情形偏高评级」。这一矩阵配置与偏高原则是否符合贵所的风险偏好？相关批注：核对 3.1
  3. 「关键」等级定义为「可能构成具体罪名或已立案/强制措施」，但矩阵对尚未现实化的风险（如可能性高 × 影响极高）同样得出「关键」，而「识别到关键风险即触发强制升级」。是否接受由矩阵推出的关键级直接强制升级刑事辩护律师，还是应先区分是否已现实化？相关批注：核对 3.2
  4. 行业对照表只有制造/贸易、金融/投资、医药/器械、房地产/建设、环保敏感、安全生产高危、互联网/科技 7 类加「混合/跨行业」；实践配置模板举例的「食品」行业没有对应行，「能源化工」只出现在环保敏感行业。是否需要新增行业或罪名？相关批注：核对 1.1
  5. 岗位对照只覆盖采购、销售、财务、高管/实控人、法务/合规 5 类；插件说明称本步覆盖「法定代表人/财务/采购/销售/安全生产等」，合规风险识别步骤还列有安全生产、环保、项目经理、对外融资负责人。安全生产等岗位缺失，是否需要补充？相关批注：核对 2.1
  6. 整改时限分级：关键立即（发现当日）、高 30 天内初步整改且 90 天内全面整改、中 90 天内纳入改进计划、低下一周期复核；关键风险由「CEO/法定代表人直接负责」。若风险本身源于法定代表人决策，这一主责安排是否需要调整？相关批注：核对 4.1
  7. 「已有线索」层的处置包括「评估主动披露/自首选项」，关键风险的控制建议包括「在律师指导下，保全相关合规努力证据（审批记录、培训记录等）」。这两处措辞是否符合贵所执业口径？是否应明确要求全面保全，而不只是保全有利材料？相关批注：核对 3.3、核对 4.2
  8. 定位分歧：刑事合规体系建设流程把本流程定位为「单次刑事风险评估：评估某具体行为是否有刑事风险」，插件说明也写「面向单次事件触发」，但本流程在事前预防立场下做「全面风险扫描，输出完整风险地图」。两者如何分工，需要律师明确。
  9. 罪名表述不统一：行业识别步骤写「操纵证券期货市场罪」，合规风险识别步骤写「操纵证券市场罪」，引用库 C节写「操纵证券、期货市场罪」；岗位步骤另有「背信损害上市公司利益等」。请律师按现行刑法罪名统一。相关批注：核对 1.3
  10. 入口要求「有苗头线索」时在风险评级步骤「触发高优先级评级」，但评级步骤对苗头只规定「立即核查、启动内部调查、评估是否升级律师」，SKILL.md 未规定苗头如何改变矩阵结果。
  11. 向检察机关只提交「仅包含整改措施与成果，不包含内部法律意见」的脱敏版，并提示特权可能失效、不得包含自证其罪的内容；向第三方监督评估组织提交「整改评估版」。这一脱敏边界与版本划分是否符合贵所实践？相关批注：核对 4.4
  12. 合规严格度三档的评级规则只有定性描述（保守偏高、平衡按实际证据、务实有明确证据方提高），没有量化标准或示例。是否需要补充贵所的判断样例？
