01概要

为尚未涉案的企业搭建事前预防型刑事合规体系，四步各出一份文件：企业刑事合规风险底图、合规制度体系设计方案、合规组织与培训体系建设方案、合规体系有效性评估报告。先从业务、岗位、区域、关联方四个维度定出重点合规领域，据此设计制度与审批、组织与培训，再用指标、年度审计和整改闭环检验体系是否真正运行，防止「纸面合规」。具体罪名只写构成要件、条号标 [条号待验证]，有效合规认定标准只描述规则并标 [待验证]。发现已立案、被采取强制措施、收到侦查传唤等涉案情形的，立即停止，强制升级给执业刑事辩护律师。

02适用与边界

适用场景

  • 企业尚未涉案，要建立或完善刑事合规管理体系：风险底图、制度、组织、评估一套做全
  • 本领域实践配置的整体服务立场是「事前合规体系建设」
  • 只需其中一环：只要风险底图、只要制度设计、只要组织与培训方案，或只要有效性评估
  • 已用刑事风险评估流程评估过某次事件的风险，需要据此更新企业的合规风险地图
  • 合规体系已经建成，需要定期检查是否真正运行，防止「纸面合规」

不做什么

  • 企业或相关人员已被立案、被采取强制措施、收到侦查传唤，或有明确迹象可能构成具体罪名：立即停止，强制升级给执业刑事辩护律师；涉案后的整改转合规不起诉方案流程，须律师主导
  • 评估「某个具体行为有没有刑事风险」：请用刑事风险评估流程
  • 不替企业作有罪无罪的最终结论，不回答「会不会被追诉」；也不出具涉案后的「有效合规证明」，涉案后是否有效合规由第三方监督评估机制认定
  • 不提供规避侦查、伪造毁灭证据、串供、转移资产的任何方法：制度里不写「应对突击检查」的证据清理规程，评估报告里不写「哪些材料不宜留存」
  • 行业专项合规细节（如医药合规、金融监管合规）只给通用框架，须结合行业法律专家的意见

03输入与产出

需要提供

  • 本领域的实践配置必需
    取行业、规模、服务立场、合规严格度、是否已涉案和制度文本风格；未填写的按临时模式
  • 三项确认：企业画像（行业、规模、主要业务模式、是否涉外）、服务立场（事前合规体系建设，或含涉案应对的混合立场）、是否已涉案（纯预防、有苗头线索、已立案或被采取强制措施）必需
    任何一步开工前都要确认；已涉案的立即停止并强制升级
  • 企业实际开展的业务环节，以及常见环节以外的特殊业务必需
    第 1 步逐项确认，如数据跨境、医疗器械、金融产品代销、政府采购
  • 现有组织架构和已有合规部门的情况可选
    第 3 步据此提补强建议，而不是推翻重建
  • 已有的制度清单、审批记录、培训记录、举报记录、内审报告、整改台账可选
    第 4 步评估制度是否真正执行的证据来源
  • 刑事风险评估流程的评估结论可选
    可以作为合规风险地图的输入

04开始前

前置条件

  • 先读本领域的实践配置：整体服务立场须为「事前合规体系建设」；「是否已涉案」显示任何已涉案情形的，立即强制升级，整个流程停止；行业、规模、重点刑事风险领域决定各步侧重，合规严格度贯穿各步。
  • 实践配置不存在或关键项未填写的，提示先做冷启动访谈；也可以由使用者口述服务立场和企业画像，按临时模式继续（事前合规体系建设立场、律师角色、保守型严格度），所有成果标 [临时模式 — 请运行冷启动访谈完成配置]。
  • 任何一步开始前，先向使用者确认企业画像、服务立场、是否已涉案三项。
  • 各步按本领域的法律依据引用规范和刑事合规法律引用库引用：具体罪名条号一律待验证，罪名构成要件取自引用库，涉案企业合规规范性文件只描述规则。

硬性规则

涉案即强制升级
出现任一情形立即停止整个流程、联系执业刑事辩护律师：已立案（转合规不起诉方案流程）、被采取强制措施（拘留、逮捕、取保、监视居住）、收到侦查传唤或询问通知、有明确迹象可能构成具体罪名、重大涉案；成果只作合规研究背景资料
不作定罪结论
本流程用于合规风险预防与体系建设，不替企业作有罪无罪的最终结论
合规不对抗调查
不以「合规」为名规避侦查、伪造毁灭证据、串供、转移资产；「应对突击检查」的证据清理规程、「哪些材料不宜留存」之类实质对抗调查的建议一律拒绝，标 [合规边界 — 拒绝]，提示正道是依法整改、如实供述
与风险评估分工
刑事风险评估流程是单次评估，回答「某具体行为有没有刑事风险」；本流程做风险底图、制度、组织、评估全套；两者的结论可以互相充实对方的风险地图
与合规不起诉分工
本流程是尚未涉案时的事前建设；涉案后的专项整改计划属于合规不起诉方案流程，须律师主导；事前建立的有效合规体系是争取合规不起诉的重要基础（有效合规认定标准 [待验证]）
目的地与特权检查
内部使用的加注「律师工作产物 — 受律师-当事人特权保护」；拟对外提交（如向检察机关提交合规报告）的，提交与否和内容须由律师指导决定，直接提交可能被作为证据使用
引用纪律
刑法第30、31、67、68、72条标「建议复核」；具体罪名条号一律 [条号待验证]、以构成要件描述；有效合规认定标准和涉案企业合规规范性文件只描述规则，标 [待验证 — 规范性文件快速演进，须核实现行版本]；案号一律 [待验证]，案例不具判例法约束力

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置判断，可逐条复制。

  1. 合规风险识别

    可单独使用

    从业务、岗位、区域、关联方四个维度画出企业刑事合规风险地图，定出重点合规领域，作为后三步的依据

    请律师核对

    • 核对 1.1业务环节表只列 10 个环节、岗位表只列 8 类岗位、关联方只列 6 类，是否需要补充贵所客户常见的业务和岗位（如人力资源、IT 与数据管理）？
    • 核对 1.28 个重点合规领域中，「反垄断合规」只对应串通投标罪和「垄断行为的刑事追诉衔接」，而业务环节表已列的知识产权（假冒注册商标罪）、走私没有单列领域，领域划分是否需要调整？
    • 核对 1.3几个领域并列时按「已有行政处罚记录 → 涉及金额大或人数多 → 法定代表人直接参与」排序，这一先后顺序是否认同？
    • 核对 1.4小企业以「20 人以下」为界、只识别前三个领域，与第 3 步以「50 人以下」为小型企业的分界不一致，贵所以哪个分界为准？

    做法

    1. 读实践配置，把企业画像（行业、规模、业务模式、是否涉外、历史涉案情况、重点刑事风险领域）复述给使用者，确认准确后才开始识别，画像有更新就重新识别；合规严格度（保守、平衡、务实）决定识别深度和红线标记的疏密，未配置的按临时模式继续。
    2. 业务维度：以「采购 → 生产 → 销售 → 财务 → 对外融资」为主线，逐环节对照十个业务环节的风险点表（见规则），请使用者确认企业实际开展哪些环节，并补充表外业务（如数据跨境、医疗器械、金融产品代销、政府采购）。
    3. 岗位维度：按岗位职责和日常决策权限，对照八类岗位（法定代表人或 CEO、财务总监或 CFO、采购总监或经理、销售总监或代表、安全生产负责人、环保负责人、项目经理或工程部门、对外融资负责人）的高风险行为和双罚制关联，按企业实际定出关键、高、中等三级高风险岗位清单。
    4. 区域维度：考察经营地的执法强度（税务稽查频次、安监执法力度、环保整治行动）、各地检察机关参与涉案企业合规试点的程度和适用口径 [待验证 — 规范性文件快速演进]、跨地区经营风险，以及自贸区、跨境电商、保税区等涉外地区的海关与外汇风险；涉及特定地区的标「地方规定需核实」（当地涉案企业合规试点口径与检察机关实践）。
    5. 关联方维度：识别供应商、销售中介或代理商、股东或投资方、政府对接人员、合作方或联营体、境外关联公司六类关联方的风险传导，例如代理商代企业行贿带来行贿共同犯罪风险，股东指令非法融资或借关联交易掏空企业带来非法集资、职务侵占风险。
    6. 把四个维度的结果汇入八个合规领域（反商业贿赂、税收、反垄断、金融融资、数据隐私、安全生产、环境、财务内控），就业务相关性、岗位敞口、关联方传导各评高、中、低，给出红、橙、黄三档优先级，列出建议优先建设的前三个领域及理由；出报告前自查：关键高管是否都已列入、双罚制下两类责任人员的风险是否已分析、罪名条号是否都标 [条号待验证]、严格度是否体现在标记疏密上、是否已说明与刑事风险评估流程的分工。

    内置规则

    • 十个业务环节与罪名：采购与供应链 → 单位行贿罪、虚开增值税专用发票罪；销售与营销 → 对非国家工作人员行贿罪、非法经营罪；财务与资金 → 挪用资金罪、职务侵占罪、非法吸收公众存款罪；税务申报 → 虚开增值税专用发票罪、逃税罪、骗取出口退税罪；生产与安全生产 → 重大责任事故罪、重大劳动安全事故罪；对外融资 → 非法吸收公众存款罪、集资诈骗罪；出口与进口 → 走私普通货物物品罪（偷逃应缴税额达一定标准，依司法解释 [待验证]）；环境与废弃物处置 → 污染环境罪；招投标 → 串通投标罪、合同诈骗罪；知识产权 → 假冒注册商标罪。条号一律 [条号待验证]
    • 岗位与双罚制：法定代表人或 CEO 为「高度关联——决策层直接负刑事责任」，对应单位犯罪的「直接负责的主管人员」；CFO 对应虚开、逃税、挪用资金罪的「其他直接责任人员」；安全生产负责人、环保负责人为「直接责任人员风险」
    • 几个领域都是高优先级、难以排序时按三条原则：已有行政处罚记录的领域优先；涉及金额大、人数多的领域优先；法定代表人直接参与的领域优先
    • 小企业（20 人以下）只重点识别前三个高风险领域，制度设计相应简化，并注明成本约束；企业画像严重不足（行业、业务都没提供）的，只给通用识别框架，等待补充
    • 新型业务（元宇宙、数字资产、平台经济）对应罪名不明的，描述行为模式与构成要件的相似之处，标 [新型业务 — 需法律研究]，提示咨询专业律师；行刑衔接只描述规则，移送标准标 [待验证]，使用者确认监管部门已有行政处理记录的须升级律师
    • 发现已发生的风险事件（已受行政处罚、发生事故、被举报、有内部违规记录），立即做强制升级评估，达到刑事追诉门槛的标 [强制升级 — 涉刑情形]
    • 使用者口述的罪名条号标 [待验证]，改写为构成要件描述，建议到国家法律法规数据库核实；要求评估「会不会被追诉」的，不作定罪结论，只描述构成要件特征、标风险等级——有罪无罪是司法机关和辩护律师的判断

    法律依据

    • 《刑法》第30条 — 单位犯罪定义，作为风险识别的主体分析基础 [模型知识 — 需验证]，已核实锚点（中度把握），建议复核
    • 《刑法》第31条 — 单位犯罪双罚制，岗位维度据此区分「直接负责的主管人员」（决策授权的高管）与「其他直接责任人员」（执行层） [模型知识 — 需验证]，已核实锚点（中度把握），建议复核
    • 《刑事诉讼法》第177条 — 不起诉（酌定相对不起诉是涉案企业合规不起诉的主要路径） [模型知识 — 需验证]，已核实锚点（中度把握），建议复核
    • 七类罪名构成要件（税收、金融、职务、商业贿赂、扰乱市场秩序、环境与安全、走私），取自刑事合规法律引用库 — 条号一律 [条号待验证]，定罪量刑数额描述规则并标 [待验证]
    • 涉案企业合规改革试点相关文件 — 企业涉嫌特定经济犯罪、认罪认罚、愿意整改的，可启动合规考察程序，考察期满评估后决定是否不起诉 [模型知识 — 需验证] [待验证 — 规范性文件快速演进，须核实现行版本]
    • 企业合规第三方监督评估机制相关规定 — 第三方评估对合规整改是否有效的认定是合规不起诉的重要依据 [模型知识 — 需验证] [待验证 — 规范性文件快速演进，须核实现行版本]

    产出

    《企业刑事合规风险底图》：企业全貌、风险地图、高风险岗位、关联方风险、建议优先建设的三个领域、与刑事风险评估的分工、下一步

  2. 合规制度与流程设计

    可单独使用

    把合规风险地图变成可落地的制度：合规政策与行为准则、重点领域专项制度、合规审批与禁止性清单，并把控制点嵌入日常业务

    请律师核对

    • 核对 2.1合规政策把违规后果写成「纪律处分 → 解除劳动合同 → 移送司法机关」三级梯度，「移送司法机关」由谁决定、依什么标准，流程没有规定。是否应写明由律师评估？
    • 核对 2.2禁止性清单的「证据销毁」对应「妨害证据罪」，刑事合规法律引用库没有收录这个罪名，表述是否与现行刑法罪名一致？请律师核对。
    • 核对 2.3七类审批中礼品、境外付款、现金交易的触发金额全部留给企业设定，是否需要贵所给出参考区间？
    • 核对 2.4政府官员接触只要求合规部门审批和留存接触记录，「两节」期间特别限制的具体内容没有写明，是否需要补充？

    做法

    1. 读实践配置并确定设计依据：行业、规模、业务模式决定专项制度覆盖哪些领域，合规严格度决定禁止性清单的严格程度和审批触发门槛，制度文本按配置里的合规制度文本风格写（未配置的按临时模式并标 [临时模式]）；依据第 1 步（或使用者提供）的风险地图和高风险岗位清单、行业监管要求（如金融监管、医药合规），大型企业做成体系，中小企业简化到能落地。
    2. 搭四层制度并写明各层由谁批准：总纲《合规管理总体政策》由董事会或最高决策层批准；《员工行为准则》由 CEO 或总经理批准；专项制度（如《反商业贿赂制度》《税收合规制度》）由合规委员会或董事会批准；操作规程（如《礼品娱乐申请程序》《差旅合规报销规程》）由合规部门或业务部门负责人批准。
    3. 起草合规政策，写明五项核心内容：法定代表人或 CEO 签署、表明对刑事合规零容忍的合规承诺（高层表率）；适用于全体员工和第三方，供应商、代理商、合作方须签合规承诺书；独立、保密的举报渠道（热线、邮箱）和不打击报复政策；违规后果梯度（纪律处分 → 解除劳动合同 → 移送司法机关）；适用的现行法律框架（刑法第30、31条双罚制的含义，建议复核）。
    4. 按风险地图选适用领域，起草五类专项制度：反商业贿赂、反垄断（含串通投标）、数据合规、安全生产、财税合规（要点见规则）。
    5. 设计七类分级合规审批，列出七类刑事红线禁止性行为清单，每类红线写明涉及罪名的构成要件并标 [条号待验证]；在八个业务环节嵌入合规控制点并指定责任岗位（见规则）。
    6. 出方案并附制度落地五步计划：执业律师法律合规审查 → 管理层批准与签署 → 全员培训与知悉确认 → 细化配套操作规程 → 试行与反馈优化；明确注明本方案是草案，须执业律师审查定稿。

    内置规则

    • 七类分级审批（审批人／所需文件）：一般礼品娱乐（直接主管加合规专员／礼品申报表）；顾问或代理协议（合规部门加法务／尽职调查报告和合同审查）；政府官员接触（合规部门／接触记录表）；三重一大决策（集体决策加合规部门见证／集体决策记录）；关联交易（合规委员会，适用时加独立董事／公允价值评估）；境外付款（财务负责人加合规部门／业务合理性说明和合同）；现金交易（财务负责人／书面说明）。礼品价值上限、一般礼品审批下限、境外付款和现金交易的触发金额都由企业自行设定，流程不给具体数额

    • 八个业务环节的控制点（控制方式／责任岗位）：供应商选择（准入尽职调查加合规承诺书／采购部门加合规专员）；合同签署（合同法律合规审查单／法务或合规部门）；差旅报销（报销系统设合规信息项加合规专员抽查／财务加合规专员）；三重一大决策（合规影响评估表加集体审批签字／合规委员会）；投标准备（投标合规审批单／业务部门加合规专员）；税务申报（申报前合规审查／财务负责人加税务顾问）；安全生产（定期检查加隐患整改台账／安全生产负责人）；对外融资（融资方案合规审批／法务或合规部门加管理层）
    • 中小企业（20 人以下）合并制度层级，用一份综合《员工合规手册》代替多份专项制度，重点保留禁止性清单和关键审批；制度与现有管理体系冲突（如现有采购流程与合规审批冲突）的，找出冲突节点，整合进现有流程，保持单一权威流程，不另起炉灶
    • 使用者说「制度上看起来合规即可，不想真正执行」的，提示形式合规挡不住刑事追诉，第 4 步会核查实质执行情况（可参考涉案企业合规规范性文件对有效合规的要求 [待验证]）；金融、药品等特许经营行业只给通用框架，提示须结合监管法规专项审查和行业法律专家意见，本步只管刑事合规风险
    • 制度设计绝不为规避侦查留口子：不设合规名义下的证据销毁规程、对抗调查程序，要求设计「如何规避证据留存」的程序一律拒绝并标 [合规边界 — 拒绝]；数据跨境要求须核实数据出境安全评估规则 [待验证]；涉及对外提交的制度须律师审核

  3. 合规组织与培训

    可单独使用

    为制度落地配好组织和人员：按规模设计合规组织与首席合规官的独立性，划分三道防线，定培训、考核问责与合规文化方案

    请律师核对

    • 核对 3.1企业分档以「500 人以上 / 50–500 人 / 50 人以下」划分，与第 1、2 步「20 人以下」的小企业口径不一致，贵所以哪一套为准？
    • 核对 3.2较重违规的处置包含「罚款（依劳动合同约定）」，是否符合贵所对用人单位内部罚款的实践口径？
    • 核对 3.3合规委员会成员预设含 CFO，而第 1 步把 CFO 列为单位犯罪「其他直接责任人员」高风险岗位，这一组成是否需要调整？
    • 核对 3.4培训频次（高管每年至少 1 次、合规专项每年至少 2 次、新员工入职第一周内完成）和记录保存「不少于 5 年」，是否作为贵所的默认建议？
    • 核对 3.5三道防线的说明把第二道防线的合规官列为涉案时通常的「直接负责的主管人员」之一，这一口径是否认同？

    做法

    1. 读实践配置里的企业规模、行业（决定组织设置的复杂度）、团队规模（决定合规人员专职还是兼职）和合规严格度（影响独立性要求和培训频次），以刑法第30、31条作为组织设计的刑事责任分析基础。
    2. 按企业规模选定组织方案并复述给使用者确认：大型企业（500 人以上，或上市公司、国企）设专职首席合规官或合规总监、合规管理部门、各业务线合规员和合规委员会；中型企业（50–500 人）设专职合规负责人（兼任总法律顾问）、合规工作小组和关键业务合规岗位；小型企业（50 人以下）设兼职合规负责人（法务总监或 CEO 直接负责）和合规工作联络员。已有合规部门的，请使用者说明现有架构，诊断独立性、职责、培训体系的缺口后补强，不推翻重建。
    3. 设计合规委员会和首席合规官（组成、职责、汇报路径、任职条件见规则）；中大型企业在销售、采购、财务、生产、安全各核心部门各设 1 名业务合规员，由合规部门任命、业务部门认可，日常向业务负责人汇报，合规事项以虚线向合规部门汇报，合规表现纳入绩效、表现好的优先晋升。
    4. 划分三道防线：业务部门是第一道（业务负责人对本部门合规风险负第一责任）；合规、风险管理、法律部门是第二道（独立于业务部门）；内审部门和外部审计机构是第三道（独立评价体系有效性，发现前两道防线失效）。写明这一划分在涉案时用来厘清责任边界：「直接负责的主管人员」通常是第一道防线的业务决策负责人或第二道防线的合规官，「其他直接责任人员」通常是具体执行层。
    5. 制定四层培训计划（见规则），形式包括面授、在线、案例研讨、合规情景模拟（模拟礼品娱乐申请、供应商谈判中的合规决策）和新员工入职培训（入职第一周内完成，签署《行为准则知悉确认书》）；每次留存时间、主讲人、参与人员、签到表和培训材料，在线培训保存完成率和测验成绩，记录保存不少于 5 年（须核实法定期限 [待验证]）。
    6. 设计考核问责与合规文化：高管和部门负责人按部门违规事件数、整改完成率、培训参与、举报处理做年度考核，权重为「绩效考核占比不低于 [X]%」（企业自行设定）；业务合规员半年考核一次，一般员工年度考核；违规按四级梯度处置（见规则）；合规文化五要素是高层表率、合规激励、举报文化、合规开放对话（如合规顾问「开放日」）、合规可视化。

    内置规则

    • 合规委员会：由董事会授权设立，成员含独立非执行董事或独立董事、首席合规官、法律总顾问、CFO；负责审批重大合规政策、审议重大违规事件及处置结果、督导年度合规审计；直接向董事会汇报、不经过 CEO；至少每季度开会一次，重大事项随时召开。首席合规官：有直接向董事会或合规委员会汇报的渠道，不受业务负责人制约；负责制定政策、运营合规程序、培训、接收举报、主导合规调查；须有法律、合规或会计背景，了解刑事合规实务，无相关刑事记录；不因发现并上报违规而受到不利影响
    • 四层培训：高管——单位犯罪双罚制、「直接负责的主管人员」认定规则 [待验证]、有效合规认定标准 [待验证]、重大违规案例警示，每年至少 1 次，新高管上任时必须；合规专项（合规、法务、财务、审计人员）——每年至少 2 次；业务岗——六类岗位对应罪名的构成要件、禁止性清单和举报渠道（销售：对非国家工作人员行贿罪；采购：非国家工作人员受贿罪；财务：虚开增值税专用发票罪、逃税罪；安全生产：重大责任事故罪、重大劳动安全事故罪；对外融资：非法吸收公众存款罪、集资诈骗罪；数据处理：侵犯公民个人信息罪），每年至少 1 次，新员工上岗前必须；全员基础——合规承诺、行为准则要点、举报渠道，每年至少 1 次
    • 问责梯度：一般违规（未遵守操作规程、漏报礼品）→ 书面警告加补充培训；较重违规（违反禁止性清单但未达刑事程度）→ 记过、降职、罚款（依劳动合同约定）；严重违规（可能构成犯罪）→ 停职调查、内部调查、解除劳动合同、评估是否移送司法机关；不实举报（恶意打击报复他人）→ 对举报人问责。主动自查上报的轻微违规可以从轻，被动发现的按常规处理，拒不配合调查的从重；不得以问责为名打击报复举报人
    • 首席合规官的独立性是有效合规的关键要素 [待验证 — 规范性文件快速演进，须核实现行版本]；必须向 CEO 汇报才能运作的，设计双线汇报（日常向 CEO，重大合规事项直接向合规委员会或董事会），并提示独立性不足可能影响有效合规认定 [待验证]
    • 培训案例须经律师筛选确认、核实案号 [待验证]，不臆造案例细节；培训材料里的法律内容须经执业律师审核，具体罪名以构成要件描述并标 [条号待验证]
    • 特殊情形：中小企业设不了专职合规部门的，用兼职合规负责人、合规工作联络员加定期外部合规顾问的精简方案，并写明最低组织保障要求；跨国企业须符合中国本地刑事合规要求，境外合规官不替代中国本地合规负责人；家族企业权力集中的，提示独立性风险，建议外部合规顾问作为第三道防线、合规委员会引入外部独立成员；合规审批拖慢业务的，设快速通道或电子化审批、明确审批时限，区分必须审批和自行合规的事项
    • 要求合规组织「配合隐瞒」违规信息的，拒绝并标 [合规边界 — 拒绝]，提示合规组织的职责是发现并上报违规，隐瞒会加重刑事责任风险

  4. 合规有效性评估与整改

    可单独使用

    检验合规体系是否真正运行、防止「纸面合规」：定期审计与自查、问题整改闭环，并说明事前有效合规与合规不起诉的衔接

    请律师核对

    • 核对 4.1衔接说明第三点写明「已建立合规体系且留有记录，有助于证明违规系部分人员个人行为而非单位决策，可能影响单位犯罪认定」，这一立场是否同意？是否需要更审慎的措辞？
    • 核对 4.2培训完成率「95% 以上」、同类问题再发率按「整改后 12 个月内」统计，是否作为贵所的默认指标？
    • 核对 4.3各「[N] 个工作日」时限（举报回应、启动调查、整改各环节）是否需要预填建议值？
    • 核对 4.4严重问题处置中「评估是否向司法机关报告」由谁决定、依什么标准，流程没有规定，是否应写明由律师决定？
    • 核对 4.5审计频次（全面审计每年 1 次、专项审计半年 1 次、业务自查每季度 1 次、外部评估每年 1–2 次）是否适合不同规模的客户？

    做法

    1. 读实践配置里的行业、规模（影响评估复杂度和审计频次）、合规严格度（影响指标严格程度）和是否已涉案；已立案或被采取强制措施的，立即强制升级并转合规不起诉方案流程。
    2. 按四个维度、各五项指标评估（指标见规则）：制度健全性看制度文件、与行业最佳实践对标；执行有效性靠访谈、问卷、案例测试，核查审批和培训记录；监测发现能力看举报统计、内审发现率、自查完成情况；响应整改能力看整改闭环完成率、同类问题再发率、整改时效。
    3. 制定年度审计计划：全面合规审计（内审，每年 1 次，覆盖全部重点领域）；专项合规审计（内审加合规部门，高风险领域半年 1 次）；日常合规监控（合规部门，持续进行）；业务自查（各业务部门，每季度）；外部合规评估（外部律师或合规顾问，视需要每年 1–2 次）。审计按计划、准备、现场审计、整理发现、草稿报告、被审计部门确认、最终报告推进，再到整改方案、合规委员会审议、监督执行、整改验证、闭环。
    4. 安排各业务部门季度自查：合规部门定标准化自查清单，业务合规员组织自查并填报，发现问题或疑似违规立即上报合规部门（不得自行处置或隐瞒），结果留存供内审抽查。
    5. 每个问题走八个环节的整改闭环：发现 → 定性（一般、较重、严重，判断是否涉及刑事风险）→ 根因分析（制度缺失、人员认知、流程漏洞、管理层因素）→ 整改方案 → 执行并留档 → 内审或合规部门独立验证 → 复盘改进、纳入年度合规报告 → 合规委员会或首席合规官确认后关闭台账条目；同时按严重程度分级处理（见规则）。
    6. 撰写与合规不起诉的衔接说明：只用规则描述写出事前有效合规的四点积极作用（见规则），全部标 [待验证 — 规范性文件快速演进，须核实现行版本]，不写文号、认定标准的具体条款和认定流程细节；尚未涉案的继续完善体系、保存合规记录，已涉案的立即强制升级，结合合规不起诉方案流程评估是否适用。

    内置规则

    • 四个维度各五项指标：制度健全性——政策完整性、对照风险地图的覆盖范围、禁止性清单、可落地性、随刑法修正案和司法解释 [待验证] 及时更新；执行有效性——培训完成率（目标示例 95% 以上）、测验通过率、关键节点审批执行率、行为准则知悉率、高风险岗位情景测试通过率；监测发现能力——举报渠道使用率、举报处理及时性、内审合规发现率、财务费用交易异常监控（如大额现金、单次费用超限预警）、自查与上级复查发现问题的比率；响应整改能力——违规响应及时性、整改按时完成率、同类问题在整改后 12 个月内的再发率、根因分析质量、整改是否经独立验证
    • 举报回应、违规事件启动调查、整改各环节的时限都写成「[N] 个工作日」，由企业设定；举报渠道使用率不单向评价：年度举报数过低可能说明举报文化不健全，过高要分析原因
    • 严重程度分级：一般问题（操作规程未遵守、审批漏填、培训未参加）由合规部门内部处理并记台账；较重问题（违反禁止性清单但未达刑事程度、审批实质缺失）报合规委员会知悉、问责责任人、专项整改；严重问题（可能构成犯罪、重大违规、管理层授意违规）立即标 [强制升级 — 涉刑情形]，律师介入内部调查，向合规委员会或董事会报告，评估是否向司法机关报告
    • 衔接说明的四点积极作用（均为规则描述，[待验证]）：合规体系完整（制度、组织、培训、评估四位一体），说明企业有预防意识和能力；合规记录完备（审计报告、自查记录、培训签到、整改台账），是体系实质运行的证明；案发风险隔离——已建体系且留有记录，有助于证明违规是部分人员的个人行为而非单位决策，可能影响单位犯罪认定（须结合案情由律师评估）；第三方评估认可——事前完善的体系是可信整改的基础
    • 整改须经内审或合规部门独立验证，不能自我宣称；自查报告有美化的，强调内审的独立评估，必要时引入外部律师或合规顾问。识别纸面合规靠访谈、现场测试、案例测验，访谈随机抽样、不只访谈合规部门的人；定性指标多的，以第一次评估为基准线，之后与之对比
    • 企业发现重大违规却不想上报的，提示隐瞒可能加重刑事风险（如妨害调查），并做 [强制升级 — 涉刑情形] 评估；涉案后要求出具「有效合规证明」的，提示须由第三方监督评估机制（规范性文件 [待验证]）认定而不是本流程，立即强制升级并转合规不起诉方案流程
    • 评估报告默认内部使用；是否向检察机关等外部提交由律师指导决定，直接提交可能被作为证据使用。索要「有效合规」认定的文号或具体标准的，不写文号，建议到最高人民检察院官网核实现行版本，标 [待验证 — 规范性文件快速演进]；以「合规评估」名义整理规避侦查的证据处理方案，一律拒绝并标 [合规边界 — 拒绝]

08交付前检查

  • 企业全貌已向使用者确认；业务维度覆盖全部实际业务环节；法定代表人、CEO、CFO 等关键高管都已列入岗位风险评估，执行层高风险岗位已识别，双罚制（刑法第31条，建议复核）下「直接负责的主管人员」与「其他直接责任人员」的风险已分析
  • 区域维度已考察经营地的监管特点，地方涉案企业合规试点口径已标「地方规定需核实」；主要供应商、中介、合作方的关联风险已识别；合规风险地图以表格列出领域、风险点、敞口、优先级，合规严格度已体现在标记疏密上
  • 制度层级清楚（总纲、行为准则、专项制度、操作规程），合规政策含法定代表人或 CEO 的合规承诺，专项制度按风险地图定制；禁止性清单覆盖主要刑事红线、措辞无歧义；三重一大、顾问协议、政府官员接触都设了合规审批；采购、销售、财务、投标、安全生产流程已嵌入控制点；制度已与现有人事、财务、业务体系整合，中小企业已适度简化
  • 合规委员会向董事会、首席合规官向董事会或合规委员会的独立汇报渠道已设计；三道防线分工表已完成；业务岗培训与高风险岗位一一对应；培训记录要求（签到、完成率、成绩、保存年限）已明确；违规问责梯度清楚
  • 四个维度的评估指标、年度审计计划、八个环节的整改闭环和按严重程度分级处理都已建立，严重问题触发涉刑强制升级；审计、自查、培训、整改台账的保存要求已明确
  • 有效合规认定标准没有写文号和具体条款编号；具体罪名条号都标 [条号待验证]、以构成要件描述，规范性文件只描述规则并标 [待验证]；没有已涉案迹象（有的已强制升级）；没有以制度或评估之名规避侦查的内容；已说明与刑事风险评估流程的分工

09何时暂停或升级

  • 已立案、被采取强制措施、收到侦查传唤，或发现可能构成具体罪名的明确迹象、重大涉案：立即停止整个流程，开工时按情形标 [强制升级 — 已立案]、[强制升级 — 强制措施]、[强制升级 — 侦查传唤]、[强制升级 — 具体罪名风险]、[强制升级 — 重大涉案]，各步执行中发现的统一标 [强制升级 — 涉刑情形]，提示联系执业刑事辩护律师
  • 发现已发生的风险事件（已受行政处罚、发生事故、被举报、有内部违规记录），或使用者确认监管部门已有行政处理记录：做强制升级评估，达到刑事追诉门槛的升级给律师
  • 合规审计发现严重问题（可能构成犯罪、重大违规、管理层授意违规）：立即强制升级，律师介入内部调查，向合规委员会或董事会报告，后续处置在律师指导下决定；企业发现重大违规却不想上报的，提示隐瞒可能加重刑事风险，并做 [强制升级 — 涉刑情形] 评估
