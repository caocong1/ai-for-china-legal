01概要

为尚未涉案的企业搭建事前预防型刑事合规体系，依次产出企业刑事合规风险底图、合规制度体系设计方案、合规组织与培训体系建设方案、合规体系有效性评估报告四份文件；律师、合规官、法务可跑完整四步，也可单独启动任一步。流程先读取 criminal-compliance/CLAUDE.md 的「我们是谁」（行业、规模、业务模式、重点刑事风险领域）和「合规与服务立场」（服务立场、合规严格度、是否已涉案），配置缺失时以临时模式按「事前合规体系建设立场 · 律师角色 · 保守型合规严格度」运行。四步依次为：从业务、岗位、区域、关联方四个维度识别风险并定出重点合规领域；按四层制度体系、五类专项制度、分级审批和禁止性清单设计制度并嵌入业务流程；按企业规模设计合规组织、三道防线、四层培训、考核问责与合规文化；用四维度指标、年度审计计划和八阶段整改闭环评估有效性。具体罪名一律以构成要件描述并标 [条号待验证]，罪名构成要件取自 _shared/criminal-law-citations.md C节，有效合规认定标准只描述规则并标 [待验证]；一旦识别已立案、强制措施、侦查传唤等涉案情形，立即停止并强制升级执业刑事辩护律师。

02适用与边界

适用场景

  • 企业尚未涉案，需要「建立或完善企业刑事合规管理体系」：全面风险底图 + 制度 + 组织 + 评估
  • 实践配置的整体服务立场为「事前合规体系建设」
  • 只需其中一环时单独启动：只要风险底图、只要制度设计、只要组织培训方案或只要有效性评估
  • 已用刑事风险评估流程（/criminal-compliance:risk-assessment）评估过单次事件风险，需要据此更新企业合规风险地图
  • 合规体系已建成，需要定期评估是否真正运行，防止「纸面合规」

不做什么

  • 企业或相关人员已被立案、被采取强制措施、收到侦查传唤，或有明确迹象可能构成具体罪名：立即停止并升级执业刑事辩护律师，涉案后整改转合规不起诉流程（/criminal-compliance:non-prosecution），须律师主导
  • 评估「某具体行为是否有刑事风险」的单次评估：转刑事风险评估流程（/criminal-compliance:risk-assessment）
  • 不替企业作有罪无罪的最终结论，不回答「是否会被追诉」
  • 不提供规避侦查、伪造毁灭证据、串供、转移资产的任何方法；不在制度中加入「应对突击检查」的证据清理规程，不在评估报告中写「哪些材料不宜留存」
  • 不出具涉案后的「有效合规证明」：涉案后的有效合规由第三方监督评估机制认定
  • 行业专项合规细节（如医药合规、金融监管合规）只给通用框架，须结合行业法律专家意见

硬性规则

涉案情形强制升级
识别到以下任一情形立即停止整个流程：已被立案 → [强制升级 — 已立案]，联系执业刑事辩护律师并转 /criminal-compliance:non-prosecution；被采取强制措施（拘留 / 逮捕 / 取保 / 监视居住）→ [强制升级 — 强制措施]，立即联系执业刑事辩护律师；已收到侦查传唤/询问通知 → [强制升级 — 侦查传唤]；可能构成具体罪名（明确迹象）→ [强制升级 — 具体罪名风险]；重大涉案情形 → [强制升级 — 重大涉案]。已涉案时输出仅作合规研究背景资料，不替代执业刑事辩护律师的辩护工作
预防立场，不作定罪结论
本流程用于合规风险预防与体系建设，不替企业作有罪无罪的最终结论
不以合规之名对抗调查
不得以「合规」为名行规避侦查、伪造毁灭证据、串供、转移资产之实；制度中加入「应对突击检查」的证据清理规程、评估报告中写「哪些材料不宜留存」、任何实质上对抗调查的「合规」建议，无论以何种形式提出一律拒绝，标 [合规边界 — 拒绝]，并提示合规的正道是依法整改、如实供述
与刑事风险评估分工
刑事风险评估（/criminal-compliance:risk-assessment）是单次刑事风险评估，评估「某具体行为是否有刑事风险」；本流程是体系化合规建设，做全面风险底图 + 制度 + 组织 + 评估。前者的评估结论可作为合规风险地图的输入，本流程的风险识别成果可完善前者的背景地图
与合规不起诉分工
本流程是企业尚未涉案时的事前合规体系建设；合规不起诉流程及其涉案专项合规整改计划是涉案后整改，须律师主导。事前建立的有效合规体系是涉案后争取合规不起诉的重要基础（有效合规认定标准 [待验证]）
目的地与特权检查
输出合规体系文件前确认目的地：内部使用（律师工作产物 / 内部合规文件）加注「律师工作产物 — 受律师-当事人特权保护」；对外提交（如向检察机关提交合规报告）须在律师指导下决定是否提交及内容，直接提交可能作为证据使用
引用纪律
刑法总则中度把握锚点（第30/31/67/68/72条）标「建议复核」；各具体罪名条号一律 [条号待验证]，以构成要件描述呈现；有效合规认定标准与涉案企业合规规范性文件只描述规则并标 [待验证 — 规范性文件快速演进，须核实现行版本]；案例案号一律 [待验证]，不具判例法约束力；验证资源为国家法律法规数据库 https://flk.npc.gov.cn 与最高人民检察院官网 https://www.spp.gov.cn

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置假设，可逐条复制。页面里的英文标记见首页「标记与术语」。

  1. 合规风险识别

    /criminal-compliance:compliance-risk-identification可单独运行

    从业务、岗位、区域、关联方四个维度梳理企业全面刑事合规风险底图，构建「领域 × 风险点 × 风险敞口 × 优先级」的合规风险地图，确定重点合规领域，作为制度设计、组织培训、有效性评估的输入。

    请律师核对

    • 核对 1.1业务环节表只列 10 个环节、岗位表只列 8 类岗位、关联方只列 6 类，是否需要补充贵所客户常见的业务与岗位（如人力资源、IT/数据管理）？
    • 核对 1.28 个重点合规领域中「反垄断合规」只对应串通投标罪及「垄断行为的刑事追诉衔接」，而业务表已列的知识产权（假冒注册商标罪）、走私没有单列领域，领域划分是否需要调整？
    • 核对 1.3多领域并列时按「已有行政处罚记录 → 涉金额大/人数多 → 法定代表人直接参与」排序，这一先后顺序是否认同？
    • 核对 1.4小企业以「20人以下」为界只识别 TOP3 领域，与第三步组织设计以「50人以下」为小型企业的分界不一致，需要统一口径。

    做法

    1. 读取 CLAUDE.md「合规与服务立场」「我们是谁」「合规严格度」「是否已涉案」「升级矩阵」；合规严格度（保守 / 平衡 / 务实）决定识别深度与红线标记密度；配置缺失以临时模式继续。
    2. 企业全貌梳理：从行业、规模、业务模式、是否涉外、历史涉案情况、重点刑事风险领域六个字段读取画像，向用户回显摘要并确认准确后才开始识别；有更新则重新识别。
    3. 业务维度：以业务流程（采购→生产→销售→财务→对外融资）为主线逐环节检索高发刑事风险，对照 10 个业务环节的风险点表（采购与供应链、销售与营销、财务与资金、税务申报、生产与安全生产、对外融资、出口与进口、环境与废弃物处置、招投标、知识产权），再请用户确认企业实际开展哪些环节，并补充表外业务（如数据跨境、医疗器械、金融产品代销、政府采购）。
    4. 岗位维度：以岗位职责和日常决策权限为基础，对照 8 类岗位（法定代表人/CEO、财务总监/CFO、采购总监/经理、销售总监/代表、安全生产负责人、环保负责人、项目经理/工程部门、对外融资负责人）的高风险行为模式与单位犯罪双罚制关联，按企业实际定制关键 / 高 / 中等三级高风险岗位清单。
    5. 区域维度：考察地方监管执法强度（税务稽查频次、安监执法力度、环保整治行动）、地方司法实践差异（各地检察机关对涉案企业合规试点的参与程度与适用口径 [待验证 — 规范性文件快速演进]）、跨地区运营风险、涉外地区（自贸区、跨境电商、保税区）的海关与外汇合规风险；涉及特定地区标 [地方 flagged — 需核实地方涉案企业合规试点口径与地方检察机关实践]。
    6. 关联方维度：识别供应商、销售中介/代理商、股东/投资方、政府对接人员、合作方/联营体、境外关联公司六类关联方的风险传导路径，如代理商代企业行贿带来行贿罪共同犯罪风险、股东指令非法融资或关联交易掏空企业带来非法集资/职务侵占风险。
    7. 重点合规领域：把四个维度的结果汇入 8 个合规领域的评估框架（反商业贿赂、税收、反垄断、金融融资、数据隐私、安全生产、环境、财务内控），对业务相关性、岗位敞口、关联方传导各评高 / 中 / 低，给出红 / 橙 / 黄三档优先级，列出建议优先建设的前三个领域及理由。
    8. 输出前过检查清单：关键高管（法定代表人/CEO/CFO）均已列入；双罚制下直接负责的主管人员与其他直接责任人员的风险已分析；罪名条号均标 [条号待验证]；合规严格度已影响标记密度；输出中已说明与刑事风险评估的分工。

    内置规则

    • 业务环节—罪名对照（节选）：采购与供应链 → 单位行贿罪、虚开增值税专用发票罪；销售与营销 → 对非国家工作人员行贿罪、非法经营罪；财务与资金 → 挪用资金罪、职务侵占罪、非法吸收公众存款罪；出口与进口 → 走私普通货物物品罪（偷逃应缴税额达一定标准，依司法解释 [待验证]）；招投标 → 串通投标罪、合同诈骗罪；知识产权 → 假冒注册商标罪；条号一律 [条号待验证]
    • 岗位与双罚制关联：法定代表人/CEO 为「高度关联——决策层直接负刑事责任」，对应单位犯罪「直接负责的主管人员」；CFO 对应虚开、逃税、挪用资金罪的「其他直接责任人员」；安全生产负责人、环保负责人为「直接责任人员风险」
    • 多个高优先级领域无法排序时按三条原则：1. 已有行政处罚记录的领域优先；2. 涉金额大 / 人数多的领域优先；3. 法定代表人直接参与的领域优先
    • 企业规模小（20人以下）时只重点识别 TOP3 高风险领域，制度设计简化并注明成本约束
    • 新型业务模式（元宇宙 / 数字资产 / 平台经济）现有罪名对应不明的，描述行为模式与构成要件的相似性，标 [新型业务 — 需法律研究]，提示咨询专业律师
    • 行刑衔接风险只描述规则，移送标准标 [待验证]；用户确认监管部门已有行政处理记录时须升级律师
    • 识别到已发生风险事件（已行政处罚 / 事故 / 被举报 / 内部违规记录）立即做强制升级评估，涉及刑事追诉门槛的标 [强制升级 — 涉刑情形]
    • 企业画像严重不足（行业、业务均未提供）时只提供通用风险识别框架并等待补充；用户口述的罪名条号标 [待验证]，改为构成要件描述并建议通过国家法律法规数据库核实
    • 用户要求评估「是否会被追诉」时不作定罪结论，只描述构成要件特征并标记风险等级：有罪无罪结论是司法机关与辩护律师的职责

    法律依据

  2. 合规制度与流程设计

    /criminal-compliance:policy-process-design可单独运行

    把合规风险地图转化为可落地的制度体系：合规政策与行为准则、重点领域专项合规制度、合规审批与禁止性清单，并把合规控制点嵌入日常业务流程。

    请律师核对

    • 核对 2.1合规政策把违规后果写成「纪律处分 → 解除劳动合同 → 移送司法机关」三级梯度，「移送司法机关」由谁决定、依什么标准，SKILL.md 未规定，是否应写明由律师评估？
    • 核对 2.2禁止性清单的「证据销毁」对应「妨害证据罪」，该罪名未收录于引用库 C节，表述是否与现行刑法罪名一致，请律师核对。
    • 核对 2.3七类审批中礼品、境外付款、现金交易的触发金额全部留给企业设定，是否需要贵所给出参考区间？
    • 核对 2.4政府官员接触只要求合规部门审批与记录，「两节」期间特别限制的具体内容未写明，是否需要补充？

    做法

    1. 读取 CLAUDE.md「合规与服务立场」「我们是谁」（行业、规模、业务模式决定专项制度覆盖范围）、「合规严格度」（影响禁止性清单严格程度与合规审批触发门槛）、「是否已涉案」、「文书风格」中的合规制度文本风格；配置缺失以临时模式继续并标 [临时模式]。
    2. 确定设计输入：合规风险地图与高风险岗位清单（来自第一步或用户提供）、行业监管要求（如金融监管合规、医药合规）、单位规模与结构（大型企业须体系化制度，中小企业须简化且可落地）。
    3. 搭建四层制度体系并写明审批权限：总纲《合规管理总体政策》由董事会/最高决策层批准；《员工行为准则》由 CEO/总经理批准；专项制度（如《反商业贿赂制度》《税收合规制度》）由合规委员会/董事会批准；操作规程（如《礼品娱乐申请程序》《差旅合规报销规程》）由合规部门/业务部门负责人批准。
    4. 起草合规政策五项核心要素：法定代表人/CEO 签署的合规承诺（高层表率，Tone at the Top，明确对刑事合规零容忍）；适用范围覆盖全体员工及适用第三方（供应商 / 代理商 / 合作方须签署合规承诺书）；独立保密的举报渠道（热线 / 邮箱）与不打击报复政策；违规后果梯度（纪律处分 → 解除劳动合同 → 移送司法机关）；适用的中国现行法律框架（刑法第30/31条双罚制含义，建议复核）。
    5. 按风险地图选择适用领域，起草五类专项制度：反商业贿赂（礼品娱乐、商业招待、顾问与代理协议、利益冲突、政府官员接触含「两节」期间特别限制、举报与调查）；反垄断含串通投标（价格与市场行为、招投标、市场支配行为、与竞争对手的合法接触）；数据合规（分类分级、最小必要与目的限制、数据安全、数据跨境、个人信息主体权利）；安全生产（责任体系、作业规程、隐患排查、事故报告不得迟报谎报漏报、劳动防护）；财税合规（发票管理、税务申报、禁止双套账、关联交易公允定价、税收优惠合法性审查）。
    6. 设计七类分级合规审批：一般礼品娱乐（直接主管 + 合规专员，礼品申报表）；顾问/代理协议（合规部门 + 法务，尽职调查报告 + 合同审查）；政府官员接触（合规部门审批，接触记录表）；三重一大决策（集体决策 + 合规部门见证）；关联交易（合规委员会 + 独立董事如适用，公允价值评估）；境外付款（财务负责人 + 合规部门）；现金交易（财务负责人，书面说明）。
    7. 列出七类刑事合规红线禁止性行为清单：行贿、发票虚开、串通投标、双套账、非法集资、证据销毁、规避侦查，每类写明涉及罪名的构成要件描述并标 [条号待验证]。
    8. 在八个业务环节嵌入合规控制点并指定责任岗位：供应商选择（准入尽职调查 + 合规承诺书，采购部门 + 合规专员）、合同签署（合同法律合规审查单）、差旅报销（报销系统合规字段 + 合规专员抽查）、三重一大决策（合规影响评估表 + 集体审批签字）、投标准备（投标合规审批单）、税务申报（申报前合规审查）、安全生产（定期检查 + 隐患整改台账）、对外融资（融资方案合规审批）。
    9. 输出方案并附制度落地五步行动计划：执业律师法律合规审查 → 管理层批准与签署 → 全员培训与知悉确认 → 配套操作规程细化 → 试行与反馈优化；明确标注本方案为草案、须执业律师审查定稿。

    内置规则

    • 礼品价值上限、一般礼品审批下限、境外付款与现金交易的触发金额均为「企业自行设定」，SKILL.md 不给具体数额
    • 禁止性清单是「无论何种商业目的均不得从事」的绝对红线；「规避侦查」一项直接标 [合规边界 — 拒绝]
    • 证据销毁红线定义为「在任何调查、诉讼、监管检查启动后销毁、篡改、隐匿相关文件」，对应「妨害证据罪（构成要件描述，[条号待验证]）」
    • 中小企业（20人以下）合并制度层级，用一份综合《员工合规手册》代替多份专项制度，重点保留禁止性清单与关键审批
    • 制度与现有管理体系冲突（如现有采购流程与合规审批冲突）时识别冲突节点，在制度中整合而非另起炉灶，保持单一权威流程
    • 用户提出「制度上看起来合规即可，不想真正执行」时，提示形式合规无法有效抵御刑事追诉，有效性评估将核查实质执行情况（可参考涉案企业合规相关规范性文件对有效合规的要求 [待验证]）
    • 行业特许经营合规（金融监管、药品监管）只提供通用框架，提示须结合监管法规专项审查与行业法律专家意见，本步聚焦刑事合规风险维度
    • 制度设计绝不为规避侦查留口子，不设置合规名义下的证据销毁规程、对抗调查程序；用户要求设计「如何规避证据留存」的程序一律拒绝并标 [合规边界 — 拒绝]
    • 数据跨境传输的合规要求须核实数据出境安全评估规则 [待验证]；涉及对外提交的制度须律师审核

    法律依据

    • 《刑法》第30条 — 单位犯罪定义 [模型知识 — 需验证]，已核实锚点（中度把握），建议复核
    • 《刑法》第31条 — 单位犯罪双罚制，合规制度须明确单位责任与直接责任人员责任的连接 [模型知识 — 需验证]，已核实锚点（中度把握），建议复核
    • 《刑事诉讼法》第177条 — 不起诉，合规制度建设是事后争取合规不起诉的重要基础 [模型知识 — 需验证]，已核实锚点（中度把握），建议复核
    • 《刑事诉讼法》第15条 — 认罪认罚从宽 [模型知识 — 需验证]，已核实锚点（中度把握），建议复核
    • 专项制度对应罪名 — 单位行贿罪、对非国家工作人员行贿罪、虚开增值税专用发票罪（虚开税额达一定标准，依司法解释 [待验证]）、逃税罪、串通投标罪、重大责任事故罪、污染环境罪、非法吸收公众存款罪、侵犯公民个人信息罪，条号一律 [条号待验证]，数额标准须以现行司法解释核实

  3. 合规组织与培训

    /criminal-compliance:organization-training可单独运行

    为制度落地提供组织与人员保障：按企业规模设计合规组织架构与首席合规官独立性，划分三道防线职责，制定分层分类培训计划、考核问责机制与合规文化建设方案。

    请律师核对

    • 核对 3.1企业分档以「500人以上 / 50-500人 / 50人以下」划分，与前两步「20人以下」的小企业口径不一致，贵所以哪一套为准？
    • 核对 3.2较重违规的处置包含「罚款（依劳动合同约定）」，是否符合贵所对用人单位内部罚款的实践口径？
    • 核对 3.3合规委员会成员预设含 CFO，而第一步把 CFO 列为单位犯罪「其他直接责任人员」高风险岗位，这一组成是否需要调整？
    • 核对 3.4培训频次（高管每年至少1次、合规专项每年至少2次、新员工入职第一周内完成）与记录保存「不少于5年」是否作为贵所默认建议？

    做法

    1. 读取 CLAUDE.md「我们是谁」的企业规模、行业（影响组织设置复杂度）与团队规模（影响兼职或专职合规人员设置），「合规严格度」（影响组织独立性要求与培训频次），「是否已涉案」；引用 _shared/criminal-law-citations.md 第30/31条作为组织设计的刑事责任分析基础。
    2. 按企业规模选定组织方案并向用户回显确认：大型企业（500人以上/上市公司/国企）设专职合规官（CCO/合规总监）+ 合规管理部门 + 各业务线合规员 + 合规委员会；中型企业（50-500人）设专职合规负责人（兼任总法律顾问）+ 合规工作小组 + 关键业务合规岗位；小型企业（50人以下）设兼职合规负责人（法务总监/CEO直接负责）+ 合规工作联络员；已有合规部门的请用户说明现有架构。
    3. 设计合规监管层：合规委员会由董事会授权设立，成员含独立非执行董事/独立董事、首席合规官、法律总顾问、CFO，负责审批重大合规政策、审议重大违规事件、督导年度合规审计，直接向董事会汇报、不经过 CEO，至少每季度开会一次、重大事项随时召开。
    4. 设计首席合规官：须有直接向董事会/合规委员会汇报的渠道，不受业务负责人制约；职责含制定政策、运营合规程序、培训、接收举报、主导合规调查；任职资格为法律/合规/会计背景、了解刑事合规实务、无相关刑事记录；不因发现并上报违规而受负面影响。
    5. 划分三道防线：业务部门为第一道（业务负责人对本部门合规风险负第一责任）；合规部门 + 风险管理部门 + 法律部门为第二道（独立于业务部门）；内审部门 + 外部审计机构为第三道（独立评价体系有效性、发现前两道防线失效）；并说明这一划分在涉案时用于厘清「直接负责的主管人员」与「其他直接责任人员」的刑事责任边界。
    6. 设置业务合规员（中大型企业）：销售、采购、财务、生产、安全各核心业务部门各设1名，由合规部门任命、业务部门认可；日常向业务负责人汇报，合规职责以虚线向合规部门汇报；合规工作表现纳入绩效考核，表现良好者优先晋升。
    7. 制定四层培训计划：高管（单位犯罪双罚制、「直接负责的主管人员」认定规则 [待验证]、有效合规认定标准 [待验证]、重大违规案例警示，每年至少1次、新高管上任时必须）；合规专项（合规/法务/财务/审计，每年至少2次）；业务岗（销售、采购、财务、安全生产、对外融资、数据处理六类岗位对应罪名的构成要件、禁止性清单与举报渠道，每年至少1次、新员工上岗前必须）；全员基础（每年至少1次）。
    8. 确定培训形式与记录：面授、在线、案例研讨、合规情景模拟（模拟礼品娱乐申请、供应商谈判中的合规决策）、新员工入职培训（入职第一周内完成并签署《行为准则知悉确认书》）；每次留存时间、主讲人、参与人员、签到表、培训材料，在线培训保存完成率与测验成绩，记录保存不少于5年（须核实法定期限要求 [待验证]）。
    9. 设计考核问责与合规文化：高管/部门负责人按部门违规事件数量、整改完成率、培训参与、举报处理年度考核，权重为「绩效考核占比不低于[X]%（企业自行设定）」；业务合规员半年度考核；一般员工年度考核；违规按四级梯度处置；合规文化五要素为高层表率、合规激励、举报文化、合规开放对话（合规顾问「开放日」）、合规可视化。

    内置规则

    • 问责梯度：一般违规（未遵守操作规程、漏报礼品）→ 书面警告 + 补充培训；较重违规（违反禁止性清单但未达刑事程度）→ 记过/降职/罚款（依劳动合同约定）；严重违规（可能构成刑事犯罪）→ 停职调查 + 内部调查 + 解除劳动合同 + 评估是否移送司法机关；不实举报（恶意打击报复他人）→ 对举报人予以问责
    • 问责区分三种情形：主动自查发现并上报的轻微违规可从轻处理；被动发现的按常规处理；拒绝配合调查的从重处理；不得以问责为由打击报复举报人
    • 首席合规官独立性是有效合规的关键要素 [待验证 — 规范性文件快速演进，须核实现行版本]；须向 CEO 汇报才能运作时设计双线汇报（日常向 CEO，重大合规事项直接向合规委员会/董事会），并提示独立性不足可能影响有效合规认定 [待验证]

    • 中小企业无法设专职合规部门时提供精简方案：兼职合规负责人 + 合规工作联络员制度 + 定期外部合规顾问，并明确最低组织保障要求

    做法

    1. 读取 CLAUDE.md「我们是谁」（行业、规模影响评估复杂度与审计频次）、「合规严格度」（影响评估指标严格程度）、「是否已涉案」；已立案或被采取强制措施的立即强制升级并转合规不起诉流程；引用 _shared/criminal-law-citations.md D节涉案企业合规规范性文件描述。
    2. 搭建四维度评估框架：制度健全性（制度文件审查、与行业最佳实践对标）；执行有效性（访谈、问卷、案例测试，审批记录与培训记录核查）；监测发现能力（举报案例统计、内审发现率、自查完成情况）；响应整改能力（整改闭环完成率、同类问题再发率、整改时效）。
    3. 逐维度套用各 5 项指标：制度健全性（政策完整性、对照风险地图的覆盖范围、禁止性清单、可落地性、随刑法修正案/司法解释 [待验证] 及时更新）；执行有效性（培训完成率、测验通过率、关键节点审批执行率、行为准则知悉率、高风险岗位情景测试通过率）；监测发现能力（举报渠道使用率、举报处理及时性、内审合规发现率、财务/费用/交易异常监控、自查与复查发现比率）；响应整改能力（违规响应及时性、整改完成率、同类问题再发率、根因分析质量、整改验证有效性）。
    4. 制定年度审计计划：全面合规审计（内审，每年1次，覆盖所有重点领域）；专项合规审计（内审 + 合规，高风险领域半年1次）；日常合规监控（合规部门，持续）；业务自查（各业务部门，季度）；外部合规评估（外部律师/合规顾问，每年1-2次，视需要）。
    5. 按审计工作流程推进：审计计划 → 审计前准备（文件清单 / 访谈安排）→ 现场审计（文件审查 / 访谈 / 测试）→ 发现整理 → 草稿报告 → 被审计部门确认 → 最终报告 → 整改方案 → 合规委员会审议 → 整改执行监督 → 整改验证 → 闭环。
    6. 安排各业务部门季度自查：合规部门制定标准化自查清单，业务合规员组织自查并填报系统，发现问题或疑似违规立即上报合规部门（不得自行处置和隐瞒），结果留存供内审抽查验证。
    7. 对每个问题走八阶段整改闭环：发现 → 定性（一般 / 较重 / 严重，识别是否涉及刑事风险）→ 根因分析（制度缺失 / 人员认知 / 流程漏洞 / 管理层因素）→ 整改方案 → 整改执行并留档 → 内审或合规部门独立验证 → 复盘改进并纳入年度合规报告 → 合规委员会/首席合规官闭环确认，关闭台账条目。
    8. 按严重程度分级处理：一般问题（操作规程未遵守、审批漏填、培训未参加）由合规部门内部处理并记台账；较重问题（违反禁止性清单但未达刑事程度、审批实质性缺失）合规委员会知悉、责任人问责、专项整改；严重问题（可能构成刑事犯罪、重大违规、管理层授意违规）立即 [强制升级 — 涉刑情形]，律师介入内部调查，向合规委员会/董事会报告，评估是否向司法机关报告。
    9. 撰写与合规不起诉的衔接说明：只以规则描述写出事前有效合规的四点积极作用（合规体系完整性、合规记录完备性、案发风险隔离、第三方评估认可），全部标 [待验证 — 规范性文件快速演进，须核实现行版本]，不硬写文号、认定标准具体条款、认定流程细节；尚未涉案的继续完善并保存合规记录，已涉案的立即强制升级并结合合规不起诉流程评估适用性。

  • 四维度评估框架与各维度指标、年度审计计划、八阶段整改闭环、严重程度分级处理均已建立，严重问题触发涉刑强制升级；合规记录（审计 / 自查 / 培训 / 整改台账）保存要求已明确
  • 有效合规认定标准未硬写文号、未写具体条款编号；所有具体罪名条号标 [条号待验证]，以构成要件描述呈现；规范性文件描述规则并标 [待验证]

09何时暂停或升级

  • 「是否已涉案」显示已立案、被采取强制措施、收到侦查传唤，或识别到可能构成具体罪名的明确迹象、重大涉案情形：立即停止全流程，入口按情形标 [强制升级 — 已立案] / [强制升级 — 强制措施] / [强制升级 — 侦查传唤] / [强制升级 — 具体罪名风险] / [强制升级 — 重大涉案]，各步执行中统一标 [强制升级 — 涉刑情形]，提示联系执业刑事辩护律师
  • 识别到已发生风险事件（已行政处罚 / 事故 / 被举报 / 内部违规记录），或用户确认监管部门已有行政处理记录：做强制升级评估，涉及刑事追诉门槛的升级律师
  • 合规审计发现严重问题（可能构成刑事犯罪、重大违规、管理层授意违规）：立即强制升级，律师介入内部调查，向合规委员会/董事会报告，在律师指导下决定后续处置
  • 企业发现重大违规但不想上报：提示隐瞒可能加重刑事风险，触发 [强制升级 — 涉刑情形] 评估
  • 提出规避侦查、「应对突击检查」证据清理、「哪些材料不宜留存」、让合规组织「配合隐瞒」等需求：拒绝并标 [合规边界 — 拒绝]
  • 合规体系文件或评估报告拟向检察机关等外部提交：须在律师指导下决定是否提交及提交内容
  • 新型业务模式罪名对应不明、行业特许经营合规细节（金融 / 医药）：提示咨询专业律师或行业法律专家
  • 实践配置缺失或含占位符：提示运行 /criminal-compliance:cold-start-interview，或以临时模式继续并在输出标注
