02概要

本插件面向刑事合规律师、企业合规官与法务，提供五条流程：冷启动访谈、刑事风险评估、合规不起诉方案、单位犯罪预防、刑事合规体系建设，共 20 个可单独触发的步骤。所有流程在开始实质工作前先读取 criminal-compliance/CLAUDE.md 实践配置（执业角色、企业画像、服务立场、合规严格度、是否已涉案、风险校准、升级矩阵、文书风格、地方试点口径），再按统一的法律引用规范与引用库出具带来源标签和待验证标注的分析。法律依据以刑法总则中度把握锚点（第30条单位犯罪定义、第31条双罚制、第67条自首、第68条立功、第72条缓刑）与刑事诉讼法（第177条不起诉、第15条认罪认罚从宽）为主，均标「建议复核」；刑法分则具体罪名条号一律以构成要件描述呈现并标 [条号待验证]，涉案企业合规试点与第三方监督评估机制属快速演进的规范性文件，只描述规则并标 [待验证]，须通过最高检官网核实现行版本。已立案、被采取强制措施、收到侦查传唤、可能构成具体罪名、重大涉案或涉及人身自由时，无论配置一律强制升级执业刑事辩护律师。

  • 输出（含 工作产物标题 / 审查者注释块 / 下一步决策树模板）

  • 事项工作区
  • 审查过的种子文档

会怎样改变输出

  • 「我们是谁 → 执业角色」与「谁在使用 → 角色」决定工作产物标题（律师角色：「律师工作产物 — 受律师-当事人特权保护 / 保密」；非律师角色：「研究笔记 — 合规研究与初步分析，非法律建议，供律师审查」），并使非律师角色在合规不起诉申请提交、向检察/公安提交材料、合规整改报告定稿、具结书签署、收到起诉或不起诉通知等重大步骤前暂停升级执业刑事律师。
  • 「合规与服务立场 → 整体服务立场」决定所有流程的审查侧重与主要输出：事前刑事风险评估出风险地图与控制建议；事前合规体系建设出制度、流程、培训、组织架构；涉案企业合规不起诉出整改计划、不起诉申请、整改报告；单位犯罪预防聚焦单位名义、单位利益、双罚制责任与高管责任；单位犯罪辩护研究须执业刑事律师主导。「合规严格度」三档调节风险标记强度：保守型一切疑点从严标红并升级，平衡型重大刑事风险标红、一般风险标橙、优先合规整改，务实型仅拦截明显高风险。
  • 「是否已涉案」是刑事合规最关键字段，直接驱动全局强制升级：选「已立案或被采取强制措施」后，无论服务立场与风险等级，所有流程输出标 [强制升级 — 涉刑情形]，仅作合规研究与初步分析；配置缺失的临时模式下不默认「无涉案」，一旦识别涉案迹象即强制升级。
  • 「刑事风险校准」四级表（关键 / 高 / 中等 / 低，原文以红橙黄绿圆点标记）决定每个发现的标注：关键级为可能构成具体罪名、已立案或强制措施，须立即处理并强制升级；「升级矩阵」的角色权限表（六类角色）与六条强制升级触发条件决定升级给谁，强制升级与合规边界护栏凌驾于服务立场与合规严格度配置之上，任何配置不得覆盖。
  • 「文书风格」四个字段分别决定刑事风险评估报告（默认客观、风险导向、可操作，逐项风险点+罪名构成要件对照+等级+控制建议，避免主观认定是否构成犯罪）、合规制度文本、合规不起诉申请与整改报告（真实客观不夸大）、单位犯罪预防/辩护研究的格式与措辞；「输出」统一附审查者注释块（分析日期与材料范围、具体罪名条号待验证提示、规范性文件快速演进提示、涉刑升级提示、法律依据来源、服务立场、是否已涉案、四级标记项数量）与十选项下一步决策树。
  • 「共享护栏」的时效性触发使具体罪名条号与数额自动标 [时效性 flagged — 需验证具体罪名条号与数额标准]、涉案企业合规试点与第三方评估文件标 [时效性 flagged — 规范性文件快速演进，需核实现行版本]、地方口径标 [地方 flagged]；来源标签五种逐行附注；目的地/特权检查要求面向检察机关、公安机关或第三方监督评估组织的材料提供内部律师工作草稿与对外提交脱敏版两套；地方试点提示列出试点覆盖范围、管委会组成、合规认定标准、听证程序四项地区差异。

05不做什么

  • 不提供规避侦查、对抗调查、伪造或毁灭或隐匿证据、串供统一口径、转移资产逃避追缴、帮助相关人员出逃的任何方法，也不提供任何以「合规」为名实质干扰侦查的建议；识别到即拒绝，输出标 [合规边界 — 拒绝]
  • 不替企业作有罪无罪的最终结论，不作「XX 行为一定构成/不构成 XX 罪」的绝对结论，只描述构成要件特征并标注待验证
  • 不替代执业刑事辩护律师的专业判断与辩护工作；已立案、被采取强制措施（拘留/逮捕/取保候审/监视居住）、收到侦查传唤、可能构成具体罪名、重大涉案、涉及人身自由时一律强制升级，本插件只提供合规研究与初步分析
  • 强制升级后不提供辩护策略的最终判断、不起草认罪认罚具结书（须在律师见证下由当事人自愿完成）、不对向司法机关提交任何材料给出最终建议
  • 不写裸的具体罪名条号、定罪量刑数额、涉案企业合规规范性文件文号；一律构成要件描述或规则描述加 [待验证]，用户口述的条号、数额、文号也不作为准确数据写入配置
  • 非律师角色（合规官/法务/当事人）在向检察机关或公安机关提交任何材料、合规不起诉申请定稿、具结书签署、合规整改方案提交第三方监督评估组织之前，本插件不替其完成，须暂停并由执业刑事律师审核确认或在场
