01概要

帮助涉案企业评估能否走涉案企业合规不起诉路径，并在可行时依次制定专项合规整改计划、配合第三方监督评估、准备合规整改报告与不起诉申请书、配合拟不起诉公开听证，直至处理不起诉决定后的合规承诺履行与行刑反向衔接。流程按「适用条件评估 → 合规计划制定 → 第三方监督评估配合 → 不起诉申请与听证」四步进行，每步均可单独触发，但适用条件评估完成前不建议启动整改计划。开始前读取 criminal-compliance/CLAUDE.md 的执业角色、服务立场（须含「涉案企业合规不起诉」）与是否已涉案；已立案、被采取强制措施等情形一律强制升级执业刑事辩护律师，各步骤只作律师参考框架。法律依据以刑事诉讼法第177条（不起诉三类型）、第15条（认罪认罚从宽）和刑法第67/68/72条为「建议复核」锚点；涉案企业合规试点、第三方监督评估、公开听证、行刑反向衔接等规范性文件只描述规则、不写文号，标 [待验证 — 规范性文件快速演进]，各地差异标 [地方 flagged]。所有向检察机关、公安机关或第三方评估组织提交的材料须律师审核，并提供内部草稿与对外脱敏两版。

02适用与边界

适用场景

  • 企业或相关人员涉嫌经济类、职务类等犯罪，想评估能否通过合规整改争取检察机关酌定不起诉
  • 适用条件已评估，需要针对涉案行为暴露的合规漏洞制定专项整改计划（漏洞诊断、整改措施、里程碑、组织保障、可验证成果）
  • 检察机关已启动或决定启动第三方监督评估，需要了解启动、整改、评估报告、考察期满各阶段的配合要点
  • 整改基本完成，需要准备合规整改报告、不起诉申请书与材料清单，或准备拟不起诉公开听证的陈述与答询
  • 不起诉决定作出后处理合规承诺履行、行刑反向衔接，或申请被否决后转入审判阶段辩护准备

不做什么

  • 不替代检察机关的不起诉决定，不保证不起诉结果；不替企业作有罪无罪的最终结论
  • 不替代执业刑事辩护律师：已立案、被采取强制措施等情形下只提供合规研究背景，申请提交与公开听证一律由律师主导
  • 不提供规避侦查、伪造毁灭证据、串供、转移资产逃避追缴等任何逃避法律追究的方法，也不提供以整改或配合评估之名掩盖问题、夸大整改成效、临时「布景」应付检查的方法
  • 不硬写涉案企业合规、第三方监督评估、公开听证、行刑反向衔接等规范性文件的文号，不臆造具体罪名条号、法定刑档与数额
  • 不做事前合规体系建设（那是刑事合规体系建设流程 /criminal-compliance:compliance-system-building 的范围）；本流程的整改计划是针对涉案具体问题的专项整改

03输入与产出

需要律师提供

  • 企业涉嫌罪名描述必需
    启动参数；以构成要件描述比对，不臆造条号；未告知罪名类型时标 [信息不足 — 须提供涉嫌罪名类型/案件状态]
  • 当前案件状态（苗头 / 立案 / 强制措施）必需
    启动参数；直接决定路径选择与强制升级
  • 企业及主要责任人员的认罪认罚意愿必需
    按自愿如实供述、承认指控犯罪事实、愿意接受处罚三要件逐项询问
  • 合规整改意愿与能力必需
    涉案企业合规程序启动的前提
  • 被害人情况（是否存在、是否已获赔偿或谅解）可选
    影响酌定不起诉的可行性评估
  • 企业类型、规模与持续经营价值可选
    影响合规整改可行性与社会效果论证
  • 涉案行为与合规漏洞描述、现有合规制度、整改时限要求可选

  • 整改报告完成情况、第三方评估结论、是否已启动听证、认罪认罚具结书可选
    不起诉申请与听证一步的参数

04开始前

前置条件

  • 读取 criminal-compliance/CLAUDE.md，检查三处是否含 [PLACEHOLDER]：「我们是谁 > 执业角色」「合规与服务立场 > 整体服务立场」（须含「涉案企业合规不起诉」）、「合规与服务立场 > 是否已涉案」；缺失时提示运行 /criminal-compliance:cold-start-interview，或说「临时模式」按默认值继续
  • 临时模式默认值：执业角色为律师（最高权限）；服务立场为涉案企业合规不起诉（用户陈述涉案情形时）；合规严格度为保守型（所有疑点从严处理）；是否已涉案按用户陈述逐案判断，识别任何涉案迹象即强制升级。所有输出标 [临时模式 — 请运行冷启动访谈完成配置]，并警示：已立案、被采取强制措施或面临侦查的，立即联系执业刑事辩护律师，不要在无律师指导下单独推进任何合规不起诉步骤
  • 确认企业画像（行业 / 规模 / 业务模式 / 历史涉案情况 / 重点刑事风险领域）；含占位符时询问「请告知企业行业与案件基本情况，以便聚焦适用条件评估。」
  • 确认服务立场：涉案企业合规不起诉立场（聚焦争取从宽路径，评估适用条件可行性）；单位犯罪辩护研究立场（同时评估不起诉路径与量刑从宽替代路径）；其他立场（说明本流程主要适用于涉案企业合规不起诉场景）
  • 在任何实质性分析前完成涉案情形检查：读取「是否已涉案」，或询问用户当前状态
  • 各步骤的先后前提：整改计划以适用条件评估通过（符合基本适用条件、已认罪认罚、明确愿意并有能力整改）为前提；第三方监督评估配合以整改计划已制定、检察机关已启动或决定启动评估程序为前提；申请与听证以前三步完成或进行中、认罪认罚具结书已签署为前提

硬性规则

涉案情形识别与强制升级（不可覆盖）
识别任一情形即触发并标记：企业或相关人员已被立案（公安或检察机关）→ [强制升级 — 已立案]；被采取强制措施（拘留/逮捕/取保候审/监视居住）→ [强制升级 — 强制措施]；已收到侦查传唤/询问通知 → [强制升级 — 侦查传唤]；有明确迹象可能构成具体罪名 → [强制升级 — 具体罪名风险]；重大涉案（多名高管/金额巨大）→ [强制升级 — 重大涉案]。触发后输出 [强制升级 — 涉刑情形]：各步骤在此情形下只提供合规研究背景，不替代执业刑事辩护律师，由律师主导路径评估与后续工作；律师指导下可调用适用条件评估（初步分析，律师参考）与合规计划制定（整改计划框架，律师审核后使用）
立场不能覆盖护栏
服务立场只决定侧重：涉案不起诉立场聚焦争取从宽路径的可行性，辩护立场同时评估替代路径；强制升级与合规边界护栏不可被任何立场覆盖
不作最终定性、不保证结果
不替企业作有罪无罪的最终结论（那是司法机关与辩护律师的职责）；所有输出立足于「帮助企业通过依法合规整改争取从宽处理」；是否作出不起诉决定由检察机关判断，不是任何合规评估或整改可以保证的结论
不提供规避侦查或逃避责任的方法
本流程及各步骤绝不提供：规避侦查的方法；伪造毁灭证据的建议；串供或统一口径的方案；转移资产逃避追缴的操作；任何帮助逃避法律追究的方法。识别到一律拒绝，标 [合规边界 — 拒绝]，并提示「合规的唯一正道是依法整改、如实供述、认罪认罚争取从宽」
整改与陈述须真实
整改计划、进度报告、整改报告、申请书与听证陈述均须如实：不得形式化整改、临时制作文件应付检查、夸大整改成效、虚构整改措施、掩盖未完成项目，不得否认已认罪认罚的事实；虚假内容不仅危及不起诉可能性，还可能加重刑事责任
目的地/特权检查
向检察机关、公安机关或第三方监督评估机构提交的材料，律师-当事人特权可能失效；生成此类材料前提供内部律师工作草稿版和对外提交脱敏版两套选项，并提示须律师审核后提交
律师审查硬性要求
不起诉申请书及全部附件、整改计划须执业律师审核确认后才能提交；非律师角色不得独立向检察机关或第三方监督评估组织提交材料（标 [律师审查 — 硬性要求]）；具结书签署须辩护律师或值班律师在场见证；申请提交与公开听证一律由执业刑事辩护律师主导
规范性文件与地方差异
涉案企业合规试点、第三方监督评估机制、拟不起诉公开听证、行刑反向衔接等规则只作描述、不硬写文号，标 [待验证 — 规范性文件快速演进]；各地适用口径与评估机制运行细节存在地区差异，标 [地方 flagged — 需核实地方涉案企业合规试点口径与地方检察机关实践]

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置假设，可逐条复制。页面里的英文标记见首页「标记与术语」。

  1. 适用条件评估

    /criminal-compliance:applicability-assessment可单独运行

    对企业所处的刑事法律状态做结构化评估，判断是否符合涉案企业合规不起诉的适用条件，识别最可能适用的不起诉类型与认罪认罚从宽条件，形成推荐路径；评估结论决定后续整改计划与第三方监督评估配合是否有必要。

    请律师核对

    • 核对 1.1六项适用条件中罪名范围（通常排除暴力犯罪）、刑罚区间、排除情形（如累犯、特定重大暴力犯罪）都只作规则描述并标 [待验证]——是否需要律师按现行规范与当地试点口径补齐？
    • 核对 1.2存疑不起诉的依据写为「刑事诉讼法第177条第3款」，而插件条文库引用的第177条原文只有法定不起诉、酌定不起诉两款——请律师核对存疑不起诉的条款出处
    • 核对 1.3被害人反对不起诉被列为「重要风险因素」、企业规模过小须加强社会效果论证——这两项在当地检察机关实践中的分量是否需要细化？
    • 核对 1.4「多罪名时按最难适用的罪名评估整体路径」这一保守口径是否同意？

    做法

    1. 读取服务立场：合规不起诉立场侧重识别满足条件的论据；辩护研究立场对比不起诉与量刑从宽替代路径；事前预防等其他立场视为预研，不承诺评估结论。同时读取是否已涉案与升级矩阵（角色权限、强制升级条件）；配置缺失时按临时模式处理
    2. 优先执行涉刑强制升级检查：已立案、被采取强制措施或收到侦查传唤的，输出 [强制升级 — 涉刑情形] 后只提供初步分析框架（辩护律师参考背景），不提供任何可能影响刑事程序的具体建议或向司法机关提交的内容；有苗头线索的标注「现处苗头阶段，如立案应立即升级律师」；纯预防的标注「未涉案，评估为预研」
    3. 步骤一 收集六类基础信息：涉嫌罪名类型、案件当前状态、认罪认罚意愿、整改意愿与能力、被害人情况、企业规模与性质；罪名以构成要件比对，用户给出的条号标 [待验证 — 请通过国家法律法规数据库核实]；不询问「有哪些证据」「如何应对调查」这类可能被视为规避侦查的信息
    4. 步骤二 逐条评估六项适用条件（主体资格、罪名范围、认罪认罚、整改意愿与能力、刑罚区间适宜性、不属排除情形），每项标是 / 否 / 待核实并写评估说明；全部满足方可启动合规考察程序；标 [地方 flagged]
    5. 按三类结论处理：全部满足 → 具备启动基础，推进整改计划制定；部分满足 → 标注未满足条件，分析补救可能与替代路径；不符合 → 评估量刑从宽、认罪认罚协商等替代路径并说明原因，不强行推荐不适用的路径
    6. 步骤三 对照法定不起诉、酌定相对不起诉、存疑不起诉三类，写出最可能适用的类型、主要论据与替代路径；以酌定相对不起诉为合规不起诉的主路径
    7. 步骤四 逐项评估认罪认罚三要件（自愿如实供述、承认指控犯罪事实、愿意接受处罚），说明须有值班律师或辩护律师参与、检察机关提出量刑建议并协商形成具结书、从宽幅度综合考量认罪认罚主动性、配合调查程度、挽回损失情况（标 [待验证 — 规范性文件快速演进]）

    • 四个律师审查节点：评估协议签署前（协议范围、权利义务、费用安排合法性）；材料提交前（特权材料识别、敏感信息处理）；访谈前（访谈准备、律师陪同方案）；评估报告出具后（评估结论核查、补充意见准备）

  4. 不起诉申请与听证

    /criminal-compliance:application-hearing可单独运行

    在整改完成并经第三方监督评估后，指导企业与律师准备合规整改报告与不起诉申请书，配合拟不起诉公开听证（如启动），并处理不起诉决定后的合规承诺履行、行刑反向衔接与申请被否决后的救济；这是合规不起诉流程的最后一步，直接决定最终结果。

    请律师核对

    • 核对 4.1听证陈述框架的措辞（「真诚认罪认罚」「对相关人员造成的损害深感歉意」「对就业/税收/地区经济有贡献」）是否符合贵所和当地检察机关的习惯？
    • 核对 4.2申请书由律师起草、法定代表人签署，材料清单把高管整改承诺书与具结书副本列为「必须」——是否同意？
    • 核对 4.3前置条件要求具结书已签署才启动本步骤，是否与当地合规考察和认罪认罚的先后顺序一致？
    • 核对 4.4听证是否必经、不起诉被撤回的条件、行刑反向衔接的具体规则均留作 [待验证]——是否需要律师补充现行规定？

    做法

    1. 读取服务立场：合规不起诉立场聚焦完整论证符合不起诉条件、有效呈现整改成效；辩护研究立场在推动申请的同时同步评估申请不被接受时的替代路径。读取是否已涉案与可用集成（当地检察院、第三方监督评估组织）；本步骤所有申请与听证环节一律由执业刑事辩护律师主导，配置缺失时同样按律师主导处理，标 [临时模式]
    2. 确认四项前置条件：适用条件评估已确认、整改计划已完成并实施（里程碑基本完成）、第三方监督评估已完成或进行中（报告已出具或即将出具）、认罪认罚具结书已签署（律师确认）；未满足时提示先完成前置步骤
    3. 步骤一 按七要素准备合规整改报告，确保与认罪认罚的事实认定一致、只写已实际落实的措施、每项成果有实物证据支撑（制度文本、培训记录、系统截图等），并呈现「不得夸大成效、虚构措施、掩盖未完成项目」的合规边界
    4. 步骤二 由律师主导起草不起诉申请书（七章结构），引用第三方评估结论须引评估报告原文、不得断章取义，并按材料清单逐项核对附件
    5. 申请书及全部附件须经执业刑事辩护律师审核确认后方可提交检察机关，标 [律师审查 — 硬性要求]；非律师角色（合规官/法务/当事人）不得独立提交
    6. 步骤三 说明听证规则（描述规则 [待验证 — 规范性文件快速演进]）：检察机关在决定对涉案企业作不起诉处理前可组织公开听证、听取各方意见；听证并非必经程序，是否启动由检察机关决定 [待验证]；企业须配合，而非主动要求或规避听证；列明各参加方的角色与参加方式
    7. 听证准备四项：陈述提纲（认罪认罚情况 → 整改措施与成果 → 社会效果 → 未来合规承诺）；证据材料（提炼整改报告亮点与评估报告关键结论，须为真实原件或经核实副本）；答询准备（预判听证员可能就整改真实性、是否已弥补损失、今后合规承诺提问，律师与企业代表模拟演练，确实不知道的说明不知道、不猜测）；被害方关系（尽量在听证前完成赔偿与谅解，谅解须真实自愿，不得威胁或诱导）
    8. 提供三段式合规版听证陈述框架：认罪认罚的真诚性（只写罪名类别，不写具体条号）→ 整改的针对性与真实性（针对哪些漏洞采取了哪些措施，已落实并经第三方监督评估机构核实）→ 社会效果与今后合规承诺（行业地位、对就业/税收/地区经济的贡献、已建立的长效机制）
    9. 步骤四 不起诉决定后：继续按整改计划推进，不得因获不起诉决定而停止整改；准备配合行刑反向衔接的行政处罚（如税务、市场监管处罚），说明不起诉不等于无任何处罚；长期保存整改报告、评估报告与证据材料；听证前未完成全额赔偿的继续履行；提示合规承诺履行不力时不起诉被撤回的风险 [待验证]；检察机关要求继续合规报告时按要求履行
    10. 申请被否决时（描述规则 [待验证]）：案件依法提起公诉进入审判程序，律师立即启动审判阶段辩护准备；认罪认罚从宽情节在审判阶段仍可主张（刑事诉讼法第15条），合规整改作为悔罪表现也可作为量刑从宽情节（须律师主导）
    11. 识别到虚构夸大整改内容的需求标 [合规边界 — 拒绝]；听证陈述包含否认认罪认罚事实的内容时拒绝起草，标 [合规说明 — 须与认罪认罚保持一致]；听证员提出整改范围外的问题时律师及时介入，如实回答或说明无法答复的原因；被害方明确反对时继续推进赔偿谈判，由律师评估影响，不得威胁或诱导被害方撤回意见
    12. 按输出模板出具《不起诉申请与听证准备报告》

    内置规则

    • 整改报告七要素：涉案问题描述（基于认罪认罚的事实认定，不得自相矛盾）；合规漏洞诊断（诚实呈现，隐瞒漏洞会影响整改认定）；整改措施清单（对应整改计划，须已实际落实）；整改进度与成果（逐项列示并有实物证据支撑）；整改效果评估（客观自评，不夸大，第三方监督评估报告是权威评估）；合规承诺（高管级别书面签署，体现持续合规决心）；赔偿/弥补情况（被害方谅解是酌定不起诉的积极因素）
    • 申请书七章：基本情况（企业名称、案件信息、申请类型为酌定相对不起诉）；法律依据（刑事诉讼法第177条（建议复核）、涉案企业合规相关规定（规范性文件描述，[待验证]），须与不起诉类型匹配）；论证符合不起诉条件（逐条论证认罪认罚 + 合规整改有效 + 社会效果，核心论据为整改的针对性与有效性、不需要刑事处罚的理由）；整改成果摘要（引用整改报告主要证据）；第三方评估结论引用；被害方处理情况（谅解书原件附备）；申请事项（明确请求作出不起诉决定，表述明确、礼貌、合规）
    • 材料清单与必要性：不起诉申请书（律师起草、法定代表人签署）、合规整改报告（完整版，附可验证成果证据）、高管整改承诺书、认罪认罚具结书副本（已签署并有律师/值班律师见证）为「必须」；第三方监督评估报告为「如已完成评估」；被害方谅解书、赔偿凭证（银行记录或收据）为「如有」；其他补充材料为「按需」
    • 听证参加方（描述规则 [待验证]）：检察机关主持并说明案情与申请情况；企业作为申请方陈述整改情况、论证符合不起诉条件；律师代理补充陈述、回答听证员询问；侦查机关（公安）就是否同意不起诉发表意见；被害方（如有）就谅解情况与对不起诉的态度发表意见；人民监督员/听证员听取各方意见后发表意见供检察机关参考；第三方监督评估机构（可能）介绍评估情况与结论
