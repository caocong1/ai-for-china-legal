02概要

面向中国大陆执业律师，审查和起草买卖合同、技术服务合同、租赁合同等商事合同，分析责任限制、违约金、赔偿范围与例外清单，并对股权交易的目标公司做资料室法律尽调，生成业务人员可读的审查摘要。五个流程入口（冷启动访谈、合同审查、合同起草、违约责任分析、股权交易尽调）下共 23 个可单独触发的步骤，每步自带详细做法、检查清单、输出模板和法律依据。所有流程从实践配置文件 commercial-legal/CLAUDE.md 读取团队立场；法条引用遵循统一的引用规范，每条标注来源标签与验证状态，写入成果前经研究闸门核对现行原文。

03实践配置

实践配置文件 <a href="https://github.com/caocong1/ai-for-china-legal/blob/master/commercial-legal/CLAUDE.md">commercial-legal/CLAUDE.md</a> 记录贵所的立场与习惯；所有流程开始前先读它。

配置哪些内容

  • 我们是谁
  • 谁在使用
  • 可用集成
  • 审查立场（整体风险偏好；甲方立场 / 乙方立场各含责任限制、违约金、知识产权、数据保护、期限与终止、管辖法律与争议解决、交易破坏者）
  • 升级矩阵（审批权限、美元阈值、自动升级触发条件）
  • 文书风格
  • 输出（工作产物标题、审查者注释块、静默模式规则、下一步决策树模板）
  • 共享护栏（无静默补充原则、时效性触发、验证用户陈述的法律事实、来源标签规范、目的地检查、双重严重性、管辖识别）
  • 事项级动态确认策略
  • 事项工作区
  • 审查过的种子文档

会怎样改变输出

  • 「谁在使用」的角色决定工作产物标题：律师角色输出「律师工作产物 — 受律师-当事人特权保护 / 保密」，非律师角色输出「研究笔记 — 非法律建议，供律师审查」；股权尽调流程从「输出」章节取此标题。
  • 「审查立场」中的甲方 / 乙方立场（当前模板填写：乙方违约金「实际损失基准（不超30%）」、乙方直接赔偿上限「不设上限」、乙方数据保护「法定最低要求」、整体风险偏好「平衡型」）是合同审查、起草、违约责任分析的默认判断基准；股权尽调的立场由委托方身份决定，不读此节。
  • 字段值「视情况而定」表示只在本事项相关时才向律师确认，不得写入结论或文书，也不触发重跑全部访谈；配置缺失或含 [PLACEHOLDER] 时按临时模式默认（律师角色、平衡型、中国法律体系）并在输出上标记。
  • 「文书风格」决定输出形态：默认修订标记文档、协商式语气、仅重要问题附法条、默认中文；「事项级动态确认策略」规定无提问工具时输出可复制到微信的 [CLARIFY:] 编号清单，每轮 2–5 题、通常最多两轮，Word 修订稿保存到源文件同目录并用新后缀、永不覆盖原件，默认先供律师内部复核，明确拟发送对方时另出不含内部评级与谈判底线的外部净化版。
  • 「共享护栏」为所有流程加硬规则：距最后更新超过 6 个月的法规标 [时效性 flagged — 需验证最新法规]；来源标签五类（[法宝] / [法规网站] / [网络搜索 — 需验证] / [模型知识 — 需验证] / [用户提供]）；每个问题同时标法律风险与商业摩擦两个维度；面向对方或全员群等会使特权失效的目的地提供特权版与脱敏版。
  • 「管辖识别」提示经济特区（深圳、珠海、汕头、厦门、海南）、民族自治地方、自贸区、港澳台的差异，涉及时标 [管辖 flagged — 需验证特别规定]；「升级矩阵」的金额阈值与自动升级触发条件决定何时提示升级给指定人员。

05不做什么

  • 不提供法律意见或法律结论
  • 不替代执业律师的判断
  • 不保证审查的完整性
  • 不自动签署合同或发送修订给对方
