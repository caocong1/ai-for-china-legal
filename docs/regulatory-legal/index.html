02概要

本插件面向监管合规律师、企业合规官与法务，提供五条完整流程：冷启动访谈、监管动态监控、行政处罚应对、合规体系建设、监管报告起草，共 20 个可单独触发的步骤。所有流程在做实质工作前先读取 regulatory-legal/CLAUDE.md 实践配置文件（企业画像与主管监管机关、服务立场与合规严格度、监管关系、风险四级表、升级矩阵与程序时限触发表、文书风格），再按统一的法律引用规范与引用库出具带来源标签和待验证标注的分析。法律依据以《行政处罚法》（2021 修订）为核心，第4/9/28/29/32/33/36/44/45/58/63条按 2021 新条号引用并一律标「建议复核」；行政许可法、行政强制法、行政复议法、行政诉讼法的具体条号、各行业监管规章文号与罚款数额、地方裁量基准、GB/T 标准号一律只描述规则并标 [待验证]。涉及吊销许可、责令停产停业、较大数额罚款、限制从业、行刑衔接或责任人人身自由风险时，无论配置为何一律强制升级执业律师；陈述申辩期、听证申请期、复议申请期、起诉期等程序时限一律强标提示，不得静默放任时限流逝。

  • 事项工作区
  • 审查过的种子文档

会怎样改变输出

  • 「执业角色」与「谁在使用 → 角色」决定输出定性：律师角色用标题「律师工作产物 — 受律师-当事人特权保护 / 保密」；合规官、法务、当事人本人用「研究笔记 — 合规研究与初步分析，非法律建议，供律师审查」，并在陈述申辩书·听证陈述定稿、复议申请书提交、起诉状提交、监管报告定稿报送、合规制度定稿、重大合规整改方案确定前暂停升级执业律师。
  • 「所属行业」与「主管监管机关（中央·地方）」是核心变量：决定行业监管规章体系与规则源识别方向、处罚决定来源、行政复议机关、规则源官网、裁量基准适用版本；含占位符时不预设行业，按用户陈述逐案判断并显式提示。
  • 「整体服务立场」（监管动态监控 / 行政处罚应对 / 合规体系建设 / 监管报告起草 / 混合多类型）决定各流程的审查侧重、风险标记侧重与主要输出，缺失时显式提示并以临时模式（监管动态监控）继续；「合规严格度」保守型把一切疑点标红并升级、平衡型只对重大监管风险标红、务实型仅拦截明显高风险。
  • 「监管关系」为被动应对时行政程序时限护栏自动加强：识别处罚决定送达日期，强标陈述申辩期、听证申请期、复议申请期、起诉期，具体天数 [待验证]、以实际收到文书日期起算，不得静默放任时限流逝。
  • 「行政违法风险校准」四级表（关键 / 高 / 中等 / 低）决定每个发现的风险标注，「升级矩阵」角色权限表决定升级给谁；吊销许可、责令停产停业·关闭·限制从业、较大数额罚款（数额 [待验证 — 地方 flagged]）、行刑衔接、责任人人身自由风险五项强制升级凌驾于服务立场与合规严格度之上，输出标 [强制升级 — 行刑衔接] 或 [强制升级 — 重大处罚] 并提示 criminal-compliance 插件衔接。
  • 「文书风格」四类默认值分别驱动监管动态简报、处罚应对文书、合规制度文本、监管报告的格式与语气；「输出」统一附审查者注释块（材料日期、范围、2021 条号提示、行业规章时效提示、程序时限提示、行刑衔接提示、来源、立场、监管关系、各级标记项计数）与九选项下一步决策树；「共享护栏」规定行政处罚法条号标「建议复核」、行业规章标 [时效性 flagged]、地方法规与裁量基准标 [地方 flagged]、GB/T 标 [待验证]，五种来源标签，以及面向监管机关的材料须提供内部草稿与对外正式两套版本。

05不做什么

  • 不提供法律意见或法律结论
  • 不替代执业律师的判断
  • 不自动向监管机构提交任何文件或报告
  • 不保证行政处罚的结果
  • 绝不提供逃避监管、虚假报送、伪造合规证据、规避检查、阻碍执法、隐匿违法事实或瞒报漏报的方法，识别此类需求一律拒绝并标 [合规边界 — 拒绝]
  • 不替代刑事辩护工作：行政违法可能升格刑事或监管机关移送公安时强制升级执业律师，并提示与 criminal-compliance 插件衔接
