01概要

帮助企业及其律师、合规官、法务系统跟踪适用于本企业的监管规则变化（新规、修订、废止、征求意见稿），判断新规是否适用、提取新增合规义务、对照现状找出合规差距并排出整改优先级，最终输出监管动态简报、合规义务台账和红橙黄绿四级到期预警清单。开始前读取 regulatory-legal/CLAUDE.md 中的所属行业、主管监管机关、服务立场、监管关系、合规严格度、风险校准与升级矩阵；配置缺失时以临时模式运行（监管动态监控立场、律师角色、合规严格度保守）。流程分四步：先按行业映射中央与地方主管机关、规则源效力层级与官方发布渠道；再把每条动态归入四类并提取制定机关、效力层级、公布日、施行日与过渡期；然后按「差距严重程度 × 合规严格度」定风险等级、按「生效时限 × 风险等级」矩阵排出 P0–P4；最后汇总成简报与台账，并按剩余天数分级预警。法律依据取自本插件的引用规范与行政法引用库：行政处罚法只引用 2021 修订后新条号并标「建议复核」，行业规章、裁量基准、国家标准一律描述规则加 [待验证]，不写文号与罚款数额。四步均可单独触发；输出是当期静态快照，不做定时推送。

02适用与边界

适用场景

  • 企业需要建立或更新监管规则跟踪机制，定期输出监管动态简报（服务立场为监管动态监控）
  • 主管机关发布了新规、修订、废止决定或征求意见稿，需要判断对本企业是否适用、带来哪些新增义务
  • 已收到处罚决定或检查通知（行政处罚应对立场），需要聚焦处罚依据规章、裁量基准的变化，并对陈述申辩、听证、复议、起诉期限设红色预警
  • 建设合规体系时，需要以新规驱动的合规差距清单决定制度新建或修订
  • 起草监管报告前，需要确认报送口径、新增报告义务、合规声明要求有无变化
  • 只需其中一步时可单独触发：识别某行业主管机关、对一批新规分类、评估某一新规影响、输出或更新合规义务台账

不做什么

  • 不提供逃避监管、规避检查、虚假报送、伪造合规证据的方法；识别到此类需求即拒绝并标 [合规边界 — 拒绝]
  • 不替代刑事辩护：识别到行刑衔接即强制升级执业律师，并提示转刑事合规插件（criminal-compliance）
  • 不做定时检查、自动推送、企业微信/钉钉通知；本流程只输出当期静态台账与提醒清单（原文称动态预警属「Phase 15」自动化范畴）
  • 不覆盖境外监管：涉外业务只识别中国境内机关与规则源，境外部分标 [涉外 — 须结合境外法律分析]
  • 不硬写行业规章文号、罚款数额、裁量阶次数值、国家标准号；征求意见稿不作为合规义务依据
  • 不生成完整合规制度文本：整改方案详细设计转合规体系建设流程（/regulatory-legal:compliance-system）

03输入与产出

需要律师提供

  • regulatory-legal/CLAUDE.md 实践配置必需
    我们是谁（所属行业、主管监管机关中央·地方、规模、业务模式、是否涉外、历史受罚情况、重点监管风险领域）、合规与监管立场（服务立场、合规严格度、监管关系）、行政违法风险校准、升级矩阵、文书风格；不存在或含 [PLACEHOLDER] 时进入临时模式
  • 所属行业、业务模式、所在省份/城市必需
    行业与主管机关是核心变量；配置缺失时须由用户陈述，不得猜测行业后静默进行
  • 待分类的监管动态：规则名称或文号、官方公告、规则全文可选
    第 2、3 步使用；文本明显缺漏时影响评估标 [前提 flagged — 新规文本不完整，评估结果可能有遗漏]
  • 企业现有合规制度、流程、措施说明可选
    第 3 步合规差距对照表「企业现状」列的来源
  • 规则源清单与影响评估结果（前序步骤产出或用户直接提供）可选
    单独触发第 4 步时需要；缺失部分在简报与台账中标注，不自行编造规则源
  • 各项义务的企业内部责任部门可选
    台账「责任部门」列须由用户确认
  • 处罚决定书、检查通知等文书及实际收到日期可选
    行政处罚应对立场下用于程序时限预警，以当事人实际收到文书日期为起算点

产出

  • 监管机关与规则源识别报告给律师内部
    主管监管机关映射（监管领域 / 中央机关 / 地方机关 / 核心监管事项 / 发布渠道，附交叉监管提示）→ 适用规则源效力层级表（含与本企业相关性高中低、验证状态）→ 规则源覆盖范围说明 → 官方发布渠道汇总 → 下一步建议
  • 监管动态分类简报给律师内部
    新规出台 / 修订 / 废止 / 征求意见稿四张表（制定机关、效力层级、公布日、施行日、过渡期、初步意义）→ 效力层级 × 动态类型数量汇总 → 待确认事项
  • 影响评估与合规差距分析报告给律师内部
    适用性判断（五维度与结论）→ 新增合规义务清单 → 合规差距对照（附关键 / 高 / 中等 / 低数量统计）→ 整改优先级表（P0–P3，含责任人）→ 后续行动建议 → 待验证事项
  • 监管动态简报与合规义务台账给律师内部 / 企业合规部门
    工作产物标题（律师版 / 非律师版）+ 审查者注释块；第一节本期动态按效力层级分类列示；第二节重点提示；第三节待办清单；第四节合规义务台账（11 列）；第五节预警提醒清单（红 / 橙 / 黄）；第六节下一步建议

04开始前

前置条件

  • 读取 regulatory-legal/CLAUDE.md 六项配置：我们是谁（执业角色与企业画像）、整体服务立场、监管关系、合规严格度、行政违法风险校准（四级定义）、升级矩阵；预警与台账一步另读文书风格中的监管动态简报风格
  • 配置不存在或关键字段含 [PLACEHOLDER] 时，提示运行 /regulatory-legal:cold-start-interview，或由用户说明服务立场与所属行业后以临时模式继续：监管动态监控立场 / 律师角色 / 合规严格度保守 / 所属行业与主管监管机关按用户陈述逐案判断 / 识别重大处罚或行刑衔接即强制升级；输出标 [临时模式 — 请运行冷启动访谈完成配置]
  • 确认已读到所属行业与主管监管机关；画像缺失时提示用户补充，不得猜测行业后静默进行
  • 明确告知当前服务立场；缺失时默认监管动态监控，并按用户陈述逐案判断
  • 读取 regulatory-legal/skills/_shared/ 下的引用规范（legal-basis-conventions.md）、行政法引用库（administrative-law-citations.md）与配置契约（practice-profile-schema.md）

硬性规则

企业画像与所属行业确认
开始任何步骤前确认已读取所属行业、主管监管机关、业务模式、重点监管风险领域；行业决定规则源范围与主管机关，缺失须显式提示
服务立场决定监控侧重
监管动态监控：全面规则源覆盖，侧重影响初判与台账建设；行政处罚应对：聚焦被处罚事项对应的具体规则源，侧重合法性审查依据与时限；合规体系建设：侧重合规差距驱动的制度更新，衔接合规体系建设流程；监管报告起草：侧重与报送义务相关的规则更新，衔接监管报告起草流程
合规严格度决定标记强度
保守型：一切新规疑点从严标红，合规义务从严认定；平衡型：重大新规标红，一般新规标橙；务实型：仅拦截直接影响企业合规义务的明确新规
行刑衔接强制升级
识别到监管机关移送公安、违法所得或情节达刑事追诉标准时，立即强制升级执业律师，输出标 [强制升级 — 行刑衔接]，提示衔接刑事合规插件（criminal-compliance）；本插件不替代刑事辩护
监管合规边界
输出立足事前合规、依法应对处罚、如实报送；绝不提供逃避监管、虚假报送、伪造合规证据、规避检查的方法，识别即拒绝并标 [合规边界 — 拒绝]，提示依法合规、如实申报、依法行使陈述申辩与复议诉讼救济权利
行政程序时限
涉及处罚决定或救济期限时，强标陈述申辩期、听证申请期、复议申请期、起诉期，升级执业律师确认具体时限计算，不得静默放任时限流逝；具体期限天数须核实现行法律规定 [待验证]
目的地 / 特权检查
输出前检查目的地是否在律师-当事人特权圈内；面向监管机关提交的材料须提供内部工作草稿与对外提交正式版两套选项
地方差异提示
地方性法规、行政处罚裁量基准、监管口径存在地区差异，涉及具体地区时标 [地方 flagged — 需核实地方性法规与地方裁量基准]；不跨区域适用裁量基准
引用纪律
行政处罚法 2021 中度把握锚点（第4/9/28/29/32/33/36/44/45/58/63条）标「建议复核」，务必用新条号；行政许可法、行政强制法、行政复议法、行政诉讼法不确定条号描述规则加 [待验证]；行业规章、规范性文件、裁量基准描述规则加 [待验证]，不硬写文号数额；国家标准号 [待验证]；案例案号一律 [待验证]

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置假设，可逐条复制。页面里的英文标记见首页「标记与术语」。

  1. 监管机关与规则源识别

    /regulatory-legal:authority-rule-source-identification可单独运行

    回答「谁管我、管我的规则有哪些、从哪获取」：按行业确定中央与地方主管机关，按效力层级梳理适用规则源，确认官方发布渠道，输出「行业—监管机关—规则源—发布渠道」映射表，作为后续动态追踪、影响评估与台账的基础。

    请律师核对

    • 核对 1.1行业—机关映射只列 7 类领域，是否需要补充贵方客户所在行业的主管机关？
    • 核对 1.2复议管辖写作「向本级政府或上一级主管部门申请」并标 [待验证]，请按现行行政复议法核实后决定是否保留这一表述。
    • 核对 1.3效力层级表把地方性法规排在部门规章之前，同时又写「部门规章与地方性法规不一致时由国务院提出意见」，对外表述口径请确认。
    • 核对 1.4各官网网址均为 [模型知识 — 需验证]，其中金融监管写作 https://www.cbirc.gov.cn，请核实是否为现行官网。

    做法

    1. 读取配置中的所属行业、主管监管机关（中央·地方）、整体服务立场与监管关系；行业或主管机关含占位符时进入临时模式：不预设行业、不预设主管机关、按用户陈述逐案判断，服务立场默认监管动态监控，并显式提示用户补充行业。
    2. 按行业—监管机关映射表确定中央主管机关、核心规则源类别与官网；跨行业经营或互联网平台等多机关交叉监管情形逐一列示，标 [交叉监管 — 多机关管辖]，提示可能存在规则冲突或重复适用。
    3. 把适用规则源按效力层级排列：法律 → 行政法规 → 地方性法规 → 部门规章 → 地方政府规章 → 规范性文件 → 行政处罚裁量基准 → 国家标准，并标注每项与本企业的相关性（高 / 中 / 低）与验证状态。
    4. 按上位法优于下位法、特别法优于一般法（行业专门法律优于行政处罚法的一般规定）、新法优于旧法说明适用关系；部门规章与地方性法规对同一事项不一致时写「由国务院提出意见」并标 [待验证]，冲突处标 [规则冲突 — 须核实适用]。
    5. 按中央—省级—市/区县三级体制确定管辖层级：处罚一般由违法行为发生地县级以上机关管辖 [待验证]；许可按类型分全国性与地方性；重大、跨省、疑难复杂案件可能由上级直接管辖或指定管辖；对县级以上地方部门决定不服的，向该部门的本级政府或上一级主管部门申请复议 [待验证]。
    6. 按服务立场调整覆盖范围：监管动态监控为全覆盖（八类规则源都要覆盖，同时关注新规、修订、废止、征求意见稿）；行政处罚应对聚焦处罚依据规章、裁量基准、程序规范，重点核实处罚决定所引依据是否正确、是否现行有效；合规体系建设为全覆盖加合规指引；监管报告起草聚焦报送义务（报告种类、期限、格式、渠道）。
    7. 按监管关系调整侧重：主动合规关注即将生效的新规与过渡期安排；被动应对关注处罚依据的有效性与适用正确性。
    8. 逐类确认官方发布渠道：法律、行政法规查国家法律法规数据库 https://flk.npc.gov.cn（行政法规另查中国政府网 https://www.gov.cn 的国务院令原文）；部门规章、规范性文件查各机关官网并注意是否已废止或修订；裁量基准以当地现行版本为准；国家标准查 https://openstd.samr.gov.cn；案例查中国裁判文书网与最高人民法院官网，案号 [待验证]。
    9. 网络搜索得到的规则文本标 [网络搜索 — 需验证]，对照官方渠道核实后才能作为结论依据。
    10. 按模板输出识别报告：主管监管机关映射、适用规则源效力层级、规则源覆盖范围说明、官方发布渠道汇总、下一步建议。

    内置规则

    • 行业—机关映射共 7 类：市场监管（竞争·广告·产品质量·价格·反垄断·消费者权益）→ 市场监管总局；网信·数据安全·个人信息保护·算法 → 网信办；工信·电信·工业产品 → 工信部；金融（银行·保险·证券·基金）→ 金融监管总局·中国人民银行·中国证监会；药品·医疗器械 → 药监局；生态环境·排污 → 生态环境部；安全生产（危化品·矿山·烟花爆竹）→ 应急管理部。各官网均标 [模型知识 — 需验证]。
    • 金融领域 2023 年机构改革后监管职能有调整（如银保监会合并为金融监管总局），以现行机关名称为准 [待验证]；机构改革导致名称或职能变更的，标注改革前后名称并标 [待验证 — 机构改革后职能调整须核实]。
    • 各层级定位：地方性法规在本行政区域内适用，可在法律、行政法规范围内作出更严格规定 [待验证]；规范性文件不具强制性法律效力，但有重要实务参考价值；裁量基准把罚款数额与情节按一般违法 / 较重违法 / 严重违法分阶次细化，是预测罚款幅度的依据，标 [地方 flagged — 各地裁量基准差异大]；国家标准（GB/T）为推荐性标准，可作合规体系建设参照。
    • 三级机关分工：中央级——制定部门规章、全国性许可、重大与跨省案件、部分情形的行政复议；省级——地方性法规/规章起草、省级许可、重大案件、裁量基准制定、对下级业务指导；市/区县级——日常监督检查、行政处罚实施、现场检查、许可初审。

  2. 动态抓取与分类

    /regulatory-legal:capture-classification可单独运行

    把收集到的监管规则变化逐条归入新规出台 / 修订 / 废止 / 征求意见稿四类，提取制定机关、效力层级、公布日、施行日与过渡期并按行业归类，为影响评估与台账更新提供结构化数据。

    请律师核对

    • 核对 2.1把「公布日至施行日的间隔」直接称为过渡期，与废止时的「过渡条款」分开处理，是否符合贵所用法？
    • 核对 2.2本步骤的效力层级识别表与汇总表只有五级（没有地方政府规章、裁量基准、国家标准），第 1 步却列了八级，分类口径是否需要对齐？
    • 核对 2.3「联合发布规则以牵头机关级别定效力层级」这一规则是否同意？
    • 核对 2.4原文称本步骤是监管动态监控的「第一步」，与流程总表（第 2 步，排在规则源识别之后）不一致，请确认实际运行顺序。

    做法

    1. 读取配置中的服务立场、所属行业与主管监管机关、合规严格度、可用集成（法规数据库连接状态决定抓取路径）；含占位符时以临时模式运行，默认监管动态监控立场，行业与机关按用户陈述逐案判断。
    2. 按识别要点把每条动态归入四类：标题含「规定」「办法」「条例」「决定」、新编年份序号文号、公告写「现予发布」「自X年X月X日起施行」的为新规出台；含「修订」「修改」「修正案」或同一文号不同版本的为修订；含「废止」「失效」或新规末尾列明「XX同时废止」的为废止；含「征求意见稿」「草案」并附征求意见截止日期的为征求意见稿。
    3. 按制定机关定效力层级：全国人大及常委会 → 法律（「XX法」）；国务院 → 行政法规（「XX条例」「XX规定」「XX办法」）；省级/设区的市级人大及常委会 → 地方性法规；国务院部委与直属机构 → 部门规章；县级以上地方政府及其部门 → 地方规范性文件（「XX通知」「XX意见」「XX细则」）；监管机关内设司局与办公室 → 规范性文件（非规章，「XX指导意见」「XX合规指引」「XX自查指南」）。
    4. 提取公布日（以政府公报或监管机关官网公告标注的发布日期为准）与施行日（正文末条或公告中「自X年X月X日起施行」）；未明确施行日的核实是否「自公布之日起施行」或另有规定，标 [待验证]；不得把公布日当作施行日。
    5. 识别过渡期（有：X个月 / 无 / 待确认）；即时施行的高亮，对企业有重大影响时标红并提示「即时施行，合规调整窗口极短」；修订已公布未施行的标「已公布·未施行」并注明过渡期截止日。
    6. 征求意见稿一律标 [征求意见稿 — 未生效，仅供预判]，只作趋势预判，可提示企业按公告载明的方式与截止日期提交书面意见；正式发布后按正式版重新分类，并标注「正式版与征求意见稿主要差异：……」。
    7. 废止规则须确认有无替代规则衔接，不能简单视为「无需合规」；设有过渡条款（如「废止前已取得许可的，在有效期内继续有效」）的提取条款内容并标注。
    8. 中央规则对应的地方版本（地方性法规、地方规章、地方裁量基准）一并分类，标 [地方 flagged — 需核实地方性法规与地方裁量基准]；联合发布的规则列明全部发布机关。
    9. 按服务立场调整侧重：监管动态监控全量分类；行政处罚应对侧重处罚种类、罚款数额、裁量基准的修订与废止；合规体系建设侧重新增合规义务来源（内控制度、报告报送、数据分类等）；监管报告起草侧重定期、专项、重大事项报告的报送时限、内容格式、数据口径变化。
    10. 按模板输出分类简报（四类分表、效力层级汇总、待确认事项），建议下一步进入影响评估。

    内置规则

    • 四类动态的初步意义：新规出台可能新增合规义务（许可申请、报告报送、内控制度建设、数据分类分级等），须评估是否适用；修订可能改变已适用义务（范围扩大或缩减、罚款数额调整、程序变更），须对比新旧条文；废止解除原义务，但须确认替代规则；征求意见稿只作趋势预判，不产生合规义务。
    • 征求意见稿企业无遵守义务，不得作为合规依据引用；误列入合规义务台账的立即移除并重新标注。
    • 公布日与施行日的间隔即为过渡期，多数规则「常见30日至数月」；少数「自公布之日起施行」，无过渡期，合规调整时间紧迫。
    • 过渡期内新旧规则并行：企业须同时遵守旧规则并为新规则做准备。
    • 联合发布的规则，效力层级以牵头机关级别为准。
    • 地方版本可在上位法范围内作出更严格规定，须分别标注。
    • 新规含「构成犯罪的，依法追究刑事责任」等衔接条款，或修订提高行政违法追诉标准使更多行为可能升格刑事时，标 [强制升级 — 行刑衔接]，涉及刑事追诉标准变化时提示衔接刑事合规插件。
    • 文号、罚款数额未标 [待验证] 就写入的，改为规则描述并标 [待验证 — 行业监管规章快速演进，须核实现行版本]；已废止规则仍在台账中的，改为「废止」并清理过期条目。

    法律依据

    • 《行政处罚法》第4条、第9条 — 处罚法定与处罚种类（已核实锚点（中度把握），建议复核）
    • 《立法法》— 法律、行政法规、地方性法规、规章的制定程序、公布程序与施行日期规则；法律之间新的一般规定与旧的特别规定不一致时由全国人大常委会裁决 [模型知识 — 需验证] [待验证]
    • 《行政法规制定程序条例》— 行政法规自公布之日起30日后施行，涉及国家安全、外汇汇率、货币政策的可以自公布之日起施行 [待验证]
    • 《规章制定程序条例》— 部门规章与地方政府规章的制定程序，规章应当自公布之日起30日后施行 [待验证]
    • 各监管机关行业监管规章 — 描述规则 [待验证 — 行业监管规章快速演进，须核实现行版本]；各地裁量基准 [待验证] [地方 flagged]；行业合规指引与自查指南 [待验证]
    • 案例占位两类（规则修订后过渡期内新旧规则适用争议；地方性法规在上位法范围内作出更严格规定的合法性认定）— 案号 [待验证]

    产出

    《监管动态分类简报》：抬头列服务立场、所属行业、主管监管机关、分类日期、动态来源期间；一、新规出台表（含行业归属与初步意义）；二、修订表（修订版名称、原规则名称、主要修订内容、初步影响）；三、废止表（废止依据、废止日期、替代规则）；四、征求意见稿表（预期效力层级、征求意见截止日期、核心内容、趋势预判）；五、效力层级汇总（法律、行政法规、地方性法规、部门规章、规范性文件 × 四类动态的数量）；六、待确认事项（生效日期、效力层级、行业归属）。

  3. 影响评估与合规差距

    /regulatory-legal:impact-gap-assessment可单独运行

    针对新发布或修订的规则，判断是否适用本企业，提取新增或变更的合规义务，与企业现状逐项对照找出差距，按合规严格度定风险等级，再按生效时限与风险等级排出整改优先级，并按服务立场给出后续衔接。

    请律师核对

    • 核对 3.1风险等级校准表与「曾受重大处罚的同类差距自动上调一级」规则是否符合贵方判断？
    • 核对 3.2优先级矩阵把征求意见稿放在「远期」一行（关键风险可得 P2），与「不纳入正式合规差距」的规定冲突，以哪条为准？
    • 核对 3.3「不得因有过渡期而降低优先级」与矩阵按生效时间远近降级之间的关系，请给出口径。
    • 核对 3.4多规重叠时把部门规章排在地方性法规之上，与第 1、2 步的排序不同，请确认。
    • 核对 3.5只有 P0 要求律师确认整改方案，是否同意？

    做法

    1. 读取配置十项字段：所属行业、主管监管机关（中央·地方）、规模、业务模式、是否涉外、重点监管风险领域、历史受罚情况、合规严格度、整体服务立场、监管关系；另读「谁在使用」的角色，决定输出标题与升级路由。行业是适用性判断的第一维度，缺失须显式提示，不得静默假定。
    2. 按五个维度填适用性判断表：行业（行业不匹配可排除）、业务（业务条线逐一比对）、规模（新规中的规模门槛）、地域（全国或特定区域，地方性法规标 [地方 flagged]）、主体类型（如关键信息基础设施运营者、上市公司、国有企业的特殊义务），每项给出是 / 否 / 存疑。
    3. 得出四种适用结论：确定适用（行业、业务、主体类型均匹配）；可能适用（标 [适用性存疑 — 须进一步确认]，纳入评估）；确定不适用（行业或主体类型明确不匹配，注明理由后排除）；部分适用（标注适用条款范围）。
    4. 对适用条款逐条提取义务，填写条款编号、义务类型、义务摘要、生效日期、过渡期、违反后果、来源标签、验证状态；违反后果按行政处罚法第9条描述处罚种类范围，结合第28条描述整改义务，罚款数额与裁量阶次引用当地裁量基准并标 [待验证 — 行业监管规章快速演进，须核实现行版本]，不自行推算。
    5. 把每项义务与企业现有制度、流程、措施对照，写明差距（缺失 / 不完善 / 执行不到位）、严重程度（重大 / 中等 / 轻微）、风险等级与整改方向。
    6. 按「差距严重程度 × 合规严格度」表定风险等级，再按历史受罚情况调整：曾受重大处罚的同类差距自动上调一级；曾受警告或小额罚款的关注同类差距是否重复出现。
    7. 按「生效时限 × 风险等级」矩阵给每项差距定 P0–P4，写明建议行动与责任人。
    8. 按服务立场确定侧重与衔接：监管动态监控以「有无」为主，侧重义务清单完整性，记入台账持续追踪并回到规则源识别更新；合规体系建设按「制度完备性 × 执行有效性」逐项评估，转合规体系建设流程修订或新建制度；行政处罚应对聚焦被处罚行为对应义务，评估是否存在系统性合规缺失，转处罚应对流程；监管报告起草评估报告渠道、格式、时限是否已建立，转监管报告起草流程。
    9. 汇总输出影响评估与合规差距分析报告，列出待验证事项及验证途径。

    内置规则

    • 义务五类：禁止性（如不得未经同意收集个人信息、不得发布虚假广告）；程序性（如须开展影响评估、取得行政许可、进行法制审核）；报告性（如定期报送合规报告、报告安全事件、报送重大事项）；许可性（如取得经营许可证、完成备案、通过安全评估）；标准性（如符合国家标准、建立合规管理体系、达到安全等级）。
    • 差距严重程度：重大 = 完全缺失或严重不足，违规可能性高（无相关制度、关键控制缺失、未取得必需许可）；中等 = 有制度但不完善或执行不到位（未覆盖全部义务、流程不清晰、台账不完整）；轻微 = 基本合规但需按新规更新或文档化不足。
    • 风险等级校准：重大差距——保守型关键、平衡型关键、务实型高；中等差距——保守型高、平衡型中等、务实型中等；轻微差距——保守型中等、平衡型低、务实型低。
    • 优先级矩阵（行为生效时限，列依次为关键 / 高 / 中等 / 低）：紧迫（生效≤30天或已生效）P0 / P0 / P1 / P2；较紧迫（生效31-90天）P1 / P1 / P2 / P3；一般（生效91天-1年）P1 / P2 / P3 / P3；远期（生效＞1年或征求意见稿）P2 / P3 / P3 / P4。
    • 优先级行动：P0 立即启动整改、须律师确认整改方案、资源优先配置；P1 制定整改计划并分配责任人、两周内启动；P2 纳入季度整改计划、按月跟进；P3 纳入年度合规计划、定期复查；P4 记入合规义务台账、新规进展时重新评估。
    • 适用性存疑：保守型严格度默认纳入，务实型可暂标观望但须记入合规义务台账；临时模式下一律按最保守处理并标 [临时模式 — 适用性存疑]，合规差距风险等级偏高标注。将不适用新规纳入会增加合规成本，将适用新规排除会产生合规盲区。
    • 过渡期内标 [过渡期 — 生效日期：XX，建议利用过渡期完成合规整改]，不得因有过渡期而降低优先级；征求意见稿标 [征求意见稿 — 尚未生效，仅供参考性评估]，评估预期影响但不纳入正式合规差距。

    做法

    1. 读取配置中的执业角色、所属行业、主管机关、服务立场、合规严格度、监管关系、风险校准、升级矩阵（含行政程序时限触发升级表）与监管动态简报风格；读取前三步产出：主管机关与规则源清单、已分类的动态条目、每条新规的影响等级、差距项与整改建议。
    2. 编制监管动态简报：按法律 > 行政法规 > 部门规章 > 规范性文件与裁量基准 > 征求意见稿分表列示本期动态（规则名称、效力层级或发布机关、发布/修订日期、生效日期、状态、一句话影响）；影响等级从影响评估结果映射为关键 / 高 / 中等 / 低。
    3. 写重点提示（按影响等级排列，重大新规写明生效日期与「距生效还有 X 天」），再列待办清单（待办事项、关联规则、责任部门、完成时限、优先级）。
    4. 建立合规义务台账：每行一项义务，按 OBL-[YYYY]-[序号] 编号，填 11 列——义务编号、义务项、规则源描述、来源标签、验证状态、主管机关、生效或截止时限、责任部门、合规状态、预警等级、备注；责任部门由用户确认。
    5. 规则源一律用描述方式（如「XX法规定：XX活动须取得许可」），不写文号、条号、罚款数额；每行必附来源标签与验证状态：行政处罚法 2021 中度把握锚点标「已核实锚点（中度把握），建议复核」，其他一律 [待验证]。
    6. 涉及追责时效的条目参考行政处罚法第36条；违法行为首发日期距今接近时效时在备注写「追责时效参考：行政处罚法第36条，[日期] 届满 [建议复核]」。
    7. 以今日日期计算各时限剩余天数，按预警分类表定红 / 橙 / 黄 / 绿；行政程序时限（陈述申辩、听证、复议、起诉）适用更严格的红色阈值，以当事人实际收到文书日期为起算点。
    8. 按服务立场调整简报、台账、预警的输出范围（见规则），输出预警提醒清单（红、橙、黄分表，含义务编号、义务项、时限类型、截止日期、剩余天数、处置建议），红色条目必附具体处置建议。
    9. 按模板组装成果并给出下一步建议：红色预警立即处理；如需应对处罚、建设合规制度、起草监管报告、更新配置，分别转处罚应对、合规体系建设、监管报告起草流程或重新运行冷启动访谈。

    内置规则

    • 预警分级：红色——整改截止日剩余≤15天、重大新规生效剩余≤30天、许可届满剩余≤30天、行政程序时限临近，须立即行动或升级律师，不得静默放任；橙色——整改截止16–45天、新规生效31–60天、许可届满31–60天，须在本月内启动；黄色——整改截止46–90天、新规生效61–120天、许可届满61–120天，纳入近期工作计划；绿色——剩余>120天，常规监控、按季度更新台账。
    • 行政程序时限红色阈值：陈述申辩期、行政复议申请期、行政诉讼起诉期剩余≤规定期限的一半即标红（具体天数 [待验证]）；听证申请期任何剩余天数都标红（逾期丧失听证权）；不得自行推算裸数字。

    • 中央与地方版本分别录入，地方版本标 [地方 flagged — 需核实地方版本]；地方版本更严格时预警等级取高；对同一义务要求冲突时建议从严合规（取更严格版本），并注明以当地现行版本为准。

  • 整改优先级为 P0（立即处理，不整改将面临现实处罚风险）时，须律师确认整改方案
  • 即时施行且对企业有重大影响的规则：高亮「即时施行，合规调整窗口极短」
  • 新规适用范围表述宽泛无法判断时：建议向主管监管机关确认或咨询执业律师
  • 需求涉及逃避监管、规避检查、虚假报送、伪造证据、阻碍执法、隐匿违法事实：拒绝并标 [合规边界 — 拒绝]
  • 配置缺失或画像不全：提示运行冷启动访谈；前序产出不完整时在简报与台账中标注缺失项（如「规则源识别未完成，以下条目主管机关待确认」），不静默填补
