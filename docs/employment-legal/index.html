02概要

面向处理劳动人事事务的律师、HR 法务与企业法务。七条流程覆盖从入职到争议、从单份合同到整家公司调查：雇佣审查、解雇审查、竞业限制审查、假期管理、劳动争议处理、劳动用工合规调查，以及把执业立场写入实践配置的冷启动访谈。所有流程读取 employment-legal/CLAUDE.md 中的服务对象立场、风险等级口径、升级矩阵与文书风格，并依赖 skills/_shared 下的劳动法引用库、引用规范、派遣/外包定性对照表、北京地方年度标准与配置契约。

会怎样改变输出

  • 「谁在使用 → 角色」决定工作产物标题：律师角色标「律师工作产物 — 受律师-当事人特权保护 / 保密」；非律师角色标「研究笔记 — 非法律建议，供律师审查」，并在签署文件、发出解除通知等有法律后果的步骤前暂停；无律师可咨询的非律师再加「建议在重大决定前咨询执业律师」。
  • 「谁在使用 → 服务对象」决定加载用人单位方（合规与风险预防）还是劳动者方（权益主张）视角；填「双方（依事项）」时每次运行先问本次代表哪一方。
  • 「我们是谁 → 主要工作地点」与「共享护栏 → 地方性规定识别」驱动社保基数、最低工资、竞业补偿指引、产假奖励假、陪产假、婚丧假、高温津贴等地方差异的 [管辖 flagged — 需验证地方性规定] 标记。
  • 「审查立场」中的试用期、工时制、社保、竞业（人员范围 / 补偿标准 / 期限 / 范围）与解雇（第39、40、41条内部认定标准、经济补偿 N / N+1 / 2N 倾向）直接成为雇佣审查、解雇审查、竞业审查的定制口径。
  • 「风险校准」四级（[红] 关键 / [橙] 高 / [黄] 中等 / [绿] 低）与「升级矩阵」决定风险标注口径与升级路由；「文书风格」与「输出 → 下一步决策树模板」决定文书语气与备忘录结尾的五个选项。
  • 配置缺失或含 [PLACEHOLDER] 时各流程按「临时模式」默认值运行并在输出标 [临时模式 — 配置你的档案以获得定制输出]；用工合规调查在此情形默认风险偏好平衡型、被调查公司合规视角、工作地点按资料确认。

05不做什么

  • 不提供法律意见或法律结论
  • 不替代执业律师的判断
  • 不自动发送解雇通知
  • 不保证劳动仲裁结果
