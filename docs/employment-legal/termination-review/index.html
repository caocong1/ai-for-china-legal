01概要

替用人单位或劳动者一方审查拟议或已实施的解除方案：先核查有无禁止解除的情形，再分四步回答能不能解、给多少、怎么解才合规、解错了怎么救济和预防，产出事由合法性结论、N、N+1 或 2N 的金额、程序合规清单、救济方案或风险预防清单，最后给出整体风险等级和下一步建议。过失性辞退的内部认定标准、经济补偿按 N 还是 N+1 等口径取自实践配置「审查立场 → 解雇审查」，未配置时按临时模式（立场平衡、按法定 N 计算）。第47条、第87条已核实，其余条号标 [待验证]。四个步骤都可以单独使用。

02适用与边界

适用场景

  • 用人单位拟解除某位劳动者，需要判断事由能否成立、程序怎么走、要付多少钱
  • 解除通知已经发出，需要评估违法解除风险和补救空间
  • 代理劳动者主张违法解除赔偿金或恢复劳动关系
  • 核算经济补偿 N、代通知金、违法解除赔偿金 2N，包括高收入封顶
  • 审查经济性裁员方案的人数门槛、法定情形，以及工会和劳动行政部门程序

不做什么

  • 医疗期分档、产假天数等假期制度本身的合规审查：交给假期管理流程；本流程只核查这些状态是否构成禁止解除
  • 竞业限制、服务期违约金等离职后义务：交给竞业限制审查等流程
  • 劳动仲裁与诉讼程序的推进：交给劳动争议处理流程；本流程只提示1年仲裁时效
  • 不凭记忆写条号、文号或施行日期；流程里的案例都是待填入的空表，不得直接引用
  • 存在禁止解除情形时，不继续推进解除方案

03输入与产出

需要提供

  • 解雇原因、解除类型（协商、过失、非过失、经济性裁员）和解除事由的事实必需
  • 劳动者的保护状态：是否在医疗期、孕期产期哺乳期，是否因工伤或职业病丧失劳动能力，是否接触职业病危害作业未做离岗前检查或在诊断、观察期，是否连续工作满15年且距退休不足5年必需
    禁止解除情形前置核查的必须项；无法获取时标高级，建议暂缓解除
  • 工龄（入职日期、解除日期）和解除前12个月的应得工资必需
    计算金额的必须项；缺失时只能估算，并声明仅供参考
  • 工作地点必需
    决定适用的地方规定，以及当地上年度职工月平均工资三倍的封顶线
  • 已完成的程序：书面通知及送达证据、工会通知、向劳动行政部门的报告、解除证明、档案和社保转移可选
  • 规章制度文本及其民主程序、公示证据；绩效考核、培训、调岗、协商变更的记录可选
  • 立场（用人单位方或劳动者方），以及劳动者是否要求恢复劳动关系可选
    从实践配置「谁在使用」读取；不明确的，分步分析前先确认
  • 本领域的实践配置可选
    未填写时提示做冷启动访谈（约2分钟），或按临时模式办理

产出

  • 解雇审查报告读者：律师内部
    六部分：禁止解除情形核查（前置）、事由合法性结论、补偿或赔偿金计算、程序合规清单、救济方案或风险预防清单、整体风险等级与下一步建议；标题按「输出」取「律师工作产物」或「研究笔记」
  • 脱敏版本读者：客户（HR、业务方）
    给 HR、业务方的沟通稿，不含风险的详细分析
  • 解雇通知书面稿读者：对方 / 仲裁机构
    用人单位方标「合规文书」，劳动者方标「维权证据」；用于仲裁或诉讼的，保留完整的特权标注
  • 四份分步报告读者：律师内部
    解除事由合法性审查报告、经济补偿与赔偿金计算报告、解除程序合规审查报告、违法解除救济分析报告；单独做某一步时各自独立出具

04开始前

前置条件

  • 读取实践配置「审查立场 → 解雇审查」：过失性辞退（第39条）的内部认定标准、非过失性辞退（第40条）提前30天通知还是额外支付一个月工资的倾向、经济性裁员（第41条）方案的审批流程、经济补偿按 N 还是 N+1 以及是否倾向高于法定标准。
  • 读取「谁在使用」确定立场：用人单位方侧重合规路径选择、风险预防、解除证据固化、程序规范；劳动者方侧重权益保障、赔偿金额最大化、违法解除举证；立场不明的，分步分析前先确认。
  • 未配置或有未填写的配置项时，请律师二选一：做冷启动访谈（约2分钟），或按临时模式办理——立场平衡（用人单位合规与劳动者权益并重），经济补偿按第47条法定标准 N 计算、不高不低，地方规定按工作地点识别、缺失的标「地方规定需核实」，每个分析块末尾注明临时模式并提示做冷启动访谈。
  • 进入任何分步分析之前，先完成禁止解除情形的前置核查；并按开工前确认的规则先读材料、列出会改变成果的问题。各步对照本领域的引用规范和劳动人事高频引用库中解除事由、经济补偿情形、第47条、第87条、三期保护几部分核对条文。

硬性规则

禁止解除前置核查
五项优先核查：医疗期内；孕期、产期、哺乳期；工伤或职业病致丧失或部分丧失劳动能力；接触职业病危害作业未做离岗前检查或在诊断观察期；连续工作满15年且距退休不足5年 [待验证]。任一为「是」即标关键级、停止审查，不推进解除方案
过失性辞退不受限
禁止解除情形只限制非过失性辞退和经济性裁员，不影响劳动者确有过错时的过失性辞退；详细分析在第 1 步
地方规定识别
北京：社保基数、竞业限制补偿指引、特殊解除情形的地方实践；上海：最低工资、综合计算工时制审批、经济补偿基数认定；广东、深圳：经济特区劳动条例差异、高温津贴。涉及特别管辖的标「地方规定需核实」
发送对象与特权
解雇方案审查通常含特权内容：给 HR、业务方的用脱敏版本（不含风险详细分析）；用于仲裁、诉讼的保留完整特权标注；解雇通知书面稿用人单位方标「合规文书」、劳动者方标「维权证据」
开工前确认
格式、保存位置和立场已明确的不重复问；有不覆盖原件的安全默认值就按默认办；只有必须确认的事项未解决，或保存位置不明、可能覆盖原件、涉及对外发送时，才发出待确认问题清单并暂停；未经明确要求不覆盖原件
先检索后结论
下结论前先检索核对现行有效的法律法规、司法解释和指导性案例（注意修订、废止）；无法核实的注明「未经检索核实，请以现行有效文本为准」；不凭记忆写条号、文号、施行日期
引用纪律
第36、39、40、41、42、46条对应的内容已相当确定，但使用时仍标 [待验证]，引用前在国家法律法规数据库核验；第47条、第87条和《劳动争议调解仲裁法》第27条已核实（成果中标「已核实锚点」），仍建议复核

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置判断，可逐条复制。

  1. 解除事由合法性（能不能解）

    可单独使用

    判断拟议解除属于哪一类、构成要件和前置程序是否满足、是否触发禁止解除情形，得出「能不能解」的结论和风险等级。

    请律师核对

    • 核对 1.1「末位淘汰不等于不能胜任工作，绝不可直接据此辞退」的绝对表述是否认同？
    • 核对 1.2「客观情况重大变化」只认外部重大变化，内部重组是否构成标为有争议 [待验证]——贵所立场？
    • 核对 1.3「连续工作满15年且距退休不足5年」这项禁止情形标 [待验证]。
    • 核对 1.4保护期内用过失性辞退可能被「穿透审查」的提示标 [待验证]。
    • 核对 1.5「拘留、羁押不等于被追究刑事责任，须等起诉或生效判决」的时点认定是否符合贵所意见？

    做法

    1. 先做禁止解除情形的前置核查（六项，第42条 [待验证]）：接触职业病危害作业未做离岗前职业健康检查，或疑似职业病病人在诊断、医学观察期间；在本单位患职业病或因工负伤并被确认丧失或部分丧失劳动能力；患病或非因工负伤，在规定的医疗期内；孕期、产期、哺乳期；在本单位连续工作满十五年且距法定退休年龄不足五年 [待验证]；法律、行政法规规定的其他情形。任一触发即标关键级，在本步停止，不再推进解除方案。
    2. 识别解除类型：协商解除（第36条 [待验证]）、过失性辞退（第39条 [待验证]）、非过失性辞退（第40条 [待验证]）、经济性裁员（第41条 [待验证]），各自的补偿后果见内置规则。
    3. 协商解除核四项：由哪方提出；一致的证据是书面协议还是只有口头；协议是否写明补偿金额；劳动者签字时有无「被迫」迹象（有则关键级）。建议协议写明解除日期、补偿金额、社保转移、工资结清；签署后劳动者原则上不能反悔。
    4. 过失性辞退逐项核六类情形的审查要点，并核规章制度的缺陷：未经民主程序或未公示告知的，不得作为解除依据（关键）；「严重」的标准缺失或模糊（高）；末位淘汰不等于「不能胜任工作」，绝不可直接据此辞退（关键）。
    5. 非过失性辞退核三类情形的前置程序，经济性裁员核数量门槛、法定情形和五步程序（均见内置规则）。
    6. 从解除类型归属、法定构成要件、前置程序（非过失性辞退和裁员）、禁止解除情形是否排除、规章制度依据（过失性辞退）五方面综合定级，出具解除事由合法性审查报告。

    内置规则

    • 四类解除与补偿：协商解除（单位提出的须付补偿，劳动者提出的不付）；过失性辞退（不付）；非过失性辞退（付 N）；经济性裁员（付 N）。禁止解除情形只限制非过失性辞退和经济性裁员，过失性辞退不受限。临时模式默认：过失性辞退须有经民主程序制定并公示的规章制度依据；末位淘汰不等于不能胜任，须经培训或调岗验证；经济性裁员须满足20人或10%门槛。
    • 过失性辞退六类情形及审查要点：试用期不符合录用条件（录用条件是否事先书面告知）；严重违反规章制度（制度是否经民主程序并公示，「严重」的标准是否明确）；严重失职、营私舞弊造成重大损害（损害认定有无量化依据）；同时与其他单位建立劳动关系（是否已书面提出而劳动者拒不改正）；以欺诈、胁迫等方式订立致合同无效（是否经仲裁或司法确认）；被依法追究刑事责任（须有生效刑事判决或检察院起诉，拘留、羁押不算）。
    • 非过失性辞退三类情形都须先履行前置程序，否则解除无效：医疗期满不能从事原工作、也不能从事另行安排的工作——须先另行安排工作；不能胜任工作——须先培训或调岗，不能只凭绩效末位；客观情况发生重大变化——须先协商变更，且须是政策法规、市场环境等外部重大变化，内部重组是否构成有争议 [待验证]。还须提前30天书面通知或支付一个月工资的代通知金，并付 N。
    • 经济性裁员：数量门槛为裁减20人以上，或不足20人但占企业职工总数10%以上（满足其一）；法定情形四类：破产重整，生产经营严重困难（认定标准有争议 [待验证]），转产、技术革新、经营方式调整（须有客观背景），其他客观经济情况重大变化（须有实质支撑）；程序五步依次履行：提前30天向工会或全体职工说明情况，听取意见并留记录，向劳动行政部门报告裁减方案，优先留用订立较长期限固定期限合同、无固定期限合同、家庭无其他就业人员且有需赡养的老人或未成年人的人员 [待验证]，6个月内重新招用的优先通知被裁减人员 [待验证]。
    • 边界情形：处于保护期又拟用过失性辞退的，须有真实过失证据，否则仲裁委或法院可能穿透审查、认定违法解除 [待验证]（关键）；「劳动者事实上知晓」不能替代正式公示（高）；末位淘汰须先转化为真实的「不能胜任」认定标准，并经培训调岗验证，才可适用非过失性辞退（关键）；协商解除后劳动者反悔，能证明欺诈、胁迫、重大误解的，协议可能被撤销，建议留下劳动者有充分考虑时间的记录。
    • 常见问题：无法提供规章制度民主程序的证明（关键，建议暂缓解除、先补程序）；「不能胜任」没有培训调岗记录（关键，解除方案无效）；裁员未达20人或10%门槛（高，改用其他合法方式或等条件满足）；以试用期不合格解除已过试用期的员工（关键）；无法获取孕期、医疗期信息（高，确认前暂缓解除）；劳动者被刑拘但未被起诉（中等，等待起诉或生效判决）。

    法律依据

    • 《劳动合同法》（2012年修正）第36条 [待验证] — 协商一致解除
    • 《劳动合同法》（2012年修正）第39条 [待验证] — 过失性辞退六类情形，不须提前通知、无需经济补偿
    • 《劳动合同法》（2012年修正）第40条 [待验证] — 非过失性辞退三类情形，提前30天通知或代通知金加经济补偿 N
    • 《劳动合同法》（2012年修正）第41条 [待验证] — 经济性裁员四类情形、20人或10%门槛、法定程序、优先留用
    • 《劳动合同法》（2012年修正）第42条 [待验证] — 六类禁止解除情形
    • 《劳动合同法》（2012年修正）第46条 [待验证] — 须支付经济补偿的情形
    • 《女职工劳动保护特别规定》（2012年）三期保护 [条号待验证]，并标「地方规定需核实」 — 三期不得以非过失性辞退或经济性裁员解除

    产出

    解除事由合法性审查报告：禁止解除情形核查表（模板只列医疗期、三期、工伤职业病丧失劳动能力、满15年且近退休四项）及结论、构成要件核查表、整体合法性结论与主要风险点、建议、法律依据

  2. 经济补偿与赔偿金计算（给多少）

    可单独使用

    区分 N、N+1、2N 三条路径，认定月工资基数和工龄年限（含高收入封顶），算出应付金额；不评估是否合法，只按合法、违法两条路径分别计算。

    请律师核对

    • 核对 2.1年终奖「按月均摊入12个月」、住房补贴计入、股权期权不计入三项都标 [待验证]，请确认贵所口径。
    • 核对 2.22008年1月1日前后的工龄是否分段计算，流程只提示各地不一 [待验证]。
    • 核对 2.3代通知金按劳动者实际月工资计算、不受三倍封顶——是否认同？
    • 核对 2.42N 的基数与封顶规则与 N 完全相同——是否符合贵所常用地区的仲裁实践？
    • 核对 2.5汇总表对未休年休假工资300%只标 [待验证]，而假期管理流程的年休假一步标的是「规则已核实、条号待验证」，两处标注不一致。

    做法

    1. 确定路径：N 适用于合法解除且须付补偿的情形（单位提出的协商解除、非过失性辞退、裁员、劳动合同期满终止（单位维持或提高条件而劳动者不续签的除外）等，第46条 [待验证]）；N+1 适用于非过失性辞退未提前30天书面通知；2N 适用于违法解除或违法终止（第87条，已核实），与 N 不并用；过失性辞退、劳动者无故辞职为零，但劳动者因单位过错依第38条解除的须付 N [待验证]。
    2. 认定月工资基数（第47条，已核实）：解除或终止前12个月的平均应得工资，含基本工资、绩效奖金、津贴、补贴等实际发放的各项工资性收入，按税前计；低于当地最低工资的按最低工资计；高于当地上年度职工月平均工资三倍的，基数按三倍封顶、年限最多12年。争议项目逐项判断是否计入。
    3. 换算工龄年限（第47条，已核实）：自入职本单位之日起算至解除或终止之日，固定期限续签的连续累计；2008年1月1日前后的工龄是否分段计算各地不一 [待验证]，提示核查当地最新仲裁口径。
    4. 按计算表三步算 N：确认基数（12个月应得总额÷12，与当地三倍比较，超过的封顶）；确认年限（整年数加余月处理，封顶时不超过12年）；N = 封顶后基数 × 封顶后年限。
    5. 算代通知金和 2N：代通知金是一个月工资，按劳动者本人月工资计、不按三倍封顶基数，N+1 = N + 一个月工资；2N = N×2（第87条，已核实），基数和封顶规则同 N。说明劳动者的选择：要求继续履行且合同能够履行的，恢复劳动关系并付解除至恢复期间的工资，不付 2N；不要求或不能履行的，付 2N，不另付 N。
    6. 汇总应付款项：经济补偿 N、代通知金、违法解除赔偿金 2N、未休年休假工资（300%，含正常工资100%和另付200% [待验证]）、未付工资与绩效，算出合计，出具经济补偿与赔偿金计算报告。

    内置规则

    • N 出自第47条（已核实）；「+1」是替代提前30天通知的对价，属工资性质、不是经济补偿，不计入 N 的基数；2N 出自第87条（已核实），与 N 不并用。
    • 临时模式默认：按法定 N 计算，不高不低；非过失性辞退未提前30天通知的，另付一个月代通知金（N+1）；违法解除按第87条付 2N，不与 N 并用。
    • 月工资基数四要素：解除前12个月平均；应得工资，含各项工资性收入；按税前计；低于最低工资的按最低工资计。高收入双封顶：基数封顶为当地上年度职工月平均工资三倍，年限最多12年；示例：当地平均8000元，三倍24000元，月薪30000元、工龄15年，经济补偿 = 24000×12 = 288000元。争议项目：年终奖按月均摊入12个月 [待验证]（各地仲裁口径不一）；股权、期权收益通常不计入 [待验证]（核查合同约定）；报销款、差旅补贴不计入；住房补贴计入 [待验证]。
    • 工龄三段：满1年计1个月工资；6个月以上不满1年按1年计；不满6个月计半个月工资。
    • 边界情形：高收入员工双封顶后写明封顶结果；工龄跨2008年1月1日的分段争议 [待验证] 在报告中注明；已提前30天通知的只付 N；未提前通知的付 N+1，「+1」按月工资计、不封顶；违法解除时劳动者要求恢复的，付中间期工资、不付 2N，不恢复的付 2N，两者不并用；合同约定的补偿高于法定标准的按约定，提示「高于法定的约定有效」；配置有 N+2 等高于法定的倾向的，按配置列出并对照法定标准，注明「超法定标准」。
    • 常见问题：没有12个月工资记录的，估算并声明「结论仅供参考，建议补充工资记录后重新计算」；绩效奖金是否计入有争议的，列含与不含两套方案并说明各自的适用情形；违法解除而劳动者未表态的，给出恢复劳动关系加中间期工资、2N 两套金额供选择；入职日期不明的，建议用劳动合同、社保记录核实，并提示「工龄确认影响补偿金额，须在最终支付前核实」。

    法律依据

    • 《劳动合同法》（2012年修正）第47条 — 经济补偿 N：每满一年一个月工资，6个月以上不满一年按一年，不满6个月半个月；月工资超当地上年度职工月平均工资三倍的按三倍计，且年限不超过12年（已核实，建议复核）
    • 《劳动合同法》（2012年修正）第87条 — 违法解除或终止按第47条标准二倍支付赔偿金 2N，与 N 不并用（已核实，建议复核）
    • 《劳动合同法》（2012年修正）第46条 [待验证] — 须支付经济补偿的情形
    • 《劳动合同法》（2012年修正）第39条 [待验证] — 过失性辞退无需经济补偿
    • 《劳动合同法》（2012年修正）第40条 [待验证] — 非过失性辞退须付 N，未提前通知须付代通知金
    • 《劳动合同法》（2012年修正）第38条 [待验证] — 劳动者因用人单位过错解除的须付 N

    产出

    经济补偿与赔偿金计算报告：N、代通知金、2N 是否适用及依据，月工资基数与工龄年限（是否封顶），计算结果与应付合计，风险提示（年终奖是否计入、历史工龄口径等）

  3. 解除程序合规（怎么解才合规）

    可单独使用

    按解除类型核查五项法定程序和送达留痕，找出程序瑕疵并给出补救建议；不评估事由是否合法。

    请律师核对

    • 核对 3.1解除后补通知工会能否「诉讼前补正」，流程标各地不一 [待验证]，立场是不依赖补正。
    • 核对 3.2协商解除「建议通知工会」标 [待验证]，是否纳入贵所流程？
    • 核对 3.3电子送达的效力条件（合同约定或劳动者已读回复）是否符合贵所经验？
    • 核对 3.4解除证明中「解除原因在劳动者要求时提供」标 [待验证]。
    • 核对 3.5临时模式写「15日内办理档案和社保转移」，正文又把社保写为「解除后当月或次月中断」，两处时限表述不一致。

    做法

    1. 对照解除类型确认适用哪些程序：协商解除不要求提前通知和报告，建议通知工会 [待验证]；过失性辞退不需提前通知，但须事先通知工会；非过失性辞退须提前30天书面通知或付代通知金，并事先通知工会；经济性裁员须提前30天向工会或全体职工说明、听取意见，并向劳动行政部门报告；四类都须出具解除证明、办理档案和社保转移。
    2. 非过失性辞退专项：是否提前30天书面通知并留存送达证明（否则付代通知金）；通知是否写明解除事由（否则高）；通知期内劳动者是否照常工作、领取工资（否则高）；未提前通知的，代通知金是否已付（未付为关键）；并核对送达方式与举证。
    3. 工会程序专项：企业是否有工会（没有的豁免，但须记录在案）；是否在解除前通知（未通知为关键）；是否说明理由（否则高）；工会有无异议，异议是否经考虑后再作决定 [待验证]（未处理为高）。经济性裁员须提前30天向工会或全体职工「说明」而不只是通知（第41条 [待验证]），听取意见须有书面记录且意见被实质考虑，意见程序结束后才可正式裁员。
    4. 向劳动行政部门报告（仅裁员）：是否已报告（未报为关键）；是否在正式裁员前完成（否则关键）；材料是否齐全——裁员原因说明、裁员名单、经济补偿方案（不齐为高）。
    5. 解除证明与档案社保：核对解除证明的法定内容是否齐全、是否注明协商解除或非过失性辞退等具体方式，未及时出具致劳动者损害的须赔偿 [待验证]，可能使其无法入职新单位（高）；档案转移手续在解除后15日内办理（超期为高）；社保关系在解除后当月或次月中断，及时在系统中操作（超期为高）；住房公积金按管理中心规定封存或转移 [待验证]；解除证明归入劳动者档案（未归档为高）。
    6. 填写检查清单，出具解除程序合规审查报告：程序合规汇总表、程序瑕疵分析、送达核查表、按优先级排列的建议措施。

    内置规则

    • 五项程序的适用：提前30天通知或代通知金只适用于非过失性辞退；事先通知工会适用于过失性、非过失性辞退，裁员改为向工会或全体职工说明并听取意见；向劳动行政部门报告只适用于裁员；解除证明、档案社保转移四类都必须。
    • 临时模式默认：非过失性辞退须提前30天书面通知，否则付代通知金；所有解除类型都出具书面解除证明；都在解除后15日内办理档案和社保转移。
    • 送达方式（按优先顺序）：当面送达（劳动者签字并注明日期，首选）；EMS（回执加签收记录，记录发件地址）；电子邮件、企业微信、钉钉（发送记录加已读回执或回复，须有对方读取的证明）；留置送达（劳动者拒签时有见证人在场并拍照或录像，最后手段）；公告送达（无法送达时按合同约定方式或在企业公告栏公示，效力最弱、争议多 [待验证]）。劳动者拒签不影响通知效力，改用留置送达或 EMS 并保留回执。
    • 工会通知必须在解除前完成，没有工会的须确认事实并记录。解除证明四项必备内容：劳动合同期限、解除或终止日期、工作岗位、本单位工作年限；解除原因在劳动者要求时提供 [待验证]。
    • 边界情形：工会通知瑕疵的补正效力各地不一 [待验证]（关键）；电子送达在合同约定电子方式或劳动者实际已读回复时一般认可，没有约定且劳动者不认可的风险高 [待验证]；未出具证明致劳动者无法入职的，按实际损失赔偿 [待验证]；因劳动者原因档案转移受阻的，留存单位已主动联系的证据，并请行政部门协助；裁员后6个月内重新招用的须优先通知被裁减人员 [待验证]（高）。
    • 常见错误：通知已发出但未送达的，送达确认前解除效力存疑（关键）；工会通知事后补做争议大 [待验证]，咨询当地劳动行政部门，不把补正当常规操作（关键）；裁员未向劳动行政部门报告属程序违法（关键），行政部门能否撤销解除各地不一 [待验证]；解除证明缺项的补齐，并就已造成的损失与劳动者协商；超过15日未办档案社保转移的承担迟延赔偿，立即办理并书面告知进度、留存记录。

    法律依据

    • 《劳动合同法》（2012年修正）第40条 [待验证] — 非过失性辞退提前30天书面通知或额外支付一个月工资
    • 《劳动合同法》（2012年修正）工会通知 [条号待验证] — 单方解除须事先通知工会，工会认为不合法有权提出意见
    • 《劳动合同法》（2012年修正）第41条 [待验证] — 裁员程序：提前30天说明、听取意见、向劳动行政部门报告
    • 《劳动合同法》（2012年修正）出具解除证明义务 [条号待验证] — 出具书面证明，15日内办理档案和社保转移

    产出

    解除程序合规审查报告：程序合规汇总表（五项程序各自是否适用、是否完成、问题、风险等级）、程序瑕疵及法律后果、送达核查表、按关键和高排序的建议措施

  4. 违法解除救济与风险预防（解错了怎么办）

    可单独使用

    解除被认定或可能被认定违法时，分析劳动者在恢复劳动关系与 2N 之间的选择和可行性、单位的举证责任，并给单位一份事前风险预防清单。

    请律师核对

    • 核对 4.1「用人单位对解除合法性承担举证责任」标 [待验证]，请确认条文依据。
    • 核对 4.2恢复劳动关系时「通常须补缴中间期社保」标 [待验证]。
    • 核对 4.3「已付 N 一般可抵扣 2N」标 [待验证]。
    • 核对 4.4纯程序违法但事由合法的后果，流程只列两种口径，没有取立场。
    • 核对 4.5代理劳动者时「建议优先考虑 2N 路径以便执行」，是否符合贵所策略？

    做法

    1. 确认立场重点：用人单位方先看能否重新合规（撤销解除、补程序），不能则如何把损失降到最低（接受 2N、谈判和解）；劳动者方看恢复劳动关系和 2N 哪个更有利。再确认违法来源：事由不符合法定情形（第 1 步的结论）；程序瑕疵，如未通知工会、未提前通知（第 3 步的结论）；解除对象处于医疗期、三期、工伤等禁止解除情形；虚构解除理由。
    2. 分析路径 A 恢复劳动关系：劳动者明确要求继续履行，且合同能够继续履行（单位存续、未注销未破产，岗位未撤销或可恢复，没有双方矛盾不可调和等客观障碍 [待验证]）；后果是按原合同继续、支付解除至恢复期间的工资（不低于原标准）、不付 2N，通常须补缴中间期社保 [待验证]；并列出不支持恢复的情形。
    3. 分析路径 B 2N（第87条，已核实）：劳动者不要求恢复或客观上不能继续履行的，先按第47条算 N（含封顶），2N = N×2，不另付 N；2N 是法定最低赔偿，单位不得低于此数，双方可协商高于 2N。
    4. 从五方面对比两条路径：适用前提、经济上的结果（中间期工资对比 2N）、社保、劳动者利益（长工龄、临近退休、关系重要的宜恢复；关系破裂、已找到工作的宜 2N）、执行难度（单位不配合时恢复难执行，2N 是金钱给付、执行简单）。
    5. 分析举证责任：单位对解除合法性承担举证责任 [待验证]，须证明五项——解除事由合法（具体事实证据）、程序合规、劳动者签收了解除通知、规章制度经民主程序并告知、劳动者的过错事实（不是结论性评价）；并列明举证不能的后果。
    6. 为用人单位方列出事前风险预防清单（五组），出具违法解除救济分析报告；同时提示劳动争议仲裁时效1年（《劳动争议调解仲裁法》第27条，已核实），自知道或应当知道权利受侵害之日起算，迟延可能丧失仲裁权利。

    内置规则

    • 恢复劳动关系与 2N 只能选一，不可兼得；劳动者同时主张两项的，须在程序中明确选择。2N 是赔偿金，与合法解除的经济补偿 N 性质不同，不可叠加；2N 是法定最低赔偿，高于 2N 的和解是合法约定。
    • 临时模式默认：违法解除时劳动者可选恢复劳动关系或 2N，二者择一；单位对解除合法性承担举证责任；预防抓四件事——事由证据固化、规章制度合规、通知送达留痕、工会程序。
    • 不支持恢复的情形：解除时合同已到期的，一般转 2N [待验证]；单位已注销的，向清算组或股东主张 2N；岗位已不存在的，由法院或仲裁委裁量 [待验证]；仲裁或诉讼期间合同期满的，转 2N [待验证]。举证不能的后果：事由不能证明，解除违法，须付 2N 或恢复劳动关系；公示不能证明，不得以违反规章制度为由解除；工会通知不能证明，程序违法，可能导致解除无效（各地不一 [待验证]）；送达不能证明，解除通知可能未生效。
    • 事前风险预防清单五组：事由证据固化（违纪书面记录及当事人签字、绩效考核标准和结果及劳动者知晓、培训或调岗的完整记录、客观变化的外部证据、欺诈违规的具体时间地点方式金额）；规章制度合规（民主程序、公示、「严重」标准按金额次数情节量化、末位淘汰与不能胜任认定脱钩、违纪定义清晰）；通知与送达留痕（当面签收或 EMS 回执、写明具体依据而非泛称「违纪」、提前30天通知或代通知金的支付记录、协商解除协议原件）；工会程序（解除前书面通知、留存工会意见、异议的书面处理说明）；全流程时间线（从发现事由到作出解除决定、各节点的书面日期记录、与劳动者协商、培训、调岗的沟通记录）。
    • 边界情形：恢复裁决单位拒不执行的，可强制执行或转 2N（各地实践 [待验证]），流程建议优先考虑 2N 路径以便执行；仲裁或诉讼期间合同届满的，恢复不再可行，转 2N [待验证]；劳动者要求高于 2N 的，按案件风险评估建议合理的协商区间；纯程序违法但事由合法的，后果各地口径不一——有的认为程序瑕疵即违法须付 2N，有的认为可酌情处理 [待验证]，标高级并在当地确认。
    • 常见问题：合法性争议大、无法判断的，出双路径分析（合法则付 N 的金额；违法则付 2N 的金额或恢复），最终由仲裁委或法院认定；单位已付 N 后被认定违法的，补差额（2N 减已付 N），已付 N 一般可抵扣 [待验证]；在禁止解除情形下强行解除的，违法性清楚，支持恢复或 2N 的概率极高，立即暂停方案、重新评估（关键）；劳动者未及时申请仲裁的，提示1年时效。

08交付前检查

  • 禁止解除情形的前置核查有明确结论后，才进入事由、金额、程序、救济的分析。
  • 事由：解除类型已明确；过失性辞退已确认规章制度经民主程序并公示；非过失性辞退已确认履行前置程序（另行安排工作、培训或调岗、协商变更）；裁员已确认20人或10%门槛、法定情形、向工会或职工说明、向劳动行政部门报告；末位淘汰情形已标关键级。
  • 金额：已按合法性判断选定 N、N+1 或 2N；基数（12个月平均、最低工资兜底、三倍封顶）和年限（满1年、6个月以上、不满6个月）计算准确；代通知金与 N 未混同；已确认 2N 与 N 不并用；已说明劳动者可选择恢复劳动关系。
  • 程序：已确认提前30天通知与代通知金二选一；工会通知在解除前完成，或已确认没有工会；送达证据已留存；解除证明法定内容齐全；15日内办理档案和社保转移；各程序的时间线清楚、可举证。
  • 救济：已评估恢复劳动关系的可行性，算出 2N，分析举证责任；用人单位方的风险预防清单（事由证据、规章制度、送达、工会、时间线）已逐项核查。
  • 引用按法条、案例、学说分类：第47条、第87条和《劳动争议调解仲裁法》第27条标「已核实锚点」，其余条号标 [待验证]；案例须检索核验后才能填入；整体结论按关键、高、中等、低分级；临时模式的分析块注明临时模式。

09何时暂停或升级

  • 任一禁止解除情形为「是」：标关键级、停止审查，不推进解除方案；无法获取劳动者孕期、医疗期等信息：标高级，确认没有这些情形前暂缓解除。
  • 规章制度民主程序没有证据，或「不能胜任」没有培训调岗记录：标关键级，建议暂缓解除、先补内部程序。
  • 工会通知事后补做、裁员未向劳动行政部门报告：标关键级，咨询当地劳动行政部门确认口径。
  • 内部重组是否构成「客观情况重大变化」：标 [待验证] 并升级处理。
  • 面向 HR、业务方沟通：改用脱敏版本，不含风险的详细分析。
  • 未配置且律师没有选择临时模式：提示做冷启动访谈；立场不明：先确认立场；必须确认的事项未解决、保存位置不明、可能覆盖原件或涉及对外发送：发出待确认问题清单并暂停。
