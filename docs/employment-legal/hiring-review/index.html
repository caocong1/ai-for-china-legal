01概要

审查劳动合同、录用通知书、培训协议等雇佣文件，找出违反《劳动合同法》强制性规定的条款，按关键/高/中等/低四级列出问题，并给出可直接替换的修改语言，最终产出一份雇佣审查备忘录。流程先读取 employment-legal/CLAUDE.md 实践配置（审查立场、工作地点、风险校准、工作产物标题），再按固定顺序走五个步骤：文件定位与必备条款、试用期与工时、社保公积金与劳动报酬、服务期与违约金、地方性规定核查与备忘录装配。每一步都对照 _shared/labor-law-citations.md 引用库中的条文（第17条、第14条、第19条、第82条、第22条、第25条等）核查，不确定的条号一律标 [待验证]。五个步骤均可单独运行，例如只核试用期，或只判断某条违约金是否合法。

02适用与边界

适用场景

  • 入职前审查用人单位拟签的劳动合同、录用通知书（offer letter）及其附件（保密协议、竞业限制协议、培训/服务期协议）
  • 审查员工手册、劳务协议、实习协议、退休返聘协议等非标准雇佣文件，需先定性是否构成劳动关系
  • 只需核查某一专项：试用期是否超上限、是否有二倍工资风险、违约金条款是否合法
  • 代表劳动者方审查用人单位提供的合同，寻找权益主张依据
  • 各专项步骤的发现已经在手，只需合并成一份分级备忘录或简版风险摘要

不做什么

  • 竞业限制条款的深度审查（人员范围、经济补偿、期限不超过2年、范围可执行性）：本流程只识别竞业违约金是否属于第25条允许的情形，深度审查须另行运行 /employment-legal:non-compete-review
  • 解雇方案与解除合法性审查（另有 /employment-legal:termination-review）
  • 劳动争议发生后的调解、仲裁、诉讼（另有 /employment-legal:labor-dispute-handling）
  • 不替代律师出具法律意见；所有条文引用须经国家法律法规数据库（flk.npc.gov.cn）核验
  • 不凭记忆断言法条编号、文号或生效日期；无法核实时在结论处标注「未经检索核实，请以现行有效文本为准」

03输入与产出

需要律师提供

  • 雇佣文件（路径或正文）：劳动合同 / 录用通知书 / 竞业限制协议 / 保密协议 / 员工手册 / 劳务协议 / 实习协议 / 培训协议必需
    须为可读取文本；非文本格式会提示先转为文字；纯英文合同会提示境内适用的劳动合同原则上须有中文版本 [待验证]
  • 审查立场（用人单位方 / 劳动者方）必需
    优先从 employment-legal/CLAUDE.md「谁在使用」读取；不明确时流程直接询问，确认一次后传给全部步骤
  • 劳动者工作地点（城市/地区）必需
    影响社保基数、最低工资、竞业补偿指引等地方性规定；配置文件未填时会询问
  • 实践配置文件 employment-legal/CLAUDE.md可选
    缺失或仍含 [PLACEHOLDER] 时可选「临时模式」，用通用默认值运行并在每步输出上标记
  • 合同期限、用工开始日期、书面合同签署日期可选
    分别用于计算试用期上限和二倍工资风险期间；缺失时对应项标中等风险并提示补充
  • 培训费用金额及凭证、服务期约定可选
    用于计算服务期违约金上限；无法核实金额时标高风险
  • 综合计算工时制 / 不定时工时制的劳动行政部门审批文件可选
    合同声称适用非标准工时制时须提供；无审批按标准工时制处理并标高风险
  • 各专项步骤已有的发现摘要可选
    仅单独运行装配步骤时需要；未提供则由装配步骤自行做综合分析，但深度不及逐项运行

产出

  • 雇佣审查备忘录（默认）给律师内部；面向对方时须改用脱敏版
    工作产物标题 → 底线（两句话：这份文件能否签署、什么必须先改）+ 四级问题统计 → 文件定位摘要（六维度表）→ 必备条款检查摘要（第17条九项）→ 按关键/高/中等分级的问题（每项含来源步骤、风险描述、修改建议）→ 地方性规定检查 → 修改建议优先级清单（立即/强烈建议/建议，附协商空间）→ 竞业限制专项提示 → 下一步决策树（五项）
  • 风险摘要（可选）给律师内部 / 升级联系人
    仅列关键级与高风险问题的简版，用于快速升级
  • 各专项步骤的单项审查报告给律师内部
    每步有固定模板：标题块（审查日期、步骤名、审查立场、工作地点或合同期限）→ 该专项的检查表 → 问题数统计 → 具体缺陷（法律规定 / 文件写的是 / 风险 / 建议修改语言）→ 下一步建议

04开始前

前置条件

  • 阅读文件之前先读取 employment-legal/CLAUDE.md；缺失或含 [PLACEHOLDER] 时给出两个选择：运行 /employment-legal:cold-start-interview（约 5 分钟），或说「临时模式」
  • 临时模式默认值（来自 practice-profile-schema.md）：风险偏好平衡型；审查立场用人单位方（合规与风险预防视角）；管辖法律为中国大陆法律（劳动合同法2012修正）；地方性规定按工作地点逐案确认，须询问工作地点；经济补偿按法定 N 标准（《劳动合同法》第47条）；标题用通用「雇佣审查备忘录」；每步输出和最终备忘录都标 [临时模式] 并在末尾提示配置档案
  • 调用任何步骤前确认审查立场：先读配置「谁在使用」的服务对象，不明确则问「你代表的是用人单位方（雇主合规视角）还是劳动者方（员工权益主张视角）？」，确认后各步骤不再重复询问
  • 读取配置「我们是谁」的主要工作地点；不明确则询问劳动者工作地点（城市/地区），记录后传入装配步骤集中核查地方性规定
  • 生成输出前做目的地与特权检查：输出面向对方（如员工）或公开渠道时，提醒发送给对方会使律师-当事人特权保护失效，让用户选择（a）内部特权版本或（b）面向对方的脱敏版本；内部流通则使用配置文件中的工作产物标题
  • 统一读取三份共享资源：_shared/legal-basis-conventions.md（引用规范）、_shared/labor-law-citations.md（引用库）、_shared/practice-profile-schema.md（配置读取契约）
  • 遵循 shared/legal-document-intake/SKILL.md 做动态 intake：格式、保存位置、立场已明确时直接执行不重复询问；有不覆盖原件的安全默认值时采用默认并简短说明；仅在影响成果的必须项未解决、写入目标不明、可能覆盖原件或涉及外部发送时输出 [CLARIFY:] 并暂停

硬性规则

竞业限制条款识别
文件涉及竞业限制时，服务期与违约金步骤只判断该违约金是否属于合法的竞业限制情形；人员范围、经济补偿、期限不超过2年、范围可执行性的深度审查须在本次审查完成后运行 /employment-legal:non-compete-review，流程会主动提示
劳动关系定性优先
文件类型不明确（劳务协议、实习协议、合作协议等非标准劳动合同）时，先定性是否构成劳动关系，再决定适用劳动合同法的程度，然后才进入必备条款检查
地方性规定适用优先级
工作地点确认后由装配步骤集中核查地方性规定；社保基数、最低工资、竞业补偿指引等常见地方差异必须在装配前已确认工作地点
固定审查顺序
完整审查按文件定位 → 试用期/工时 → 社保/报酬 → 违约金 → 装配的顺序执行：先确定文件属性和适用范围，再查合同开始阶段的高频风险，再查强制性法定义务与二倍工资，再查常见无效条款，最后叠加地方性规定出备忘录
审查立场一次确认、全程继承
立场在入口确认后传入所有步骤；发现用人单位方文件明显倾向劳动者利益时不静默调整立场，而是提示「当前审查立场为[用人单位方]，已发现多项对用人单位不利条款，请确认立场」
永不覆盖原件
除用户明确指定覆盖外，永远不覆盖原件
先检索、后结论
给出任何法律结论、条款建议或风险判断前，优先用检索工具核对现行有效的法律法规、司法解释和指导性案例（注意修订、修正与废止）；无法核实时在结论处标注「未经检索核实，请以现行有效文本为准」；禁止凭记忆断言法条编号、发文文号或生效日期

05执行步骤

共 5 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置假设，可逐条复制。页面里的英文标记见首页「标记与术语」。

  1. 文件定位与必备条款检查

    /employment-legal:document-mandatory-terms可单独运行

    确定文件类型、用人单位性质、劳动者类型、工作地点、合同期限、是否涉及竞业这六项基本属性，逐项核查《劳动合同法》第17条九项必备条款，识别无固定期限劳动合同触发情形，为后续步骤建立标准化的「文件背景档案」

    请律师核对

    • 核对 1.1劳动关系认定三要素的表述及其出处（《关于确立劳动关系有关事项的通知》）均标 [待验证]，请核对条号与现行效力
    • 核对 1.2在校实习生、退休返聘、外籍人员三类的定性结论都带 [待验证]，是否符合贵所所在地的裁审口径
    • 核对 1.3「录用通知书与劳动合同不一致一般以劳动合同为准」这一默认立场是否接受
    • 核对 1.4常见缺陷的风险分级（单方调岗条款定高风险、工作内容宽泛定中等）是否合适

    做法

    1. 读取 employment-legal/CLAUDE.md，加载审查立场、工作地点、工作产物标题；读取引用规范、引用库（重点第17条、第14条）和配置读取契约
    2. 快速阅读文件，填写六问定位表：文件类型（劳动合同/录用通知书/竞业限制协议/保密协议/员工手册/劳务协议/实习协议/其他）、用人单位性质（企业/个体经济组织/民办非企业单位/国家机关/事业单位/社会团体）、劳动者类型（全日制/非全日制/劳务派遣/在校实习生/退休返聘/外籍人员/其他）、工作地点、合同期限（固定期限X年/无固定期限/以完成一定工作任务为期限）、是否涉及竞业限制（是则记录岗位与竞业范围）
    3. 按文件类型做定性判断：劳动合同直接进入必备条款检查，并一并审查附件（保密协议、竞业限制协议）；录用通知书本身不等于劳动合同，检查是否约定生效条件（如签字即视为同意劳动条件），以及薪酬、试用期、竞业等核心条款是否与后续劳动合同一致
    4. 非劳动合同文件（劳务协议/实习协议/合作协议等）先按劳动关系认定三要素定性：用人单位依法成立（用工主体资格）、劳动者受用人单位管理（人身从属性）、劳动者提供有报酬的劳动（经济从属性）；构成劳动关系才按劳动合同审查，否则转劳务合同审查路径
    5. 逐项核查第17条九项必备条款，每项列检查项、要求、文件现状、风险等级：一、用人单位名称（与营业执照一致）/住所/法定代表人或主要负责人；二、劳动者姓名/住址（用于送达）/身份证件号码；三、合同期限类型、起止日期、试用期约定；四、工作内容与工作地点、调岗调地条款；五、工时制度类型、每日每周工时、休息日；六、工资标准、支付周期、薪资构成；七、社保缴纳义务声明、是否有「放弃社保」条款；八、劳动保护声明、职业危害告知；九、行业特殊要求与地方性规定要求
    6. 对每项记录常见缺陷并给修改建议：仅写「甲方」未写完整名称；住所与实际用工地不一致（影响争议管辖）；住址未填影响解雇通知送达；「具体工作内容由用人单位安排」过于宽泛；「工作地点可由用人单位调整」单方调岗；劳动保护仅一句套话而高危行业须更详细
    7. 对照第14条识别无固定期限劳动合同触发情形：连续工作满十年；连续两次固定期限到期续签且劳动者提出；用工满一年未订书面合同（视为已订立无固定期限，与第82条二倍工资并行）；国企改制/初次实行合同制下连续工作满10年且距法定退休年龄不足10年；核对服务年限记录、是否第二次续签、是否有较长事实劳动关系期间
    8. 工作地点标注 [管辖 flagged — 需验证地方性规定]；把试用期/工时、社保/报酬、违约金、竞业、装配五个方向的触发范围交接给后续步骤
    9. 按输出模板生成单项报告：文件定位档案表、必备条款检查摘要（九项完整性、常见缺陷、风险等级）、无固定期限触发风险、具体缺失条款与修改建议、下一步建议

    内置规则

    • 六问定位是第一动作：必备条款完整性要求、适用的地方性规定、劳动者权益边界均因文件类型和劳动者类型而异
    • 录用通知书与劳动合同条款不一致时，一般以劳动合同为准，但特殊情况存在争议 [待验证]
    • 劳务协议（承揽性质）若存在人身从属性（固定工作时间、按指令工作），可能被认定为劳动关系，标高风险，建议先做劳动关系认定分析
    • 在校学生实习通常不构成劳动关系（缺乏劳动者主体资格），但近年实践有争议 [待验证]；只审查实习安全、实习报酬等保护性条款
    • 退休返聘通常认定为劳务关系而非劳动关系，不适用劳动合同法（须核查地方做法 [待验证]）；外籍人员须有有效工作许可和外国人就业证 [待验证]，竞业限制有特殊报备要求待验证
    • 非全日制用工以小时工资为基础，不得约定试用期 [待验证]，无固定期限触发情形不同
    • 缺陷分级要点：期限未写起始日期、固定期限未写终止日期、无固定期限未明确标注均为中等风险；「工作地点可由用人单位调整」为高风险；「放弃社保」条款为关键风险须删除
    • 合同正文与附件期限重大不一致标高风险并询问以何版本为准；通常正文优先，但须核查附件条款协调情况
    • 文件签署状态不明时在输出头部标注「审查基于[草稿/收到版本]，最终以签署版为准」

    法律依据

    • 《劳动合同法》（2012年修正）第17条 — 劳动合同九项必备条款，本步骤核心法条 [待验证]
    • 《劳动合同法》（2012年修正）第14条 — 无固定期限劳动合同触发情形（连续工作10年/两次固定期限续签/用工满1年未订书面合同等）；已核实锚点，建议复核
    • 《劳动合同法》（2012年修正）第10条 — 建立劳动关系须订立书面劳动合同，自用工之日起一个月内订立 [待验证]
    • 《劳动合同法》（2012年修正）第82条 — 未订书面合同二倍工资，与第14条配合：超1个月不满1年二倍工资，满1年视为已订无固定期限；已核实锚点，建议复核
    • 《关于确立劳动关系有关事项的通知》— 劳动关系认定三要素（主体资格/人身从属性/经济从属性）[条号待验证]

    产出

    「雇佣文件审查：文件定位与必备条款检查」单项报告：文件定位档案表（六维度）、九项必备条款完整性与风险等级表、无固定期限触发风险分析、逐条缺失条款的法律规定/文件现状/风险/修改语言、后续步骤触发建议

  2. 试用期与工时合规

    /employment-legal:probation-working-hours可单独运行

    核查试用期约定是否符合第19条分档上限及试用期工资下限，审查工时制度类型与审批、加班费三档及规避加班费的条款，给出补救成本与修改建议

    请律师核对

    • 核对 2.1试用期工资下限写为「三者取最高值」，第20条原文中「相同岗位最低档工资」与「约定工资」之间为「或」，请确认是否接受流程的从严口径
    • 核对 2.2「法律规定每周不超过44小时」与「行政法规每周不超过40小时」双重表述，审查时以哪一个为准
    • 核对 2.3月加班36小时上限标 [待验证]，请确认引用口径
    • 核对 2.4包薪制有效要件（明确加班小时数与基数）是否与贵所所在地裁审实践一致
    • 核对 2.5加班费基数「须包含全部报酬要素」的立场各地差异大，是否要按工作地点细化

    做法

    1. 读取配置中的试用期标准立场、工时制度配置（标准/综合/不定时各是否适用）、风险等级定义、工作地点（最低工资基准）；读取引用库（重点第19条、加班费三档）
    2. 按合同期限对应第19条分档表确定法定试用期上限，再对照合同约定填写检查表：试用期是否存在、时长是否不超过上限、是否包含在合同期限内、是否为同一单位同一劳动者的第一次约定
    3. 核查试用期工资：以「本单位相同岗位最低档工资的80%」「劳动合同约定工资的80%」「用人单位所在地最低工资标准」三者的最高值为下限，计算转正工资的80%并与当地最低工资（标 [管辖 flagged — 需验证当地标准]）比较，低于下限标关键风险
    4. 对发现的违法情形套用后果表（超上限、工资低于下限、重复约定、不应约定却约定，均标高风险），按偏离模板写出「法律规定 / 文件写的是 / 风险 / 建议修改」四段，建议修改写成「试用期为 [Y] 个月，自 [起始日] 至 [终止日]」
    5. 识别合同声称的工时制度类型（标准/综合计算/不定时），核查综合或不定时工时制是否有劳动行政部门审批文件、不定时制岗位是否符合高管/外勤/独立作业条件
    6. 对照加班费三档审查加班费条款：工作日延长150%、休息日安排工作且不能补休200%、法定节假日300%；休息日能补休可不付，法定节假日不得以补休代替
    7. 扫描加班条款风险：「员工自愿延长工作时间，用人单位无需支付加班报酬」和未经审批即以综合工时折算规避加班费为关键风险；加班费基数仅用基本工资、「工资已包含加班费」但未约定加班小时数与基数为高风险 [待验证]；未约定加班上限为中等风险
    8. 审查加班费计算基数是否包含绩效、津贴等全部报酬要素，排除绩效/津贴的标高风险；地方有更具体规定时以地方为准并标 [管辖 flagged]
    9. 按模板输出：试用期合规评估（合同期限→法定上限→约定时长→结论；试用期工资是否不低于转正工资80%且不低于最低工资；是否包含于合同期）、工时制度评估、风险点四级统计、修改建议

    内置规则

    • 第19条分档表（已核实）：以完成一定工作任务为期限、期限不满3个月——不得约定试用期；3个月至不满1年——不超过1个月；1年至不满3年——不超过2个月；3年以上（含）固定期限——不超过6个月；无固定期限——不超过6个月
    • 同一用人单位与同一劳动者只能约定一次试用期；试用期包含在劳动合同期限内，不可延长合同期来规避
    • 试用期工资下限（第20条 [待验证]）：不低于本单位相同岗位最低档工资的80%，且不低于合同约定工资的80%，且不低于用人单位所在地最低工资标准
    • 试用期超上限的后果：超出部分视为劳动合同期限，劳动者可要求按转正后工资补足差额 [待验证]；二次试用期无效，相应期间按转正工资计算 [待验证]；可能被行政处罚 [待验证]
    • 标准工时制：每日不超过8小时，每周不超过40小时（行政法规规定，法律规定每周不超过44小时 [待验证]）；综合计算与不定时工时制均须经劳动行政部门审批 [待验证]
    • 无审批文件的综合计算工时制按标准工时制处理，超出部分须付加班费，标高风险；不定时制用于非高管岗位标高风险
    • 包薪制（固定月薪包含加班费）须同时明确约定包含的加班小时数及计算基数，否则「包含加班费」约定无效 [待验证]
    • 月加班超过36小时违法 [待验证]，用于判断无加班上限约定的中等风险
    • 合同无工时约定时默认标准工时制，标中等风险并建议明确约定；试用期工资仅约定「不低于最低工资」时须计算是否低于转正工资的80%

    法律依据

    • 《劳动合同法》（2012年修正）第19条 — 试用期分6档上限、只能约定一次；本步骤核心法条，已核实锚点，建议复核
    • 《劳动合同法》（2012年修正）第20条 — 试用期工资下限 [待验证]
    • 《劳动合同法》（2012年修正）违法约定试用期的法律后果 — 以满足试用期后工资标准补足超出部分差额 [条号待验证]
    • 《劳动法》（1994年通过）标准工时与加班费三档 — 每日不超过8小时；150%/200%/300%；规则已核实，条号 [待验证]
    • 《劳动法》综合计算工时制/不定时工时制 — 须经劳动行政部门审批 [条号待验证]
    • 《国务院关于职工工作时间的规定》— 每日不超过8小时、每周不超过40小时（行政法规层级）[待验证]

  3. 社保公积金与劳动报酬

    /employment-legal:social-insurance-wages可单独运行

    核查五险一金法定缴纳义务的履行与无效放弃条款，审查工资标准、支付周期与克扣风险，并专项评估未订书面劳动合同的二倍工资风险及金额

    请律师核对

    • 核对 3.1社保基数上下限写为「60%/300%」并带 [管辖 flagged]，请按工作地点确认当年标准
    • 核对 3.2二倍工资「每月工资」以含绩效津贴的实际工资计算，这一基数立场标 [待验证]，是否符合贵所所在地裁审口径
    • 核对 3.3「工资支付周期超过一个月违法」「不得以实物代替」均标 [待验证]，请核对依据
    • 核对 3.4「社保补贴代替缴纳」定为高风险而非关键风险，分级是否合适
    • 核对 3.5非全日制用工「按灵活就业方式参保、工伤保险须依法参加」的表述标 [待验证]

    做法

    1. 读取配置中的社会保险标准立场、公积金立场、工作地点（社保基数/最低工资）、风险等级；读取引用库（重点第82条、社会保险法、第14条）
    2. 对照五险表审查社保条款：养老/医疗/失业为用人单位与劳动者共同缴纳，工伤/生育为用人单位单独缴纳，五项均强制、放弃均无效
    3. 扫描社保条款四类风险：「员工自愿选择不参加社会保险」等自愿放弃表述为关键风险；「按月支付X元社保补贴、员工自行购买」为高风险（不免除法定义务）；仅形式声明「依法缴纳」未明确险种与标准为中等风险；以基本工资为基数排除绩效津贴为高风险 [待验证]
    4. 核查社保缴纳基数：下限一般为当地上年度职工月平均工资的60%，上限一般为300%（各地不同，标 [管辖 flagged — 需验证地方性规定]）；实际工资低于下限按下限缴、高于上限按上限缴；合同约定以基本工资为基数且明显低于实际工资并低于下限时标高风险
    5. 核查住房公积金：是否声明依法缴纳、是否有「放弃公积金」条款（无效，关键风险）、缴纳比例是否符合当地规定（通常5%~12% [管辖 flagged]）
    6. 审查劳动报酬：工资金额或计算方式是否明确（第17条第六项）、是否不低于当地最低工资（低于为关键风险）、支付周期（超过一个月支付违法 [待验证]）、支付方式（货币按时足额，不得以实物代替 [待验证]）
    7. 审查工资构成与克扣风险：「用人单位有权根据员工表现扣减工资」等宽泛扣薪条款未限定明确情形为关键风险；基本工资极低大量依赖绩效为高风险；「因不可抗力或特殊原因可延迟支付工资」未限定范围为高风险
    8. 第82条专项：核对合同是否已签、用工开始日期与签署日期的间隔，套用风险矩阵，并按公式估算额外工资 = 劳动者每月工资 × 未签书面合同的月数（超1个月不满12个月部分）
    9. 对外籍人员、退休返聘、非全日制三类特殊劳动者标注社保特殊规则（均 [待验证]，多数带 [管辖 flagged]）
    10. 按模板输出：社保公积金合规摘要表（五险/公积金/缴纳基数）、劳动报酬合规摘要表（工资标准/支付周期/最低工资）、二倍工资风险（用工开始日、签署日、未签月数、估算金额、风险等级）、修改建议

    内置规则

    • 「自愿放弃社保」规则（已核实）：无论劳动者是否书面声明自愿放弃，用人单位法定缴纳义务不免除，条款无效，仍需补缴并可能面临滞纳金（通常按日计算 [待验证]）和罚款
    • 替代修改语言：「用人单位依法为劳动者缴纳养老、医疗、失业、工伤、生育保险，缴纳基数和比例按当地现行规定执行」
    • 二倍工资风险矩阵：用工不超过1个月为低风险；用工超过1个月且不满12个月仍未签为关键风险且每月累积；用工已满12个月仍未签视为已订立无固定期限劳动合同、另有违法责任，关键风险；已签但签署日晚于用工日超过1个月的，未签期间有二倍工资风险，须评估是否已超时效 [待验证]
    • 二倍工资的「二倍」含义：第一倍是已实际支付的正常工资，第二倍是额外赔偿；「每月工资」以实际工资为准（含绩效津贴）[待验证]；起算点为用工之日起第二个月，终止点为书面合同签署当日或用工满12个月时
    • 二倍工资仲裁时效1年（《劳动争议调解仲裁法》第27条，已核实）
    • 商业保险不能代替法定工伤保险，关键风险 [待验证]；外籍员工同时在本国缴纳社保的，须查中国是否与该国签有社保双边协议，有协议可豁免 [待验证]
    • 「工资中包含社保份额，社保由用人单位一并缴纳」：实际已缴且符合法定标准则合规；仅名义包含未实际缴纳为关键风险
    • 工资仅约定区间时，分析以最低值作为社保基数是否合规，并标注「具体金额须在入职时确认」；多份工资约定（合同+补充协议）时梳理优先顺序，以最终确认的标准为准
    • 无法确认用工开始日期时标中等风险，建议核查入职记录、社保缴纳记录

    法律依据

    • 《劳动合同法》（2012年修正）第82条 — 未订书面劳动合同二倍工资；本步骤核心法条，已核实锚点，建议复核
    • 《劳动合同法》（2012年修正）第14条 — 用工满1年未订书面合同视为已订无固定期限，与第82条联动；已核实锚点，建议复核
    • 《劳动合同法》（2012年修正）第17条 — 必备条款第六项劳动报酬、第七项社会保险 [待验证]
    • 《社会保险法》（2011年施行）— 五险法定缴纳义务，放弃无效；规则已核实，条号 [待验证]
    • 《住房公积金管理条例》（国务院）— 用人单位和劳动者共同缴纳住房公积金 [待验证]
    • 《劳动争议调解仲裁法》第27条 — 仲裁时效1年；存续期间拖欠报酬不受1年限制；已核实锚点，建议复核

    产出

    「雇佣文件审查：社保公积金与劳动报酬」单项报告：五险/公积金/缴纳基数合规表、工资标准/支付周期/最低工资合规表、第82条二倍工资风险估算（金额 × 月数）、修改建议语言

  4. 服务期与违约金合法性

    /employment-legal:service-period-penalty可单独运行

    识别文件中全部违约金条款并归入服务期/竞业限制/无效三类，审查服务期是否满足专项培训前提及违约金上限，标记提前离职违约金等无效条款并给出两种立场的处理建议

    请律师核对

    • 核对 4.1第25条、第22条的条号在文件中均标 [待验证]，而第23-24条标已核实锚点，请统一核对
    • 核对 4.2服务期违约金按月精确分摊与「约定计算方式优先」之间，流程采用前者，是否符合贵所主张
    • 核对 4.3「未提前30天通知」不得约定违约金但可主张实际损失赔偿，这一立场标 [待验证]
    • 核对 4.4无正式竞业协议的「跳槽违约金」定为高风险而非直接无效，是否同意
    • 核对 4.5「不一致时以对劳动者更有利的约定为准」是否作为贵所的默认解释规则

    做法

    1. 读取配置中的审查立场、风险等级、升级矩阵；读取引用库（重点第25条、第22条、第23-24条）
    2. 扫描文件中所有违约金约定，按五类归类：服务期违约金（第22条，有条件合法）、竞业限制违约金（第23-24条，合法，须与竞业限制约定同时存在）、提前离职违约金（无效）、未提前30天通知违约金（无效）、其他限制劳动者离职的违约金（无效）
    3. 审查服务期合法前提是否全部满足：用人单位提供专项技能培训（非入职培训、日常工作培训）[待验证]、实际支出培训费用且能举证 [待验证]、以书面形式明确约定服务期限和违约金；任一不满足标高风险并说明「日常工作培训/入职培训不构成合法服务期前提 [待验证]」
    4. 计算服务期违约金上限：不得超过用人单位提供的培训费用，且不得超过服务期尚未履行部分应分摊的培训费用；按「培训费用 ÷ 服务期月数 × 未履行月数」核算并与合同约定（固定金额/按月递减/其他）比较；约定「超出部分劳动者承担」为关键风险
    5. 处理服务期与合同期限不一致：服务期短于合同期限属正常；服务期长于合同期限须确认是否自动续签至服务期满 [待验证]，建议明确续签机制；服务期内合同期满用人单位不愿续签涉及 N 经济补偿 [待验证]，标中等风险
    6. 识别「提前离职违约金」典型表述（提前离职支付X万元、入职X年内离职赔偿Y元、未完成绩效目标离职支付Z元、主动解除支付N个月工资），按模板写出关键风险、无效后果（不具约束力，已收取须全额退还）及用人单位方/劳动者方两套处理建议
    7. 识别「未提前30天通知违约金」：劳动者提前30天书面通知解除为法定权利，不可通过违约金限制 [待验证]；用人单位只能就实际损失有证据地主张赔偿，不能预设违约金 [待验证]；关键风险
    8. 归类其他无效违约金：末位淘汰违约金（关键，绩效末位不构成过失性辞退事由）、无正式竞业协议的跳槽违约金（高，效力有争议 [待验证]）、非专项培训的返还培训费（中等，效力存疑 [待验证]）
    9. 对竞业限制违约金只做三项检查：是否有独立竞业限制约定（第23-24条）、违约金是否依附于合法竞业协议而非单独存在、是否需要深度竞业审查；涉及竞业即提示运行 /employment-legal:non-compete-review
    10. 按模板输出：违约金条款汇总表（编号、类型、金额/计算方式、效力、风险等级）、关键风险点、服务期合法性评估（培训费用、服务期、约定违约金、法定上限、是否合规）、下一步建议

    内置规则

    • 第25条（已核实规则，条号 [待验证]）：除第22条服务期和第23条竞业限制两情形外，用人单位不得与劳动者约定由劳动者承担违约金；列举是封闭的
    • 上限计算示例：培训费用100,000元、服务期3年（36个月）、月均分摊约2,778元，工作12个月后离职，未履行24个月，违约金上限约66,667元
    • 劳动者已部分履行服务期的，违约金按未履行部分的分摊比例计算，不得按全额主张
    • 服务期内用人单位违法解除合同的，无权主张服务期违约金，还可能须支付违法解除赔偿金（2N）加经济补偿 N [待验证]
    • 「日常技能培训」被包装为「专项培训」时标高风险，说明服务期约定效力存疑 [待验证]
    • 保密协议中单独约定的非竞业、非服务期违约金同样无效，仍受第25条两情形限制
    • 劳动合同与培训协议约定不一致时，以对劳动者更有利的约定为准（劳动法倾斜保护原则 [待验证]）
    • 无法核实培训费用金额（未附发票/协议无记录）时标高风险：违约金上限无法计算，须提供培训费用证明材料
    • 用人单位方替代方案：提供专项培训并签合法服务期协议；或以长期绩效/股权激励替代违约金约束。劳动者方口径：条款无效无需受约束，被扣薪或追偿可通过劳动仲裁主张权利

    法律依据

    • 《劳动合同法》（2012年修正）第25条 — 违约金仅限服务期与竞业限制两情形；本步骤核心法条，规则已核实，条号 [待验证]
    • 《劳动合同法》（2012年修正）第22条 — 服务期前提（专项培训费用）及违约金上限（不超过培训费用；不超过未履行部分分摊费用）[待验证]
    • 《劳动合同法》（2012年修正）第23-24条 — 竞业限制有效要件（人员范围/经济补偿/期限不超2年）；已核实锚点，建议复核
    • 《劳动合同法》（2012年修正）劳动者提前30天通知解除权 — 不因违约金约定而受限 [条号待验证]

    汇总前四步发现，叠加工作地点的地方性规定核查，按关键/高/中等/低分级合并问题，组装最终雇佣审查备忘录并完成交付前质量检查

    请律师核对

    • 核对 5.1地方性规定表只覆盖北京、上海、广东省、深圳、浙江/江苏五组，其余仅指向人社局官网，是否要补充贵所主要业务地

    做法

    1. 读取配置中的文书风格、工作产物标题、审查立场、升级矩阵、工作地点；读取引用规范与引用库
    2. 收集前四步的发现状态与问题数（每步各记关键/高/中等数量）；若某步未完成，提示先依次运行四个专项步骤再回到装配；单独运行且未提供发现时自行做综合分析，但告知深度不及逐项运行
    3. 按工作地点核查地方性规定表并标 [管辖 flagged — 需验证地方性规定]：北京（社保基数上下限每年3月调整、最低工资、竞业限制补偿指引 [待验证]）；上海（最低工资分全日制/非全日制、综合计算工时制审批、竞业补偿以离职前12个月月均工资为基准 [待验证]）；广东省（5月至10月高温津贴、特殊工时审批、佛山/东莞/中山等地市规定）；深圳（经济特区劳动合同条例 [待验证]、竞业补偿比例指引、社保基数）；浙江/江苏（最低工资、高温津贴、社保基数）；其他地区查工作地点所在省市人社局官网
    4. 完成地方性规定检查清单：最低工资（影响工资合规与试用期工资下限）、社保基数上下限、竞业限制补偿指引、特殊工时/高温津贴、是否跨地区工作（工作地点与用人单位注册地不同）
    5. 按配置文件的四级定义合并全部发现，生成问题汇总表（序号、类别、来源步骤、风险等级、修改优先级：优先级1立即/优先级2强烈建议/优先级3建议）
    6. 文件涉及竞业限制时输出专项提示并做三项快速评估：人员是否为高管/高技/保密义务人员（第24条）、期限是否超过2年（第24条已核实上限）、是否约定经济补偿（第23条，无补偿可能无效）；深度审查指向 /employment-legal:non-compete-review
    7. 按配置选择工作产物标题（律师角色「律师工作产物 — 受律师-当事人特权保护 / 保密」；非律师角色「研究笔记 — 非法律建议，供律师审查」），按备忘录结构组装：底线、问题统计、文件定位摘要、必备条款摘要、按等级分类的问题、地方性规定检查、修改建议优先级清单、竞业限制专项提示、下一步决策树
    8. 逐项执行交付前质量检查（对照条款、地方性规定、每题有改法、分级校准、条号标注、标题、竞业提示、无遗漏、立场体现）后再输出

    内置规则

    • 风险等级定义（来自配置文件）：关键=明显违反强制性规定（如「自愿放弃社保」「提前离职违约金」），几乎肯定败诉/无效，必须修改或删除、不得签署；高=有较大法律风险可能败诉（如试用期超期、加班费计算基数偏低），强烈建议修改；中等=存在争议空间取决于仲裁员/法官裁量（如工作内容描述过宽泛），建议修改可协商；低=合规或有充分依据，记录即可
    • 修改建议优先级清单对应协商空间：关键级无协商空间（强制性规定）；高风险协商空间有限；中等风险可协商
    • 各步骤发现相互矛盾时，采用更严格（风险更高）的结论，并注明「存在不一致，建议人工复核」
    • 某步骤发现为空时在对应位置标注「[步骤名] 尚未运行，该项风险未评估；建议单独触发获取完整分析」
    • 多个关键风险时底线写明「本文件存在 [N] 项关键风险，不建议签署/发出——须先解决以下关键问题」
    • 多工作地点（员工跨城市工作）时分别列出各地差异，标注「以实际提供劳动的工作地点为准 [待验证]」
    • 劳动者方立场下明确提示「以下条款可能侵害您的合法权利，如有需要可通过劳动仲裁主张权利」

    • 下一步决策树五项：修改并重新审查；谈判协商（对高风险条款启动协商）；升级给配置升级矩阵指定人员；竞业限制深度审查；准备谈判方案（各问题的谈判底线与可让步范围）
