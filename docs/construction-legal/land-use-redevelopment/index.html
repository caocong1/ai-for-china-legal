01概要

面向持有划拨或出让土地的企业（含国有企业），回答三件事：这块地能否不经招拍挂改变用途、由原使用权人补办出让；补缴价款怎么算、怎么分期、何时登记、出让合同签什么；土地怎样进入项目公司或与开发企业合作开发（作价出资即转让与 25% 条件、预告登记、开发资质、国资参股约束、税负）。成果是律所致客户的咨询型法律备忘录（客户成稿）加给承办律师的《成稿说明》。做法是：读实践配置文件，按动态事项确认口径读材料并提问，依次走「改变用途与供地方式 → 价款、出让合同与登记 → 土地进入项目公司与合作开发」三步，每一处法条与地方文件经研究闸门取官方原文核对，国家规则、国家保留通道、地方通道三层不跳层，依赖未取得文件的结论写成附条件并列签约前提与替代路径。源于案例库 LWC-2026-0007 及其后四轮复核，固化判断顺序与检查清单，不固化该案结论。

02适用与边界

适用场景

  • 划拨土地（教育、工业、办公等非经营性用地）拟改为住宅或商业并补办出让
  • 客户询问能否以协议方式、不经招拍挂由原使用权人补办出让
  • 需要复算政府窗口价或客户测算的补缴价款、分期、契税与登记时间
  • 拟以土地作价出资设立项目公司、引入房地产企业控股或签合作开发合同
  • 国有企业盘活存量土地，涉及主业、负面清单、参股与进场增资
  • 客户材料援引城市更新、低效用地再开发等地方政策，需要核验时效与反向条款

不做什么

  • 集体土地、宅基地事项不适用
  • 开发商与购房人之间的商品房买卖合同，由商品房买卖合同审查流程处理
  • 不固化 LWC-2026-0007 案的结论；不给税额结论（只做税负提示，建议专项税务论证）
  • 不替代有权机关的书面确认、集团或国资委的书面意见、税务机关的书面意见

03输入与产出

需要律师提供

  • 客户材料目录（供地文件与权属证明、土地证或不动产权证、划拨决定书或出让合同原件、房屋所有权证）必需
    划拨决定书有无「政府收回」约定决定地方通道是否可用
  • 需要回答的委托问题（如「变性是否可行」「能否与开发商设立项目公司」）必需
    委托问题不清属阻断项
  • 我方身份与立场（土地使用权人 / 拟合作的开发企业 / 政府平台公司）必需
    立场来自委托关系，不来自配置；身份不清属阻断项
  • 律所模板（如有）及参考稿的使用排除规则可选
    「格式按某份旧稿、内容不参考」可从指令推出；排除规则不清属阻断项
  • 控规调整批准文件与规划条件可选
    可后置：未提供时在成稿中用条件句与待补材料处理
  • 政府计价文件或窗口价口径、「双评估」报告可选
    可后置
  • 拟签出让合同、客户的分期与时间安排、政府工作时间表可选
  • 合作方案、可研或请示；合作方类型与资质；股权比例与治理设想可选
  • 地块是否纳入城市更新 / 低效用地项目库及报部备案情况可选
    可后置
  • 客户援引但检索不到的上级文件原文可选
    取不到的，客户成稿写「未取得该文件文本，未据此分析」

产出

  • 法律备忘录（客户成稿）给客户
    按「法律备忘录（致客户，咨询型）」骨架，有律所模板时以模板为准；法律分析按委托问题分节：（一）变性——规划前提、供地方式（一般规则 → 保留通道 → 地方依据 → 我们的意见 → 替代路径）、价款核定、分期登记与出让合同、房地一致、内部决策资金与时间安排、小结；（二）合作开发——国资监管、作价出资与第 39 条、项目公司设立方式、开发资质、评估备案与增资程序、参股治理、毗邻土地、税负、小结；可选附件摘录对结论最关键且客户不易取得的地方文件条款。正文不放内部标记。
  • 成稿说明（致承办律师）给律师内部
    按 document-delivery-qa.md 第 5 节九节结构，重点是「客户材料问题表」「发送前请律师确认」「核验来源表」「复核情况」；对客户价值大但措辞须律师把握分寸的点（如价款可能多算）单独说明；独立复核意见的处理写在这里。
  • INTAKE_DECISION给律师内部
    在第一次实质检索或起草之前输出的事项确认结论（ready / conditional / critical）
  • REVIEW_STATUS给律师内部
    交付前输出的复核状态

04开始前

前置条件

  • 读取 construction-legal/CLAUDE.md；配置缺失或含 [PLACEHOLDER] 时进入临时模式，默认值为律师角色、土地使用权人立场、保守型风险提示
  • 执行 shared/legal-document-intake/SKILL.md 的动态事项确认：先读材料后提问；国有企业主体、亿元级价款、政府设定签约时限任一情形即为 critical，在第一次实质检索或起草之前输出 INTAKE_DECISION
  • 读取 land-law-citations.md 对应章节与所在城市的 local-rules-<city>.md；没有地方库的，按 search-playbooks.md 的土地 Playbook 现场检索并按同一结构记录
  • 每一处法条与地方文件写入前经 shared/research-gate/SKILL.md 取官方原文核对现行版本；引用库中标「代理核对」的条目由主笔重新取原文
  • 材料目录、模板、问题与输出位置已明确时直接执行，不重复询问；模板与原件永不覆盖

硬性规则

三层不跳层
先写国家一般规则（含反向规定），再写国家保留通道，最后写地方通道及其前提。只引地方有利文件的稿子不得交付。
有利依据同摘反向条款
同一地方文件中「经营性用地公开出让」的规定、适用范围、项目库或备案前提，必须与有利条款一并写出。LWC-2026-0007 的独立复核把遗漏反向条款列为「必须修改」。
地方文件时效
核对施行日、有效期与失效标注；按日期分档的规则，以出具日计算当前档位和下一个届满日。
客户材料中的依据先核验
逐条判定准确 / 部分准确 / 不准确 / 未能核验。错误写入成稿说明；客户成稿中性处理（「不宜作为……依据」「未取得该文件文本，未据此分析」）。
结论强度
依赖未取得文件的，写成附条件结论，明示残余风险，把有权机关的书面确认列为签约前提，并给出替代路径。国资监管类结论以「存在……的实质风险」为限，等集团书面意见。
不构成法律确认的材料
申请表中的勾选项、政府工作时间表、窗口指导价、战略合作协议中的意向性条款，都不构成供地方式或价款的法律确认。
主体变更先定性
客户拟先把土地划转、转让给子公司或项目公司再补办出让或出资的，按转让对待（政府批准、公开交易、房地一并、补缴价款），并核对补办出让与地方自主改造的申请人资格是否随之丧失（第三步方案 B）。
数字
单价乘面积复算；现金与非现金分列（账面净值不是现金支出）；期限推算写明起算日与届满日。
先检索、后结论
每一处法条与地方文件，写入前经研究闸门取官方原文核对现行版本。
独立复核可观察
critical 事项由不同模型在新上下文中复核：只传原始材料、成稿与已抓取的官方原文目录。交付前输出 REVIEW_STATUS；复核意见的处理写入成稿说明。
动态事项确认与输出确认
可从指令推出的不问（委托问题、受众、事实截止日、是否给建议方案、模板使用规则）；阻断项只有四种：我方身份不清、委托问题不清、参考稿或模板排除规则不清、写入目标可能覆盖原件；其余为可后置项，用条件句、签约前提和待补材料处理。

05执行步骤

共 3 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置假设，可逐条复制。页面里的英文标记见首页「标记与术语」。

  1. 改变用途与供地方式

    /construction-legal:land-use-change-path可单独运行

    回答「这块地能不能变性、怎么变」：说清国家规则与地方通道之间的张力，把地方通道的前提逐项对到客户证据，给出可执行的签约前提和备选路径。

    请律师核对

    • 核对 1.1三档结论的固定措辞（「具有相应的政策依据」「缺乏充分依据」）与残余风险的表述尺度
    • 核对 1.2把有权机关对「协议补办、用于商品住宅」的书面确认列为签约前提是否在当地可操作
    • 核对 1.3替代路径中协商收储补偿「按新规划用途市场评估价一定比例」的当地口径
    • 核对 1.4停用收回风险「作背景风险、不写成威胁」的表述分寸
    • 核对 1.5所在城市没有地方通道时结论保守到何种程度，SKILL.md 只写「签约前提更多」

    做法

    1. 把「变性」拆成两层——土地用途变更（如教育、工业改住宅）与供应方式变更（划拨改出让、补办出让并缴价款）；先固定五项现状事实并逐项注明来源：证载权利人、权利类型、用途、面积、取得时间（土地证、不动产权证）；划拨决定书或出让合同有无「政府收回」约定（供地文件原件）；是否停用及停用时间与原因；地上建筑权属登记在谁名下（房屋所有权证）；控规是否已调整、规划条件是否已核发。
    2. 核规划前提：改变用途须经自然资源主管部门同意、报原批准用地的人民政府批准，城市规划区内报批前先经规划主管部门同意；住宅不在划拨范围内、变更后须有偿使用；出让前须有依据控规的规划条件并纳入出让合同，否则出让合同无效；控规修改须经法定程序；用途变更为居住用地的，变更前须按规定进行土壤污染状况调查并在省级确定的时限前完成，报告由生态环境主管部门会同自然资源主管部门评审；规划条件有效期、已供地项目重新申请规划条件须经属地政府批准等见地方规则。
    3. 客户只说「控规已调整」的，基本事实中写「根据贵司介绍」并注明尚未提供批准文件和规划条件；建议核对用地性质、容积率、限高等指标与客户测算口径是否一致。
    4. 供地方式第①层国家一般规则（必写，作为反向依据）：经营性用地（含商品住宅）公开竞价出让；原划拨土地改为商品住宅等的纳入统一管理、统一供应；非经营性用地改为经营性用地的应当约定或明确政府可以收回；规避招拍挂的追责。
    5. 第②层国家保留通道：原划拨使用权人经批准可以协议补办，但划拨决定书、法律、法规、行政规定明确应当收回、公开出让的除外；停用的原划拨土地经批准由原使用者自行开发的按市场价补缴；存量盘活政策鼓励自主、联营、入股、转让。写明除外条款可能被第①层文件触发；鼓励性文件均以政府无须收回为前提，且未就商品住宅专门授权。
    6. 第③层地方通道（城市更新 / 低效用地再开发）：适用范围、项目库纳入与报部备案、供地文件未约定收回、政府审核同意、监管协议，连同同一文件的反向条款，逐项对照「已具备 / 未提供 / 不具备」。
    7. 填前提条件对照表：每项前提写依据、客户材料中的证据、状态与取得途径；申请人已不是原土地使用权人（已划转或拟划转给关联主体）的，转第三步方案 B 按转让论证。
    8. 按前提状态三选一写结论：全部具备写「具有相应的政策依据」并写残余风险，建议保留集体决策记录；前提未提供写附条件结论「如本地块已……并取得……，则……」，基本事实中写「截至本法律备忘录出具之日，贵司尚未向我们提供……」，并把有权机关就「以协议方式补办出让、用于商品住宅」出具的书面依据确认列为签约前提；前提不具备写「以协议方式补办出让缺乏充分依据」，列出可能后果（出让合同效力争议、土地被收回、按市场价补差、相关人员被追责），转替代路径。
    9. 写替代路径：政府依法收回后招拍挂并给予合理补偿（「有开发意愿，但没有开发能力」情形）；原使用权人形成「净地」后与土地储备机构协商收储，补偿按新规划用途市场评估价的一定比例计算，并与客户自估（常只计账面残值和拆除补偿）对比；原使用权人以竞买人身份参加公开出让（须具备开发资质，资金须为合规自有资金）。
    10. 写停用收回风险：因迁移等原因停止使用的原划拨土地政府可依法收回，应当无偿收回、地上物适当补偿；长期「划拨、闲置」本身有被收回风险，在政府支持原使用权人改造开发的窗口期内依法完成变性有利于稳定权益；表述克制，作背景风险写。
    11. 说明以下材料只反映政府意向与工作安排、不构成供地方式或价款的法律确认：前置审查申请表中「非招拍挂」勾选（申请人自报）、政府工作时间表、窗口指导价、战略合作协议（客户常不是当事人，「在……政策范围内」「依法依规」属意向性约定）。

    内置规则

    • 现状事实五项（权利人与权利类型用途面积取得时间 / 供地文件收回约定 / 停用情况 / 地上建筑权属 / 控规与规划条件）必须固定并注明来源。
    • 三层判断表：①国家一般规则——《民法典》第347条第2款、《土地管理法实施条例》第18条、39号令第4条、21号令第3、9条、国土资发〔2002〕265号、〔2003〕356号、国发〔2008〕3号（十三）（十四）；②国家保留通道——114号文 4.3(2)、6.1(2)、国发〔2008〕3号（七）、国发〔2004〕28号（十七）、147号（七）、205号二（二）、171号第8项、2025年中办国办城市更新意见三（二）；③地方通道——local-rules-<city>.md。
    • 前提条件对照表九项：属于地方通道适用范围；已纳入项目库（及报自然资源部备案）；供地文件未约定由政府收回；政府审核同意改造申请、方案或实施方案；控规调整已批准、规划条件已核发；土壤污染状况调查已安排在用途变更前进行且评审已安排；申请人仍是原土地使用权人；不动产权利归属清晰、主体明确；出让方案经集体决策。状态只能是「已具备 / 未提供 / 不具备」。
    • 结论三档写法：全部具备→「具有相应的政策依据」+残余风险（国家层面强调公开出让的背景下，出让合同效力可能被质疑，审计或巡视中可能被认定为规避招拍挂）；未提供→附条件结论+签约前提；不具备→「缺乏充分依据」+可能后果+替代路径。
    • 禁止用无出处的理论论证消解第①层规则，例如「补办出让不属于设立，因而不适用第347条」；LWC-2026-0007 的复核因此删去了一处论证。
    • 不构成法律确认的四类材料：申请表勾选、政府时间表、窗口指导价、战略合作协议。
    • 边界：已出让土地改变用途不涉及补办出让，按《城市房地产管理法》第18条或地方城市更新条例签变更协议或重签合同并补缴；工业改住宅先查地方工业类条款与「工改住」联动要求（171号第8项要求建立竞争性准入机制），工业类计收档位不同；划拨决定书约定收回的地方通道不适用，转替代路径；所在城市没有地方通道的只能依国家保留通道加个案集体决策，结论更保守、签约前提更多；集体土地、宅基地不适用；政府平台或开发企业一方委托时立场相反，关注取得土地的合规性与可撤销风险、合作对价公允性。

  2. 价款、出让合同与登记

    /construction-legal:land-premium-contract可单独运行

    让补缴价款的依据和口径可复算、地方计收比例与时间窗口不漏、分期登记与合同条款不自相矛盾，并把签约前必须拿到的文件列清楚。

    请律师核对

    • 核对 2.1补办出让分期采用财综〔2009〕74号口径（≤1 年、特殊 2 年、首期 ≥50%）而排除地方招拍挂分期政策，是否符合当地实践
    • 核对 2.2窗口价与「全额价差」比较后可能多算亿元级的提示，客户成稿中如何措辞由律师把握
    • 核对 2.3房地一致处理明确不走「更名」路径的判断
    • 核对 2.4政府时间表短于前提落实时间时建议「前提落实后再签约」的立场
    • 核对 2.5出让金与征收安排脱钩的建议是否会影响客户与政府的谈判

    做法

    1. 先读取第一步结论（供地方式与签约前提）；读引用库第三、五节（契税见第六节）与所在城市的分档规则；国有企业另读交易程序引用库第八节的内部决策锚点。
    2. 写价款公式：应缴价款 = 新土地使用条件下出让市场价格 − 原土地使用条件下划拨土地使用权权益价格（「双评估」价差）；当地另有补办出让价款规定的对比后确定。程序上写出让底价集体决策、协议出让最低价不低于基准地价 70%、合同签订后公布结果。
    3. 查地方是否对自主改造或补办出让按价差的一定比例计收、有无按拆除进度或日期分档、叠加系数；以出具日计算当前档位与下一个届满日，已届满档位明说，避免客户按旧材料预期；「完成节点」（拆除认定、签约、缴清价款、登记）不明的，提示分期缴款可能落入下一档，建议取得政府书面确认；写明国家「按市场价补缴」与「减免出让金」问责同地方按比例计收之间的张力——比例计收属地方试点政策，适用须以书面计价文件和集体决策为依据。
    4. 复算四项：单价×面积（亩 / 平方米换算），客户材料常见单价与总价对不上；窗口价是否已适用计收比例——与同片区出让起始价（楼面价×容积率折算亩价）减去原用途权益价比较，窗口价接近「全额价差」未体现地方比例时差额可能达亿元级；现金与非现金分列——出让价款、契税、印花税、不可预见费分列，账面净值不是现金支出，避免立项额度与现金需求混同；分期额只对出让价款分期，不得把含税合计数对半当每期金额。数字写进客户成稿时注明口径；客户材料内部矛盾（总额、方位、增值测算）写进成稿说明。
    5. 分期与利息：地方招拍挂土地的分期政策（如「首期 50%、1 个月内、余款 1 年、不计息」）须核对适用对象，不能直接套用到补办出让；补办出让的分期一般依财综〔2009〕74号——原则上不超过一年，特殊项目经集体认定可两年，首期不低于 50%；示范文本第 11 条第二期及以后各期按 LPR 计息；客户「余款次年内缴清」要与「签约后一年内」衔接；契税不随出让价款分期——以全部补缴价款为计税依据，纳税义务发生时间为改变土地使用条件当日，办理权属登记前申报缴纳，资金计划按全额列支。
    6. 登记：付清全部价款（含利息、违约金）后方可申请出让登记，不按缴款比例分割发证；指出分期会推迟取得不动产权证书、进而推迟以土地出资或转让的时间；指出客户时间表中「年底前缴库并完成变更登记」与分期安排的矛盾。
    7. 出让合同：划拨土地没有原出让合同，补办出让应签《国有建设用地使用权出让合同》，「出让合同变更协议」的说法与现状不符；示范文本第 8 条补办出让的出让期限自合同签订之日起算。审阅规划条件附件、土地交付条件（含地上物处置）、价款与支付方式、开竣工期限、首次转让条件（第 20 条：完成开发投资总额 25% 以上等）、违约责任（第 29 条：迟延付款按日计违约金，使用说明按 1‰ 填写；延期超过 60 日经催缴仍未付的出让人可解除合同、定金不予返还）。首次转让条件直接限制后续以土地出资的路径，签约前就要确定合作路径，争取在合同或监管协议中写明允许的合作方式。开竣工期限（第 15 条）与合作方进入、项目公司设立和开工计划对表：逾期开工按日计违约金（第 32 条）；超过约定动工日期满 1 年未动工可征收出让价款 20% 的土地闲置费，满 2 年可无偿收回。
    8. 房地一致与地上房屋：房屋与土地一并登记、主体一致、一并处分；纳入再开发范围的不动产须权利归属清晰；拆除新建以「具有合法权属」为前提。房屋登记在已重组的原关联企业名下的两种处理：一是依重组、划转文件办理转移登记（备齐划转批准、评估或免评估依据与契税减免依据），原登记主体与承继主体不是同一主体的不能按「更名」办——变更登记只适用于同一权利人的名称变更；二是履行国有资产处置程序后拆除，由登记权利人或承继主体申请注销登记，拆除前完成房屋安全鉴定与资产核销。承继主体是上市公司的须履行其内部决策与关联交易程序。地方价款按拆除进度分档时，拆除路径与价款档位联动，一并说明。
    9. 资金来源与内部决策：银行业金融机构不得发放用于缴交土地出让价款及相关税费的贷款，地价须以自有资金或其他合规资金支付，集团内资金安排也要避免间接使用信贷资金；国有企业须纳入年度投资计划（未纳入的调整计划），履行「三重一大」、党委前置研究、董事会与集团审批，未按规定决策擅自投资属责任追究情形；在签约和缴纳首期价款之前完成。
    10. 列签约前提清单（项目库纳入及备案文件；政府对改造申请或实施方案的批准及用地批文；协议补办用于商品住宅的书面依据确认；规划条件；土壤污染状况调查及报告评审安排；「双评估」报告与书面计价依据；房屋处置路径；内部决策与上级批准；资金落实）。政府时间表短于前提落实所需时间的，结合出让合同的违约金与解约条款建议前提落实后再签约，必要时在政府年度窗口内协商调整时点；与本地块无关的政府诉求（如其他片区前期工作）分别办理，不写入出让合同。
    11. 政府或客户材料把本地块出让金写成其他片区征收的资金来源、把缴款写成征收启动前置条件的，指出：出让收入全额缴入国库、实行「收支两条线」，未列入土地出让支出预算的项目（包括土地征收项目）不得通过出让收入安排支出，不得减免缓缴或变相减免；征收补偿费用须在作出征收决定前足额到位。建议取得政府书面文件写明出让价款依「双评估」与集体决策独立核定、出让收入使用属政府预算事项；出让合同不设返还、专款回拨或以征收为条件的条款。

    内置规则

    • 价款 = 「双评估」价差；协议出让最低价不低于基准地价 70%；出让底价集体决策；合同签订后公布结果。
    • 补办出让分期：原则上不超过一年，特殊项目经集体认定可两年，首期不低于 50%；第二期及以后按 LPR 计息；地方招拍挂土地的分期政策不得直接套用。
    • 契税不随价款分期：以全部补缴价款为计税依据，纳税义务发生于改变土地使用条件当日，权属登记前申报；资金计划按全额列支。
    • 付清全部价款（含利息、违约金）后方可登记，不按缴款比例分割发证。
    • 复算四项检查表：单价×面积；窗口价是否已适用计收比例；现金与非现金分列；分期额只对出让价款。
    • 出让合同审阅要点：新签出让合同而非变更协议；出让期限自签约起算（第 8 条）；规划条件附件；交付条件与地上物处置；首次转让条件 25%（第 20 条）；迟延付款按日 1‰ 违约金、延期超 60 日可解约且定金不退（第 29 条）；开竣工期限（第 15 条）、逾期开工违约金（第 32 条）、满 1 年闲置费 20%、满 2 年无偿收回。
    • 房地一致两条路径（依划转文件转移登记 / 处置后拆除注销），不得写「更名」；拆除路径与价款档位联动。
    • 出让金不得与征收等政府安排挂钩：收支两条线、不得减免缓缴、征收补偿费须在征收决定前足额到位。
    • 边界：已有政府书面计价文件→核对计价依据、比例、集体决策记录，与地方规则不一致的写入成稿说明由律师决定是否提示客户；价款明显低于地方比例下限或基准地价 70%→提示「低于最低价出让」问责风险；客户拟以子公司作受让人→转第三步方案 B 论证；价款涉及建设用地指标→核对是否需购买指标、价款是否已含，并在书面计价文件中一并确认。

    做法

    1. 先读取第二步的登记时间与出让合同首次转让条件；读引用库第四、六节（方案 B 另读第一、二节）；国有企业读交易程序引用库第三、八节与主体资格陷阱的国企部分；读所在城市的转让管理办法。
    2. 定性——作价出资就是转让：建设用地使用权可以出资；以房地产作价入股、与他人成立企业法人、权属变更的属于房地产转让；出资导致使用权转移的视为转让；地方转让办法通常也把作价出资（入股）列为转让。转让条件为已付清全部出让金并取得证书、属于房屋建设工程的完成开发投资总额 25% 以上（地方办法可能明确 25% 不含土地价款和相关税费，或以动工面积达三分之一替代；示范文本第 20 条同）。结论：补办出让后立即出资至少面临两重障碍——全款缴清并取得证书前不能过户；尚未开发投资不满足投资条件。
    3. 出资协议效力与出资责任：物权变动合同与登记相区分；强制性规定规制履行行为的不因违反而无效；最高人民法院第一巡回法庭参考观点认为第 39 条条件不是效力性强制性规定——但须注明：协议约定未满足条件即须过户的可能落入「合同履行必然导致违反强制性规定」的但书；九民纪要没有提到第 39 条，不能引作支持；一巡观点只是参考观点。以非货币财产出资须依法办理财产权转移手续，未按期足额缴纳承担赔偿责任，经催缴可失权。落地建议：出资协议中把「达到转让条件」设为土地过户的先决条件，并在五年认缴期内合理设定出资期限。
    4. 比较四条路径并写做法、依据、前提与障碍、适用：A 预告登记、先投入后转让（原使用权人补办出让、缴清价款、取得证书后与项目公司签出资协议并预告登记，项目公司凭预告登记证明办规划建设环评消防手续并开工，达到条件后过户；须有现行有效的地方规定、主管部门转让审查意见与履约协议；过户前出让合同义务仍在原使用权人身上须约定由项目公司履行；预告登记有 90 日失效规则；地方有接续规定时作基础方案）；B 划转或转让给关联主体后由其补办出让（时间宽裕、地上物权属清晰、政府明确同意且书面确认受让方资格时）；C 合作开发合同（一方有资质即有效，但提供土地一方不承担经营风险只收固定利益的认定为转让仍受第 39 条限制，国企直接成为开发主体与国资规则冲突更明显，一般不建议）；D 股权层面合作（土地已在项目公司名下时以股权转让或增资引入合作方，股权转让不征契税，须先完成 A 或 B 且走国资进场程序）。无论选哪条，建议在出让合同、监管协议或政府审核意见中事先写明后续可采取的联营、入股方式及转让条件；地方城市更新条例对实施主体有规定的，报批实施方案时一并明确项目公司能否作为实施主体。
    5. 客户拟集团内划转或协议转让的（方案 B），逐项写五个判断要点：①定性——无偿划转、协议转让都按划拨土地使用权转让对待，须经有批准权的人民政府批准；受让方不是目录所列用地主体或用途已改的须有偿使用；②房地一并——只转土地、房屋另行处理的安排与暂行条例第 23 条、《民法典》第 356、357 条和地方一并转让条款冲突，补办申请须附地上建筑物产权证明；③受让人如何确定——114 号文 7.1「由受让人办理协议出让」以 7.5 公开交易确定受让人为前提，不是为指定受让人预留的通道；受让方不再是原土地使用权人的，6.1 协议补办和地方「自主改造」的申请资格、按比例计收可能随之丧失；④办理顺序——先收回划拨决定书、注销划拨登记、签出让合同，后办登记，没有「先把划拨地登记到受让方名下、再补办」的路径；地方对政府同意的划转另有「先办有偿用地手续、再办转移登记」规定的，核对文义是否涵盖企业集团决定的划转并取得解释机关书面意见，取不到的退回由原使用权人作申请人补办出让、再走方案 A，出资主体与持股安排相应调整；⑤评估与税费先定性——有偿协议转让（如按账面净值）不在 12 号令第 7 条免评估之列；无偿划转与有偿转让在契税、增值税（视同应税交易）、企业所得税上处理不同，定性后再测算。
    6. 比较合资项目公司两种设立方式（土地方以出让土地作价出资、合作方以货币出资，最终股权结构相同）：方式一先设全资子公司再增资扩股引入合作方——属企业增资，遴选前完成审计、评估及备案，进场公开征集投资方且资格条件不得有明确指向性，与特定合作方协议增资须经同级国资机构批准；合作方在产权交易机构公开竞争产生不能事先锁定；多一轮增资决策、审计评估备案、进场和变更登记，仅披露期就不少于 40 个工作日；增资时土地通常只有预告登记项下权利，过渡期全资持有以住宅开发为目的的公司非房地产主业企业须先取得集团书面意见，一人公司须防财产混同；唯一可能的契税节省是「母公司以土地、房屋权属向其全资子公司增资，视同划转，免征契税」，但文义是「增资」、以土地出资设立能否适用未明确，宜先货币设立再以土地增资，过户时已非全资能否维持、2027-12-31 后能否延续都不确定，须事先取得主管税务机关书面意见。方式二直接共同出资新设——不属于企业增资或产权转让，以土地作价出资是否属于须进场的资产转让按对外投资理解可不进场但无直接规定、取得集团书面确认；按集团批准的遴选办法公开征集、评审、决策，做尽调且不选择与领导人员存在特定关系的合作方；无产权交易机构环节的法定期限；设立即为参股企业，设立时股东对出资不足相互承担连带责任，国有企业不得先于其他股东缴纳出资，约定合作方货币出资不晚于土地过户；项目公司作为承受方缴纳契税。判断要点：程序、时间和契税以外的费用通常方式二占优且自始符合参股定位；方式一的优势是公开竞争、价格发现，集团要求进场或认定作价出资须进场的选方式一；契税节省在取得税务机关书面意见前不计入比较；两方共同控制且达到申报标准的，须在设立登记（方式二）或增资变更登记（方式一）前申报经营者集中。
    7. 开发资质：未取得资质不得从事开发经营，资质证书不得出租、出借、转让，二级资质可承担建筑面积 25 万平方米以下的项目；新设项目公司不能承继股东的资质，只能以自身人员与条件申请（通常为二级），须核对项目规模是否在二级范围内；设立条件见《城市房地产开发经营管理条例》第 5、9 条，项目资本金不低于总投资的 20%，注册资本与股东投入安排要与之衔接。
    8. 国有企业的国资监管逐项写：是否房地产主业（主业经国资委确认；2010-03-18 国资委发布会房地产主业中央企业 16 户、另有 78 户非主业企业须在完成自有土地开发等阶段性工作后退出；以公开信息为准，2010 年名单之后的重组更名不作推断）；负面清单（禁止类一律不得投资，特别监管类报国资委审核；负面清单不公开，无法确认分类，结论以「存在……的实质风险」为限）；以参股方式开展（41 号文第 6 条不得通过参股等方式开展负面清单禁止类业务，第 33 条废止曾点名商业性房地产的 126 号文；非房地产主业企业参股商品住宅项目在取得集团、必要时国资委书面意见前存在被认定为通过参股开展禁止类业务的实质风险）；参股的定义与控制力（持股不超过 50% 且不具有实际控制力；联签审批权、一票否决等应限于保护性权利以免影响「参股」认定）；有利口径（205 号文支持国企以自主、联营、转让盘活存量土地，地方通道允许联营、入股；可以「主业企业控股并主导开发 + 原使用权人仅以存量土地参股 + 不新增其他房地产投资」作为向集团请示的基础方案，但不能替代集团决策）；决策与追责（取得意见、完成决策后再实施）；评估与备案（土地出资、增资导致国有股比变动的均须评估，价格低于评估结果 90% 的应暂停交易；免评估只限 12 号令第 7 条——政府或国资机构批准的无偿划转、国有独资企业与其下属独资企业之间的合并置换无偿划转——和中央企业适用的 8 号文二（一）所列情形，须核实双方股权结构；有偿协议转让不在豁免之列；以土地出资仍须评估作价）；增资进场（增资由国家出资企业决定；遴选前完成评估备案；公开征集投资方，披露不少于 40 个工作日——预披露加正式披露合计不少于 40 个工作日、其中正式披露不少于 20 个工作日，产权转让则正式披露不少于 20 个工作日；资格条件不得有明确指向性；与特定国有企业协议增资须符合第 45 条并经同级国资机构批准；中央企业的增资在国资委确定的权益类产权交易机构进行）；共同出资新设（不属于企业增资或产权转让；仍须履行投资决策、评估与备案程序，并同样受第 39 条限制）。客户援引而官方渠道检索不到的上级文件，客户成稿写「我们未能取得该文件文本，本法律备忘录未据此作出分析」，请客户提供原文，不按客户转述分析。
    9. 参股治理（41 号文第 8、10、11、12、18 条）转化为合资协议与章程条款建议：不得以股权代持或「名为参股合作、实为借贷融资」的名股实债方式合作；投资协议或章程须明确分红权、人员委派、特定事项否决权、股权退出；达到一定额度的参股投资纳入「三重一大」由集团决策；不为其他股东出资垫资、不先于其他股东缴纳出资、非货币出资公允作价；不超股权比例提供担保。建议约定：合作方的出资及开发资金投入义务；董事、监事委派；重大事项表决机制（增减资、担保、关联交易、利润分配、清算）；资金监管与财务知情权；控股方为项目融资增信；分红与剩余财产分配；僵局解决与退出。
    10. 毗邻土地：政府储备的经营性用地只能以招拍挂出让，出让公告不得设定影响公平、公正竞争的限制条件，项目公司只能以普通竞买人身份参加；地方城市更新立法可能允许多宗经营性用地整体供应、同场竞买但不能事先锁定结果；核对相关宗地出让公告（竞买人资质要求、合规自有资金要求、拍卖日期）；宗地若先于合作落地被他人竞得则整合开发设想落空，合作条款要考虑单独开发的经济性。
    11. 税负提示四项：土地增值税（改制重组以房地产作价入股暂不征，但房地产转移任意一方为开发企业的不适用，向开发项目公司出资原则上不能享受）；契税（母公司以土地向全资子公司增资视同划转免征，以「全资」为前提，预告登记方案下过户时项目公司可能已非全资，「出资设立」是否等同「增资」须与税务机关确认，纳税义务发生于签订权属转移合同当日、登记前申报，政策执行至 2027-12-31）；企业所得税（非货币性资产投资所得可在 5 年内分期计入，5 年内转让股权停止递延；集团内划转的特殊性税务处理以账面净值划转、双方不确认损益、12 个月内不变化等为条件，按评估值作价或随即引入控股方的难以适用）；增值税（作价出资属应税转让税率 9%，非货币对价按市场价格确定销售额，集团内无偿划转可能视同应税交易；5% 简易计税并扣除取得原价只适用于 2016-04-30 前取得的土地使用权且交易在 2027-12-31 前发生，补办出让或划转后取得的能否适用须与税务机关确认，确认前按 9% 做敏感性测算）。不同方案税负差异大，建议确定方案前做专项税务论证；客户成稿不给税额结论。

    内置规则

    • 转让条件：已付清全部出让金并取得证书 + 属于房屋建设工程的完成开发投资总额 25% 以上（地方可明确不含土地价款和相关税费，或以动工面积达三分之一替代）；示范文本第 20 条同。
    • 合同效力三点注意：但书（约定未满足条件即过户）；九民纪要未提第 39 条不能引作支持；一巡观点只是参考观点，写明性质。
    • 路径表 A/B/C/D：A 预告登记先投入后转让为地方有接续规定时的基础方案；B 划转或转让给关联主体后补办出让须按转让对待；C 合作开发合同一般不建议；D 股权层面合作须先完成 A 或 B。
    • 方案 B 五个判断要点：定性为转让须政府批准与有偿使用；房地一并；受让人须经公开交易确定、原使用权人资格可能丧失；办理顺序先收回划拨决定书注销登记再签出让合同；评估与税费先定性。
    • 两种设立方式比较六项：国资交易规则、合作方的确定、时间（方式一仅披露期不少于 40 个工作日）、过渡期与出资责任、契税、经营者集中；判断要点为程序时间和契税以外费用通常方式二占优，集团要求进场的选方式一，契税节省未经税务机关书面确认不计入。
    • 国资结论强度一律以「存在……的实质风险」为限，等集团书面意见；负面清单不公开不作分类推断；2010 年名单后的重组更名不作推断。
    • 参股定义：持股不超过 50% 且不具有实际控制力；联签审批权、一票否决限于保护性权利。
    • 评估：土地出资、增资导致国有股比变动均须评估；价格低于评估结果 90% 应暂停交易；免评估仅限 12 号令第 7 条与 8 号文二（一）情形。
    • 增资进场披露：不少于 40 个工作日（预披露加正式披露合计不少于 40、其中正式披露不少于 20）；产权转让正式披露不少于 20 个工作日；资格条件不得有明确指向性。
    • 资质：二级资质承担建筑面积 25 万平方米以下项目；新设项目公司不能承继股东资质；项目资本金不低于总投资 20%。
    • 税负四项：土地增值税改制重组优惠不适用任一方为开发企业；契税免征以「全资」为前提、执行至 2027-12-31；企业所得税非货币资产投资所得 5 年分期、5 年内转让股权停止递延；增值税作价出资 9%，5% 简易计税限 2016-04-30 前取得且 2027-12-31 前交易。
    • 边界：土地方为民营企业→删国资部分，保留转让、资质、税负，合作开发合同方案空间更大；合作方不是房地产主业企业或没有资质→重新评估项目公司资质与合作开发合同效力；地方没有预告登记接续规定→方案 A 改为「原使用权人自行投资达到 25% 后再转让」或股权层面合作并说明时间与资金代价；出让合同已签且未预留合作条款→评估补充协议或变更的可能，不作承诺。

08交付前检查

  • 三步写完后回到第一步，复核签约前提清单是否完整
  • 现状事实五项已固定并注明来源；规划前提三项已写
  • 第①层反向规定已写未省略；第②层除外条款与「可能被触发」的风险已写；第③层每个前提都有对照状态且同一地方文件的反向条款已摘录
  • 地方文件有效期与失效状态已核对；客户援引的文件逐条判定；申请表、时间表、合作协议的效力已说明
  • 结论按三种情形之一写并列出签约前提；替代路径与停用收回风险已写
  • 价款公式、集体决策、公示与最低价已写；地方计收比例、当前档位、届满日、完成节点不明的风险已写
  • 单价、总额、现金与非现金口径已复算，矛盾已写入成稿说明；分期政策适用对象已核对；契税等税费按全额另列未随价款分期；全款后登记与客户时间表的矛盾已指出
  • 出让合同形式、出让期限起算、首次转让条件、开竣工期限、违约与解约条款已写；房地一致处理路径不写「更名」；资金来源限制与内部决策程序已写；出让金未与征收等政府安排挂钩
  • 作价出资即转让的定性与第 39 条、地方 25% 口径已写；合同效力（含但书）与出资责任已写并给出过户先决条件建议
  • 至少比较 A、B、C 三个方案并写明依据、障碍与推荐；涉及划转或转让给关联主体的方案 B 五要点逐项写；两种设立方式已比较，契税节省未经税务机关书面确认不计入
  • 资质不可承继、二级规模校验、资本金比例已写；国企主业、负面清单、参股定义、追责、评估备案、增资进场逐项写且结论以「实质风险」为限；客户援引而检索不到的文件按「未据此分析」处理
  • 参股治理要求已转化为合资文件条款建议；毗邻土地竞买规则与相关公告状态已核对；税负提示四项已写、未给税额结论
  • 客户成稿正文无内部标记；成稿说明含客户材料问题表、发送前请律师确认、核验来源表、复核情况；交付前输出 REVIEW_STATUS

09何时暂停或升级

  • 阻断项出现即暂停提问：我方身份不清、委托问题不清、参考稿或模板的排除规则不清、写入目标可能覆盖原件
  • 国有企业主体、亿元级价款、政府设定签约时限任一情形即为 critical，第一次实质检索或起草前输出 INTAKE_DECISION
  • critical 事项由不同模型在新上下文中独立复核，复核意见的处理写入成稿说明
  • 国资监管类结论等集团（必要时国资委）书面意见；契税节省等税务结论等主管税务机关书面意见；地方划转条款能否涵盖企业集团决定的划转等解释机关书面意见
  • 客户援引而官方渠道检索不到的上级文件，请客户提供原文，不按转述分析
  • 对客户价值大但措辞须律师把握分寸的点（如价款可能多算、政府书面计价文件与地方规则不一致），写入成稿说明由律师决定是否提示客户
  • 不给税额结论，建议确定方案前做专项税务论证

10请律师重点核对

下面是这个流程内置的法律假设、立场、阈值和清单，每一条都可以同意、反对或补充。条目下的「相关批注」按文字重合自动匹配到步骤旁的核对条目，可能不全。

  1. 供地方式判断强制「三层不跳层」并把国家一般规则（《民法典》第347条第2款、39号令第4条等）作为必写的反向依据，「只引地方有利文件的稿子不得交付」——这一交付底线是否符合贵所对客户成稿的尺度？
  2. 前提全部具备时结论措辞固定为「具有相应的政策依据」并必附残余风险（出让合同效力可能被质疑、审计或巡视可能认定规避招拍挂）；前提不具备时固定为「缺乏充分依据」——这两档措辞是否过于保守？相关批注：核对 1.1
  3. 前提未提供时，把「有权机关就以协议方式补办出让、用于商品住宅出具的书面依据确认」列为签约前提——当地政府实践中是否会出具此类书面确认？是否应改为更可操作的前提？相关批注：核对 1.2
  4. 明确禁止「补办出让不属于设立，因而不适用第347条」这类无出处的理论论证——贵所是否认同这一限制？
  5. 出资协议效力部分采纳一巡参考观点（第 39 条条件非效力性强制性规定），同时提示但书、九民纪要未提第 39 条、一巡观点只是参考——对合同效力的这一把握与贵所立场是否一致？相关批注：核对 3.1
  6. 国资监管结论强度一律限于「存在……的实质风险」并等集团书面意见；参股的联签审批权、一票否决被限定为保护性权利——是否符合贵所对 41 号文「参股」认定的理解？相关批注：核对 3.3
  7. 合资项目公司设立方式比较预设「程序、时间和契税以外的费用通常方式二（直接共同出资新设）占优」，且「契税节省未经税务机关书面确认不计入比较」——这一比较基准是否认同？相关批注：核对 3.2
  8. 补办出让分期采用财综〔2009〕74号口径（原则上不超过一年、特殊两年、首期不低于 50%）并明确地方招拍挂分期政策（如「首期 50%、1 个月内、余款 1 年、不计息」）不得套用到补办出让——贵所所在地是否有相反实践？相关批注：核对 2.1
  9. 替代路径中「协商收储补偿按新规划用途市场评估价一定比例」要求与客户自估对比，但 SKILL.md 未给出比例区间——是否由律师补充当地口径？相关批注：核对 1.3
  10. 合作开发合同路径（方案 C）被定为「一般不建议」，理由是提供土地方不担风险只收固定利益会被认定为转让、国企直接成为开发主体与国资规则冲突——这一立场是否绝对？相关批注：核对 3.4
  11. 临时模式默认「律师角色；土地使用权人立场；保守型风险提示」，与插件整体默认的中立审查不同；立场来自委托关系（土地使用权人 / 拟合作的开发企业 / 政府平台公司）——默认立场是否合适？
  12. 地方规则目前只有成都样板；其他城市须现场检索并按同一结构建库，SKILL.md 对「所在城市没有地方通道」只规定「结论更保守，签约前提更多」而未规定具体写法——律师可补充。相关批注：核对 1.5
  13. 停用收回风险要求「表述克制，作背景风险写，不要写成威胁」；房地一致处理明确不得写「更名」；税负只提示不给税额、增值税确认前按 9% 做敏感性测算——这些措辞与处理规则是否符合贵所文书习惯？相关批注：核对 3.5、核对 1.4、核对 2.3
