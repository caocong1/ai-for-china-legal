01概要

用四轮访谈首次填写或更新本领域的实践配置：主体画像与项目组合，审查与争议立场，风险校准与升级矩阵，文书风格与地方规定。答案填进配置的对应位置；跳过的问题留空待填，涉及司法解释条号、期限、金额标准等法律事实的，保留 [待验证] 标注，不因用户口述而去掉。配置只有一份，所有建设工程流程都从这里读取，律师也可以直接修改，修改记录可以追溯。四轮可以连着做，也可以只做其中一轮来更新某一章；不想访谈的，只告知代理立场即可按临时模式工作。完整访谈约需 10–15 分钟。

02适用与边界

适用场景

  • 首次使用建设工程各流程，配置还没有填写
  • 代理立场变化（如从承包人侧转为发包人侧，或新增商品房业务），只需更新「审查与争议立场」
  • 团队权限、金额升级阈值或自动升级清单调整，只需更新「风险校准」与「升级矩阵」
  • 更换文书风格、造价鉴定机构或主要业务省市，只需更新「文书风格」与地方规定
  • 任一流程读取配置时发现「建设工程角色」「整体代理立场」或「谁在使用」的角色还没填写

不做什么

  • 不处理具体案件或文书，只收集偏好并写进配置
  • 律师可以直接修改配置，不必为改一处重做访谈
  • 不把用户口述的司法解释条号、期限、金额标准写成确定结论，一律保留 [待验证] 标注

03输入与产出

需要提供

  • 访谈回答必需
    每题都可答「不确定 / 暂不填写」跳过，该项留空待填
  • 只更新某一部分的说明（如「只更新审查立场」）可选
    只做对应的那一轮访谈
  • 现有的建设工程实践配置必需
    访谈结果写进配置的对应章节；重做时覆盖原答案
  • 跳过访谈时的代理立场（发包人侧 / 承包人侧 / 购房人侧 / 中立）可选
    按临时模式工作，其余项用默认值并标 [临时模式]

产出

  • 填好的建设工程实践配置读者：律师内部
    我们是谁（含建设工程角色、项目类型组合）、谁在使用、可用集成、审查与争议立场（含三小节）、风险校准、升级矩阵、文书风格、输出、共享护栏各章

04开始前

前置条件

  • 读取本领域的法律依据引用规范，用于核对访谈中口述的法律事实
  • 读取本领域的实践配置说明：每题写进配置哪一处、临时模式的默认值
  • 本领域的实践配置模板已存在，访谈结果填进其中对应章节

硬性规则

写入原则
答案填进配置对应章节的空白处；跳过的问题留空待填；涉及司法解释具体条号或法律事实的，保留 [待验证] 标注，不因用户口述而去掉。
配置只有一份
访谈结果只写进本领域的实践配置，不另建配置表；访谈完成后，所有建设工程流程都只从这份配置读取。
口述事实先核对
口述条号、期限、赔偿数额、规模标准的，写入前先复述自己的理解请用户确认，并标「前提需核实」；口述的司法解释条号标 [待验证 — 司法解释条号易变，须核实现行版本]。
临时模式默认值
不访谈只告知代理立场的，其余按默认值标 [临时模式]：中立审查（双向呈现风险）、保守型、商品房双向提示、标准四级风险、结构化分析文书、涉及地方问题时提醒核实。
更新方式
可以完整访谈，也可以只做其中一轮更新某一章，或直接修改配置；配置的修改记录可以追溯。

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置判断，可逐条复制。

  1. 主体画像与项目组合

    可单独使用

    填好「我们是谁」「谁在使用」「可用集成」三章；成果标题、项目类型识别和资质判断都以此为据。

    请律师核对

    • 核对 1.1实体类型 6 项、代理角色 8 项、合同对手方 7 项，是否覆盖贵所业务？EPC 总承包商、代建单位、政府平台公司、实际施工人都没有单列。
    • 核对 1.2非律师使用者一律用「研究笔记」标题，是否符合贵所内部法务的使用习惯？
    • 核对 1.3平台清单 8 项，是否要加入地方公共资源交易平台、信用中国、裁判文书网以外的案例库？

    做法

    1. 开场说明每题都可以跳过（答「不确定 / 暂不填写」），之后也可以直接修改配置。
    2. 问主体画像与建设工程角色：组织、律所或企业名称；实体类型六选一（律所建设工程部门、发包人即建设单位法务部、承包人即施工方法务部、房地产开发商法务部、造价咨询机构、其他）；主要代理角色（可多选：发包人、施工总承包、专业分包、监理单位、造价咨询方、房地产开发商、购房人代理、多角色混合并说明主要比例），这是审查立场默认值的核心输入，第 2 步再细化；典型合同对手方（政府或国企发包人、民营发包人、大型施工总包、中小施工企业、专业分包、购房人、混合）。
    3. 问项目类型组合：主要项目类型（可多选并说明比例：房屋建筑、市政基础设施、装饰装修、机电安装、公路、水利、电力、商品房买卖含预售合同审查、其他专业工程、多类型混合）；典型项目规模与造价区间（例如单项目 500 万至 5000 万、商品房项目 1 亿以上）；主要痛点（例如工程款拖欠、工期索赔、黑白合同、转包分包、商品房逾期交付、资质核查）；团队规模；负责人或联系人。
    4. 问谁在使用：使用者角色六选一（建设工程律师；发包人内部法务、承包人内部法务、监理人员、造价咨询人员，均有律师可咨询；非律师且无律师可咨询，须明确提示），角色决定成果标题；非律师的，问律师联系人。
    5. 问可用资源：工程造价咨询或鉴定机构（已委托并写明机构名 / 未委托、可按需委托 / 不适用），影响工程款争议流程走结算还是鉴定；八个平台逐项确认可用、不可用或需配置：全国建筑市场监管公共服务平台（资质、业绩）、中国招标投标公共服务平台、国家企业信用信息公示系统（失信核查）、网签备案系统、中国裁判文书网、项目管理或 OA 系统、文档存储、企业微信或钉钉。
    6. 访谈中口述法律事实的先核对：引用建设工程合同条号的标 [待验证]，提示到官方数据库核实；口述项目规模阈值的，提示必须招标规模标准因项目类型与地方而异，标「前提需核实」；口述商品房预售条件的，提示受地方规定影响，标「地方规定需核实」；复述时的说法是「你提到 [X]；我的理解是 [Y]。建设工程司法解释修订频繁，请确认是否要按此填入配置？」；结束后把 13 项回答逐项写进配置，答「不确定 / 暂不填写」的留空待填。

    内置规则

    • 使用者角色决定成果标题：律师用「律师工作产物 — 受律师-当事人特权保护 / 保密」；非律师用「研究笔记 — 非法律建议，供律师审查」。
    • 选「多角色混合」的，追问主要比例，并提示在第 2 步逐项设定立场。
    • 非律师且无律师可咨询的，明确提醒所有成果都是研究笔记，须律师审查后才能作出法律结论。
    • 实体类型与角色不一致（如律所选「购房人代理」）不算冲突，两种描述都保留。
    • 项目类型含商品房买卖的，提示还需在第 2 步设定商品房审查立场（购房人侧或开发商侧）。
    • 资源未接入时核心功能照常工作，造价鉴定数据、资质信息由用户手动提供。

    产出

    配置中「我们是谁」（含建设工程角色、项目类型组合）、「谁在使用」、「可用集成」三章填写完毕。

  2. 审查与争议立场

    可单独使用

    确定整体代理立场、审查严格度、争议处理倾向和商品房审查立场；立场不同，同一份合同的结论可能截然相反。

    请律师核对

    • 核对 2.1五种立场各自预设的关注清单（如发包人侧「结算高估冒算防控」、承包人侧「无效合同折价补偿」）是否贴合贵所实践？
    • 核对 2.2三档严格度的定义，尤其「保守型＝任何可能不利的条款都标红」，是否会产生过多标记？
    • 核对 2.3面积误差 3% 作为购房人侧与开发商侧的处理分界，以及「双倍返还超出部分」的说法，是否需按现行司法解释复核？
    • 核对 2.4争议解决机构只列北京仲裁委员会、中国国际经济贸易仲裁委员会、当地仲裁机构和人民法院四类，是否需加入上海、深圳等常用仲裁机构？

    做法

    1. 问整体代理立场五选一，每项附关注清单：发包人侧（承包人资质核查、工期质量违约追责、结算高估冒算防控、合同无效风险防控）；承包人侧（足额结算保障、工期顺延签证、无效合同折价补偿、优先受偿权行使时机）；中立审查（识别显失公平条款、双向争议点、合同缺口）；购房人侧（预售资质与五证、逾期交房违约救济、面积误差处理、贷款不成解除、网签保护）；多场景混合（说明主要组合及比例）；另可补充立场说明（如「绝大多数为承包人侧，偶尔承接发包人方尽职调查」）。
    2. 问审查严格度三选一：保守型——任何可能对代理方不利的条款都标红，优先识别风险；平衡型——重大风险标红、一般风险标橙，优先商务对话；进取型——只拦截明显不利条款，一般条款尽量放行；再问各立场的保守重点（供参考）：发包人侧——承包人资质核查要求、价款调整封口条款、结算逾期答复条款、违约金基数与上限；承包人侧——签证权限与期限、工期顺延事由是否完整、变更程序（口头指令的书面确认）、进度款支付条件、质保金返还期限与条件；购房人侧——逾期交房或办证违约金的封顶条款、面积误差条款是否排除法定规则、预售资质核查。
    3. 问争议处理倾向：优先路径（协商优先 / 造价鉴定优先，适用于争议金额大或结算依据不足 / 仲裁优先，适用于有仲裁条款且倾向非公开 / 诉讼优先 / 视情况）；承包人优先受偿权（《民法典》第807条，建议复核）的行使倾向（积极行使，拖欠即评估启动 / 仅在金额重大时 / 以启动作为催款手段 / 不适用，我方通常是发包人侧），并提示行使期限须核实现行司法解释版本 [待验证 — 司法解释条号易变，须核实现行版本]；争议解决机构偏好（北京仲裁委员会 / 中国国际经济贸易仲裁委员会 / 当地仲裁机构，注明地区 / 人民法院 / 视合同约定）。
    4. 项目类型含商品房买卖的，再问商品房审查立场：代理方向（购房人侧——五证合规、逾期违约金不被封顶、面积误差超 3% 退款或解除、按揭不成无责解除；开发商侧——确认五证合规、限制过高违约金、面积误差据实结算、约定贷款不成的可归责情形；中立）；逾期违约金容忍度（购房人侧严格，任何封顶条款都标红 / 开发商侧宽松，可接受约定上限 / 视约定数额）；面积误差处理（购房人侧超 3% 即评估追究，解除或双倍返还超出部分 / 开发商侧尽量在误差范围内解决，3% 以内据实结算 / 中立，按面积误差比的实际数值分析）；退房条件容忍度（口头描述即可）。
    5. 口述法律事实的先核对：口述优先受偿权行使期限的，标「前提需核实」（须核实现行司法解释版本）；口述仲裁时效的，标「前提需核实」（须核实现行规定）；口述商品房违约金比率或上限的，提示须与合同约定及司法解释调整规则对照，标「前提需核实」；违约金率明显偏高或偏低的，参照《民法典》第585条第2款的调整规则（建议复核）提示核实。
    6. 把答案写进「审查与争议立场」章及「合同审查严格度」「争议处理倾向」「商品房审查立场」三小节；写完提示配置的修改记录可以追溯。

    内置规则

    • 选「多场景混合」的，记录比例描述，并提示在临时模式下每次都须明确告知代理立场。
    • 不确定审查严格度的，默认保守型并标 [临时模式]，提示这是稳健做法。
    • 没有商品房业务的，商品房各题全部跳过，商品房审查立场留空待填。
    • 面积误差 3% 是购房人侧「评估追究」与开发商侧「据实结算」的分界。
    • 不要把「中立」当作未经思考的默认值：真正的中立审查是双方风险均衡呈现，而不是不设立场。

    法律依据

    • 《民法典》第807条 — 承包人工程价款优先受偿权（建议复核；行使期限须核实现行司法解释版本 [待验证]）
    • 《民法典》第585条第2款 — 违约金过高或过低的调整规则（建议复核），用于口述违约金率的合理性检查

    产出

    「审查与争议立场」章（整体代理立场、立场说明）及审查严格度、争议处理倾向、商品房审查立场三小节填写完毕。

  3. 风险校准与升级矩阵

    可单独使用

    设定四级风险、角色权限、自动升级条件和诉讼、仲裁、优先受偿权的触发时机，让事务在正确时点交给有资质的律师。

    请律师核对

    • 核对 3.1优先受偿权期限「30 天内升级」与「60 天以上低风险」之间的 30–60 天没有定级，是否要补为中等或高风险？
    • 核对 3.2工程款升级阈值示例 500 万 / 2000 万是否贴近贵所案件规模？
    • 核对 3.3面积误差 ±2%～3% 定为中等风险、超过 3% 由第 2 步的立场决定是否追究，这样分级是否合理？
    • 核对 3.4高风险清单中「进度款长期拖欠超过 3 个月」「变更签证超出约定期限」两个默认示例是否合适？

    做法

    1. 确认关键风险与高风险的默认触发情形（可勾选、修改或补充）：关键风险须立即处理——合同因转包、违法分包、必须招标而未招标、黑白合同可能无效（须律师出具效力意见），优先受偿权期限临近（期限须核实现行司法解释 [待验证]），收到合同解除通知或起诉、仲裁申请，工程质量存在重大安全隐患，商品房群体性退房风险（多户同时主张）；高风险须采取行动但不需立即升级——承包人资质有问题（证书不全、超范围施工），结算依据不足或结算金额有重大争议，变更签证未按时确认（超出约定期限 [待验证]），进度款长期拖欠（超过多久留空待填，示例 3 个月），逾期交房或办证违约金数额较大，商品房预售手续不完整（五证缺一）。
    2. 确认中等风险与低风险的默认情形：中等——合同约定不明确可能引发纠纷，工期顺延条件限制较多，面积误差接近 3% 临界值（±2%～3%），造价鉴定申请条件有争议，保修条款不完整或质保金返还期限不明确；低——主体资质核查无问题（资质等级符合、无失信记录），合同条款明确公平，商品房五证齐全且预售许可在有效期内，优先受偿权期限尚早（离截止日 60 天以上 [待验证期限]）。
    3. 设定角色权限与金额阈值：初级人员（内部法务、助理律师）可独立处理合同初步审查（资质查询、条款对比、标准条款分析）、招标文件合规初步审核、逾期通知或催款函草稿、工程款主张材料整理、商品房审查信息收集（五证核查、备案查询）；须升级的情形（可多选）：合同可能无效、工程款重大争议（超过多少留空待填，示例 500 万）、作出解除判断或发送解除通知、行使优先受偿权、重大索赔诉讼或仲裁策略决策、商品房群体性退房；工程款或索赔金额升级阈值（示例：单项争议超过 500 万须升级，超过 2000 万须合伙人介入）。
    4. 确认自动升级清单（默认全选、可调整、可新增）：合同可能无效；工程款数额重大（超过上述阈值）；拟行使优先受偿权（启动前须律师确认期限与程序 [待验证]）；收到解除通知或起诉、仲裁申请；商品房群体性退房；优先受偿权期限临近（离截止日 30 天内 [待验证]），须主动提示并升级。
    5. 设定诉讼、仲裁与优先受偿权的触发：工程款拖欠后何时启动仲裁或诉讼（催款函发出后多少天无回应留空待填，示例 30 天；明确拒绝支付；优先受偿权期限临近；金额超过阈值）；是否行使优先受偿权的考虑因素（期限为首要因素，须核实 [待验证]；是否已进入诉讼或仲裁；金额；发包人资产状况；是否已竣工交付，影响行使条件 [待验证]）；收到对方解除通知的标准程序（立即升级主办律师、评估解除条件是否成就、准备已完工程验收与结算证据、视情况发异议函）；商品房违约或退房触发升级的情形（逾期交房或办证累计超过多久留空待填，示例 6 个月，且购房人发出解除通知；一房二卖或房屋被查封、抵押；群体性退房；贷款不成后购房人主张无责解除）。
    6. 口述法律事实的先核对后写入：口述优先受偿权期限（如「6 个月」「18 个月」）的，标「前提需核实」（须核实现行司法解释版本）；口述工程款诉讼时效（如「3 年」）的，提示适用《民法典》诉讼时效的一般规定、起算点须确认 [待验证]；口述仲裁时效的，标「前提需核实」（注意仲裁时效与诉讼时效的区别）；口述必须招标金额标准（如「200 万以上」）的，提示因项目类型与地方而异，标「前提需核实」；写入「风险校准」四级表和「升级矩阵」三小节，选「视情况 / 不确定」的留空待填，司法解释期限保留 [待验证]。

    内置规则

    • 四级风险：关键（明显违法或重大权益受损，极可能影响合同效力或工程款回收，须立即处理）、高（有较大法律风险或显著权益损失风险，须采取行动）、中等（建议进一步核实或采取预防措施）、低（正常推进，备案记录）；配置中用红、橙、黄、绿四色标记。
    • 自动升级优先于角色权限：六项默认清单一旦触发，无论风险等级都升级。
    • 优先受偿权期限阈值：离截止日 30 天内升级；60 天以上为低风险；具体期限一律 [待验证]。
    • 角色权限三级：内部法务或助理律师、主办律师或合伙人、法务总监或高级合伙人（无上限）；团队很小的简化为两级（本人 / 须转委托）。
    • 没有商品房业务的，商品房违约退房一题跳过，商品房条目保留但标「不适用」；主要为开发商侧的，优先受偿权相关问题标「不适用」，商品房升级触发改为开发商侧视角。
    • 不确定工程款升级阈值的，留空待填，提示以后直接修改配置设定。

    法律依据

    • 《民法典》总则编诉讼时效规定 — 工程款诉讼时效适用通则规定，计算起点须确认 [待验证]
    • 建设工程施工合同司法解释关于优先受偿权行使期限的规定 — 具体期限 [待验证 — 司法解释条号与期限易变，须核实]

    产出

    「风险校准」四级表（含典型触发情形）与「升级矩阵」（角色权限、自动升级条件、诉讼仲裁与优先受偿权触发）填写完毕。

  4. 文书风格与地方规定

    可单独使用

    确定四类文书风格、存放与交付、造价资源与地方定额、业务省市与地方重点，让各流程遇到地方问题时自动提示「地方规定需核实」。

    请律师核对

    • 核对 4.1主要业务省市清单只列 9 个地区，其他地区要选「其他」再说明，是否要按贵所业务扩充？
    • 核对 4.2地方造价定额只具名全国、北京、广东、上海四种，是否要补充贵所常用地区的定额？
    • 核对 4.3地方规定重点关注 8 项，是否遗漏贵所所在地的特殊规定（如地方工程担保、保证金比例）？
    • 核对 4.4阶梯式函件「友好提醒→正式催告→法律声明」三封的模式，是否符合贵所催款惯例？

    做法

    1. 问合同审查意见书结构：结构化分析（主体资质→工期质量→价款结算→违约解除，附风险等级清单和修改建议）/ 摘要式（只列重要风险）/ 对照表式（合同原文对照建议修改，用于谈判阶段）/ 简报式（3–5 个要点加风险结论，向领导汇报）/ 其他；风险标注方式：颜色图标四级加文字 / 纯文字四级 / 只标关键和高风险 / 视成果发给谁而定。
    2. 问工程款主张函件的语气：正式强硬（不留协商空间）/ 正式但留余地（适合长期合作方）/ 阶梯式（友好提醒→正式催告→法律声明）/ 视关系与金额而定；问优先受偿权行使通知有无格式与律师签署要求，并提示行使有期限要求 [待验证 — 须核实现行司法解释版本]，送达方式与时间都有法律意义。
    3. 问争议分析意见书结构：分析框架式（事实→争议焦点→法律依据→胜诉概率→策略建议）/ 问题回答式 / 诉讼仲裁预案式（请求草案、证据清单、抗辩预案）/ 结算鉴定前置式 / 其他；有商品房业务的，再问商品房审查报告形式：购房人侧风险清单加修改建议 / 开发商侧合规核查报告加问题清单 / 双向风险评估 / 五证资质核查摘要（购房前尽调）/ 其他。
    4. 问成果存放与交付，并再确认造价资源：存放位置（内部系统、共享文件夹、项目管理系统、不设固定位置）；交付方式（电子邮件发 PDF、企业微信或钉钉、内部系统提交、纸质打印盖章、其他）；造价咨询或鉴定机构（第 1 步已填的显示已填内容、快速确认：已委托固定机构 / 有意向未委托 / 未委托可委托，问倾向国有、私营还是官方名册内的机构 / 不适用）；地方造价计价定额（全国统一即住建部颁布 / 北京市建设工程费用定额 / 广东省建设工程计价依据 / 上海市建设工程预算定额 / 其他省市定额 / 视项目所在地每次确认）。
    5. 问地方规定：主要业务省市（最多三个：北京、上海、广东含深圳、江苏、浙江、四川、湖北、重庆、山东、其他）；需重点关注的地方规定（可多选：地方必须招标规模标准是否高于国家标准 [待验证]、农民工工资保障专项规定如工资专用账户和保证金、地方造价定额与调价规则、地方施工许可条件与期限、地方商品房预售条件、地方限购限贷政策、建筑企业资质互认 [待验证]、其他）；跨类型项目怎么识别主要类型（按主体工程类型即合同总价值最大者 / 按资质要求 / 按适用法律分别识别 / 每次由用户说明）。
    6. 口述地方事实的先核对后写入：地方必须招标规模标准（如「200 万以上」）标「地方规定需核实」，注明须核实该省市现行标准 [待验证]；定额版本（如「2018 年版」）提示定额定期修订、须确认是否现行 [待验证]；地方预售许可条件标「地方规定需核实」（须核实住建、房产主管部门现行规定 [待验证]）；限购限贷条件提示政策频繁调整，标「时效性需核实」；最后把答案写进「文书风格」（含交付方式）、「可用集成」的造价机构、「共享护栏」的地方性规定提示和项目类型识别，涉及地方规定的保留「地方规定需核实」或 [待验证] 标注。

    内置规则

    • 没有商品房业务的，商品房审查报告一题跳过，该项留空并注明「不适用」。
    • 业务跨多个省市的，全部记录，并提示涉及具体地区时会自动做地方规定检查。
    • 不熟悉造价定额的，说明定额影响结算审核与鉴定，建议向配合的造价咨询机构确认。
    • 第 1 步已填过造价机构的，显示已填内容，问是否更新，快速确认即可。
    • 地方定额选「视项目所在地」的，写入「视项目所在地，每次确认」，并提示各主要省市的定额差异较大。
    • 地方规定默认重点关注四项：地方必须招标规模标准（部分省市高于国家标准 [待验证]）、农民工工资保障专项规定、地方造价计价定额与调价规定、地方施工许可申请条件与期限。

    产出

    「文书风格」（四类文书、存放、交付）、「可用集成」的造价机构、「共享护栏」的地方规定提示与项目类型识别填写完毕。

06主要法律依据

  • 《民法典》第807条 — 承包人工程价款优先受偿权（建议复核），用于设定争议处理倾向与升级触发
  • 《民法典》第585条第2款 — 违约金调整规则（建议复核），用于核对用户口述的违约金率
  • 建设工程施工合同司法解释与商品房买卖合同司法解释 — 优先受偿权期限、面积误差 3% 等具体条号一律 [待验证 — 司法解释条号易变，须核实现行版本]，不因用户口述而去掉

09何时暂停或升级

  • 使用者为非律师且无律师可咨询：明确提示所有成果都是研究笔记；作合同效力判断、发解除通知、行使优先受偿权等有重大法律后果的步骤前，暂停并建议交执业律师确认。
  • 用户口述的优先受偿权期限、诉讼时效、必须招标金额与常见理解不符：先核对并标「前提需核实」，不直接写入。
  • 用户选「多场景混合」立场：提示在临时模式下每次都须明确告知代理立场。
  • 用户不确定升级阈值或严格度：阈值留空待填，严格度按保守型并标 [临时模式]，提示以后可直接修改配置。

  1. 临时模式默认「中立审查」「保守型严格度」「商品房双向提示」，而第 2 步又告诫不要把「中立」当作未经思考的默认值；跳过访谈时要求先告知代理立场，默认值表却仍列「中立审查」。默认立场是否应改为要求用户必答？

  4. 工程款金额升级阈值的示例「单项争议超过 500 万须升级；超过 2000 万须合伙人介入」是否贴合贵所案件规模？相关批注：核对 3.2

  6. 角色权限表预设内部法务、助理律师可以独立准备「逾期通知、催款函草稿」，而「发送解除通知」须升级。草稿与发送的边界这样划分是否符合贵所流程？
