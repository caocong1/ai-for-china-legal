01概要

协助当事人走完法律援助申请全流程：先正式评估是否符合法律援助条件（经济困难、事项范围两个维度），再按案件类型生成材料清单、处理材料瑕疵并整理装订，提交后计算审查期限、按四级预警跟踪进度并处理补正，最后针对批准、补正、不予援助三种审查结果给出衔接、补正或异议与替代渠道方案。开始前读取 legal-aid/CLAUDE.md 中的本地最低生活保障标准、法律援助经济困难标准和民政部门信息，配置缺失时可用「临时模式」并在输出标 [临时模式]；本地经济困难标准未配置的，须先补配置或由用户提供。条件评估逐项对照内置的经济困难认定方式表、免予核查情形表和民事/行政、刑事法援事项表，这些清单均标 [模型知识 — 需验证] [待验证]，涉及各省扩大规定的另标 [管辖 flagged — 需验证地方性规定]；审查、补正、异议的期限在文件中都写作「期限待验证」，须律师核实后填入。遇诉讼时效即将届满、羁押期限即将届满或人身安全受威胁，简化评估、优先提交并申请加急。

02适用与边界

适用场景

  • 当事人询问能否申请法律援助，需要系统判断经济困难与事项范围；客户 intake 流程初评为「建议申请」的可直接进入，未做 intake 也可单独运行
  • 已决定申请，需要按案件类型列出申请材料、指导获取经济困难证明并整理装订
  • 申请已提交，需要登记回执、计算审查期限、跟踪进度并处理补正通知
  • 收到法援机构批准、补正或不予援助的决定，需要制定后续方案、起草异议申请书或寻找替代援助渠道
  • 当事人曾申请被拒，准备针对前次拒绝原因再次申请

不做什么

  • 不作出给予法律援助与否的决定：评估报告注明最终以法律援助机构审查决定为准
  • 不自行假定本地经济困难标准：未配置时须先运行 /legal-aid:style-local-resources 或由用户手动提供
  • 不内置法定期限：审查决定、补正、异议提出与异议审查的期限均写作「期限待验证」，须核实后填入
  • 获批后的案件登记与承办律师指派不在本流程内，转 /legal-aid:case-docket-assignment

03输入与产出

需要律师提供

  • 当事人基本信息与家庭经济状况：家庭人口、家庭人均月收入、是否持有低保证/特困证、支出与负担必需
    收入在标准边缘的要综合支出、负担做个案审查
  • 案件类型与具体事项：民事/行政请求事项，或刑事案件中当事人的身份（犯罪嫌疑人/被告人/被害人）与特殊情形必需
  • 客户 intake 流程的资格初评结论可选
    初评为「建议申请」的可直接进入本流程
  • 前次申请被拒的决定与理由可选
    重复申请时须了解，针对性改进
  • 已有材料：身份证明、经济困难证明、案件证据可选
    材料准备步骤逐项标「已备/待准备/免予」
  • 提交与补正信息：提交日期与方式、收件机构、申请编号、回执编号、补正通知可选
  • 法援机构的审查决定：批准/补正/不予援助的决定书、理由和编号可选
  • legal-aid/CLAUDE.md 实践配置可选
    本地最低生活保障标准、法律援助经济困难标准、免予核查情形、民政部门名称/联系方式/证明开具流程；缺失时提示运行 /legal-aid:cold-start-interview 或说「临时模式」

产出

  • 法律援助条件评估报告给律师内部 / 当事人
    评估日期、评估人、当事人；一、经济困难审查表（家庭人均月收入、本地法援标准、认定方式、结论）；二、事项范围审查表（案件类型、具体事项、是否在法援范围）；三、综合评估结论（建议申请/条件评估中/不符合条件）与下一步；页脚注明本评估为初步评估，最终以法律援助机构审查决定为准
  • 申请材料准备清单给当事人 / 法援机构
    材料清单表（材料名称、状态、获取方式/备注）、待补充材料、获取协助表（需协助事项、联系部门、联系方式）；另按装订顺序整理成册的申请材料
  • 申请提交与审查跟踪记录给律师内部
    提交记录（提交日期、方式、收件机构、申请编号、回执编号）、审查进度（提交日期、审查期限届满日、当前状态）、补正记录（通知日期、期限、提交日期、状态）、预警级别
  • 审查结果应对方案给律师内部 / 当事人
    审查结果摘要、方案一与备选方案二的具体步骤、期限提醒表、替代渠道（如适用）
  • 异议申请书给法援机构
    申请人；申请事项（对某法援中心某日某编号不予法律援助决定提出异议，请求重新审查并给予法律援助）；事实与理由（逐项反驳不予援助理由，提供事实和法律依据）；此致、签名与日期

04开始前

前置条件

  • 开始前读取 legal-aid/CLAUDE.md；缺失时提示运行 /legal-aid:cold-start-interview（约 5 分钟），或由用户说「临时模式」后使用通用默认值，输出标记 [临时模式]
  • 条件评估先从配置读取本地最低生活保障标准和法律援助经济困难标准；未配置时请用户运行 /legal-aid:style-local-resources 或手动提供
  • 加载 legal-aid/skills/_shared/legal-basis-conventions.md（法律援助引用规范）和 legal-aid-citations.md（法律援助高频引用库）
  • 已完成客户 intake 流程且初评结论为「建议申请」的可直接进入；未做的也可单独运行——本流程的条件评估是比初评更深入、更系统的正式评估
  • 当事人曾申请被拒的，先了解前次拒绝原因

硬性规则

紧急情形优先
案件存在即将超过诉讼时效、羁押期限即将届满或人身安全受威胁时，简化评估流程、优先提交申请；提交时一并申请加急：时效即将届满的说明紧急情况申请加急审查，羁押期限将满的通过看守所/法院转交并申请加急，人身安全受威胁的说明情况申请优先处理
重复申请
当事人曾申请被拒的，须了解前次拒绝原因，针对性改进
边缘情形不轻易排除
经济状况在标准边缘的不轻易排除，建议正式申请；事项属地方扩大范围或边缘情形的，建议正式申请由法援机构认定
来源与管辖标注
免予核查情形、民事/行政与刑事法援事项清单逐项标 [模型知识 — 需验证] 和 [待验证]；涉及各省扩大规定的另标 [管辖 flagged — 需验证地方性规定]，并查询地方规定
评估不等于决定
条件评估报告注明「本评估为初步评估，最终以法律援助机构审查决定为准」

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置假设，可逐条复制。页面里的英文标记见首页「标记与术语」。

  1. 援助条件评估（经济困难·事项范围）

    /legal-aid:eligibility-assessment可单独运行

    系统评估当事人是否符合法律援助条件：先做经济困难审查，再做事项范围审查，最后按组合矩阵给出「建议申请 / 条件评估中 / 不符合条件」的综合结论

    请律师核对

    • 核对 1.1持低保证/特困证「凭证件直接认定」标 [待验证]，其他社会救助对象的证件是否也可直接认定？
    • 核对 1.2个案审查只写「综合考虑支出、负担等因素」，没有量化口径；是否写入贵中心的判断规则？
    • 核对 1.3事项「需确认」时一律「建议正式申请由法援机构认定」，是否同意这一默认？
    • 核对 1.4综合结论矩阵未覆盖的组合（如需补充证明 + 需确认、不符合 + 需确认或不在范围内）应归入哪一结论？

    做法

    1. 从实践配置读取本地最低生活保障标准和法律援助经济困难标准；未配置时请用户运行 /legal-aid:style-local-resources 或手动提供
    2. 先查是否属于免予核查经济困难状况的情形（英雄烈士近亲属维护权益、见义勇为行为主张民事权益、再审改判无罪请求国家赔偿、各省规定的其他情形）；属于的跳过经济审查，直接进入事项范围审查
    3. 不属于免予核查的，按认定方式判断：持有低保证/特困证的凭证件直接认定 [待验证]；其余比对家庭人均收入是否 ≤ 法援标准；收入在标准边缘的做个案审查，综合考虑支出、负担等因素
    4. 得出经济困难结论：经济困难（符合标准，继续事项范围审查）/ 需补充证明（信息不完整，列出需补充的材料）/ 不符合（超过标准且无例外，告知不符合并建议其他途径）/ 免予核查（跳过，继续事项范围审查）
    5. 做事项范围审查：民事/行政事项对照 5 类法定事项加各省补充事项；刑事案件对照 3 类情形（经济困难申请辩护、应当通知法援指派的强制辩护、被害人申请代理）
    6. 得出事项范围结论：在范围内（明确属于法定事项，条件评估通过）/ 需确认（地方扩大事项或边缘情形，建议正式申请由法援机构认定）/ 不在范围内（明确不属于，告知并建议其他途径）
    7. 按综合结论矩阵组合两项结论，写出综合结论与下一步
    8. 边界处理：经济状况边缘的不轻易排除，建议正式申请；标准不确定的标注待确认，查询最新公布数据；省级扩大事项标 [管辖 flagged] 并查询地方规定；多次申请被拒的了解前次拒绝原因，针对性改进
    9. 按检查清单核对后输出《法律援助条件评估报告》

    内置规则

    • 经济困难认定方式四种：直接认定（持有低保证/特困证，凭证件直接认定 [待验证]）；收入比对（家庭人均收入 ≤ 法援标准）；个案审查（收入在标准边缘，综合考虑支出、负担等因素）；免予核查（法定免予核查情形，跳过经济审查）
    • 免予核查情形表 4 项：英雄烈士近亲属维护权益；见义勇为行为主张民事权益；再审改判无罪请求国家赔偿（冤假错案）；各省规定的其他情形（地方扩大规定，另标 [管辖 flagged — 需验证地方性规定]）；每项均标 [模型知识 — 需验证] [待验证]
    • 民事/行政法援事项表：请求给付赡养费/抚养费/扶养费；请求确认劳动关系或支付劳动报酬；请求工伤事故/交通事故/食品药品安全事故/医疗事故人身损害赔偿；请求国家赔偿；请求社会保险待遇/最低生活保障；各省补充事项（标 [管辖 flagged]）；法律依据均写「法律援助法 [待验证]」，来源标 [模型知识 — 需验证]
    • 刑事法援范围表：经济困难没有委托辩护人——申请类，可申请法援辩护；盲聋哑/半精神病人/可能判无期死刑/未成年——强制类，应当通知法援指派；被害人经济困难没有委托代理人——申请类，可申请法援代理；均标 [模型知识 — 需验证] [待验证]
    • 综合结论矩阵：经济困难 + 在范围内 → 建议申请，进入材料准备；需补充证明 + 在范围内 → 条件评估中，补充材料后重新评估；经济困难 + 需确认 → 条件评估中，建议正式申请由法援机构认定；不符合 + 在范围内 → 不符合条件，告知其他解决途径；经济困难或需补充证明 + 不在范围内 → 不符合条件，告知事项不在范围内
    • 免予核查与「经济困难」同属通过类结论（原文用同一通过标记），直接进入事项范围审查
    • 检查清单 6 项：本地经济困难标准已确认；经济状况已评估；免予核查情形已检查；事项范围已对照法定清单；特殊群体快速通道已检查；综合评估结论已输出

    法律依据

    • 《中华人民共和国法律援助法》相关规定 — 民事/行政法律援助事项范围 [待验证] [模型知识 — 需验证]
    • 免予核查经济困难状况的法定情形 — 英雄烈士近亲属、见义勇为、再审改判无罪请求国家赔偿 [模型知识 — 需验证] [待验证]
    • 刑事法律援助范围 — 申请辩护、强制辩护（应当通知法援指派）、被害人申请代理 [模型知识 — 需验证] [待验证]
    • 各省法律援助地方性规定 — 地方扩大的免予核查情形和补充事项 [待验证] [管辖 flagged — 需验证地方性规定]

    产出

    《法律援助条件评估报告》：经济困难审查表（家庭人均月收入、本地法援标准、认定方式、结论）、事项范围审查表（案件类型、具体事项、是否在法援范围）、综合评估结论与下一步；页脚注明「本评估为初步评估，最终以法律援助机构审查决定为准」

  2. 申请材料准备

    /legal-aid:material-preparation可单独运行

    按案件类型和当事人情况生成个性化材料清单，指导获取经济困难证明，处理材料瑕疵并按规范整理装订

    请律师核对

    • 核对 2.1经济困难证明的五类来源与获取部门（含街道办/乡镇政府开具的经济困难证明）是否符合贵地现行做法？
    • 核对 2.2「材料伪造嫌疑」只标注并报告负责人，SKILL.md 未规定是否暂停申请、是否告知当事人后果，是否补充？
    • 核对 2.3装订要求中复印件「与原件核对一致」由谁签名没有写明；整套装订规范是否与贵中心收件要求一致？
    • 核对 2.4五类案件证据清单之外，是否补充贵中心常办的其他案件类型？

    做法

    1. 生成必备材料四项：法律援助申请表（按法援中心统一格式，到法援中心领取或下载）、身份证或其他有效身份证明（核对原件，提交复印件）、经济困难证明、与案件相关的证据材料（当事人收集和协助调取）
    2. 按当事人情况选经济困难证明并说明获取部门：已享受低保的用最低生活保障证（民政局/街道办）；特困人员用特困人员救助供养证（民政局）；无低保证但经济困难的到户籍所在地街道办事处/乡镇政府申请开具经济困难证明；有固定收入的由工作单位开具收入证明；无固定收入的由社区/村委会开具无收入声明
    3. 从实践配置读取本地民政局名称、联系方式和证明开具流程，填入获取指南
    4. 按案件类型列出证据材料清单（劳动争议、赡养/抚养费、交通事故人身损害、工伤赔偿、刑事辩护五类，见规则）
    5. 制作完整性检查表，逐项标「已备 / 待准备」，经济困难证明可标「免予」
    6. 按瑕疵类型处理：材料缺失的告知获取方式，必要时协助联系；材料过期的告知需更新（如低保证年审）；信息不一致的请当事人说明原因，必要时更正；材料不完整的指出缺失部分，限期补充；无法取得某材料的评估能否以其他材料替代，或说明情况
    7. 按边界情形调整：当事人行动不便的上门收集或委托他人代办；材料在异地的协助联系异地部门或邮寄获取；无法取得经济困难证明的说明情况，由法援机构核实；免予核查的跳过经济证明，改备免予核查情形证明；文盲或半文盲的协助填写表格，口头陈述由工作人员记录并确认；外国人增加护照复印件、出入境记录、翻译件
    8. 异常处理：经济困难证明被拒绝开具的协助分析原因，建议向民政部门上级机关反映；关键证据确实无法取得的标「关键证据缺失」并评估对案件的影响；材料之间信息矛盾的请当事人说明原因、必要时更正；有伪造嫌疑的标「材料真实性存疑」并报告负责人
    9. 按装订顺序和装订要求整理成册，输出《申请材料准备清单》

    内置规则

    • 劳动争议 7 项：劳动合同（证明劳动关系）、工资条/银行流水（工资标准）、考勤记录（出勤情况）、社保缴纳记录（劳动关系存续）、解除/终止通知书（解除事实）、工作证/工牌（辅助证明劳动关系）、同事证人证言（辅助证据）
    • 赡养/抚养费 5 项：户口簿/亲属关系证明、对方收入证明、已支付/未支付记录、申请人收入证明、生活支出证明
    • 交通事故人身损害 6 项：交通事故认定书、医疗费票据、伤残鉴定报告、误工证明、护理证明、保险单
    • 工伤赔偿 5 项：工伤认定决定书、劳动能力鉴定结论、医疗费票据、劳动合同、工资条
    • 刑事辩护 4 项：拘留通知书/逮捕通知书、起诉书（如有）、亲属关系证明（申请人资格）、经济困难证明（如适用）
    • 装订顺序：材料目录 → 法律援助申请表 → 身份证明材料 → 经济困难证明材料 → 案件证据材料（按逻辑顺序）→ 其他材料
    • 装订要求：A4 纸单面打印；从第一页起连续编页码；首页为材料目录，标明各材料起止页码；左侧装订或线装；复印件注明「与原件核对一致」并签名；外文材料附中文翻译件

    产出

    《申请材料准备清单》：材料清单表（材料名称、状态、获取方式/备注）、待补充材料、获取协助表（需协助事项、联系部门、联系方式），以及按顺序装订成册的申请材料

  3. 申请提交与审查跟踪

    /legal-aid:application-submission-tracking可单独运行

    协助提交申请并取得回执，计算并跟踪审查期限，按四级预警催办，处理审查期间的补正要求

    请律师核对

    • 核对 3.1审查决定期限、补正期限都写作「期限待验证」，期限届满日和四级预警却以此为基准计算；请填入现行法定天数与起算规则
    • 核对 3.2预警阈值「> 7日 / 3-7日 / 1-3日 / 超期」在 3 日处重叠，期限届满当日未归入任何一级，是否调整？
    • 核对 3.3红级的处理写「投诉或申诉」，边界情形又写「必要时向司法行政机关反映」，救济渠道的表述是否统一？
    • 核对 3.4转交申请（法院/看守所/社区等）标 [待验证]，贵地实际可由哪些机关或组织转交？

    做法

    1. 选择提交方式：现场到法援中心窗口提交（推荐）；邮寄提交并保留邮寄凭证；通过法援机构网站/APP 网上申请（如有）；通过法院/看守所/社区等转交 [待验证]
    2. 提交后取得五项确认信息：收件回执、申请编号（受理编号）、收件日期（正式收件日期，影响审查期限起算）、审查联系人、法援机构告知的预计审查期限
    3. 登记提交记录：提交日期、提交方式、收件机构、申请编号、收件回执编号，并附提交材料目录
    4. 按法定审查决定期限自动计算审查期限届满日，记录当前状态（审查中/已补正/已决定）和距届满天数；审查决定期限、补正期限在文件中写作「[期限待验证]」
    5. 按距期限天数定四级预警并采取对应动作（原文用绿、黄、橙、红四色圆点区分，下称绿级、黄级、橙级、红级，依次表示正常、关注、警告、超期；阈值见规则）
    6. 收到补正通知后：仔细阅读，逐项准备补充材料，在补正期限内提交并保留凭证，登记补正记录（通知日期、补正期限、需补充材料、提交日期、补正材料清单）
    7. 案件紧急的在申请时一并申请加急：时效即将届满的说明紧急情况申请加急审查；羁押期限将满的通过看守所/法院转交并申请加急；人身安全受威胁的说明紧急情况申请优先处理
    8. 异常处理：法援机构不予受理的了解原因、判断是否合理，必要时申诉；审查超期的主动催办，必要时向司法行政机关反映；补正期限不足的申请延期，或说明情况先行提交已有材料；联系不上法援机构的通过上级司法行政机关联系
    9. 按检查清单核对后输出《申请提交与审查跟踪记录》

    内置规则

    • 四级预警：绿级（正常）距期限 > 7日，等待；黄级（关注）距期限 3-7日，主动询问进度；橙级（警告）距期限 1-3日，联系法援机构催办；红级（超期）超过审查期限，投诉或申诉
    • 提交方式以现场提交为推荐；邮寄提交须保留邮寄凭证
    • 收件日期为正式收件日期，影响审查期限起算
    • 法援机构认为材料不齐全时，可一次性告知需补充的材料 [待验证]
    • 法定审查期限表：审查决定期限为收到申请后 [期限待验证] 内作出决定（《法律援助法》相关规定 [待验证]）；补正期限为收到补正通知后 [期限待验证] 内补充（相关规定 [待验证]）
    • 检查清单 6 项：申请已提交；收件回执已获取；申请编号已记录；审查期限已计算并录入；进度跟踪机制已建立；补正材料已及时提交（如有）

    法律依据

    • 《中华人民共和国法律援助法》相关规定 — 收到申请后作出是否给予法律援助决定的审查期限 [期限待验证] [待验证]
    • 相关规定 — 补正期限 [期限待验证]；材料不齐全时一次性告知需补充的材料 [待验证]
    • 转交申请 — 通过法院/看守所/社区等转交 [待验证]

    产出

    《申请提交与审查跟踪记录》：提交记录表、审查进度表（提交日期、审查期限届满日、当前状态）、补正记录表、预警级别（绿级/黄级/橙级/红级）

  4. 审查结果应对（补正·不予援助救济）

    /legal-aid:review-result-response可单独运行

    针对批准、补正、不予援助三种审查结果分别给出衔接、补正或救济方案，必要时起草异议申请书并告知替代援助渠道

    请律师核对

    • 核对 4.1异议写成「向作出决定的法援机构提出」、由该机构作出异议审查决定，期限待验证；请按现行《法律援助法》核实异议的受理机关、期限及对异议结果不服时的后续救济
    • 核对 4.2「经济困难不符合」的应对方向只写「评估是否有例外情形」，没有列出可援引的例外，是否补充？
    • 核对 4.3「案件紧急但被拒绝」时「申请先行提供援助」，在贵地是否有制度依据？
    • 核对 4.4替代渠道清单是否接入配置中的本地资源，并补充贵地其他公益渠道？

    做法

    1. 先识别审查结果：批准援助（衔接案件管理流程）、要求补正（在期限内补充材料）、不予援助（评估是否申诉或寻求其他途径）
    2. 批准援助的：确认批准内容（援助类型、范围、阶段），签署委托代理协议/指定辩护函，配合案件登记和承办律师指派，提示运行 /legal-aid:case-docket-assignment 继续
    3. 要求补正的：读补正通知，弄清需补充哪些材料、具体要求和截止日期；制作补正方案表（补正项、原状态、补正措施、完成日期）；在期限内提交全部补充材料，保留凭证，更新跟踪记录
    4. 无法按期补正的：向法援机构书面说明情况，申请延长补正期限，先提交已取得的补充材料
    5. 不予援助的：对照四类常见理由确定应对方向（见规则）
    6. 选择救济途径：异议审查、重新申请、行政投诉、其他援助渠道
    7. 走异议审查的：准备异议申请书、原不予援助决定书复印件和支持异议的证据，在法定期限内（[期限待验证]）向作出决定的法援机构提交；跟踪其在 [期限待验证] 内作出的异议审查决定——异议成立的撤销原决定、给予援助，不成立的书面告知理由
    8. 按模板起草异议申请书：申请事项写明对某法援中心某日作出的某编号不予法律援助决定提出异议、请求重新审查并给予法律援助；事实与理由逐项反驳不予援助理由，提供事实和法律依据
    9. 不予援助决定最终未改变的，帮助当事人寻求替代渠道（见规则）
    10. 异常处理：不予援助理由不明确的要求法援机构书面说明理由；理由明显错误的在异议申请中明确指出并引用法律依据 [待验证]；异议审查超期的向司法行政机关反映；错过异议期限的评估能否重新申请或向司法行政机关投诉；法援机构不回复异议的向司法行政机关投诉并要求督促；当事人不接受不予援助的耐心解释，提供书面救济途径说明；案件紧急但被拒绝的说明紧急情况，申请先行提供援助
    11. 按检查清单核对后输出《审查结果应对方案》

    内置规则

    • 不予援助理由与应对方向：经济困难不符合（收入超过标准）→ 评估是否有例外情形；事项不在范围内（不属于法定援助事项）→ 评估是否属于地方扩大范围；材料不充分（证据不足）→ 补充材料重新申请；不符合免予核查条件（主张免予核查但未认定）→ 补充证明材料
    • 救济途径四种：异议审查（对不予援助决定有异议，向作出决定的法援机构提出，《法律援助法》相关规定 [待验证]）；重新申请（补充新材料后重新提交）；行政投诉（认为法援机构违法不作为，向司法行政机关投诉，相关规定 [待验证]）；其他援助渠道（不符合法援条件但有困难）
    • 异议审查结果：异议成立的撤销原决定、给予援助；异议不成立的书面告知理由；提出期限与审查期限均为 [期限待验证]
    • 替代渠道 6 类：律师协会公益服务（一般法律帮助，当地律协 [待验证]）；高校法律诊所（法律咨询和简单代理，当地高校法学院）；12348 法律服务热线（法律咨询，全国统一热线）；人民调解（适合调解的纠纷，当地司法局/调委会）；社会救助（需要综合救助，民政部门）；妇联/残联/工会（特定群体）
    • 应对方案至少列方案一和备选方案二，附期限提醒表；最终不予援助的列出替代渠道
    • 检查清单 6 项：审查结果已确认；若批准，已衔接案件登记流程；若补正，补正方案已制定并在期限内完成；若不予援助，已分析理由并选择救济途径；若异议，异议申请书已准备并提交；最终不予援助的已告知替代渠道

    法律依据

    • 《中华人民共和国法律援助法》相关规定 — 对不予援助决定提出异议审查 [待验证]；异议提出期限与审查期限 [期限待验证]
    • 相关规定 — 认为法援机构违法不作为的，向司法行政机关投诉 [待验证]

    产出

    《审查结果应对方案》（审查结果摘要、方案一与备选方案二、期限提醒表、替代渠道）；不予援助走异议的另附异议申请书

  • 提交跟踪：申请已提交；收件回执已获取；申请编号已记录；审查期限已计算并录入；进度跟踪机制已建立；补正材料已及时提交（如有）
  • 结果应对：审查结果已确认；批准的已衔接案件登记流程；补正的方案已制定并在期限内完成；不予援助的已分析理由并选择救济途径；走异议的异议申请书已准备并提交；最终不予援助的已告知替代渠道

09何时暂停或升级

  • 实践配置缺失：提示运行 /legal-aid:cold-start-interview，或经用户说「临时模式」后继续并在输出标 [临时模式]
  • 本地经济困难标准未配置：先请用户运行 /legal-aid:style-local-resources 或手动提供，再做经济困难审查
  • 紧急情形（诉讼时效即将届满、羁押期限即将届满、人身安全受威胁）：简化评估、优先提交并申请加急；案件紧急但被拒绝的，说明紧急情况，申请先行提供援助
  • 材料有伪造嫌疑：标「材料真实性存疑」，报告负责人
  • 经济困难证明被拒绝开具：协助分析原因，建议向民政部门上级机关反映
  • 审查超期或联系不上法援机构：主动催办，必要时向司法行政机关反映或通过上级司法行政机关联系；异议审查超期或法援机构不回复异议的，向司法行政机关反映、投诉并要求督促
  • 错过异议期限：评估能否重新申请或向司法行政机关投诉
  • 实践配置中的使用者为非律师角色时：输出作为工作辅助供律师审查而非结论，涉及法律后果的步骤前暂停（实践配置规定）

10请律师重点核对

下面是这个流程内置的法律假设、立场、阈值和清单，每一条都可以同意、反对或补充。条目下的「相关批注」按文字重合自动匹配到步骤旁的核对条目，可能不全。

  2. 经济困难认定按「持低保证/特困证凭证件直接认定 [待验证] → 家庭人均收入 ≤ 法援标准的收入比对 → 标准边缘的个案审查」进行，边缘情形「不轻易排除，建议正式申请」；而文书模板流程的申请书写的是「家庭月总收入」。人均口径、认定顺序和这一宽松取向是否符合贵地标准与贵中心做法？相关批注：核对 1.1
  3. 免予核查经济困难状况的情形表只列英雄烈士近亲属维护权益、见义勇为行为主张民事权益、再审改判无罪请求国家赔偿和「各省规定的其他情形」四项，全部标模型知识待验证；这份清单是否完整、各项的法定归类是否准确？
  4. 民事/行政法援事项表列 5 类（赡养费/抚养费/扶养费，劳动关系与劳动报酬，四类事故人身损害赔偿，国家赔偿，社会保险待遇/最低生活保障）加各省补充事项；请对照现行《法律援助法》核对有无遗漏或表述偏差。
  5. 刑事法援范围表只列 3 种情形，强制辩护写作「盲聋哑/半精神病人/可能判无期死刑/未成年」；「半精神病人」等简称是否改用法定表述（高频引用库写作「尚未完全丧失辨认或控制自己行为能力的精神病人」），引用库收录的值班律师法律帮助是否也应列入？
  6. 综合结论矩阵只有 5 行，「需补充证明 + 需确认」「不符合 + 需确认或不在范围内」等组合没有归类；检查清单要求「特殊群体快速通道已检查」，但本步骤没有对应内容（该表在客户 intake 流程的资格初评里）。是否补全？相关批注：核对 1.4
  7. 审查决定期限、补正期限、异议提出期限和异议审查期限全部写作「期限待验证」，期限届满日的「自动计算」和四级预警都依赖这些数字；请填入现行法定天数与起算规则（文件只写明审查期限自正式收件日期起算）。相关批注：核对 3.1
  8. 超期预警阈值为绿级「> 7日」、黄级「3-7日」、橙级「1-3日」、红级「超过审查期限」：3 日同时落入黄级和橙级，期限届满当日未归入任何一级；阈值是否合适、是否调整？相关批注：核对 3.2
  9. 异议审查写成向「作出决定的法援机构」提出并由其作出异议审查决定（成立则撤销原决定给予援助，不成立则书面告知理由），向司法行政机关投诉作为并列的另一途径；请按现行《法律援助法》核实异议的受理机关、期限及对异议结果不服的后续救济。相关批注：核对 4.1
