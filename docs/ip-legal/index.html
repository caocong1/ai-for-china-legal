02概要

ip-legal 面向知识产权律师、企业 IP 经理、商标代理人和专利代理师，提供五个流程：冷启动访谈、商标查询与近似分析、专利侵权初步分析、著作权登记、知识产权清权（clearance），共 5 个入口流程、20 个步骤。所有流程执行实质性工作前先读取 ip-legal/CLAUDE.md 实践配置文件（权利人画像、IP 组合、维权立场、风险矩阵、文书风格），据此调整近似判断阈值、FTO 清权严格度、清权结论门槛、风险标注强度和升级路由。法律依据以商标法（2019修正）、专利法（2020修正/2021施行）、著作权法（2020修正/2021施行）、反不正当竞争法（2019修正）及相关司法解释为主；因条号重排，具体条号除少数中度把握锚点外一律标「待验证」，引用前须通过国家法律法规数据库核实现行版本。

03实践配置

实践配置文件 <a href="https://github.com/caocong1/ai-for-china-legal/blob/master/ip-legal/CLAUDE.md">ip-legal/CLAUDE.md</a> 记录贵所的立场与习惯；所有流程开始前先读它。

配置哪些内容

  • 我们是谁（基本信息、IP 组合概况：商标/专利/著作权/字号域名、核心品牌与技术、IP 痛点、IP 团队）
  • 谁在使用（执业角色、律师/代理人联系人）
  • 可用集成（商标网、专利检索系统、商业数据库、版权保护中心、企业信用公示系统、WHOIS、裁判文书网、内部 IP 管理系统等）
  • 维权与申请立场（整体维权立场、商标策略、专利策略、著作权策略、清权严格度）
  • 风险校准（[红][橙][黄][绿] 四级与知识产权典型触发情形）
  • 升级矩阵（角色权限表、自动升级触发条件、维权/异议/诉讼触发与时限）
  • 文书风格（检索报告、侵权分析意见书、清权报告、维权函/律师函、工作产物存放位置）
  • 输出（工作产物标题、审查者注释块、下一步决策树模板）
  • 共享护栏（无静默补充、时效性触发、验证用户陈述的法律事实、来源标签规范、目的地/特权检查、行业识别）
  • 事项工作区
  • 审查过的种子文档

会怎样改变输出

  • 「谁在使用」角色为非律师（IP 经理/内部法务/无律师）时，所有输出改用标题「研究笔记 — 非法律建议，供律师/代理人审查」，并在侵权判断、提起异议/无效宣告、发维权函/律师函前暂停升级；律师/代理人角色用「律师工作产物 — 受律师-当事人特权保护 / 保密」
  • 「整体维权立场」进取/平衡/防御决定哪一级风险被重点标注（进取：[黄] 及以上；平衡：[橙]/[红] 重点、[黄] 备注；防御：主要关注 [红]）以及清权结论的严格程度
  • 「商标策略 → 近似容忍度」（严格/平衡/宽松）驱动商标近似判断阈值与在先权利障碍评估的严格度；「注册防御范围」和「海外布局」决定商标检索范围与地域
  • 「专利策略 → FTO 清权严格度」与「清权严格度 → 结论门槛」决定专利 FTO 评估范围，以及 √可用 / !有风险 / ×不可用 三档清权结论的落点
  • 「可用集成」各数据库可用性决定商标检索步骤的检索路径；未连接时要求手动粘贴检索结果，不自行填补空白
  • 「所属行业」与「共享护栏 → 行业识别」命中医药、互联网、音乐影视、半导体、消费品、制造行业时自动标 [行业 flagged — 需核实主管部门规定]；距最后更新超过 6 个月的条号引用自动标 [时效性 flagged — 需验证现行 IP 法版本]

05不做什么

  • 不代替律师作出最终侵权结论、发送维权函/律师函、提起异议/无效宣告/诉讼：角色权限表把这些事项一律设为须律师确认或主导；非律师角色使用时所有输出标注「研究笔记 — 非法律建议，供律师/代理人审查」
  • 不自动连接检索数据库：集成未连接时核心功能仍可工作，但检索结果需手动从中国商标网、专利检索系统等数据库粘贴提供
  • 不保证自由实施：FTO 分析有局限性，不能保证完全自由实施
  • 不处理海外知识产权事务的实质判断：涉及海外商标注册、专利申请、跨境侵权的事务一律自动升级律师
  • 不以模型记忆的条号作为确定结论：IP 法 2019/2020/2021 修正后条号重排，除中度把握锚点外一律标 [待验证]
