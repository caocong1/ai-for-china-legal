01概要

对拟登记的作品（文字、美术、摄影、视听、图形、音乐、计算机软件等）依次完成作品类型认定、著作权权属判定、登记材料清单整理和登记流程指引，最终汇总为一份《著作权登记综合方案》。开始前读取 ip-legal/CLAUDE.md 中的著作权策略（主要作品登记立场、软件著作权登记立场、维权方式优先级）、IP 组合概况与执业角色，配置缺失时可按「临时模式」用通用默认值运行并在输出打标。四个步骤既可依次执行，也可任选一步单独使用；每一步都对照《著作权法》（2020年修正，2021年6月1日施行）、《作品自愿登记办法》与《计算机软件著作权登记办法》的规则作判断，具体条号除保护期规则外一律标注待验证。全程坚持自愿登记原则：著作权自作品创作完成自动产生，登记证书只是权属的初步证据、可被反证推翻。

02适用与边界

适用场景

  • 企业或个人拟就某一作品（含计算机软件）办理著作权登记，需要判断能否登记、由谁申请、准备什么材料、走什么流程
  • 委托开发、职务创作、合作创作、法人主持创作等权属关系复杂，登记前需先厘清著作权归属与登记申请主体
  • 只需单独判断某作品是否具有独创性、属于哪一法定作品类型、哪些部分受保护
  • 只需整理某类作品的登记材料清单，或了解登记流程、周期与登记证书效力
  • 软件企业需要区分软件著作权登记与一般作品登记两条路径并准备源程序样本

不做什么

  • 不是确权程序：登记证书只是权属初步证据，流程不能替代诉讼确权，也不审查作品独创性的实质
  • 不做著作权侵权比对或第三方素材（图片/音乐/代码）来源合规核查，这类需求转 /ip-legal:ip-clearance 的著作权清权/使用权评估
  • 不处理商标注册或专利申请；商标图案若有独创性可单独作美术作品登记，但商标保护须走商标注册，两条路径不同
  • 不替代登记机构的最新官方要求：样本页数、审查周期、补正期限等均标待验证，须以中国版权保护中心当日规定为准
  • 单位与员工之间的权属争议本身须经仲裁或诉讼解决，本流程只作初步评估
  • 海外著作权登记不在范围内，仅说明已在海外登记的作品可在中国单独登记

03输入与产出

需要律师提供

  • 作品名称、内容描述、表达载体（文字/图像/代码/音频/视频/建筑图纸/产品设计图等）必需
  • 创作方式（作者独立创作/合作创作/基于模板改编/AI 辅助创作/其他）与创作完成时间必需
    创作完成时间是著作权自动产生的起点
  • 创作背景：实际创作人或单位、是否为完成单位工作任务、是否主要利用单位物质技术条件、是否受委托、是否多人合作、是否由法人主持并承担责任必需
    决定适用哪一套权属规则
  • 劳动合同、委托合同、合作协议等文件中的著作权归属约定可选
    有书面约定的按约定优先
  • 是否已发表及首次发表时间与媒介；是否含有第三方内容可选
    影响保护期计算与独创性判断
  • 申请主体身份材料（身份证/营业执照）、作品样本、软件源代码与说明书可选
    进入材料准备步骤时核对
  • ip-legal/CLAUDE.md 实践配置可选
    缺失或含 [PLACEHOLDER] 时提示运行 /ip-legal:cold-start-interview 或进入临时模式

产出

  • 作品类型认定意见给律师内部
    独创性判断表（独立创作/最低程度创造性/综合结论）、法定作品类型认定结论与理由、思想表达二分对照表、不受保护对象排查、后续建议勾选项
  • 著作权权属判定意见给律师内部 / 客户
    权属类型判断与依据、各权属主体权利明细表、当前约定状态与补约建议、建议登记申请主体
  • 著作权登记材料清单给律师内部 / 客户
    作品名称/类型/权属/申请主体/登记路径抬头；按申请主体证明、作品说明、权利归属证明、作品样本、软件特殊材料、代理材料分类的清单表（具体要求、待准备/已准备）；注意事项；后续建议
  • 著作权登记综合方案给客户 / 律师内部
    自愿登记原则提示；综合方案汇总表（作品类型、权属与申请主体、登记路径、登记机构、材料准备状态、预期周期、保护期）；登记证书效力说明；登记流程步骤表（含周期）；后续建议与里程碑（优先级高/中/低）

04开始前

前置条件

  • 读取 ip-legal/CLAUDE.md：「维权与申请立场 → 著作权策略」（主要作品登记立场、软件著作权登记立场、维权方式优先级）、「我们是谁 → IP 组合概况」著作权/软件著作权部分（主要作品类型与已登记数量）、整体维权立场、「谁在使用」执业角色
  • 配置缺失或仍含 [PLACEHOLDER] 时，提示两个选择：运行 /ip-legal:cold-start-interview（约 5 分钟）配置档案，或由用户说「临时模式」后按通用默认值运行（维权立场平衡型、角色为律师、独创性按最低门槛判断、权属按法定规则即无约定时受托人默认/职务作品按一般规则），输出标注 [临时模式] 并在末尾提示配置档案
  • 开始任何分析前先向用户说明著作权自愿登记原则：著作权自作品创作完成之日起自动产生、无需登记；登记为自愿、非确权手段；登记证书是权属的初步证据、可被反证推翻；并提示保护期规则（自然人作品为作者终生及死亡后50年；法人/视听作品为首次发表后50年；条号建议复核）
  • 读取「我们是谁」确认权利人画像：行业类型（文创/软件/互联网/制造等，软件走不同登记路径）、是否有主动登记政策及软件是否全部登记、现有著作权登记情况
  • 每个步骤开始前还须读取 ip-legal/skills/_shared/legal-basis-conventions.md（引用规范）、ip-law-citations.md（引用库）、practice-profile-schema.md（配置读取契约）

硬性规则

著作权策略加载
按配置中的主要作品登记立场（主动登记/选择性登记/不登记）确认本次登记必要性；软件著作权登记立场（全部登记/核心版本登记/不登记）决定软件是否走特殊登记路径；著作权维权方式优先级（协商/行政投诉/诉讼）影响登记重要性判断
行业识别
涉及以下行业/作品类型时标注 [行业 flagged — 需核实主管部门规定]：互联网/软件（软件著作权登记、开源许可合规、AI 生成内容独创性争议 [待验证]）；音乐/影视/出版（集体管理组织、视听作品 2020 年修正更名）；游戏/动漫（美术/视听/文字作品综合保护，游戏规则作为思想不受保护）；建筑设计（建筑作品与图形作品交叉）；文创/设计（美术作品与外观设计专利竞合选择）
IP 法时效性提示
著作权法经 2020 年修正、2021年6月1日施行、条号重排；除保护期规则（规则稳定、条号建议复核）外，分析中的具体条号均标 [待验证]，引用前建议通过国家法律法规数据库 https://flk.npc.gov.cn 核实现行版本
目的地与特权检查
输出前检查目的地是否在律师-当事人特权圈内；面向对方当事人、法院的内容会使特权失效，须提供内部特权版本和脱敏版本两套选项
著作权清权衔接
用户涉及作品/素材来源合规（第三方图片/音乐/代码的许可状态）或需系统评估拟使用内容是否侵犯他人著作权时，转 ip-clearance 的著作权清权/使用权评估做授权链核查
工作产物标题
继承配置「输出 → 工作产物标题」：律师/代理人角色用「律师工作产物 — 受律师-当事人特权保护 / 保密」，非律师角色（IP 经理/内部法务）用「研究笔记 — 非法律建议，供律师/代理人审查」

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置假设，可逐条复制。页面里的英文标记见首页「标记与术语」。

  1. 作品类型认定

    /ip-legal:work-type-determination可单独运行

    判断作品是否达到独创性门槛、属于哪一法定作品类型、哪些部分是受保护的表达，并排查不受保护对象；结论决定后续适用的权属规则和登记路径（软件登记还是一般作品登记）

    请律师核对

    • 核对 1.1「独创性门槛与作品类型」表把文字、美术、摄影、软件一律定为「较低」，数据库/资料汇编定为「较高（争议）」，是否符合贵所对独创性高度的把握？
    • 核对 1.2AI 独立生成内容默认列入「独创性不足的常见情形」并标待验证，是否要按最新裁判调整这一默认立场？
    • 核对 1.3合并原则只写「可能不受保护」并标学说争议，是否需要给出更明确的适用口径？
    • 核对 1.4实用艺术品「分离判断 + 建议同时考虑外观设计专利」的处理是否符合贵所实践？

    做法

    1. 先收集作品基本信息表：作品名称、作品内容描述、创作方式（作者独立创作/合作创作/基于模板改编/AI 辅助创作/其他）、表达载体、创作完成时间为必填；是否已发表、是否含有第三方内容为选填
    2. 按两个要件判断独创性：独立创作（非抄袭复制他人作品）与最低程度的创造性（表达上有一定独特性，门槛较低），得出「具有独创性，受保护 / 独创性存疑 / 不具有独创性，不受保护」三选一结论
    3. 对照「独创性门槛与作品类型」表校准尺度：文字、美术、摄影、计算机软件门槛均为较低；汇编作品（选择与编排）为中等；数据库/资料汇编为较高（有争议）
    4. 排查独创性不足的常见情形：纯粹事实/数据记录（股票价格清单、时刻表、电话号码本）、机械性劳动产出、过于简短的表达（极短短语、标语）、通用模板照搬、AI 独立生成且无人工干预 [待验证 — 学说与判例尚在发展]
    5. 按 14 类法定作品类型表（文字、口述、音乐、戏剧、曲艺、舞蹈、杂技艺术、美术、建筑、摄影、视听、图形和模型、计算机软件、法律行政法规规定的其他作品）认定类型，并走决策表：主要以文字表达→文字作品；主要是视觉图像→美术/摄影/图形作品；计算机代码或软件文档→计算机软件（走软件著作权登记路径）；可播放视频→视听作品；建筑设计或工程图纸→建筑作品/图形作品；多媒介组合→主要类别加附属类别
    6. 应用思想表达二分法，对照示例表（合同模板、软件源代码、教材、绘画、商业计划书、食谱）写明哪部分是受保护的具体表达、哪部分是不受保护的思想、概念、原理、算法、方法或题材；思想的表达方式极为有限时提示合并原则 [待验证 — 学说争议，司法实践适用程度不一]
    7. 排查不受著作权保护的对象：法律法规、国家机关决议/决定/命令及裁判文书、国家机关认可的上述文件翻译、时事新闻（仅事实部分，新闻文章的具体撰写可受保护）、历法/通用数表/通用表格/公式
    8. 按检查清单核对后输出《作品类型认定意见》，后续建议中注明进入权属判定、计算机软件应走中国版权保护中心软件登记路径、独创性存疑时建议律师评估风险

    内置规则

    • 独创性 = 独立创作 + 最低程度创造性；不要求文学价值，软件不要求算法新颖
    • 独创性结论三档对应处置：受保护→继续类型认定与登记；存疑→标注并建议咨询律师、谨慎登记；不受保护→登记无意义，可考虑商业秘密、专利等其他保护
    • 视听作品为 2020 年修正后对「电影作品和以类似摄制电影的方法创作的作品」的更名
    • 源代码、目标代码、软件设计文档一经认定为计算机软件即走软件著作权登记路径；软件的技术文档/用户手册若单独登记按文字作品处理
    • 实用艺术品须分离判断：有独立欣赏价值的艺术性外观可按美术作品保护，纯实用功能部分不受保护，并建议同时考虑外观设计专利 [待验证具体判断标准]
    • AI 生成内容：中国著作权法对其是否具有独创性无明确规定；2023 年以来部分法院对有人工智能辅助但有人工创作成分的作品给予保护 [待验证]
    • 汇编作品整体的选择与编排可受保护，但各被汇编内容的著作权状态须单独判断（可能涉及许可）；衍生作品（改编/翻译/注释）须核实对原作品的改编是否获原权利人授权
    • 外国作者在中国缔结或参加的国际条约范围内受保护，保护期与中国著作权法相同 [待验证具体条约适用]
    • 作品描述不清时停止判断并追问内容、载体与创作方式，不得凭猜测认定类型；纯功能性设计建议转外观设计专利或实用新型；作品明显是现有作品简单拷贝的，提示不具独创性且可能构成侵权

    法律依据

    • 《著作权法》（2020年修正）法定作品类型条款 — 文字、口述、音乐、戏剧、曲艺、舞蹈、杂技、美术、建筑、摄影、视听、图形与模型、计算机软件及其他作品 [待验证 — IP 法修正后条号重排，须核实现行版本]
    • 《著作权法》（2020年修正）不受保护对象条款 — 法律法规、国家机关决议/决定/命令、时事新闻、历法/通用数表/通用表格/公式不受保护 [待验证 — IP 法修正后条号重排]
    • 《著作权法》（2020年修正）著作权自动保护原则条款 — 著作权自作品创作完成之日起自动产生，无需登记 [待验证 — IP 法修正后条号重排]
    • 著作权民事纠纷司法解释关于独创性认定 — 独立创作并具有最低限度的创造性，对创造性高度要求较低 [待验证 — 具体条号须核实]
    • 著作权民事纠纷司法解释关于思想表达二分 — 保护作品的具体表达，不保护思想、概念、原理、方法 [待验证 — 具体条号须核实]

    产出

    《作品类型认定意见》：独创性判断表（独立创作是/否/存疑、最低程度创造性具备/不足/存疑、综合结论）、法定作品类型认定结论与理由及特别注意、思想表达二分对照表、不受保护对象排查结论、后续建议勾选项；临时模式运行时带 [临时模式] 标注

  2. 权属判定

    /ip-legal:ownership-determination可单独运行

    以作品类型为前提，判断著作权归谁、登记申请主体是谁、现有合同约定留下多大空间，为材料准备提供权属定性依据

    请律师核对

    • 核对 2.1一般职务作品「作品完成后两年内作者不得许可第三人以相同方式使用」标为待验证，请按现行法确认是否保留
    • 核对 2.2特殊职务作品的三种情形与「软件通常归单位」的默认倾向是否符合贵所口径？
    • 核对 2.3合作作品无约定时「推定均等共有」是流程内置的推定，文件未给依据，是否接受？
    • 核对 2.4单位与员工权属争议只作初步评估并提示须经仲裁/诉讼解决，是否足够？

    做法

    1. 收集权属判定信息表：作者姓名/单位、创作时间、是否为完成工作任务、是否为合作创作为必填；创作地点、是否使用单位物质技术条件、是否有委托合同、是否有权属约定、是否为法人主持创作为选填；读取配置中的组织类型（企业/律所/个人影响职务作品判断）、著作权策略与执业角色（IP 经理为企业方立场，律师为中立）
    2. 先声明自动保护原则（著作权自作品创作完成之日起自动产生），再按优先级判定：有书面合同约定的按约定；无约定才适用法定规则
    3. 无约定时按创作情境分流：单人创作→创作者原始取得；为完成单位工作任务→职务作品；受委托创作→委托作品；法人主持创作→法人作品；多人合作→合作作品
    4. 创作者原始取得：创作作品的自然人是作者，无相反证据时署名的自然人推定为作者；适用于自然人独立创作、非工作任务、非法人主持的情形
    5. 职务作品区分一般与特殊：一般职务作品著作权归员工，单位在业务范围内有优先使用权，作品完成后两年内作者未经单位同意不得许可第三人以与单位相同的方式使用 [待验证具体规则]；特殊职务作品（主要利用单位物质技术条件创作并由单位承担责任的工程设计图、产品设计图、地图、计算机软件等；法律行政法规规定归单位的；合同约定归单位的）著作权归单位、作者保留署名权
    6. 委托作品：有约定按约定（归委托方则委托方享完整著作权，归受托方则委托方按合同享使用权）；约定不明须解释合同；无约定的著作权归受托人（创作者），委托方只能在约定目的范围内使用；提示在委托合同中明确约定权属并配套转让/独家许可条款，与 commercial-legal 的知识产权条款衔接
    7. 法人作品逐一核对三要件：法人主持（组织、策划）、代表法人意志、法人承担责任；典型为法人主导的综合研究报告、企业官方白皮书、以法人整体名义发表的作品
    8. 合作作品先判断可否分割使用：可分割的各部分作者可单独行使但不得侵犯整体著作权；不可分割的须全体协商一致或按比例行使；有合作协议按约定，无约定按贡献通常推定均等共有
    9. 走权属类型判定决策表（有无书面约定→是否法人作品→是否两人以上合作→是否受委托→是否为完成工作任务→以上均否则原始取得），输出《著作权权属判定意见》并给出建议登记申请主体

    内置规则

    • 判定优先级：书面约定优先于一切法定规则
    • 「为完成工作任务」是职务作品的核心标准；仅利用单位设备但非为工作任务的不足以认定职务作品；非在职期间创作的不是职务作品
    • 计算机软件若主要利用单位物质技术条件（服务器、开发平台）且由单位承担技术和经济责任，通常认定为特殊职务作品、著作权归单位
    • 署名权不可剥夺：特殊职务作品中单位享有除署名外的完整著作权（财产权及其他人身权）
    • 委托作品无约定时默认归受托人；外包/自由职业者创作的内容通常视为委托作品，务必在外包合同中约定知识产权转让
    • 法人作品三要件缺一不可
    • 不可分割合作作品须全体合作作者同意才能登记，一方不配合时记录情况并评估替代路径；三人以上贡献比例不明建议签书面合作协议
    • 员工离职前为完成工作任务创作的仍属职务作品；竞业限制中的知识产权条款可能影响离职后的归属争议 [待验证]
    • 纠正常见误解：委托方不会默认取得著作权；「作者」（实际创作者）与「著作权人」（可含受让人）可以不同；纯 AI 生成内容的著作权归属不确定、目前归于有人工创作成分的参与者 [待验证]

    法律依据

    • 《著作权法》（2020年修正）创作者原始取得条款 — 创作作品的自然人是作者，署名者推定为作者，著作权自创作完成产生 [待验证 — IP 法修正后条号重排]
    • 《著作权法》（2020年修正）职务作品权属条款 — 一般职务作品归作者、单位优先使用；特殊职务作品归单位、作者享署名权 [待验证 — IP 法修正后条号重排]
    • 《著作权法》（2020年修正）委托作品权属条款 — 有约定按约定，无约定归受托的创作者 [待验证 — IP 法修正后条号重排]
    • 《著作权法》（2020年修正）法人作品条款 — 法人主持、代表法人意志、由法人承担责任的作品法人视为作者 [待验证 — IP 法修正后条号重排]
    • 《著作权法》（2020年修正）合作作品权属条款 — 全体合作作者共同享有；可分割使用的各部分可单独行使，不可分割的须协商一致 [待验证 — IP 法修正后条号重排]

    产出

    《著作权权属判定意见》：权属类型（创作者原始取得/一般职务作品/特殊职务作品/委托作品/法人作品/合作作品）与判断依据、各权属主体权利明细表（主体、享有的权利、依据为条款/法定/约定）、当前约定状态（有约定/无约定/约定不明）与补约建议、建议登记申请主体

  3. 登记材料准备

    /ip-legal:registration-materials可单独运行

    把作品类型和权属结论转成一份可直接照着收集、提交的登记材料清单，并提前指出各类材料的具体要求与常见缺陷

    请律师核对

    • 核对 3.1软件源程序「前后各连续30页、不足60页提交全部」与文字作品「长篇前后各若干页」均标待验证，请按中国版权保护中心现行要求填入确切数字
    • 核对 3.2一般职务作品由单位基于优先使用权申请登记被写成「较少见」，贵所是否接受这一处理？
    • 核对 3.3外国/港澳台申请人材料要求只给粗略清单并标待验证，是否补充公证认证等要求？
    • 核对 3.4《作品自愿登记办法》的发布机关在文件中写为「国家版权局/国家互联网信息办公室」，请核实

    做法

    1. 读取配置中的主要作品登记立场、软件著作权登记立场、版权登记查询系统可用性与执业角色；若前两步未完成，要求先完成作品类型认定与权属判定，或由用户直接提供作品类型与权属信息
    2. 确认登记路径：计算机软件（含源代码）走《计算机软件著作权登记办法》路径、由中国版权保护中心受理；文字/美术/摄影/视听/图形/音乐等其他作品走《作品自愿登记办法》路径、由中国版权保护中心或地方版权局/著作权登记机构受理；同一作品不重复登记，软件说明书若单独登记作文字作品处理
    3. 列通用材料 A 申请主体证明：自然人提供身份证正反面复印件（清晰、与申请表姓名一致）；法人/其他组织提供加盖公章的营业执照复印件（三证合一可用）且须在有效期内、与申请表单位名称一致；外国/港澳台申请人提供护照/港澳通行证/台胞证，有代理的加授权委托书 [待验证 — 具体要求须核实登记机构最新规定]
    4. 列通用材料 B 作品说明：作品名称（与样本封面一致）、作品类别（须与作品类型认定结论一致）、独创性说明（创作者客观自述创作目的与过程即可）、创作完成时间、是否首次发表及时间与媒介
    5. 按权属类型匹配权利归属证明：创作者原始取得通常无需单独证明（有争议可附草稿、创作记录、时间戳）；特殊职务作品提供劳动合同 + 单位说明函 + 作者确认声明；一般职务作品由单位申请须说明基于优先使用权（较少见，通常由作者申请）；委托作品约定归委托方须提交含权属约定条款且双方签署的委托合同；无约定归受托人的委托合同只作创作背景材料；法人作品提交创作组织说明 + 作者/参与人员名单；合作作品须全体合作作者共同签署申请表或授权书 + 合作协议；继承/受让须提供遗嘱/继承公证书或转让合同等完整权利链文件
    6. 按作品类型列一般作品样本要求：文字作品全文（短篇原文，长篇可提交前后各若干页 [待验证 — 须核实登记机构最新要求]，须有封面/标题页）；美术作品高清彩色图片并建议附原件照片；摄影作品高清图并说明拍摄时间地点、原始文件有 EXIF 更佳；视听作品光盘/U 盘视频文件 + 截图（全片或精华部分 [待验证]）；音乐作品曲谱 + 录音；图形作品图纸原件或高清扫描件并标注设计人员与日期；建筑作品设计图 + 建成照片
    7. 软件单独列特殊材料：源程序样本为连续源程序文本，通常前后各连续30页、总页数不足60页提交全部 [待验证 — 须核实登记办法最新要求]，须为实际源代码非截图或伪代码、每页有页码；软件设计说明书或用户手册（含功能描述、运行环境、使用方法）；标识页（软件名称、版本号、著作权人、开发完成日期）须与申请表完全一致；源代码含商业秘密的可申请鉴别材料例外、删除后提交 [待验证 — 具体例外规则须核实]
    8. 如委托代理申请，补授权委托书（权利人个人签名或法人盖章，注明委托事项）与代理机构营业执照
    9. 制作材料完整性检查表（材料类别、材料名称、是否已准备、备注），输出《著作权登记材料清单》并建议进入登记流程步骤

    内置规则

    • 登记路径二分：软件走软件著作权登记（中国版权保护中心），其他作品走一般作品登记
    • 用户提交的营业执照已过期的，材料状态标为「无效」并要求更新
    • 软件仅有截图无源代码不满足要求，须准备连续源代码文本
    • 未发表作品可以登记，登记时注明「未发表」；保护期以创作完成时间为起点，法人/视听作品未发表有特殊处理 [待验证具体规则]
    • 不可分割合作作品某合作作者不配合提供材料的，记录情况，通常无法申请登记
    • 作品已在海外登记的可在中国单独登记，两者独立，可说明海外登记情况但非必须；保护期自中国登记之日起的计算方式 [待验证]
    • 一般作品含商业秘密部分建议慎重处理；软件商业秘密例外的删除比例须符合登记机构规定 [待验证]
    • 委托代理可提高效率，但须核实代理机构资质，授权委托书须由权利人本人签署

    法律依据

    • 《作品自愿登记办法》（国家版权局/国家互联网信息办公室） — 一般作品自愿登记程序、申请材料（申请表、样本、权利归属证明）及证书效力 [待验证 — 须核实现行版本]
    • 《计算机软件著作权登记办法》（国家版权局） — 软件登记由中国版权保护中心受理；源程序样本前后各连续30页 [待验证 — 须核实最新版本]；商业秘密例外申请规则 [待验证]

    产出

    《著作权登记材料清单》：作品名称、作品类型、权属类型、申请主体、登记路径（软件著作权登记/一般作品登记）抬头；分类材料清单表（类别、材料名称、具体要求、待准备/已准备）；注意事项（含时效性提醒）；后续建议

  4. 登记流程与综合方案

    /ip-legal:registration-process可单独运行

    讲清登记怎么走、要多久、登记证书有什么效力、登记后如何维护，并把前三步结论汇总成《著作权登记综合方案》

    请律师核对

    • 核对 4.1受理 1-5 个工作日、形式审查 1-4 周、一般作品总周期 1-3 个月、软件 15-30 个工作日/约 1 个月等周期全部标待验证，是否按贵所近期办案经验更新？
    • 核对 4.2「转让/许可备案可增强对抗效力」标待验证，贵所是否认可这一说法？
    • 核对 4.3登记价值评估高/中/低的判断标准文件未写明，是否补充依据（如商业价值、维权可能性）？
    • 核对 4.4详细流程表为 7 步（含登记公告），输出模板缩为 5 步，是否统一？

    做法

    1. 先向用户说明自愿登记与自动保护：著作权自创作完成自动产生，登记不是产生前提，与商标须注册、专利须授权根本不同；用「权利产生时间/登记性质/保护效力/推翻可能/优势」五维表说明登记的作用
    2. 说明登记的实践价值：侵权诉讼/行政投诉中作为初步证据便于举证；高商业价值软件与核心创意作品登记可降低维权难度；许可/转让交易中提供清晰权利凭证
    3. 列登记机构：一般作品由中国版权保护中心（国家版权局委托）及地方版权局/著作权登记机构受理，地方开放情况 [待验证 — 各地不同]；软件登记由中国版权保护中心统一受理（全国唯一）；中国版权保护中心已开通网上申报，建议优先在线申请 [待验证 — 系统与流程可能已更新]
    4. 列一般作品 7 步流程及预期周期：准备材料→提交申请（网上须注册中国版权保护中心账号，或邮寄/现场）→受理并出具受理通知（通常 1-5 个工作日 [待验证]）→形式审查（通常 1-4 周 [待验证]，不审查独创性或权属实质）→补正（补正期限 [待验证]，未及时补正可能被视为撤回）→登记公告（因机构而异 [待验证]）→颁发证书（受理后总周期约 1-3 个月 [待验证 — 随机构与作品类型而变]）
    5. 列软件登记 4 步流程及周期：准备材料（含源程序前后各连续30页 [待验证]，须为实际代码）→中国版权保护中心在线系统或邮寄提交→受理与形式审查（受理后约 15-30 个工作日 [待验证]，不审查软件功能或代码正确性）→颁发证书（总周期约 1 个月左右 [待验证 — 网上申请通常较快]），可在线查询状态
    6. 说明登记证书效力四点：初步证据效力（持证方在纠纷中推定为著作权人，对方须反证）、可被推翻（如证明创作时间更早、登记内容有误）、不等于确权（仅形式审查）、不等于侵权结论（仍须分析思想表达二分等）；用「登记证书 vs 实质确权（诉讼判决）」对比表和「与商标强制注册的区别」澄清
    7. 列登记后维护事项：变更登记（单位更名、地址变更）、补充登记（重大修订版本或转让后权利人变更）[待验证]、撤销登记（登记错误）[待验证]、著作权转让/独家许可在版权局备案（非强制，可增强对抗效力 [待验证]）、继承登记（提供继承证明）
    8. 汇总四步结论为《著作权登记综合方案》：作品类型、独创性结论、权属类型、申请主体、登记路径、材料准备状态、登记机构、预期周期约 1-3 个月 [待验证]、登记价值评估（高—建议登记/中—视情况/低）；附保护期提示，并列后续建议与里程碑（立即提交、转让/许可备案、有侵权线索及时取证、商业授权前先登记、涉及素材来源合规时转 ip-clearance 著作权清权）

    内置规则

    • 登记机构只作形式审查：不审查独创性、权属实质，也不审查软件功能或代码正确性
    • 保护期：自然人作品为作者终生及死亡后50年，截止于死亡后第50年的12月31日，合作作品以最后死亡的合作作者计；法人作品/视听作品为首次发表后50年，截止于首次发表后第50年的12月31日，创作完成后50年内未发表则不再受保护；保护期届满进入公有领域（规则稳定，条号建议复核）
    • 高商业价值作品建议在登记之外补充创作记录、时间戳、草稿等证据链，因为登记证书存在被推翻的可能
    • 境外申请人可在中国申请著作权登记，须提供相关翻译文件及公证资料 [待验证 — 具体要求须核实]
    • 已开源（公开源代码）的软件仍享有著作权，也可进行著作权登记
    • 登记申请被退回时分析退回原因（材料不齐/格式问题/其他），按补正通知修正后重新提交
    • 纠正三类误解：登记不是获得保护的必要条件；登记证书不等于最终确权，实质确权须经诉讼；著作权登记是形式审查，与专利实质审查根本不同

08交付前检查

  • 作品类型认定：基本信息已收集；独创性两要件已判断且结论明确；AI 生成内容争议已单独标注（如涉及）；法定作品类型已认定并说明边界；思想表达二分已应用；不受保护对象已排查；是否属于计算机软件已判断（决定登记路径）
  • 权属判定：权属约定已优先核查；职务作品一般/特殊已区分且计算机软件已特别注意；委托作品无约定时已确认归受托人；法人作品三要件已逐一核对；合作作品分割性已判断；权属结论含归属主体 + 依据类型 + 约定空间
  • 材料准备：登记路径已确认；申请主体证明材料已明确；权利归属证明已对应权属类型选取；作品说明五项（名称/类别/独创性/创作完成时间/是否发表）已准备；样本已按作品类型确认要求（文字全文、软件源程序前后30页等）；软件特殊材料（源程序 + 说明书 + 商业秘密处理选项）已核查；材料完整性检查表已制作
  • 登记流程：自愿登记原则与证书初步证据效力已向用户说明；登记机构已确认；流程步骤完整（提交→受理→审查→补正→登记→发证）；预期周期已标注待验证；软件与一般作品流程差异已说明；保护期已说明；登记后变更/补充/撤销路径已说明；综合方案已汇总四步结论
  • 每步均已读取实践配置并确认著作权策略，或已标注 [临时模式]；输出带配置规定的工作产物标题

09何时暂停或升级

  • 独创性存疑：在意见中标注并建议咨询律师，谨慎登记
  • 作品描述不清、无法判断作品类型：停止判断并询问具体内容、表达载体与创作方式，不得凭猜测认定
  • 单位与员工对是否职务作品有争议：只梳理关键事实作初步评估，提示权属争议须经仲裁/诉讼解决
  • 不可分割合作作品一方不同意或不配合：记录情况、评估替代路径，不能直接申请登记
  • 未完成作品类型与权属判定即要求出材料清单：要求先完成前两步，或由用户直接提供作品类型与权属信息
  • 非律师角色：输出标为「研究笔记 — 非法律建议，供律师/代理人审查」，涉及具有法律后果的维权步骤前按配置的升级矩阵暂停并建议升级
  • 涉及第三方素材来源合规或侵权评估：转 ip-clearance 著作权清权/使用权评估
  • 输出面向对方当事人或法院：另备脱敏版本，避免特权失效
