01概要

通过四步结构化访谈（约 10-15 分钟）采集权利人画像与 IP 组合、维权与申请立场、风险校准与升级矩阵、文书风格与检索数据库，把答案填进 ip-legal/CLAUDE.md 实践配置文件的 [PLACEHOLDER] 字段。该文件是唯一真相来源：商标查询、专利分析、著作权登记、清权四个流程执行实质性工作前都先读它，据此决定近似判断阈值、FTO 严格度、清权结论门槛、风险标注强度和升级路由。访谈开始前先检查配置文件状态（全新 / 部分填充 / 已完整），只问未填充的字段；四步各可单独触发，只更新对应章节，律师也可直接编辑该文件而无需重跑。用户口述的条号、期限、金额一律先做合理性检查并带「待验证」标记写入；跳过或不确定的字段保留占位符，不凭猜测填充。

02适用与边界

适用场景

  • 首次使用 ip-legal，需要初始化 ip-legal/CLAUDE.md 实践配置（全部字段为 [PLACEHOLDER]），约 10-15 分钟
  • 配置已部分填充，需要补齐剩余字段（流程自动只问未填充项，跳过已有内容）
  • IP 组合有变化（新增商标/专利/软著等）→ 单独触发 /ip-legal:identity-team
  • 需要调整维权立场、近似容忍度、FTO 严格度或清权结论门槛 → 单独触发 /ip-legal:enforcement-stance
  • 需要更新风险等级定义、角色权限或自动升级规则 → 单独触发 /ip-legal:risk-escalation
  • 需要调整报告格式、维权函措辞、工作产物存放位置、检索数据库或行业识别 → 单独触发 /ip-legal:style-search-databases
  • 原文建议每年重新确认配置中的法律事实是否仍然有效

不做什么

  • 不对任何具体商标、专利或作品做检索、近似判断或侵权分析；本流程只采集配置，实质分析由商标查询、专利分析、著作权登记、清权四个流程完成（它们执行前读取本配置）
  • 不另存独立配置文件（YAML 等）：旧版「生成独立格式配置文件」的表述已更正，访谈结果只填充 ip-legal/CLAUDE.md 对应章节
  • 配置已完整时不重跑全部访谈，只提示档案已配置完整，请指明要更新的步骤（如「更新 identity-team 部分」）
  • 不是修改配置的唯一途径：律师/IP 经理可直接编辑 ip-legal/CLAUDE.md，编辑后即时生效，无需重跑访谈
  • 不把用户口述的条号、期限、赔偿数额、惩罚性赔偿规则作为确定法律事实写入，只以「待验证」标记记录

03输入与产出

需要律师提供

  • ip-legal/CLAUDE.md 实践配置模板必需
    访谈填充目标；开始前读取以判断全新 / 部分填充 / 已完整三种状态
  • ip-legal/skills/_shared/practice-profile-schema.md 字段映射契约必需
    四个步骤分别按其第 2.1–2.11 节把访谈答案映射到配置文件章节
  • 律师/IP 经理的访谈回答必需
    可随时说「跳过」「不确定」「使用默认」；跳过项保留 [PLACEHOLDER] 或填「未提供」
  • 权利证书、注册证、检索报告等种子文档可选
    配置模板设有「审查过的种子文档」表，但四步访谈的问题清单均未采集此项

产出

  • 填充后的 ip-legal/CLAUDE.md给律师内部
    Markdown 散文模板，章节依次为：我们是谁（含 IP 组合概况）/ 谁在使用 / 可用集成 / 维权与申请立场（商标策略、专利策略、著作权策略、清权严格度）/ 风险校准 / 升级矩阵 / 文书风格 / 输出 / 共享护栏 / 事项工作区 / 审查过的种子文档；访谈答案替换 [PLACEHOLDER]，已填内容保留；纳入 git 版本控制，支持历史查看与回滚
  • 写入摘要给律师内部
    列出本次写入的字段；跳过项注明「未提供」；确认默认值的表格注明「已确认使用预设值」；无明确分工时注明「无明确分工，暂以通用分工为准」

04开始前

前置条件

  • 读取 ip-legal/CLAUDE.md 并判断状态：全部字段为 [PLACEHOLDER] → 从头访谈；部分填充 → 只访谈未填充字段；全部已填 → 提示已完整，询问要更新哪一步
  • 读取 ip-legal/skills/_shared/practice-profile-schema.md 的字段映射表，确定每个答案写到哪个章节
  • 完整访谈按步骤 1→4 顺序进行：步骤 1（身份与团队）是后续基础，建议首先完成；步骤 2（维权立场）最关键，驱动所有流程的风险判断阈值；步骤 3、4 为精细化配置，可按需完成
  • 单独触发某一步时，只更新该步对应章节，不影响其他章节

硬性规则

配置档案检查
访谈开始时检查 ip-legal/CLAUDE.md：全新初始化（全部 [PLACEHOLDER]）提示「将从头开始访谈，约 10-15 分钟」；部分填充只访谈未填充字段、跳过已有内容；已完整配置则提示指明要更新的部分
唯一真相来源
访谈结果填充 ip-legal/CLAUDE.md 对应章节（Markdown 散文），不另存独立 YAML/配置文件；该文件纳入 git 版本控制，支持历史查看与回滚
时效性提示
访谈涉及的商标法/专利法/著作权法/反不正当竞争法条号基于 2019/2020/2021 修正版本，条号重排风险高，所有条号均标「待验证」或「建议复核」；建议每年重新确认配置中的法律事实
非律师角色提示
若角色为非律师（IP 经理/内部法务/无律师），提示所有 ip-legal 输出将标注「研究笔记 — 非法律建议，供律师/代理人审查」，在侵权结论、发函维权、提起异议/无效宣告、诉讼等步骤前暂停并建议升级给律师/代理人确认
不凭猜测填充
用户跳过或不确定的字段保留 [PLACEHOLDER] 或填「未提供」，不得凭猜测填充；已有字段只补未填项，不覆盖已有配置
验证用户陈述的法律事实
用户提供条款号、期限、赔偿数额时先做合理性检查并复述确认（「你提到 [X]；我的理解是 [Y]……请确认是否要按此填入配置？[前提 flagged — 需验证]」）；口述条号须标 [待验证 — IP 法修正后条号重排，须核实现行版本]，不直接写为确定结论

05执行步骤

共 4 步，按执行顺序。每步旁边（窄屏在步骤说明之后）是请律师核对的内置假设，可逐条复制。页面里的英文标记见首页「标记与术语」。

  1. 身份与团队：权利人画像、IP 组合、角色、检索数据库

    /ip-legal:identity-team可单独运行

    采集组织信息、实体类型、行业、IP 组合现状、核心品牌/技术与痛点、IP 团队、执业角色和可用检索数据库，填入「我们是谁」「谁在使用」「可用集成」三个章节，为其余所有流程提供画像基础和升级路由依据

    请律师核对

    • 核对 1.1实体类型选项与 CLAUDE.md 模板不一致：访谈列了教育机构、金融机构，模板列了电商平台却无教育/金融——写入时以哪套为准？
    • 核对 1.2著作权保护期「自然人终生 + 50 年，法人/视听首次发表后 50 年」在合理性检查表中未带任何「待验证/建议复核」标记，而专利期限带 [建议复核]——口径是否要统一？
    • 核对 1.3外观设计 15 年标为「2021 修正后」，而本插件其他文件称专利法为「2020 年修正 / 2021 年施行」——表述是否统一？
    • 核对 1.4非律师角色把「内部法务（有律师可咨询）」也归入非律师，所有输出均降为研究笔记——是否符合贵司内部法务的实际权限？
    • 核对 1.5允许以「某消费品企业」代替客户名称写入配置——是否满足贵所保密要求？

    做法

    1. 先读 ip-legal/CLAUDE.md，逐个查看 [PLACEHOLDER] 字段确认哪些已填充（已有信息不重复问），并对照 practice-profile-schema.md 第 2.1、2.10、2.11 节的字段映射表
    2. 第一节组织基本信息：问组织/律所名称（或所代表客户名称）；实体类型从 9 个选项中选（可多选）；所属行业用几个词描述（如「智能硬件/消费电子」「生物制药」「服装零售」）
    3. 根据行业答案做行业识别：医药/生物技术 → 标注 [行业 flagged — 需核实主管部门规定（药品专利链接制度 [待验证]）]；互联网/软件 → 标注软件著作权与域名商标特殊关注
    4. 第二节 IP 组合，依次问商标（已注册数量与主要尼斯类别、待注册/在审数量、是否有驰名商标认定、覆盖地域：中国大陆 / 含港澳台 / 含海外）→ 专利（发明/实用新型/外观设计各自数量、核心专利领域）→ 著作权（已登记作品数、软件著作权登记数、主要作品类型：软件/文字/美术/视听/其他）→ 企业字号（企业名去掉地区和行业词后的核心词）与主要域名
    5. 第三节：问最重要的核心品牌与核心技术（用于清权和分析时优先保护核心资产），以及主要 IP 痛点（7 项多选）
    6. 第四节：问 IP 团队规模（如「IP 经理 2 人 + 外聘律所」「仅外聘律所」）和 IP 负责人/联系人
    7. 第五节：问执业角色（7 个选项）；若选非律师角色（选项 2/3/6/7）立即提示所有输出将作为研究笔记供律师审查、在侵权结论/维权函/异议/诉讼前暂停升级；再问合作的主要律师/专利代理师或外聘律所
    8. 第六节：按 10 行工具表逐项确认检索数据库与工具的可用状态（可用 / 不可用 / 需配置，或已连接：名称 / 未连接）
    9. 对用户口述的数字做法律事实合理性检查：商标类别号对照尼斯分类 1–45 类；商标有效期 10 年；专利期限锚点；著作权保护期；不常见法律事实标 [待验证 — IP 法修正后条号重排，须核实现行版本]
    10. 按写入映射表逐字段替换 [PLACEHOLDER]（实体类型、执业角色替换为所选选项文字；数据库替换为「可用/不可用/已连接：名称」），保留已填内容，在写入摘要中注明「未提供」项

    内置规则

    • 实体类型 9 选项：科技企业（互联网/软件/AI）、制造企业、文创/内容企业、消费品/快消企业、医药/生物技术企业、教育机构、金融机构、律所 IP 部门（代理客户）、其他
    • 执业角色 7 选项：知识产权律师（有律师执照）、企业 IP 经理、内部法务（有律师可咨询）、商标代理人、专利代理师、非律师但有律师可咨询、非律师且无律师可咨询；其中选项 2/3/6/7 视为非律师角色
    • IP 痛点 7 选项：频繁遭到商标仿冒/仿冒品、海外维权难题、专利布局薄弱担心竞争对手专利阻碍、拟进入新市场需要清权、侵权诉讼（处理中或预防）、著作权素材使用合规、其他
    • 检索数据库表 10 行：中国商标网（sbj.cnipa.gov.cn）、国家知识产权局专利检索系统（pss-system.cponline.cnipa.gov.cn）、商业专利数据库（智慧芽/合享/药智等）、商标商业数据库（商标 SaaS 管理系统）、中国版权保护中心（ccopyright.com.cn）、国家企业信用信息公示系统（gsxt.gov.cn）、域名 WHOIS 查询、中国裁判文书网（wenshu.court.gov.cn）、内部 IP 管理系统、文档存储位置
    • 商标类别号须在尼斯分类 1–45 类之内，数字异常（如「第 50 类」）须提示核实
    • 商标注册有效期 10 年，期满需续展（规则稳定，具体条号建议复核）
    • 专利期限对照中度把握锚点：发明 20 年 / 实用新型 10 年 / 外观设计 15 年（2021 修正后）[建议复核]
    • 著作权保护期对照规则：自然人作者终生 + 50 年，法人/视听作品首次发表后 50 年
    • 律所代理客户不希望泄露客户名称时，允许以客户类型描述代替（如「某消费品企业」）；不知道确切数量时填「不确定，约 [范围]」或保留占位符

    法律依据

    • 《专利法》— 专利权期限对照锚点：发明 20 年 / 实用新型 10 年 / 外观设计 15 年（2021 修正后）[建议复核]
    • 《商标法》— 商标注册有效期 10 年，期满需续展（规则稳定，具体条号建议复核）
    • 《著作权法》— 保护期：自然人作者终生 + 50 年，法人/视听作品首次发表后 50 年
    • 尼斯分类（1–45 类）— 商标类别号合理性核查
    • 药品专利链接制度 [待验证] — 医药/生物技术行业标注 [行业 flagged — 需核实主管部门规定]

    产出

    ip-legal/CLAUDE.md 的「我们是谁」（基本信息、IP 组合概况、核心品牌/技术、IP 痛点、IP 团队）、「谁在使用」（角色、律师/代理人联系人）、「可用集成」（各数据库状态）三个章节被填充；附写入摘要注明未提供项

  2. 维权与申请立场：整体立场、商标/专利/著作权策略、清权严格度

    /ip-legal:enforcement-stance可单独运行

    采集整体维权立场和各类 IP 的策略偏好及清权严格度，填入「维权与申请立场」章节；这是最关键的配置，直接驱动各流程的风险标记强度、近似判断阈值、FTO 清权严格度和清权结论门槛

    请律师核对

    • 核对 2.1进取 / 平衡 / 防御与 [黄]/[橙]/[红] 重点标注的对应关系是否符合贵所实践？「防御型主要关注 [红]」是否会漏掉需要处理的 [橙] 风险？
    • 核对 2.2用户犹豫时默认落在「平衡型」——贵所是否更希望默认偏严格？
    • 核对 2.3无效宣告倾向、规避设计倾向、清权范围的访谈选项比 CLAUDE.md 模板多出一档（基本不主动 / 视情况 / 按项目决定），写入时模板需同步扩充吗？
    • 核对 2.4「登记证书具有初步证据效力，非确权手段」的表述是否认可？
    • 核对 2.5矛盾回答检查只定义了一种组合；其他矛盾（如近似容忍度「严格」但异议倾向「不主动」）SKILL.md 未规定，是否补充？

    做法

    1. 先读 ip-legal/CLAUDE.md「维权与申请立场」章节确认已填字段，并对照 practice-profile-schema.md 第 2.2–2.6 节映射
    2. 第一节整体维权立场三选一（进取维权型 / 平衡型 / 防御型），同时告知立场对后续流程的影响：进取 → 对任何 [黄] 中等以上风险重点标注、清权结论偏严格；平衡 → 重点标注 [橙] 高 / [红] 关键，[黄] 中等备注；防御 → 主要关注 [红] 关键，其余风险较少干预
    3. 第二节商标策略 5 问：注册防御范围（全类 45 类 / 核心类别 / 按需申请）→ 近似容忍度（严格 / 平衡 / 宽松）→ 商标异议倾向（主动 / 被动 / 不主动）→ 无效宣告倾向（主动清理 / 仅被侵权时反击 / 基本不主动）→ 驰名商标认定意向（已申请或认定 / 有意向 / 暂不考虑）与海外布局（已布局地区 / 规划中 / 无海外需求）

    • 立场 → 风险标注映射：进取 → [黄] 及以上重点标注、清权偏严格；平衡 → [橙]/[红] 重点标注、[黄] 备注；防御 → 主要关注 [红]
    • 近似容忍度三档：严格 = 任何读音/字形/含义接近均不容忍并主动追究；平衡 = 仅高度近似不容忍，一般近似视情况；宽松 = 仅相同或极高度近似才采取行动
    • FTO 清权严格度三档：严格 = 任何新产品/新技术上市前均做 FTO，任何专利风险均评估；平衡 = 仅高风险技术领域或重要产品；宽松 = 仅在有具体专利侵权诉讼风险时
    • 清权风险四级示例：[红] 与核心商标相同 / 专利权利要求完全覆盖 / 著作权完全复制；[橙] 商标高度近似 / 专利等同侵权可能性大；[黄] 商标有一定近似但混淆存疑 / 专利边缘风险；[绿] 无相同或高度近似商标 / 无核心专利障碍
    • 清权结论三档门槛示例：可注册可使用 = 无相同商标且无高度近似商标 / 无核心专利障碍；有障碍需处理 = 存在近似商标需提异议或规避；建议放弃规避 = 存在相同商标且权利人活跃 / 存在核心专利无法规避
    • 用户不确定立场时的默认值为「平衡型」
    • 矛盾组合示例：整体「进取维权型」+ 清权门槛「宽松」→ 写入前提示确认
