# Surface: skill 页 (`docs/<plugin>/<skill>/`)

Visitor mode: Read - Targets: web 1280×800, 390×844, print - Direction: 实务指引 + 批注栏 - Updated: 2026-11-03

## Thesis

读完这一页，律师不开 SKILL.md 就能说出这个 skill 做什么、分几步、每步依据什么规则，并且知道哪几条是可以提意见的内置假设。

## Own-world

按条编号的实务操作指引，右侧留批注栏。

One memorable idea: 「批注栏」——每个步骤旁边浮着朱砂色的「请律师核对」条目，每条可一键复制成「领域／skill · 第 n 步 · 核对 n.k」加原文的微信引用。

## Story

类型与名称 → 一句话 + 页头批注栏（核对与审阅条数，链到两处）→ 概要（能做什么、靠什么做到）→ 适用 / 不适用、需要提供 / 产出（列表）→ 开始前（前置条件、护栏）→ 执行步骤（主体：每步先写目标，紧接着是本步批注，再是做法、内置规则、法律依据、产出）→ 法律依据、共用规则、质量检查、暂停与升级 → 请律师重点核对（审阅清单，相关批注作提示；复制）→ 示例提示词 → 维护信息（折叠：标识、命令、源文件）。

## First viewport

- 1280：面包屑、左侧目录（含步骤名）、名称、一句话、右侧页头批注栏、概要第一段。
- 390：名称、一句话、页头批注栏；目录收起为「本页目录 · N 节」。
- Above the fold（`lint.mjs --above-fold` 实测）: 1280×720 `h1, .lead .tagline, #summary h2`；390×844 `h1, .lead .tagline`。

## Form + seed

宋体标题 / 黑体正文 / 正文只用律师语言（标识只在页末维护信息里，等宽）；克制配色（纸、墨、朱砂）；步骤为编号段落而非卡片；「需要提供 / 产出」用列表；宽屏批注栏在右，窄屏批注紧跟步骤目标；行长 ≤ 38em；无图标、无 emoji、无阴影。
