# Surface: skill 页 (`docs/<plugin>/<skill>/`)

Visitor mode: Read - Targets: web 1280×800, 390×844, print - Direction: 实务指引 + 批注栏 - Updated: 2026-11-01

## Thesis

读完这一页，律师不开 SKILL.md 就能说出这个 skill 做什么、分几步、每步依据什么规则，并且知道哪几条是可以提意见的内置假设。

## Own-world

按条编号的实务操作指引，右侧留批注栏。

One memorable idea: 「批注栏」——每个步骤旁边浮着朱砂色的「请律师核对」条目，每条可一键复制成「skill · 步骤 · 条目 · 原文」的微信引用。

## Story

名称与命令 → 一句话 + 页头批注栏（核对与审阅条数，链到两处）→ 概要（能做什么、靠什么做到）→ 适用 / 不适用、需要提供 / 产出（列表）→ 开始前（前置条件、护栏）→ 执行步骤（主体：每步先写目标，紧接着是本步批注，再是做法、内置规则、法律依据、产出）→ 法律依据、共享规则、质量检查、暂停与升级 → 请律师重点核对（审阅清单，每条注明对应的步骤批注；复制）→ 示例提示词 → 源文件。

## Form + seed

宋体标题 / 黑体正文 / 等宽标识（路径、命令、英文标识自动等宽，只在 / _ - : . 后折行）；克制配色（纸、墨、朱砂）；步骤为编号段落而非卡片；「需要提供 / 产出」用列表；宽屏批注栏在右，窄屏批注紧跟步骤目标；行长 ≤ 38em；无图标、无 emoji、无阴影。
